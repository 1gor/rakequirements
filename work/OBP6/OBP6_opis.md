## 4. Пользователи и роли

|  |  |
| --- | --- |
|  |  |
| Роль | Описание |
| Специалист архива | Инициирует процесс в момент передачи документов в архив, определяет место хранения дела в архиве и вносит информацию о месте хранения в систему, вносит дело в реестр передачи соответствующего года, обеспечивает сохранность документов до ликвидации суда, обеспечивает сохранность документов до даты уничтожения документов, изменяет срок хранения, обеспечивает сохранность в соответствии с сроком хранения |
| Экспертная комиссия | Экспертная комиссия проводит заседания в соответствии с планом работы, по решению экспертной комиссии арбитражного суда сроки хранения отдельных дел могут быть продлены исходя из их научной и практической ценности по согласованию с Центральной Экспертной комиссией Высшего Арбитражного Суда Российской Федерации и экспертно-проверочной комиссией уполномоченного органа исполнительной власти субъекта Российской Федерации в области архивного дела |
| Система | Система анализирует судебные дела при поступлении в архив, формирует рекомендации о передаче в Госархив, регистрирует дела в реестре, отслеживает сохранность документов, автоматически отбирает документы для экспертной оценки, создает задачи для членов комиссии, генерирует шаблоны экспертных оценок, управляет сроками хранения документов и поддерживает условия их сохранности до момента уничтожения или передачи в государственное хранилище. |
