## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Помощник судьи | Формирование списка участников процесса, контроль извещения участников, проверка поступления ходатайств, фиксация явки/неявки участников, контроль надлежащего уведомления, отражение сведений о причинах неявки, доклад судье о составе присутствующих. |
| Секретарь судебного заседания | Формирование списка участников процесса, контроль извещения участников, проверка поступления ходатайств, фиксация явки/неявки участников, контроль надлежащего уведомления, отражение сведений о причинах неявки, доклад судье о составе присутствующих. |
| Судья суда | Получение информации о явке участников, принятие решения о проведении судебного заседания с учетом состава присутствующих или об отложении судебного заседания при невозможности его проведения при данной явке. |
