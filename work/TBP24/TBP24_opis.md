## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья арбитражного суда | Вынесение частного определения, принятие решений по наличию признаков преступления, рассмотрение информации об исполнении, принятие решения о наложении судебного штрафа, приобщение материалов |
| Помощник судьи арбитражного суда | Консолидация поступивших материалов и сроков, информирование судьи, приобщение материалов к делу |
| Канцелярия арбитражного суда | Направление судебных актов адресатам, прием и регистрация входящих, передача материалов судье |
| Орган/организация/должностное лицо, в отношении которого вынесено частное определение; вышестоящие организации | Получение частного определения, принятие решения об исполнении, исполнение, уведомление суда, принятие решения об обжаловании |
| Органы дознания/предварительного следствия | Получение направленного частного определения (при наличии признаков преступления) |
| Лицо, в отношении которого было вынесено частное определение | Получение частного определения, принятие решения об обжаловании |
| Система арбитражного суда | Уведомление пользователей, подготовка документов, контроль сроков |
