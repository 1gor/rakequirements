| Руководитель отдела МТО | Принимает решения по закупкам и согласовывает контракты с поставщиками, осуществляет проверки подготовленной документации |
| Комиссия по осуществлению закупок | Проводит торги/аукцион, выбирает победителя, формирует протокол, направляет уведомление о подписании председателю |
| Сотрудник отдела МТО | Ищет поставщиков, определяет способ закупки, исправляет замечания, публикует данные в ЕИС. |
| Система | Меняет ответственных в сущностях, подготавливает документацию, сохраняет данные, направляет документы на согласование ответственным лицам, публикует итоги торгов/аукциона |
