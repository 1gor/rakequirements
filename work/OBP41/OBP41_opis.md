## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела бухгалтерского учета и отчетности | - Инициирует процесс при необходимости составления бюджетной отчетности (старт процесса) - Составляет пояснительную записку - Формирует бюджетную отчетность - Получает замечания председателя и вносит корректировки - Ожидает ответа УСД - Получает ответ УСД по отчетности - При необходимости вносит корректировки по замечаниям УСД - Формирует новую скорректированную отчетность и направляет ее на согласование - Завершает процесс, когда отчетность принята УСД |
| Система | - Создаёт сущность «бюджет» - Автоматически составляет отчет об исполнении бюджета - Автоматически составляет баланс исполнения бюджета - Автоматически составляет отчет о финансовых результатах деятельности - Автоматически составляет отчет о движении денежных средств - Передает отчетность на согласование председателю суда - Передает замечания к отчетности сотруднику бухгалтерии - Передает исправленную отчетность после корректировок - Сохраняет подписанную отчетность в сущности процесса - Направляет бюджетную отчетность в УСД - Передает скорректированную отчетность в УСД |
| Председатель суда / заместитель председателя (в отсутствие председателя) | - Ознакамливается с бюджетной отчетностью - Принимает решение: требуется корректировка или нет - Подписывает отчетность УКЭП - Подписывает скорректированную отчетность после замечаний УСД - Участвует в шлюзах (принятие решения) |
| УСД (Управление Судебного Департамента) | - Принимает бюджетную отчетность, направленную системой - Формирует ответ: принята отчетность или требуется корректировка - Передает замечания (если есть) |
