## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела МТО | Принимает заявку на ТМЦ, проверяет наличие на складе, изучает локальные акты о нормах выдачи, проверяет соответствие заявки установленным нормативам, осуществляет выдачу ТМЦ со склада. |
| Руководитель МТО | Принимает решение о выдаче ТМЦ сверх установленной нормы, согласовывает или отклоняет такую заявку, ставит визу о разрешении выдачи. |
| Сотрудник суда (автор заявки) | Подает заявку на получение ТМЦ, получает запрошенные материальные ценности, подтверждает получение путем подписи в журнале выдачи ТМЦ. |
| Сотрудник бухгалтерии | Осуществляет бухгалтерский учет движения ТМЦ: фиксирует перемещение основных средств или списание расходных материалов в системе складского учета после факта выдачи |
