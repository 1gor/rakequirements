## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Канцелярия суда | Регистрация дел и документов, проверка тождественности, заполнение штампов, поиск ЛУВД в базе САС, определение типов документов, заполнение обязательных полей, работа с классификаторами |
| Система | Заполняет обязательные поля для регистрации, определяет вид спора, указывает вид спора и специализацию дела, формирует карточку дела, формирует протокол проверки, ставит задачи на валидацию, присваивает номер дела, формирует штамп, отменяет регистрацию, уведомляет пользователя об отмене регистрации, регистрирует в существующее дело в качестве дополнения, загружает информацию из карточки дела нижестоящей инстанции, определяет тип документа по классификатору, ищет ЛУВД в базе САС, ставит задачи на сотрудника, создает карточку документа, присваивает номер обособленного спора, регистрирует дело, создание электронного штампа |
