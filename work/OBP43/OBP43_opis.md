## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела бухгалтерского учета и отчетности | - Инициирует процесс при необходимости обеспечить своевременность налоговых платежей - Создает сущность «запрос» в системе - Запрашивает необходимые данные у отделов - Получает сводные сведения от отдела кадров и отдела МТО - Получает данные, необходимые для налогового расчета - Проверяет выводы системы (ТБП139) - При наличии замечаний председателя — выполняет перерасчет - После формирования поручений — направляет платежные документы в казначейство - Ожидает подтверждение («уведомление о кассовом исполнении») - Отражает удержание НДФЛ, начисление страховых взносов и уплату налогов - Сверяет обязательства на конец месяца - Формирует налоговую отчетность (6-НДФЛ, 2-НДФЛ, СЗВ-М, СЗВ-СТАЖ, РСВ) - Корректирует отчетность по замечаниям председателя (если есть) - Подаёт отчетность в ФНС/СФР - Ожидает сообщения от ФНС/СФР - Устраняет замечания ФНС/СФР (если есть) и повторяет этапы процесса - Осуществляет внутренний контроль и сверку платежей в течение отчетного периода - Завершает процесс при успешном прохождении всех проверок |
| Сотрудник отдела кадров | - Ознакамливается с запросом бухгалтерии - Готовит сведения о приеме и увольнении сотрудников - Предоставляет данные о больничных, отпусках, командировках - Формирует сведения о льготах и налоговых вычетах - Объединяет данные в единый документ и передает в систему |
| Сотрудник отдела МТО | - Ознакамливается с запросом бухгалтерии - Готовит сведения об имуществе - Готовит акты списания - Формирует единый документ и передает его в систему |
| Система | - Передает запросы в отделы - Автоматически передает сводные отчеты в бухгалтерию - Выполняет автоматический налоговый расчет - Передает налоговый расчет на согласование председателю - Передает замечания председателя сотруднику бухгалтерии - После согласования — формирует платежные поручения - Проверяет корректность реквизитов - Указывает сроки перечисления - Принимает участие в ТБП139 (автоматические проверки вывода) - Отражает удержания НДФЛ - Передает налоговую отчетность на согласование председателю - Передает замечания по отчетности - Поддерживает цикл переработки отчетности до ее утверждения - Фиксирует процессы в системе |
| Председатель суда / заместитель председателя суда | - Ознакамливается с налоговым расчетом - Принимает решение о наличии замечаний (эксклюзивный шлюз) - Утверждает налоговый расчет при отсутствии замечаний - Подписывает скорректированный налоговый расчет (если были замечания) - Ознакамливается с налоговой отчетностью - Принимает решение о наличии замечаний - Утверждает налоговую отчетность или отправляет на корректировку - Участвует в закрывающих шлюзах |
