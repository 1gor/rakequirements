## 2. Схема процесса

BPMN-файл: "TBP92\_vernut\_iz\_arhiva\_bpmn\_tobe.bpmn"

Схема отражает полный цикл возврата дела из архива суда, включая:

* Проверку факта уничтожения дела
* Формирование служебных записок и заявок
* Получение резолюций от руководства
* Поиск и выемку дела из архива
* Передачу дела судье

## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья/Председатель судебного состава/Председатель суда | Дает поручение запросить дело из архива, получает служебную записку на возврат архивного дела, ставит резолюцию, передает служебную записку с резолюцией |
| Сотрудник суда, запрашивающий дело из архива | Проверяет факт уничтожения дела, указывает необходимые тома дела, формирует и подписывает документы, передает документы, получает служебную записку с резолюцией, передает служебную записку в архив суда, получает копию акта об уничтожении, знакомится с документами |
| Сотрудник отдела архивации | Получает служебную записку, проверяет резолюцию, проводит поиск архивного дела, проводит выемку дела из архива, сверяет наименование на обложке с описью дела, передает дело/документ судье, делает копию акта об уничтожении дела, передает копию акта |
| Система | Уведомление пользователей, изменение статуса дела, управление задачами, поиск архивных дел, формирование актов и отчетов |
