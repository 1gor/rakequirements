## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела обобщения судебной практики и анализа судебной статистики | * Ознакомление с изменениями в законодательстве; * Информирование работников об изменения в законодательстве; * Создание/изменение локальных актов. |
| Система | Выполняет анализ изменений используя интеграции, создает или изменяет локальные НПА в соответствии с изменениями законодательства, вносит изменения в систему, информирует подписанных на данный объект пользователей об изменении. |
