## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Руководитель отдела МТО | 1. Определяет объем работ на оказание услуг по уборке помещений 2. Проверяет соблюдение санитарных норм 3. Подготавливает техническое задание 4. Контролирует исполнение если нормы соблюдены — завершает процесс с отметкой об исполнении, если нарушения обнаружены — фиксирует нарушение. |
| Система | Получает уведомление о наступлении даты заключения контракта на уборку, создает объект "контроль санитарных норм", формирует шаблон технического задания, уведомляет Руководителя отдела МТО, инициирует переход в процесс участия в госзакупках, инициирует переход в процесс контроля исполнения госконтракта |
