## 2. Схема процесса

BPMN-файл: "TBP137\_kas\_priostanovlenie\_SA\_bpmn\_tobe.bpmn"

Схема отражает полный цикл рассмотрения заявления о приостановлении исполнения судебного акта, включая:

* Анализ правовых оснований для приостановления
* Оценку возможности поворота исполнения
* Принятие решения о приостановлении или отказе
* Уведомление участников процесса о принятом решении

## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья суда первой инстанции | Оценка доказательств, определение применимых НПА, установление содержания норм права, принятие решений о приостановлении исполнения, составление судебных актов, приобщение документов к делу |
| Помощник судьи суда первой инстанции | Направление документов участникам процесса, техническое обеспечение процесса |
| ЛУВД (лица, участвующие в деле) | Получение и ознакомление с определениями, принятие решений об обжаловании, ожидание приостановления исполнения |
| Судебный пристав-исполнитель | Получение и ознакомление с определениями, приостановление исполнительного производства в соответствии с определением суда |
| Система | Редактирование документов, уведомление пользователей |
