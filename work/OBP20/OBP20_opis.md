## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела, ответственного за выдачу литературы | Получает приобретенные судом издания, организует передачу полученной литературы по составам/коллегиям, формирует акт приема-передачи |
| Система | Уведомление инициатора закупки о получении литературы |
| Председатель судебных составов и судебных коллегий | Получает закупленную литературу, организует ее передачу внутри состава/коллегии, подписывает акт приема-передачи |
| Сотрудник суда | Получает заказанную литературу на руки, подписывает акт приема-передачи |

## 5. Реестр справочников
