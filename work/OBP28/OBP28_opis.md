## 4. Пользователи и роли

|  |  |
| --- | --- |
|  |  |
| Роль | Описание |
| Председатель суда | Утверждение комиссии, разработка плана по устранению нарушений |
| Руководитель МТО | Проработка подготовительных работ на устранение нарушений, выполнение плана, фиксация результатов |
| Система | Возникает необходимость проверки по охране труда и техники безопасности, руководитель МТО создает сущность проверки для ведения процесса, определяет участников проверки, система проверяет является ли проверка комиссионной (если да — председатель суда утверждает состав комиссии в системе по процессу согласования, если нет — переход к следующему шагу), система объединяет потоки после определения комиссионности, руководитель МТО производит проверку по охране труда и техники безопасности, система проверяет установило ли соблюдение требований охраны труда и техники безопасности (если да — процесс завершается с результатом «Требования охраны труда и техники безопасности соблюдены», если нет — руководитель МТО устанавливает факты нарушения и сообщает о нарушении председателю), председатель суда разрабатывает в системе локальный акт по устранению нарушений, руководитель МТО исполняет поручение, устанавливает устранение нарушений и фиксирует результат в системе, процесс завершается с результатом «Нарушения устранены. |
