## 4. Пользователи и роли

Процесс формирования учетно-статистических карточек по делам полностью автоматизирован. Пользователь не участвует в процессе.

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Система | Сохраняет атрибуты первичного документа, создает связи между первичным документом, делом и документами рассмотрения в базе данных ИС суда, формирует выбранную форму отчета. |

## 5. Реестр справочников

Справочники указаны в Приложении к Заключению об обследовании текущего состояния субъектов автоматизации (3-я очередь) - Справочники (классификаторы) ПК САД

## 6. Непроцессуальные документы

В процессе отсутствует создание документов.

## 7. Межведомственное взаимодействие

Межведомственное взаимодействие в процессе не используется

## 8. Информация о сроках

Сроки действий в процессе не регламентированы
