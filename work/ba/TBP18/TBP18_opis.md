# [To be] ТБП18. Истребовать доказательства

| **Наименование процесса** | ТБП18: Истребовать доказательства |
| --- | --- |
| **Суть процесса** | Процесс описывает истребование доказательств от лиц участвующих в деле. Истребование доказательств может быть инициировано как сторонами по ходатайству, так и по инициативе суда. После рассмотрения ходатайства суд выносит определение об истребовании доказательств, которые направляются сторонам. В случае, если предоставление доказательств невозможно, стороны обязаны подать извещение о невозможности в суд. После получения извещения суд в свою очередь обязан запросить доказательств у них органов/лиц, у которых могут находиться доказательства (документы и их копии, иные объекты и вещи). В случае невозможности затребовать доказательства- суд накладывает судебный штраф на стороны участвующие в деле. В случае если стороны могут предоставить доказательства, согласно положениям АПК допустимо, чтобы доказательства были выданы сторонами на руки третьей стороне, которая после направляет доказательства в суд. Или стороны участвующие в деле направляют доказательства непосредственно и самостоятельно. После приобщения доказательств к материалам дела, копии направляются сторонам. |
| **Участники процесса** | Судья, ЛУВД, Лицо/должностное лицо/гос. орган, у которого находится доказательство |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ст. 66; глава 11 в части судебного штрафа); Постановление Пленума Верховного Суда РФ от 23.12.2021 № 46 (п. 38); Постановление Пленума ВАС РФ от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации». |

# **3. Реестр UC**

**UC001 — Контроль получения доказательств в ходе истребования**

| **№ шага процесса** | 12, 30–32, 40 |
| --- | --- |
| **Выполняемая задача** | Ознакомиться с отображаемым Системой результатом контроля представления истребованных доказательств и зафиксировать результат контроля. |
| **Цель** | Обеспечить выбор дальнейшего рассмотрения на основе сведений о представлении либо непредставлении истребованных доказательств. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе отображен и зафиксирован актуальный результат контроля представления истребованных доказательств. |
| **Рекомендуемая функциональность** | Отображение статуса представления доказательств; уведомление о поступлении либо непредставлении доказательств; фиксация результата контроля в карточке дела. |
| **Критичность** | Необходимая |
| **Триггер** | Система отображает судье сведения о результате контроля представления истребованных доказательств. |
| **Предварительные условия** | В Системе существует дело и принято определение об истребовании доказательств. |
| **Основной сценарий** | 1. Судья открывает в Системе сведения о ходе исполнения определения об истребовании доказательств.  2. Система отображает актуальный статус: доказательства представлены либо не представлены в установленный срок.  3. Судья фиксирует результат контроля представления доказательств.  4. Система сохраняет результат контроля в карточке дела и отображает его для дальнейшего процессуального действия. |
| **Расширение (альтернативный сценарий)** | Если Система отображает сведения о невозможности представить доказательства, судья знакомится с указанной причиной и использует ее при выборе дальнейшего процессуального действия. |
