## 4. Пользователи и роли

| **Роль** | **Функции** |
| --- | --- |
| Судья | Принятие решений о назначении экспертизы, выбор кандидатур, координация процесса |
| ЛУВД | Предложение кандидатур, выражение позиции по предложенным кандидатурам |
| Система | проверяет кандидатуру эксперта, специалиста или переводчика по связям с ЛУВД в других делах, анализирует наличие конфликтов интересов, проверяет отсутствие оснований для отвода, формирует рекомендацию на основании результатов проверок, создает событие с результатами и уведомляет пользователя, сохраняет результаты проверок в системе, передает данные для формирования отчета и принятия решения судьей |
