# [To be] ТБП126. Рассмотреть вопрос о присуждении при неисполнении

| **Наименование процесса** | ТБП126 — Рассмотреть вопрос о присуждении при неисполнении |
| --- | --- |
| **Суть процесса** | Процесс TO BE описывает формирование позиции суда по ходатайству арбитражного управляющего о присуждении денежной суммы на случай неисполнения судебного акта. После начала рассмотрения Система выполняет предварительный анализ ходатайства, процесс переходит к оценке доказательств, затем Система проверяет наличие реального риска неисполнения и разумность заявленной суммы и формирует протокол проверки. Судья проверяет сформированные выводы, оценивает отсутствие извлечения выгоды из незаконного или недобросовестного поведения и фиксирует итоговый вывод об обоснованности ходатайства. При необоснованности ходатайства процесс завершается позицией об отказе. При обоснованности Система формирует размер денежной суммы, порядок и срок исполнения и сведения об обязанном лице; сформированные параметры проверяются судьёй. Процесс завершается сформированной позицией об удовлетворении ходатайства с определёнными параметрами исполнения. В рамках данного ТБП судебный акт не формируется; результаты используются при последующем формировании выводов в шаблоне судебного акта. |
| **Участники процесса** | Судья, Система |
| **НПА** | «Арбитражный процессуальный кодекс Российской Федерации» от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026)  Федеральный закон от 26.10.2002 N 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026)  «Гражданский кодекс Российской Федерации (часть первая)» от 30.11.1994 N 51-ФЗ (ред. от 10.06.2026), ст. 308.3 |

# **3. Реестр UC**

**UC001 — Рассмотрение вопроса о присуждении при неисполнении**

| **№ шага процесса** | 1–15 |
| --- | --- |
| **Выполняемая задача** | Рассмотреть ходатайство арбитражного управляющего о присуждении денежной суммы при неисполнении и сформировать итоговую позицию по его обоснованности и условиям удовлетворения. |
| **Цель** | Определить наличие оснований для удовлетворения ходатайства и, при положительном выводе, проверить параметры присуждения денежной суммы. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | Судьёй сформирован итоговый вывод об обоснованности ходатайства; при положительном выводе проверены параметры присуждения денежной суммы. |
| **Рекомендуемая функциональность** | Отображение результатов предварительного анализа и протокола проверки; фиксация вывода судьи по критерию отсутствия извлечения выгоды и обоснованности ходатайства; формирование Системой параметров присуждения и обеспечение их последующей проверки судьёй. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступает к рассмотрению поступившего ходатайства арбитражного управляющего о присуждении денежной суммы на случай неисполнения судебного акта. |
| **Предварительные условия** | В Системе доступно поступившее ходатайство арбитражного управляющего; выполнены предусмотренные процессом предварительный анализ и оценка доказательств. |
| **Основной сценарий** | 1.Система формирует предварительный анализ по вопросу  2. Судья проверяет отсутствие извлечения выгоды арбитражным управляющим из незаконного или недобросовестного поведения и фиксирует свой вывод.  3. Судья выбирает итоговый вывод об обоснованности ходатайства.  4. Судья подтверждает проверенные параметры; рассмотрение завершается сформированной позицией об удовлетворении ходатайства. |
| **Расширение (альтернативный сценарий)** | 3а. Судья выбирает итоговый вывод о необоснованности ходатайства; рассмотрение по данной ветви завершается сформированной позицией об отказе в его удовлетворении. |
