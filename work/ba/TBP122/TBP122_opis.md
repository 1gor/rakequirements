# [To be] ТБП122. Рассмотреть дело о взыскании обязательных платежей

| **Наименование процесса** | ТБП122 — Рассмотреть дело о взыскании обязательных платежей |
| --- | --- |
| **Суть процесса** | Процесс описывает принятие решения по заявлению о взыскании обязательных платежей после завершения автоматических проверок и валидации выводов Системы (произошло в ТБП142). Процесс является частью ТБП 140 в котором происходит формирование итоговых выводов по вопросу рассмотрения в зависимости от вида рассматриваемого спора. Процесс начинается с проверки оснований, судья решает, подлежит ли требование удовлетворению, затем указывает данные для формирования Системой обще суммы задолженности. Процесс завершается фиксацией выводов по рассмотрению вопроса о взыскании платежей и санкций, а затем возвращается в ТБП140 для завершения рассмотрения вопроса. |
| **Участники процесса** | Судья |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026)  Налоговый кодекс Российской Федерации (часть первая) от 31.07.1998 N 146-ФЗ (ред. от 04.08.2026, с изм. и доп., вступ. в силу с 01.10.2026)  Налоговый кодекс Российской Федерации (часть вторая) от 05.08.2000 N 117-ФЗ (ред. от 04.08.2026, с изм. и доп., вступ. в силу с 01.10.2026)  Постановление Пленума Верховного Суда РФ от 23.12.2021 N 46 «О применении Арбитражного процессуального кодекса Российской Федерации при рассмотрении дел в суде первой инстанции»  Постановление Пленума Верховного Суда РФ от 18.04.2017 N 10 «О некоторых вопросах применения судами положений Гражданского процессуального кодекса Российской Федерации и Арбитражного процессуального кодекса Российской Федерации об упрощенном производстве» |

# **3. Реестр UC**

**UC001 — Рассмотрение требования о взыскании обязательных платежей и санкций**

| **№ шага процесса** | 0-14 |
| --- | --- |
| **Выполняемая задача** | Определить результат рассмотрения требования о взыскании обязательных платежей и санкций, при необходимости зафиксировать основания отказа либо объём удовлетворения и размеры взыскания. |
| **Цель** | Зафиксировать в Системе решение Судьи по вопросу взыскания обязательных платежей и санкций и данные, необходимые для дальнейшего принятия решения по делу. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксирован результат рассмотрения требования: при отказе — основания отказа; при удовлетворении — объём удовлетворения, размер основной задолженности, размер санкции и рассчитанный Системой общий размер взыскиваемой суммы. |
| **Рекомендуемая функциональность** | Карточка рассмотрения требования с полями для фиксации вывода о законности акта, решения об удовлетворении либо отказе, оснований отказа, объёма удовлетворения, размеров основной задолженности и санкции; автоматическое определение части отказа при частичном удовлетворении и расчёт общей взыскиваемой суммы. |
| **Критичность** | Необходимая |
| **Триггер** | После проверки выводов Системы Судья переходит к принятию решения по делу о взыскании обязательных платежей и санкций. |
| **Предварительные условия** | В Системе доступна карточка дела и результаты ранее выполненных проверок, необходимые Судье для рассмотрения требования. |
| **Основной сценарий** | 1. Судья открывает в Системе карточку рассматриваемого требования и изучает акт, являющийся основанием начисления обязательного платежа или санкции.  2. Судья фиксирует в Системе вывод о законности либо незаконности указанного акта.  3. Судья указывает в Системе, подлежит ли заявленное требование удовлетворению.  4. При наличии оснований для удовлетворения Судья указывает в Системе, подлежит ли требование удовлетворению полностью либо в части.  5. При частичном удовлетворении Судья указывает в Системе часть требования, подлежащую удовлетворению.  6. Судья вводит в Системе размер основной задолженности, подлежащей взысканию.  7. Судья вводит в Системе размер санкции, подлежащей взысканию; после ввода Система автоматически рассчитывает общий размер взыскиваемой суммы. |
| **Расширение (альтернативный сценарий)** | 1. Если Судья устанавливает отсутствие оснований для удовлетворения требования, он выбирает в Системе результат «отказ» и фиксирует основания отказа и применимые нормы права; ввод размеров взыскания не выполняется.  2. Если Судья устанавливает частичное удовлетворение требования, он указывает в Системе удовлетворяемую часть требования; Система автоматически определяет соответствующую часть требования, в удовлетворении которой отказано, после чего Судья вводит суммы взыскания для удовлетворённой части. |
