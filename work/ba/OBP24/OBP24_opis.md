## ****3. Реестр UC****

**UC001 — Подготовить требования и организовать закупку услуг по уборке помещений**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–3 |
| **Выполняемая задача** | Подготовка технического задания на услуги по уборке помещений с учетом санитарных требований и инициирование закупочной процедуры. |
| **Цель** | Определить объем работ по уборке помещений и обеспечить заключение госконтракта на оказание соответствующих услуг. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель отдела МТО. Участник: Система. |
| **Ожидаемый результат** | Подготовлено техническое задание с определенным объемом работ и по результатам ОБП18 заключен госконтракт на оказание услуг по уборке помещений. |
| **Рекомендованная функциональность** | Автоматическое формирование шаблона технического задания; возможность заполнения и сохранения технического задания с определенным объемом работ; поддержка вызова связанного процесса ОБП18 «Участвовать в госзакупках». |
| **Критичность** | Необходимая. |
| **Триггер** | Согласно графику госзакупок наступила дата ежегодного заключения контракта на оказание услуг по уборке помещений. |
| **Предварительные условия** | Определена плановая дата закупки услуг по уборке помещений; руководителю отдела МТО доступны сведения, необходимые для определения объема работ. |
| **Основной сценарий** | 1. По наступлении плановой даты начинается процесс подготовки ежегодной закупки услуг по уборке помещений.  2. Система автоматически формирует шаблон технического задания.  3. Руководитель отдела МТО определяет объем работ по уборке помещений с учетом применимых санитарных требований.  4. Руководитель отдела МТО фиксирует определенный объем работ в техническом задании.  5. Инициируется связанный процесс ОБП18 «Участвовать в госзакупках».  6. По результатам ОБП18 заключается госконтракт на оказание услуг по уборке помещений. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

**UC002 — Проконтролировать соблюдение санитарных норм при исполнении госконтракта**

|  |  |
| --- | --- |
| **№ шага процесса** | 4–8 |
| **Выполняемая задача** | Контроль соблюдения санитарных норм при исполнении госконтракта и определение результата исполнения работ. |
| **Цель** | Подтвердить соблюдение санитарных требований при оказании услуг по уборке помещений либо зафиксировать нарушение и основание для предъявления претензий исполнителю. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель отдела МТО. |
| **Ожидаемый результат** | Подтверждено соблюдение санитарных норм и выполнение работ по договору либо установлено нарушение санитарных норм и сформированы основания для претензий к исполнителю. |
| **Рекомендованная функциональность** | Фиксация результатов контроля соблюдения санитарных норм; поддержка вызова связанного процесса ОБП29 «Контролировать исполнение госконтракта»; фиксация итогового результата процесса. |
| **Критичность** | Необходимая. |
| **Триггер** | Заключен госконтракт на оказание услуг по уборке помещений и началось его исполнение. |
| **Предварительные условия** | Заключен действующий госконтракт на оказание услуг по уборке помещений; определены применимые санитарные требования к выполнению работ. |
| **Основной сценарий** | 1. Руководитель отдела МТО контролирует соблюдение санитарных норм при оказании услуг по уборке помещений.  2. Выполняется связанный процесс ОБП29 «Контролировать исполнение госконтракта».  3. По результатам контроля определяется, соблюдаются ли санитарные нормы.  4. Если санитарные нормы соблюдаются, процесс завершается с результатом «Санитарные нормы соблюдены. Работы по договору выполнены». |
| **Расширение (альтернативный сценарий)** | 3а. По результатам контроля установлено, что санитарные нормы не соблюдаются.  3а.1 Процесс завершается с результатом «Установлено нарушение санитарных норм. Сформированы претензии к исполнителю». |
