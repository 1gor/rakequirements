# [To be] ТБП117. Рассмотреть КЖ на СП по существу

| **Наименование процесса** | ТБП117 — Рассмотреть КЖ на СП по существу |
| --- | --- |
| **Суть процесса** | Процесс описывает рассмотрение судом кассационной инстанции кассационной жалобы на вступивший в законную силу судебный приказ по существу после оценки доказательств по делу. Судья последовательно проверяет обстоятельства и возможные нарушения норм процессуального и материального права, определяет наличие оснований для оставления судебного приказа без изменения либо его отмены. При формировании варианта отмены Система подготавливает вспомогательные выводы и рекомендацию, которые проверяются Судьей в рамках типового процесса «Проверить выводы системы». Процесс завершается результатом об оставлении судебного приказа без изменения либо его отмене. |
| **Участники процесса** | Судья, Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026)  Постановление Пленума Верховного Суда РФ от 27.12.2016 N 62 (ред. от 05.04.2022) «О некоторых вопросах применения судами положений Гражданского процессуального кодекса Российской Федерации и Арбитражного процессуального кодекса Российской Федерации о приказном производстве»  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)» |

# **3. Реестр UC**

**UC001 — Проверка оснований для пересмотра судебного приказа**

| **№ шага процесса** | 1–8 |
| --- | --- |
| **Выполняемая задача** | Проверить обстоятельства и возможные нарушения, влияющие на законность судебного приказа, и сформировать итоговый вывод по результатам проверок. |
| **Цель** | Обеспечить последовательную фиксацию Судьей результатов проверок, необходимых для определения дальнейшего результата рассмотрения кассационной жалобы. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе сохранены результаты проверок и итоговый вывод Судьи, определяющий переход к установлению оснований для оставления судебного приказа без изменения либо его отмены. |
| **Рекомендуемая функциональность** | Формы фиксации результатов проверок по отдельным вопросам, отображение ранее сохраненных результатов, поле итогового вывода и подтверждение его сохранения. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступил к рассмотрению кассационной жалобы на судебный приказ по существу после оценки доказательств. |
| **Предварительные условия** | Материалы дела и результаты оценки доказательств доступны Судье в Системе. |
| **Основной сценарий** | 1. Судья открывает в Системе материалы кассационной жалобы и результаты оценки доказательств.  2. Судья проверяет соответствие выводов обстоятельствам дела и сохраняет результат.  3. Судья последовательно фиксирует результаты проверки соблюдения норм процессуального права, возможности должника заявить возражения и наличия спора о праве.  4. Судья фиксирует результаты проверки применения норм материального права и правильности толкования закона.  5. Судья выбирает и подтверждает итоговый вывод о том, подлежит ли судебный акт отмене/изменению; Система сохраняет вывод для дальнейшей маршрутизации. |
| **Расширение (альтернативный сценарий)** | До подтверждения итогового вывода Судья возвращается к результату одной из проверок, изменяет его и повторно подтверждает итоговый вывод. |

| **Расширение (альтернативный сценарий)** | Судья возвращается к результатам предыдущих проверок до подтверждения основания и корректирует ранее сохраненный вывод. |

| **№ шага процесса** | 11–19 |
