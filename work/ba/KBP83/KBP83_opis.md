# [To be] КБП83.Производство по делам по корпоративным спорам, включая отдельные категории

| **Наименование процесса** | КБП83. Производство по делам по корпоративным спорам, включая отдельные категории |
| --- | --- |
| **Суть процесса** | Процесс описывает TO BE-порядок рассмотрения арбитражным судом дел по корпоративным спорам, включая отдельные категории таких споров (ст. 225.7 и ст. 225.8 АПК РФ) и связанные с ними процессуальные действия в Системе. Он начинается с возникновения у заявителя необходимости подать исковое заявление по корпоративному спору и последующей подачи документов в суд. В ходе процесса заявление регистрируется, рассматривается вопрос о его принятии, участники получают доступ к электронным материалам дела, уведомляются заинтересованные лица и участники юридического лица, подаются отзывы, возражения, встречные иски, ходатайства и иные документы. Далее суд подготавливает и проводит судебное заседание, Система формирует правовую позицию по делу, судья разрешает процессуальные вопросы, рассматривает спор по существу и принимает судебный акт. После вынесения решения участники знакомятся с ним, при необходимости подтверждают исполнение, обращаются за исполнительным листом, разъяснением, исправлением описок или вынесением дополнительного решения. Процесс завершается исполнением судебного акта либо завершением производства без рассмотрения спора по существу, после чего дело передается в архив. |
| **Участники процесса** | Судья; Канцелярия; Заявитель/Истец по первоначальному иску (Орган ЮЛ, Участник ЮЛ, Учредитель ЮЛ); Иные ЛУВД; Ответчик (Истец по встречному иску, ЮЛ, Участник ЮЛ, Орган управления ЮЛ, Учредитель ЮЛ); Система |
| **НПА** | АПК РФ, глава 28.1 (статьи 225.1–225.9), общие положения искового производства; ГК РФ (корпоративные отношения); Федеральный закон № 208-ФЗ «Об акционерных обществах»; Федеральный закон № 14-ФЗ «Об обществах с ограниченной ответственностью». |
