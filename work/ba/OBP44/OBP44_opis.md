## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Сотрудник отдела бухгалтерского учета и отчетности | Проверяет первичные документы, отражает принятие обязательств в ИС, присваивает статью расходов, формирует платежную заявку, корректирует ошибки, отмеченные казначейством/УСД, получает уведомление о кассовом исполнении, отражает проводку по оплате в регистре, сравнивает данные учета с исполненными платежами, осуществляет контроль расчетов |
| Председатель суда/зам. председателя суда | Проверяет корректность платежной заявки, направляет замечания, подписывает платежную заявку в УКЭП |
| Отдел, ответственный за проведение закупок | Направляет документы поставщику для исправления, ожидает исправленные документы, передает исправленные документы в бухгалтерию |
| Система | Получает комплект первичных документов от поставщика и формирует сущность с данными по контракту и загруженными документами, возвращает документы на доработку отправляя информацию о неполном комплекте с просьбой дослать документы, направляет документы поставщику для исправления, передает исправленные документы в бухгалтерию после исправления, зафиксирует документы в журнале учета сохраняя их в электронном журнале, передает платежную заявку на согласование изменяя статус сущности, передает замечания в отдел бухгалтерского учета информируя ответственных, направляет платежное поручение фиксируя данные об успешной отправке в системе, подшивает документы по операциям в соответствующую номенклатуру сохраняя данные в ИС и объединяя взаимосвязанные сущности, сохраняет подписанные электронной подписью документы с открепленной подписью в сущности, обменивается данными с казначейством/УСД, обменивается данными с платежной системой, фиксирует информацию о проведении контроля расчетов и подтверждает соответствие или несоответствие в системе. |
