# [To be] ТБП104. Проверить соответствие признакам градообразующей организации

| **Наименование процесса** | ТБП104 — Проверить соответствие градообразующей организации |
| --- | --- |
| **Суть процесса** | Процесс отражает рассмотрение вопроса о соответствии юридического лица признакам градообразующей организации. В рамках процесса Система получает и анализирует сведения о численности работников юридического лица и среднесписочной численности работников муниципального образования, выполняет их сопоставление и формирует протокол проверки. Судья проверяет выводы Системы и определяет достаточность имеющихся данных. При недостаточности сведений выполняется повторное получение необходимых данных через типовой процесс направления запроса в ведомство. При достаточности данных Судья принимает итоговое решение о соответствии либо несоответствии юридического лица признакам градообразующей организации. |
| **Участники процесса** | Судья; Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)». |

# 3. Реестр UC

UC001 — Осуществление проверок численности работников ЮЛ и работников МО для решения вопроса о соответствии признакам градообразующей организации

| **№ шага процесса** | 0-7 |
| --- | --- |
| **Выполняемая задача** | Осуществить проверки численности работников юридического лица и работников муниципального образования для последующего сопоставления по признакам градообразующей организации. |
| **Цель** | Зафиксировать значения численности работников юридического лица и среднесписочной численности работников муниципального образования и получить результат сравнения для решения вопроса о соответствии признакам. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В карточке дела сохранены значения численности работников юридического лица и среднесписочной численности работников муниципального образования, а также зафиксирован результат сравнения численности. |
| **Рекомендуемая функциональность** | Карточка дела; отображение значений численности, результата сравнения и протокола проверки; подтверждение выводов Судьёй. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступает к проверке юридического лица на соответствие признакам градообразующей организации. |
| **Предварительные условия** | В карточке дела имеются представленные документы для определения численности работников юридического лица; определён период, используемый в расчёте по делу. |
| **Основной сценарий** | 1. Судья запускает в Системе проверку юридического лица на соответствие признакам градообразующей организации.  2. Судья направляет в ведомство запрос сведений, необходимых для проверки.  3. Система отображает установленную численность работников юридического лица.  4. Система отображает среднесписочную численность работников муниципального образования за период проверки.  5. Система отображает результат сравнения численности.  6. Система отображает сформированный протокол проверки.  7. Судья просматривает результаты проверки и протокол.  8. Судья подтверждает протокол проверки.  9. Система сохраняет подтверждённый протокол проверки в карточке дела. |
| **Расширение (альтернативный сценарий)** | 8а. Судья фиксирует недостаточность данных для решения вопроса.  8а1. Судья направляет в ведомство дополнительный запрос сведений. |
