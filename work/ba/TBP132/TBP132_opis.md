# [To be] ТБП132. Рассмотреть вопрос о завершении фин. оздоровления

| **Наименование процесса** | ТБП132 — Рассмотреть вопрос о завершении финансового оздоровления |
| --- | --- |
| **Суть процесса** | Процесс описывает рассмотрение судьёй вопроса о завершении финансового оздоровления после оценки доказательств. Судья проверяет необходимость продления процедуры, влияние её завершения на права лиц, участвующих в деле, полноту рассмотрения ходатайств и заявлений, применимые нормы права, выводы и исполнение обязанностей арбитражного управляющего, возможность восстановления платежеспособности должника и необходимость дополнительного исследования доказательств. Система обеспечивает отдельные автоматизированные действия, включая предоставление формы по вопросу тайны совещательной комнаты, ограничение доступа к вынесению судебного акта при выявленном нарушении, фиксацию прекращения текущего цикла принятия решения, определение НПА, на которые ссылались ЛУВД, и заполнение идентифицирующих реквизитов судебного акта. При отсутствии препятствий судья разрешает связанные вопросы обеспечительных мер и подтверждает один из итогов рассмотрения результатов финансового оздоровления. |
| **Участники процесса** | Судья, Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026), в том числе ст. 88. |

**UC001 — Проверка соблюдения тайны совещательной комнаты**

| № шага процесса | 0-7 |

| Выполняемая задача | Проверить соблюдение тайны совещательной комнаты судей для принятия решения о завершении финансового оздоровления. |
| Цель | Обеспечить корректность процедуры рассмотрения вопроса о завершении финансового оздоровления с учетом требований о соблюдении тайны совещательной комнаты. |

Судья открывает форму в интерфейсе Системы и вносит сведения о соблюдении либо несоблюдении тайны совещательной комнаты при принятии судебного акта.  4. Система устанавливает запрет (ограничение) на вынесение судебного акта по вопросу завершения финансового оздоровления с указанием причины «нарушение тайны совещательной комнаты»  7.
