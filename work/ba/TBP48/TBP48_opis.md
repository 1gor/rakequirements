## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Председатель суда арбитражного суда | Рассмотрение вопросов об отводе судей, предоставление пояснений о заинтересованности судей, принятие решений по отводам в случаях, предусмотренных законом |
| Заместитель председателя суда арбитражного суда | Рассмотрение вопросов об отводе судей при отсутствии председателя суда, проведение проверок оснований для отвода |
| Председатель судебного состава арбитражного суда | Рассмотрение вопросов об отводе членов судебного состава, координация проверок при коллегиальном рассмотрении дел |
| Судья арбитражного суда | Проведение проверок оснований для отвода участников процесса, принятие решений об отводе, самоотвод при наличии оснований |
| Система арбитражного суда | Проведения проверок, формирование рекомендаций, возможность формирования запросов в сторонние ведомства, подготовка шаблонов документов, анализ документов и дел в арбитражной системе суда, проверка данных в системе учета персонала. |
