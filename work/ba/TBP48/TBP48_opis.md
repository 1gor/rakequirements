# [To be] ТБП48. Рассмотреть вопрос об отводе

| **Наименование процесса** | ТБП48: Рассмотреть вопрос об отводе |
| --- | --- |
| **Суть процесса** | Основанием запуска процесса служит заявление об отводе либо заявление самоотвода лицом, на которое распространяются правила главы 3 АПК РФ. В ходе процесса определяется своевременность заявления, квалифицируется вид обращения, при отводе по ходатайству стороны выбирается порядок рассмотрения вопроса и при необходимости проводится отдельное судебное заседание. После рассмотрения вопроса определяется порядок принятия решения в зависимости от единоличного или коллегиального состава, устанавливается наличие оснований для отвода/самоотвода и оформляется результат. При удовлетворении отвода/самоотвода определяется лицо, подлежащее замене, и выполняется соответствующий типовой процесс либо указывается новый сотрудник аппарата суда. |
| **Участники процесса** | Председатель суда; Заместитель председателя суда; Председатель судебного состава; Судья; Коллегия судей; Помощник судьи/Секретарь СЗ; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025) глава 3. | **Цель** | Обеспечить принятие решения по заявленному отводу на основе объяснений и заслушивания участников. |
| **Роль / Актор** | Председатель суда, заместитель председателя суда, председатель судебного состава, судья, коллегия судей, Помощник судьи/Секретарь СЗ |
| **Ожидаемый результат** | В Системе отражено решение по вопросу отвода, заявленного по ходатайству стороны. |
| **Рекомендуемая функциональность** | Ведение материалов рассмотрения вопроса об отводе с фиксацией результатов заслушивания и принятого решения. |

| **Основной сценарий** | 1. Председатель суда, заместитель председателя суда, председатель судебного состава, судья, коллегия судей выбирает опцию по вопросу назначения отдельного СЗ.  2. Система регистрирует заключение о родственных связях в составе суда и выбранный вариант опции по вопросу назначения отдельного СЗ.  5. Председатель суда, заместитель председателя суда, председатель судебного состава, судья, коллегия судей предупреждает об уголовной ответственности.  6. Система отражает факт предупреждения об уголовной ответственности, связанный с рассмотрением вопроса об отводе в текущем СЗ.  7. Председатель суда, заместитель председателя суда, председатель судебного состава, судья, коллегия судей заслушивает ЛУВД по вопросу отвода.  8. Система фиксирует факт заслушивания ЛУВД по вопросу отвода  9. Система формирует основание для выбора дальнейшего действия.  10. Председатель суда, заместитель председателя суда, председатель судебного состава, судья, коллегия судей заслушивает лицо, которому заявлен отвод.  11. Система отражает объяснения лица, которому заявлен отвод, в материалах судебного заседания и учитывает их для дальнейшего принятия решения об отводе.  12.
