ТБП36:Рассмотреть вопрос об оставлении без рассмотрения

|  |  |
| --- | --- |
| **Наименование процесса** | ТБП36:Рассмотреть вопрос об оставлении без рассмотрения |
| **Суть процесса** | Процесс начинается с возникновения необходимости рассмотреть вопрос об оставлении заявления без рассмотрения после его принятия к производству. В рамках процесса производятся проверки оснований оставления заявления без рассмотрения, предусмотренные законодательством, такие как проверка тождественности, проверка соблюдения досудебного порядка урегулирования спора, проверка полномочий ЛУВД (включая право на подачу) и иные проверки, отраженные на схеме. По итогам проверок судья принимает решение — оставить заявление без рассмотрения или продолжить рассмотрение по делу. В случае, если судья приходит к выводу об оставлении заявления без рассмотрения, решается вопрос о возврате государственной пошлины и выносится соответствующее определение, которое впоследствии направляется ЛУВД. В случае, если судья не нашел оснований для оставления заявления без рассмотрения, происходит переход в основной процесс. |
| **Участники процесса** | Судья, канцелярия, ЛУВД |
