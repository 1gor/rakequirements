# [To be] ТБП118. Подготовиться к упрощенному/документарному рассмотрению. (Ранее -Подготовить дело к рассмотрению)

| **Наименование процесса** | ТБП118: Подготовить дело к рассмотрению |
| --- | --- |
| **Суть процесса** | Процесс охватывает действия судьи, направленные на организацию и обеспечение возможности рассмотрения дела в порядке упрощённого судопроизводства либо, в рамках дел о банкротстве,  в документарном порядке без проведения судебного заседания. Бизнес-процесс начинается с принятия судьёй решения о необходимости подготовки дела к рассмотрению в соответствующем порядке и включает изучение материалов дела и представленных сторонами документов, проверку наличия оснований для примирения сторон, анализ дополнительных доказательств и соблюдения процессуальных сроков их представления, а также оценку достаточности доказательственной базы для принятия судебного акта в упрощенном или документарном порядке. В рамках процесса судья осуществляет контроль надлежащего уведомления всех участников, проверяет предоставление сторонам доступа к материалам электронного дела и оценивает соблюдение процессуальных гарантий. По результатам подготовки судья принимает решение о готовности дела к рассмотрению в упрощённом или документарном порядке, о проведении одного судебного заседания в рамках упрощённого производства либо о необходимости перехода к рассмотрению дела по общим правилам искового производства. Процесс завершается установлением дальнейшего порядка рассмотрения дела. |
| **Участники процесса** | Судья. |

| Предварительные условия | В карточке дела загружены документы (поступившие от сторон и/или сформированные судом), судья имеет доступ к карточке дела; включены классификаторы/правила анализа. |
| Основной сценарий | 1. Система выполняет анализ материалов дела и поступающих документов  2. Система формирует протокол проверки с рекомендациями для судьи.  3. Система направляет судье уведомление о необходимости проверить выводы Системы.  4. Судья подтверждает выводы системы.  5. Открывается окно интерфейса с данными поступивших документов  6 Судья нажимает элемент интерфейса, подтверждающий достаточность доказательств для рассмотрения.  7. Система запускает контроль надлежащего уведомления сторон.  8. Система в ходе контроля делает вывод, что все извещены надлежащим образом.  9. Система записывает результат подготовки «Дело готово к рассмотрению в упрощенном порядке» |
| Альтернативные сценарии / расширения | 5а Система установила примирение сторон  5а.1 Система фиксирует наличе оснований для прекращения производства по делу.  5а2. Система запускает процесс рассмотрения вопроса о прекращении производства.  6а   Представленных доказательств не достаточно судье, но судья не будет переходить к общему порядку рассмотрения  6а1 Судья нажимает на элемент интерфейса, подтверждающий, что доказательств недостаточно.  6а2 Система выводит форму с выбором порядка рассмотрения  6а3 Судья нажимает на элемент интерфейса «Рассмотреть в упрощенном порядки с одним СЗ»  6а4.Система записывает результат подготовки «Дело готово к рассмотрению в упрощенном порядке с проведением одного СЗ»  6б  Представленных доказательств не достаточно судье, судья хочет  перейти к общему порядку рассмотрения.  6а1 Судья нажимает на элемент интерфейса, подтверждающий, что доказательств недостаточно.  6а2 Система выводит форму с выбором порядка рассмотрения  6а3 Судья нажимает на элемент интерфейса «Рассмотреть в общем порядки»  6а4.Система записывает результат подготовки «Дело будет рассмотрено в общем порядке»  8а Есть неизвещенные стороны  8а1 Система в ходе контроля делает вывод, что есть стороне не извещенные  надлежащим образом.  8а2.
