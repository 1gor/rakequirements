# [To be] ТБП77. Рассмотреть заявление о фальсификации доказательств

| Наименование процесса | ТБП77: Рассмотреть заявление о фальсификации доказательств |
| --- | --- |
| Суть процесса | Процесс описывает рассмотрение судьёй письменного заявления лица, участвующего в деле, о фальсификации доказательств в стадии судебного разбирательства. Судья разъясняет лицу, заявившему о фальсификации, ответственность за заведомо ложный донос (ст. 306 УК РФ), а лицу, представившему оспариваемое доказательство, — ответственность за фальсификацию доказательств (ст. 303 УК РФ), после чего получает от заявителя расписку. Затем судья предлагает лицу, представившему доказательство, исключить его из дела и выслушивает мнения всех участвующих в деле лиц. Если лицо соглашается на исключение, суд выносит соответствующее определение и при необходимости частное определение в порядке ст. 188.1 АПК РФ. Если лицо заявляет возражения, суд назначает меры по проверке достоверности доказательства, при необходимости откладывает заседание, а по завершении проверки делает вывод о наличии или отсутствии факта фальсификации: при его подтверждении — исключает доказательство из дела и вправе направить материалы в правоохранительные органы, при опровержении — отклоняет заявление; в обоих случаях при необходимости выносится частное определение. |

## **2.3 Реестр UC (в части выполняемых пользователем задач и рекомендованной функциональности Системы)**

UC-001: Определение перечня мер для проверки достоверности доказательства

| **Поле** | **Значение** |
| --- | --- |
| Выполняемая задача | Анализ обстоятельств дела и требований закона с целью определения перечня мер для проверки достоверности оспариваемого доказательства |
| № шага процесса | 9-10, 12-17 |
| Цель | Сформировать рекомендацию по перечню мер для проверки достоверности доказательства |
| Роль / Актор | Судья |
| Ожидаемый результат | Рекомендация с релевантным перечнем мер для проверки достоверности доказательства сформирована и провалидирована судьей. |
| Рекомендованная функциональность | Создание проекта СА на основании данных дела; отображение проекта судье; уведомление о готовности проекта; возможность внесения дополнительной информации и повторного формирования проекта; сохранение версии проекта. |
| Критичность | Необходимая |
| Триггер | Поступило мнение стороны, представившее доказательство, содержащее в себе отказ в исключении оспариваемого доказательства. |
| Предварительные условия | Судья авторизован в системе. Данные дела заполнены в объеме, достаточном для определения перечня мер. |
| Основной сценарий | 1. Судья запрашивает согласие лица на исключение доказательства. 2. Система получает мнение лица в машиночитаемом формате. 3. Система анализирует характер мнения по критерию согласия или несогласия на исключение доказательства.  4. Система определяет мнение как отрицательное.  5. Система анализирует данные дела, сопоставляя их с требованиями законодательства.  6. Система формирует рекомендацию, содержащую перечень и описание мер проверки достоверности доказательства.  7. Судья знакомится с перечнем.  8. Судья подтверждает перечень.  9. Система сохраняет данные о мерах в объекте для последующего использования. |
| Альтернативные сценарии / расширения | 4а. Система определяет мнение как положительное. 4а1. Система исключает оспариваемое доказательство из общего перечня доказательств, присваивая ему статус «Исключено».  8а. Судья корректирует перечень мер.  8а1. Система сохраняет изменения в текст рекомендации. |
