# [To be] ОБП8. Учет списания дела (производства) в архив и уничтожение дел

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП8. Учет списания дела (производства) в архив и уничтожение дел |
| **Суть процесса** | Процесс предназначен для оформления и согласования отбора дел с истекшим сроком хранения к уничтожению. После наступления срока хранения Система формирует акт о выделении к уничтожению и направляет его на согласование в архив. Далее формируется состав экспертной комиссии, проводится заседание комиссии, оформляются и утверждаются акт и протокол заседания. После утверждения документов сотрудник архива подготавливает дела к утилизации и передает их на уничтожение с обеспечением сохранности оригиналов судебных актов, подлежащих дальнейшему хранению. |
| **Участники процесса** | Судебный состав/ подразделение суда; Сотрудник архива; Председатель суда; Экспертная комиссия; Председатель экспертной комиссии; Система |
| **НПА** | Федеральный закон от 22.10.2004 № 125-ФЗ (ред. от 13.12.2024) «Об архивном деле в Российской Федерации».  Постановление Пленума ВАС РФ от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)», в том числе п. 38.15–38.16, 39.2–39.4 и приложение № 45.  Приказ Судебного департамента при Верховном Суде РФ от 23.12.2021 № 245 (ред. от 05.12.2025) «Об утверждении Перечня документов, образующихся в процессе деятельности федеральных арбитражных судов, с указанием сроков хранения». |

**UC002 — Принятие локального акта о составе комиссии**

|  |  |
| --- | --- |
| **№ шага процесса** | 4-5 |
| **Выполняемая задача** | Инициировать создание и утверждение локального акта и приказа о составе экспертной комиссии. |
| **Цель** | Сформировать приказ о составе экспертной комиссии для отбора дел на хранение или уничтожение. |
| **Роль / Актор** | Председатель суда |
| **Ожидаемый результат** | Система создает локальный акт и приказ о составе экспертной комиссии, сохраняет локальный акт в статусе «Принят локальный акт о составе комиссии» и отображает карточку акта в указанном статусе для дальнейших действий по назначению заседания. |
| **Рекомендуемая функциональность** | Оформление карточки акта и реквизитов состава комиссии на основании представленных сведений; создание приказа о составе экспертной комиссии. |
| **Критичность** | Необходимая |
| **Триггер** | Председатель суда инициирует создание локального акта о составе комиссии |
| **Предварительные условия** | В Системе создана информация для формирования состава комиссии и доступны сведения для заполнения реквизитов акта. |
| **Основной сценарий** | 1. Председатель суда инициирует создание локального акта о составе комиссии.  2. Система оформляет карточку акта о составе комиссии и заполняет реквизиты состава комиссии на основании представленных сведений.  3. Председатель суда утверждает состав комиссии локальным актом и приказом.  4. Система создает приказ о составе экспертной комиссии.  5. Система сохраняет локальный акт в статусе «Принят локальный акт о составе комиссии».  6. Система отображает карточку акта. |

| **Ожидаемый результат** | В Системе зафиксированы организационные параметры заседания, создан протокол заседания, документы переданы на утверждение, а затем протокол утвержден и доступен для последующего этапа. |
| **Рекомендуемая функциональность** | Управление назначением заседания экспертной комиссии, создание и согласование протокола заседания, передача документов на утверждение, фиксация статусов и утверждения. |
| **Критичность** | Необходимая |
| **Триггер** | Экспертная комиссия назначает заседание. |
| **Предварительные условия** | В Системе имеются единицы архивного хранения, для которых требуется рассмотрение сведений по делам, выделяемым к уничтожению; доступен акт о выделении к уничтожению и материалы дел, подлежащих рассмотрению на заседании. |
| **Основной сценарий** | 1. Экспертная комиссия назначает заседание экспертной комиссии. Система отображает созданное расписание/запись заседания экспертной комиссии со статусом «Заседание назначено» и сформированный пакет материалов по единицам архивного хранения.  2. Экспертная комиссия рассматривает акт о выделении к уничтожению и материалы дел. Система отображает созданный документ «Протокол заседания» со статусом «Согласовано», а также переводит акт о выделении к уничтожению в статус «На согласование/доработку при необходимости».  3. Экспертная комиссия передает акт и протокол на утверждение. Система отображает перевод акта о выделении к уничтожению и протокола заседания в статус «Переданы на утверждение» и фиксирует запись о доставке комплекта документов.  4. Председатель экспертной комиссии подписывает утверждение акта и протокола заседания. Система подтверждает фиксацию утверждения «Акт о выделении к уничтожению» и «Протокол заседания» экспертной комиссии.  5. Председатель экспертной комиссии передает протокол на согласование. Система отображает протокол заседания в статусе «Передан на согласование» и доступность протокола председателю экспертной комиссии для рассмотрения.  6. Председатель суда подписывает утверждение протокола заседания. Система подтверждает перевод протокола заседания в статус «Утвержден» и доступность для последующего этапа ознакомления с утвержденными материалами. |
