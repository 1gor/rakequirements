## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Председатель суда | Принимает локальный акт о составе комиссии, наделяет комиссию полномочиями |
| Руководитель архива | Создает план-график уничтожения дел, проводит сверку наличия дел выделяемых к уничтожению, выделяет из материалов дел документы постоянного хранения, передает дела на уничтожение, уведомляет комиссию о планируемых датах уничтожения, вносит в ИС информацию об уничтожении, проводит розыск отсутствующего дела |
| Комиссия | Составляет акт об уничтожении, сверяет наличие дел передаваемых на уничтожение, передает дела на уничтожение, фиксирует факт уничтожения, подписывает акт об уничтожении, передает информацию об отсутствующем деле |
