## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Судья | Проверяет документ на возможность публикации, запрещает документ к публикации, публикует СА, проверяет факт публикации |
| Система | Сохраняет данные, деперсонифицирует СА, отображает данные в карточке |
| КАД Арбитр | Осуществляет отображение публикуемых материалов в общем доступе в сети Интернет, отправляет дату и время публикации в ИС суда |
| Председатель суда | Осуществляет контроль за своевременностью и корректность публикаций, проводит служебную проверку при выявлении нарушений |
