## ****3. Реестр UC****

**UC001 — Определить основание списания и подготовить материалы**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–10 |
| **Выполняемая задача** | Определение основания и порядка списания ТМЦ, подготовка подтверждающих материалов и проведение инвентаризации при порче или утрате. |
| **Цель** | Сформировать документально подтвержденный комплект материалов, достаточный для принятия комиссией решения о выбытии ТМЦ. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Руководитель МТО. Участники: Главный бухгалтер; Комиссия. |
| **Ожидаемый результат** | Определены порядок и причина списания; при расходовании в деятельности подготовлены подтверждающие документы, а при порче или утрате сформирован акт о результатах инвентаризации с зафиксированной причиной списания. |
| **Рекомендованная функциональность** | Доступ к сведениям о ТМЦ и учетной политике; фиксация порядка и причины списания; связывание материалов списания с ТМЦ; вызов ОБП30 для проведения инвентаризации; хранение акта о результатах инвентаризации и указанной причины списания. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость списания товарно-материальных ценностей. |
| **Предварительные условия** | Имеются сведения о ТМЦ, подлежащих списанию, и актуальная учетная политика; определено ответственное лицо за организацию списания. |
| **Основной сценарий** | 1. Руководитель МТО получает сведения о ТМЦ, подлежащих списанию.  2. Руководитель МТО знакомится с требованиями учетной политики, применимыми к списанию соответствующих ТМЦ.  3. Руководитель МТО определяет порядок и причину списания ТМЦ.  4. Руководитель МТО устанавливает, что списание связано с расходованием ТМЦ в деятельности.  5. Руководитель МТО подготавливает и передает комиссии журнал выдачи ТМЦ и связанные сведения, подтверждающие расходование.  6. Подготовленные материалы переходят на рассмотрение комиссии. |
| **Расширение (альтернативный сценарий)** | 4а. Установлено, что ТМЦ испорчены или утрачены.  4а.1 Руководитель МТО инициирует ОБП30 «Участие в проведении инвентаризации материальных ценностей и технических средств».  4а.2 По результатам ОБП30 формируется акт о результатах инвентаризации.  4а.3 Главный бухгалтер указывает в акте причину списания ТМЦ.  4а.4 Если причиной является порча, комиссия формирует решение о прекращении признания испорченных объектов нефинансовых активов активами.  4а.5 Материалы по порче или утрате переходят на рассмотрение комиссии для принятия решения о выбытии. |

| **Рекомендованная функциональность** | Предоставление комиссии комплекта материалов по списанию; формирование и хранение решения о выбытии; создание акта о списании материальных запасов; фиксация признака утраты; формирование акта об утилизации (уничтожении); объединение документов в комплект по списанию ТМЦ. |
| **Критичность** | Необходимая. |
| **Триггер** | Комиссии передан комплект документов, подтверждающий расходование, порчу или утрату ТМЦ. |
| **Предварительные условия** | Причина списания определена и документально подтверждена; материалы по соответствующим ТМЦ доступны комиссии. |
| **Основной сценарий** | 1. Комиссия получает комплект документов для принятия решения о выбытии ТМЦ.  2. Комиссия рассматривает представленные материалы и основания списания.  3. Комиссия принимает решение о выбытии активов.  4. Комиссия оформляет акт о списании материальных запасов.  5. Комиссия устанавливает, что ТМЦ не являются утраченными и подлежат утилизации.  6. Комиссия принимает решение об утилизации ТМЦ.  7. Комиссия оформляет акт об утилизации (уничтожении) материальных ценностей.  8. Комплект документов по списанию передается главному бухгалтеру для отражения операций в учете. |
| **Расширение (альтернативный сценарий)** | 5а. ТМЦ утрачены.  5а.1 Отдельное решение об утилизации и акт об утилизации не формируются.  5а.2 Акт о списании материальных запасов включается в комплект документов по списанию.  5а.3 Комплект документов передается главному бухгалтеру для отражения операций в учете. |

**UC003 — Отразить списание ТМЦ в учете**

|  |  |
| --- | --- |
| **№ шага процесса** | 15–19 |
| **Выполняемая задача** | Отражение выбытия ТМЦ в бухгалтерском учете и, при наличии основания, на забалансовых счетах. |
| **Цель** | Корректно отразить завершенное списание ТМЦ в бухгалтерском учете и обеспечить дальнейший забалансовый учет при его необходимости. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Главный бухгалтер. |
| **Ожидаемый результат** | Бухгалтерские операции по списанию выполнены; при необходимости ТМЦ отражены на забалансовых счетах; учетные операции завершены. |
| **Рекомендованная функциональность** | Получение и хранение комплекта документов по списанию; формирование бухгалтерских записей по выбытию ТМЦ; фиксация решения о необходимости забалансового учета; отражение ТМЦ на соответствующих забалансовых счетах; фиксация завершения учетных операций. |
| **Критичность** | Необходимая. |
| **Триггер** | Комиссия оформила комплект документов по списанию ТМЦ. |
| **Предварительные условия** | Имеются акт о списании материальных запасов и, при необходимости, акт об утилизации; решение комиссии оформлено. |
| **Основной сценарий** | 1. Главный бухгалтер получает комплект документов по списанию ТМЦ.  2. Главный бухгалтер выполняет бухгалтерские операции по отражению выбытия ТМЦ.  3. Главный бухгалтер определяет необходимость дальнейшего учета ТМЦ на забалансовых счетах.  4. При отсутствии необходимости забалансового учета главный бухгалтер завершает учетные операции.  5. Процесс завершается с результатом «ТМЦ списаны». |
| **Расширение (альтернативный сценарий)** | 3а. Требуется учитывать ТМЦ на забалансовых счетах.  3а.1 Главный бухгалтер отражает ТМЦ на соответствующих забалансовых счетах.  3а.2 Сведения о забалансовом учете связываются с бухгалтерскими записями по списанию.  3а.3 После отражения ТМЦ на забалансовых счетах учетные операции завершаются.  3а.4 Процесс завершается с результатом «ТМЦ списаны». |
