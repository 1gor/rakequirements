# [To be] ТБП129. Рассмотреть вопрос о признании банкротом

| **Наименование процесса** | ТБП129 — Рассмотреть вопрос о признании должника банкротом |
| --- | --- |
| **Суть процесса** | Процесс обеспечивает рассмотрение судьёй вопроса о признании должника банкротом: при необходимости проводится проверка соблюдения тайны совещательной комнаты; определяются применимые НПА и судебная практика; фиксируются мотивы неприменения НПА; устанавливаются признаки банкротства, недостаточность имущества, причины неисполнения обязательств, характер задолженности и неплатежеспособность. По результатам принимается решение о соответствии либо несоответствии должника признакам банкротства либо текущий цикл принятия решения прекращается для дополнительного исследования доказательств. |
| **Участники процесса** | Судья, Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026)  Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026) |

# **3. Реестр UC**

**UC001 — Проверка соблюдения тайны совещательной комнаты**

| **№ шага процесса** | 1–7 |
| --- | --- |
| **Выполняемая задача** | Проверить соблюдение тайны совещательной комнаты для дальнейшего рассмотрения вопроса и формирования судебного акта. |
| **Цель** | Обеспечить корректность рассмотрения с учетом соблюдения тайны совещательной комнаты. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксирован ответ судьи по вопросу соблюдения тайны совещательной комнаты; при установленном нарушении доступ к вынесению судебного акта закрыт, при отсутствии нарушения рассмотрение может быть продолжено. |
| **Рекомендуемая функциональность** | Отображение формы по вопросу тайны совещательной комнаты, фиксация ответа судьи и автоматическое ограничение доступа к вынесению судебного акта при установленном нарушении. |
| **Критичность** | Необходимая |
| **Триггер** | Появились основания полагать, что тайна совещательной комнаты могла быть нарушена, либо судья запросил форму о соблюдении тайны совещательной комнаты. |
| **Предварительные условия** | В Системе открыто судебное дело, по которому судья находится на стадии принятия решения. |
| **Основной сценарий** | 1. Система предоставляет судье форму по вопросу тайны совещательной комнаты.  2. Судья заполняет форму и указывает, установлено ли нарушение тайны совещательной комнаты.  3. Система фиксирует ответ судьи.  4. При отсутствии нарушения проверка завершается с результатом, допускающим продолжение рассмотрения вопроса о признании должника банкротом. |
| **Расширение (альтернативный сценарий)** | 4а Если судья указывает на нарушение тайны совещательной комнаты, Система закрывает доступ к вынесению судебного акта, после чего текущая ветвь принятия решения завершается. |

**UC002 — Рассмотрение вопроса признания должника банкротом**

| **№ шага процесса** | 8–26 |
| --- | --- |
| **Выполняемая задача** | Определить наличие оснований для признания должника банкротом и отразить результаты оценки в судебном деле. |
| **Цель** | Подготовить обоснование и итоговый вывод по вопросу о признании должника банкротом. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе отражены применимые НПА и судебная практика, результаты оценки признаков банкротства и неплатежеспособности, а также итоговый маршрут принятия решения. |
| **Рекомендуемая функциональность** | Ведение судебного дела с фиксацией результатов правовой оценки, автоматическим заполнением идентифицирующих реквизитов судебного акта и формированием признака необходимости дополнительного исследования доказательств. |
| **Критичность** | Необходимая |
| **Триггер** | Судья перешёл к принятию решения по вопросу о признании должника банкротом. |
| **Предварительные условия** | В Системе имеется судебное дело и материалы, необходимые для правовой оценки вопроса о признании должника банкротом. |
| **Основной сценарий** | 1. Судья определяет законы и НПА, подлежащие применению.  2. Система формирует перечень НПА, на которые ссылались лица, участвующие в деле.  3. При наличии ссылок на иные НПА судья указывает в судебном акте мотивы их неприменения.  4. Судья устанавливает содержание норм права в официальном толковании и судебной практике.  5. Система заполняет необходимые идентифицирующие реквизиты судебного акта.  6. Судья устанавливает наличие признаков банкротства, недостаточность имущества, причину неисполнения обязательств и характер задолженности, после чего проверяет неплатежеспособность должника.  7. Система формирует признак необходимости дополнительного исследования доказательств.  8. Если дополнительное исследование не требуется, процесс маршрутизируется по результату проверки неплатежеспособности к итоговому решению. |
| **Расширение (альтернативный сценарий)** | Если необходимо дополнительное исследование доказательств или выяснение обстоятельств, текущий цикл принятия решения прекращается. Если неплатежеспособность не установлена, фиксируется решение о несоответствии должника признакам банкротства; если установлена — о соответствии признакам банкротства. |
