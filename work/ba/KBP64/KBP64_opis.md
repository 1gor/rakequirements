# Описание КБП64 TO BE: ""Приостановление исполнительного производства"

## 1. Нормативно-правовые акты

| **Название НПА с реквизитами** |
| --- |
| Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ |
| Федеральный закон "Об исполнительном производстве" от 02.10.2007 № 229-ФЗ |

## 2. Схема процесса

BPMN-файл: "KBP64\_IP\_priostanovlenie\_ispolnitelnogo\_bpmn\_tobe.bpmn"

Схема отражает процесс производства о приостановлении исполнительного производства, включая:

* Подачу заявления
* Проверку документов
* Рассмотрение заявления
* Вынесение определения
* Взаимодействие с участниками разбирательства
