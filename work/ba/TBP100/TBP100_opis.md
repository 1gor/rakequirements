| **№ шага процесса** | 0-7 |

| **Выполняемая задача** | Проверить операции по банковским счетам должника за 12 месяцев для установления признаков недействующего юридического лица. |
| **Цель** | Установить наличие либо отсутствие операций по банковским счетам должника за последние 12 месяцев для выявления признаков недействующего юридического лица. |

| **Рекомендуемая функциональность** | Проверка операций по банковским счетам за период и фиксация результата в карточке дела. |
