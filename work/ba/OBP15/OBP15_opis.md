# [To be] ОБП15. Сопровождение в проведении различных внутренних мероприятий

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП15 — Сопровождение в проведении различных внутренних мероприятий |
| **Суть процесса** | Организация технического сопровождения внутренних мероприятий суда: фиксация мероприятия и требований к техническому обеспечению, назначение ответственных, проверка готовности техники, устранение неисправностей либо поиск замены, проведение мероприятия, а также сохранение и предоставление доступа к записям при необходимости. |
| **Участники процесса** | Организатор мероприятия  Начальник отдела информатизации  Сотрудник отдела информатизации |
| **НПА** | Процесс не регулируется НПА |

## ****3.  Реестр UC****

### UC001 — Организовать техническую подготовку мероприятия

|  |  |
| --- | --- |
| **№ шага процесса** | 0–23 |
| **Выполняемая задача** | Формирование требований к техническому сопровождению мероприятия, назначение ответственных, проверка работоспособности техники и обеспечение мероприятия необходимыми техническими средствами. |
| **Цель** | Обеспечить техническую готовность оборудования и техники к проведению внутреннего мероприятия суда. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** организатор мероприятия.**Участники:** начальник отдела информатизации; сотрудник отдела информатизации. |
| **Ожидаемый результат** | Определены требования к техническому сопровождению, назначены ответственные сотрудники и обеспечена готовность необходимой техники либо скорректирована программа мероприятия с учетом доступного технического обеспечения. |
| **Рекомендованная функциональность** | Создание сущности мероприятия; фиксация программы/сценария и требований к техническому обеспечению; создание и маршрутизация поручений; определение перечня используемой техники и ответственных сотрудников; фиксация результатов проверки техники; направление запроса на предоставление техники другим судом; корректировка программы/сценария мероприятия. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость в техническом сопровождении мероприятия, проводимого в суде. |
| **Предварительные условия** | Определён организатор мероприятия; известны основные сведения о планируемом мероприятии и требования к его проведению. |
| **Основной сценарий** | 1. Организатор мероприятия создаёт в Системе сущность мероприятия. 2. Организатор подготавливает программу/сценарий и указывает требования к техническому сопровождению. 3. Организатор направляет начальнику отдела информатизации поручение о техническом сопровождении. 4. Начальник отдела информатизации изучает программу/сценарий мероприятия. 5. Начальник отдела информатизации определяет перечень необходимой техники. 6. Начальник отдела информатизации определяет ответственных сотрудников и выдаёт им поручения. 7. Сотрудник отдела информатизации проверяет работоспособность техники. 8. Техника исправна и может использоваться при проведении мероприятия. 9. Техническая подготовка мероприятия завершена. |
| **Расширение (альтернативный сценарий)** | **8а. Выявлена неисправность техники, которую возможно устранить до начала мероприятия.** 8а.1 Начальник отдела информатизации определяет срок ремонта. 8а.2 Инициируется ОБП14 «Организация текущего обслуживания установленного в суде оборудования и техники». 8а.3 После восстановления техники процесс подготовки продолжается. **8б. Восстановить технику до начала мероприятия невозможно.** 8б.1 Начальник отдела информатизации определяет возможность получения необходимой техники в другом суде и направляет соответствующий запрос. 8б.2 При возможности предоставления техники организуется её получение, после чего процесс подготовки продолжается. **8в. Получить необходимую технику невозможно.**8в.1 Начальник отдела информатизации сообщает организатору об отсутствии техники. 8в.2 Организатор определяет возможность проведения мероприятия с учетом технических ограничений. 8в.3 Если проведение возможно, организатор корректирует программу/сценарий мероприятия, после чего процесс подготовки продолжается. 8в.4 Если проведение невозможно, процесс завершается со статусом «Провести мероприятие невозможно по техническим причинам». |

### UC002 — Обеспечить техническое сопровождение мероприятия и сохранить его материалы

|  |  |
| --- | --- |
| **№ шага процесса** | 24–34 |
| **Выполняемая задача** | Подготовка техники непосредственно к началу мероприятия, техническое сопровождение его проведения, завершение работы оборудования и сохранение записей при необходимости. |
| **Цель** | Обеспечить проведение мероприятия с использованием подготовленного технического оборудования и сохранить материалы мероприятия при наличии такой необходимости. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** сотрудник отдела информатизации.**Участники:** организатор мероприятия. |
| **Ожидаемый результат** | Мероприятие проведено с необходимым техническим сопровождением; при необходимости фото-, видео- и аудиоматериалы сохранены и организатору предоставлен доступ к ним. |
| **Рекомендованная функциональность** | Фиксация даты и времени мероприятия; подготовка технических средств к проведению мероприятия; фиксация необходимости сохранения записей; сохранение материалов мероприятия; предоставление организатору доступа к сохранённым материалам и сведениям о месте их хранения. |
| **Критичность** | Необходимая. |
| **Триггер** | Техническая подготовка мероприятия завершена и наступает установленная дата его проведения. |
| **Предварительные условия** | Определены программа мероприятия, необходимое техническое обеспечение и ответственные сотрудники; техника подготовлена либо обеспечена возможность проведения мероприятия с учетом скорректированной программы. |
| **Основной сценарий** | 1. Сотрудник отдела информатизации ожидает наступления установленной даты и времени мероприятия. 2. Перед началом мероприятия сотрудник включает и подготавливает необходимую технику. 3. Организатор проводит мероприятие с использованием подготовленного технического обеспечения. 4. После завершения мероприятия сотрудник отдела информатизации выключает использованную технику. 5. Сотрудник определяет необходимость сохранения фото-, видео- и аудиоматериалов мероприятия. 6. Сохранение записей не требуется. 7. Процесс завершается со статусом «Мероприятие проведено». |
| **Расширение (альтернативный сценарий)** | **6а. Необходимо сохранить записи мероприятия.** 6а.1 Сотрудник отдела информатизации сохраняет необходимые фото-, видео- и аудиоматериалы в предусмотренном хранилище. 6а.2 Сотрудник отдела информатизации предоставляет организатору доступ к сохранённым материалам и сведения о месте их хранения. 6а.3 Организатор мероприятия знакомится с сохранёнными записями. 6а.4 Процесс завершается со статусом «Мероприятие проведено. Фото, видео сохранены в электронном архиве суда». |
