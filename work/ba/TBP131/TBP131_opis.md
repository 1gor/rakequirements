# [To be] ТБП131. Рассмотреть вопрос о введении внешнего управления

| **Наименование процесса** | ТБП131 — Рассмотреть вопрос о введении внешнего управления |
| --- | --- |
| **Суть процесса** | Процесс в TO BE описывает действия суда по разрешению вопроса о введении внешнего управления в деле о банкротстве с использованием Системы для выполнения отдельных автоматизированных проверок и формирования данных. Процесс начинается после оценки доказательств, когда судья переходит к рассмотрению вопроса о введении внешнего управления, при этом предварительно контролируется полнота рассмотрения поступивших заявлений и ходатайств. В ходе процесса Система формирует сведения о нормативных правовых актах, заполняет идентифицирующие реквизиты и проверяет действующую процедуру банкротства, а судья определяет применимое правовое регулирование, оценивает платежеспособность должника, рассматривает ходатайство о введении внешнего управления и достаточность имеющихся доказательств. Если требуется рассмотрение неразрешенного заявления либо получение дополнительных доказательств, текущий процесс принятия решения прекращается для совершения необходимых процессуальных действий; если основания для введения внешнего управления отсутствуют, суд переходит к рассмотрению вопроса об иной процедуре банкротства. При принятии решения о введении внешнего управления судья определяет срок процедуры, вводит мораторий на удовлетворение требований кредиторов, при наличии кандидатуры утверждает внешнего управляющего и при необходимости разрешает вопросы обеспечительных мер. Процесс завершается подтверждением судьей решения о введении внешнего управления и переходом к изготовлению судебного акта. |
| **Участники процесса** | Судья, Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026) |
