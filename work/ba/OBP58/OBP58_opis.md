# [To be] ОБП58. Формирование кадрового резерва

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП58 — Формирование кадрового резерва |
| **Суть процесса** | Формирование и ведение кадрового резерва суда: подготовка и публикация условий конкурса, прием документов, проведение конкурсных процедур и оценка кандидатов, оформление решений, включение лиц в кадровый резерв, информирование участников и последующее сопровождение резервистов. |
| **Участники процесса** | Председатель/заместитель председателя; Сотрудник отдела кадров; Сотрудник/кандидат на должность; Конкурсная комиссия; Система |
| **НПА** | Указ Президента РФ от 01.03.2017 N 96 (ред. от 10.10.2024) «Об утверждении Положения о кадровом резерве федерального государственного органа, кадровом резерве органа публичной власти федеральной территории» Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)» |

|  |  |

Сотрудник отдела кадров начинает подготовительный этап формирования кадрового резерва.  4. Сотрудник отдела кадров создает и заполняет карточку кадрового резерва.  5. Сотрудник отдела кадров размещает информацию об открытых вакансиях через СМИ.  6. Система информирует сотрудников суда об открытых вакансиях по внутренним каналам.  7. Сотрудник отдела кадров объявляет конкурс на включение в кадровый резерв.  8. Система размещает информацию о приеме документов, условиях конкурса, сроке приема документов, предполагаемой дате, месте и порядке его проведения.  9. Сотрудник отдела кадров определяет перечень лиц, желающих участвовать в конкурсе.  10. Сотрудник/кандидат на должность, не являющийся сотрудником суда, составляет заявление, заполняет анкету и прикладывает необходимые документы.  11. **UC002 — Провести конкурс и оформить результаты**

|  |  |
| --- | --- |
| **№ шага процесса** | 27–43 |
| **Выполняемая задача** | Проведение заседания конкурсной комиссии, проверка кворума, оценка кандидатов, принятие решения, оформление и подписание протокола, информирование кандидатов и обработка отказа во включении в кадровый резерв. |

| **Роль/Актор (в соответствии со схемой)** | Основной актор: Конкурсная комиссия. Участники: Председатель/заместитель председателя; Сотрудник отдела кадров; Система. |

| **Рекомендованная функциональность** | Формирование состава конкурсной комиссии; автоматическая проверка кворума; фиксация результатов конкурса и оценок кандидатов; фиксация результатов открытого голосования; формирование и подписание протокола; маршрутизация протокола председателю; уведомление кандидатов; подготовка и отправка выписки об отказе; учет архивного хранения и возврата документов. |
| **Критичность** | Необходимая. |
| **Триггер** | Определены точные дата, место и время конкурса, сформирован список кандидатов и завершен срок приема документов. |
| **Предварительные условия** | Имеется список кандидатов и материалы по ним; сформирован состав конкурсной комиссии; конкурс может проводиться при наличии требуемого числа кандидатов и кворума. |
| **Основной сценарий** | 1. Конкурсная комиссия собирается для проведения заседания.  2. Система проверяет присутствие не менее двух третей от общего числа членов конкурсной комиссии.  3. Конкурсная комиссия проводит конкурсные процедуры по отбору кандидатов.  4. Конкурсная комиссия оценивает кандидатов на соответствие установленным требованиям и потребностям суда.  5. Конкурсная комиссия принимает решение о возможности включения каждого кандидата в кадровый резерв.  6. Конкурсная комиссия оформляет результаты голосования и принятые решения протоколом.  7. Члены конкурсной комиссии подписывают протокол.  8. Система передает подписанный комиссией протокол председателю/заместителю председателя.  9. Председатель/заместитель председателя подписывает протокол и подтверждает результаты конкурса.  10. Сотрудник отдела кадров сообщает кандидатам результаты конкурса.  11. Сотрудник отдела кадров получает согласие кандидатов, рекомендованных для включения в кадровый резерв.  12. Для кандидатов, рекомендованных к включению, процесс продолжается в UC003. |
| **Расширение (альтернативный сценарий)** | 11а. По кандидату принято решение об отказе во включении в кадровый резерв.  11а.1 Сотрудник отдела кадров подготавливает выписку из протокола с решением об отказе.  11а.2 Система направляет выписку кандидату и фиксирует факт направления.  11а.3 Система передает документы кандидата на архивное хранение.  11а.4 При поступлении письменного заявления сотрудник отдела кадров возвращает кандидату представленные документы.  11а.5 Процесс завершается с результатом «Кандидату отказано во включении в кадровый резерв». |

| **№ шага процесса** | 22, 44–51 |
| **Выполняемая задача** | Оформление включения сотрудника или кандидата в кадровый резерв, направление приказа, размещение сведений и последующее сопровождение и актуализация кадрового резерва. |
| **Цель** | Юридически оформить включение лиц в кадровый резерв и обеспечить его дальнейшее ведение и актуализацию. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участники: Председатель/заместитель председателя; Система. |
| **Ожидаемый результат** | Принят приказ о включении в кадровый резерв, его копия направлена включенному лицу, сведения размещены на предусмотренных ресурсах, а кадровый резерв сопровождается и периодически актуализируется. |
| **Рекомендованная функциональность** | Формирование списка лиц для включения; объединение конкурсной и бесконкурсной ветвей; вызов ОБП37 для принятия приказа; автоматическое направление копии приказа; добавление приказа в личное дело сотрудника; публикация сведений о включенных лицах; ведение сведений о сопровождении резервистов; контроль периодического пересмотра кадрового резерва. |
| **Критичность** | Необходимая. |
| **Триггер** | Получено указание председателя о включении сотрудника без конкурса либо по результатам конкурса сформирован список кандидатов, рекомендованных к включению и давших согласие. |
| **Предварительные условия** | Имеются материалы для оформления включения в кадровый резерв: указание председателя либо решения конкурсной комиссии и согласия кандидатов. |
| **Основной сценарий** | 1. Сотрудник отдела кадров формирует список лиц, подлежащих включению в кадровый резерв по результатам конкурса.  2. Материалы конкурсной ветви объединяются с указанием председателя о включении сотрудника без конкурса, если такая ветвь имеется.  3. Председатель/заместитель председателя инициирует ОБП37 «Принять приказ по кадровому вопросу».  4. По результатам ОБП37 принимается приказ о включении лиц в кадровый резерв.  5. Система направляет копию приказа сотруднику или гражданину, включенному в кадровый резерв.  6. Для сотрудника суда Система автоматически добавляет приказ в его личное дело.  7. Система размещает предусмотренные сведения о сотрудниках и гражданах, включенных в кадровый резерв.  8. Сотрудник отдела кадров осуществляет сопровождение резервистов.  9. Сотрудник отдела кадров периодически пересматривает и при необходимости дополняет кадровый резерв.  10. Процесс завершается с результатом «Кадровый резерв сформирован». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
