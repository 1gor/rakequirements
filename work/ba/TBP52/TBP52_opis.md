# [To be] ТБП52. Рассмотреть вопрос об исправлении ошибок

| **Наименование процесса** | ТБП52: Рассмотреть вопрос об исправлении ошибок |
| --- | --- |
| **Суть процесса** | Процесс инициирует необходимость рассмотрения вопроса об исправлении описки, опечатки, арифметической ошибки, которая может возникнуть либо по инициативе суда, либо по поступившему заявлению от стороны. Сперва судья производит проверку самого наличия описки, опечатки, арифметической ошибки в судебном акте. Если таковые были найдены, судья проверяет, повлияет ли внесение корректив на существо решения - в том случае, если исправление ошибок напрямую повлияет на решение, изложенное в судебном акте, судья: а) либо просто завершает процесс, если он был инициирован непосредственно судом; б) приходит к выводу о необходимости вынесения определения об отказе в удовлетворении заявления стороны. Если внесение корректив не повлияет на существо решения, судья делает вывод о необходимости вынесения определение об исправлении описок, опечаток, арифметических ошибок, после чего процесс завершается. |
| **Участники процесса** | Судья |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026), статья 179. |

# **3. Реестр UC**

**UC001 — Проверка оснований рассмотрения вопроса**

| **№ шага процесса** | 0-4 |
| --- | --- |
| **Выполняемая задача** | Выполнить проверку оснований для исправления ошибок в судебном акте |
| **Цель** | Выявить наличие арифметической ошибки, описки или опечатки в судебном акте |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе сформированы отметки о наличии либо отсутствии арифметической ошибки и описки/опечатки, а также создан и сохранён протокол проверки |
| **Рекомендуемая функциональность** | Отображение и сохранение отметок о результатах проверки ошибок и создание протокола проверки |
| **Критичность** | Необходимая |
| **Триггер** | Судья инициирует проверку оснований рассмотрения вопроса |
| **Предварительные условия** | В Системе зарегистрировано решение о рассмотрении вопроса об исправлении ошибок |
| **Основной сценарий** | 1. Система проверяет наличие арифметической ошибки в судебном акте  2. Система проверяет наличие описки/опечатки в судебном акте  3. Система формирует протокол проверки  4. Судья подтверждает выводы системы. |
| **Расширение (альтернативный сценарий)** | 3а. Судья вносит коррективы в протокол проверки.  Далее - шаг 4. |
