## 4. Пользователи и роли

|  |  |
| --- | --- |
|  |  |
| Роль | Описание |
| Лицо ответственное за межведомственный документооборот | Регистрация входящих/исходящих документов, направление документов |
| Начальник отдела кадров | Формирование документов |
| Председатель суда | Согласование, постановка задач, контроль правильности составления документов, подписание документов |
| Система | Система автоматически регистрирует входящий документ при получении запроса от СД при ВС РФ, извлекает метаданные и сохраняет в базу данных, назначает ответственную группу лиц для принятия документа в порядке очереди обращений или согласно нагрузке, уведомляет выбранных пользователей об их назначении, изменяет статус сущности после подписания председателем суда |
