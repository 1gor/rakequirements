## ****3. Реестр UC****

**UC001 — Подготовить проект штатного расписания**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–8 |
| **Выполняемая задача** | Регистрация поступившего запроса Судебного департамента при Верховном Суде РФ, назначение ответственного лица и подготовка проекта штатного расписания. |
| **Цель** | Обеспечить прием и обработку запроса на формирование штатного расписания и подготовить проект документа на будущий год для рассмотрения председателем суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Начальник отдела кадров. Участники: Лицо ответственное за межведомственный документооборот; Председатель суда; Система. |
| **Ожидаемый результат** | Запрос зарегистрирован и передан председателю суда, ответственное лицо определено и уведомлено, проект штатного расписания сформирован и направлен председателю суда. |
| **Рекомендованная функциональность** | Автоматическая регистрация входящего документа; вызов ТБП106 для передачи документа; фиксация ответственного лица; автоматическое уведомление исполнителя; создание и хранение проекта штатного расписания; передача проекта председателю суда. |
| **Критичность** | Необходимая. |
| **Триггер** | Поступил запрос от Судебного департамента при Верховном Суде РФ на формирование штатного расписания. |
| **Предварительные условия** | Запрос поступил в электронный контур суда; доступны сведения, необходимые для подготовки штатного расписания на будущий год. |

Председатель суда определяет ответственное лицо за подготовку проекта штатного расписания.  5. **UC003 — Направить штатное расписание в СД при ВС РФ**

|  |  |
| --- | --- |
| **№ шага процесса** | 14–24 |
| **Выполняемая задача** | Регистрация исходящего письма и направление подписанного штатного расписания в Судебный департамент при Верховном Суде РФ выбранным способом с фиксацией доставки. |
| **Цель** | Обеспечить официальное направление подписанного штатного расписания адресату по требуемому каналу связи. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Лицо ответственное за межведомственный документооборот. |
| **Ожидаемый результат** | Исходящее письмо зарегистрировано, штатное расписание направлено в СД при ВС РФ фельдъегерской связью, через систему ведомственного документооборота либо по электронной почте; при электронных способах получено подтверждение доставки. |
| **Рекомендованная функциональность** | Регистрация исходящего письма; выбор одного или нескольких способов направления; фиксация подготовки бумажного экземпляра; отправка через систему ведомственного документооборота или электронную почту; хранение квитанции или отчета о доставке; фиксация результата направления. |
| **Критичность** | Необходимая. |
| **Триггер** | Подписанное штатное расписание передано лицу, ответственному за межведомственный документооборот. |
| **Предварительные условия** | Штатное расписание подписано председателем суда; определен адресат — Судебный департамент при Верховном Суде РФ. |
| **Основной сценарий** | 1. Лицо ответственное за межведомственный документооборот регистрирует исходящее письмо для направления штатного расписания.  2. Ответственное лицо определяет требуемый способ или способы направления документа.  3. При направлении через систему ведомственного документооборота ответственное лицо отправляет штатное расписание по соответствующему каналу.  4. Ответственное лицо получает квитанцию о доставке документа.  5. Процесс завершается с результатом «Штатное расписание направлено в СД при ВС РФ по системе ведомственного документооборота». |
| **Расширение (альтернативный сценарий)** | 3а. Требуется направление фельдъегерской связью.  3а.1 Ответственное лицо распечатывает документы.  3а.2 Ответственное лицо передает подготовленные документы для доставки фельдъегерской связью.  3а.3 Процесс завершается с результатом «Штатное расписание направлено в СД при ВС РФ фельдъегерской связью».  3б. Требуется направление по электронной почте.  3б.1 Ответственное лицо направляет штатное расписание по электронной почте.  3б.2 Ответственное лицо получает отчет о доставке сообщения.  3б.3 Процесс завершается с результатом «Штатное расписание направлено в СД при ВС РФ по электронной почте». |
