# [To be] ТБП30. Рассмотреть вопрос о дополнительном решении

| **Наименование процесса** | ТБП30:Рассмотреть вопрос о дополнительном решении |
| --- | --- |
| **Суть процесса** | Процесс направлен на устранение неполноты ранее принятого судебного решения в случаях, предусмотренных ст. 178 АПК РФ и начинается с поступления заявления стороны о принятии дополнительного решения, либо если в процессе производства судья пришел к выводу о необходимости принятия дополнительного решения до вступления основного решения в законную силу. В рамках процесса судья назначает судебное заседание, извещает лиц, участвующих в деле, и проводит его. При рассмотрении проверяются основания для вынесения дополнительного решения. По результатам рассмотрения суд выносит дополнительное решение либо определение об отказе в его принятии. Процесс завершается направлением соответствующего судебного акта лицам, участвующим в деле. |
| **Участники процесса** | Судья, Помощник судьи |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ, статья 178 "Дополнительное решение арбитражного суда"  Постановление Пленума ВАС РФ от 17.02.2011 N 12 (ред. от 27.06.2017) "О некоторых вопросах применения Арбитражного процессуального кодекса Российской Федерации в редакции Федерального закона от 27.07.2010 N 228-ФЗ "О внесении изменений в Арбитражный процессуальный кодекс Российской Федерации"  Постановление Пленума Верховного Суда РФ от 18.04.2017 N 10 (ред. от 05.04.2022) "О некоторых вопросах применения судами положений Гражданского процессуального кодекса Российской Федерации и Арбитражного процессуального кодекса Российской Федерации об упрощенном производстве" |

# **3. Реестр UC**

**UC001 — Автоматические проверки по вопросу возможности вынесения дополнительного решения**

| **№ шага процесса** | 4-13 |
| --- | --- |
| **Выполняемая задача** | Выполнить автоматические проверки по вопросу возможности вынесения дополнительного решения. |
| **Цель** | Определить наличие оснований для вынесения дополнительного решения. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе создан и сохранен протокол проверки оснований для вынесения дополнительного решения. |
| **Рекомендуемая функциональность** | Автоматическая проверка статуса вступления в законную силу, наличие решения по требованию, наличие оснований по судебным расходам, проверка указания суммы, обязанности ответчика и имущества, подлежащего передаче, с сохранением результатов в карточке дела и формированием протокола. |
| **Критичность** | Необходимая |
| **Триггер** | Судья запуск автоматических проверок по вопросу возможности вынесения дополнительного решения |
| **Предварительные условия** | В Системе доступны реквизиты дела, первичный судебный акт и сведения, необходимые для проверок, включая материалы о судебных расходах и требования. |
| **Основной сценарий** | 1. Судья запускает автоматические проверки по вопросу возможности вынесения дополнительного решения.  2. Система отображает результат проверку вступления в законную силу первичного судебного акта и отображает в карточке дела статус «СА вступил в законную силу» либо «СА не вступил в законную силу» с указанием даты при наличии.  3. Система отображает результат проверку отсутствия решения по требованию и отображает в карточке дела признак «отсутствует решение по требованию» (истина/ложь) с указанием соответствующих судебных актов/требований.  4. Система отображает результат проверку необходимости решения вопроса о судебных расходах и отображает в карточке дела признак «не разрешен вопрос о судебных расходах» (истина/ложь) с указанием наличия сведений о разрешении по ст.112 АПК РФ.  5. Система отображает результат проверки наличия размера денежной суммы и отображает в карточке дела признак «размер денежной суммы не указан» (истина/ложь) с привязкой к требованию и реквизитам судебного акта.  6. Система отображает результат проверки наличия обязанности в отношении ответчика и отображает признак наличия/отсутствия обязанности ответчика, подлежащей указанию в дополнительном решении.  7. Система отображает результат проверку указания подлежащего передаче имущества и отображает вывод о наличии/отсутствии указания подлежащего передаче имущества в судебном акте.  8. Система формирует протокол проверки оснований для вынесения дополнительного решения.  9. Судья принимает итоговое решение. |
