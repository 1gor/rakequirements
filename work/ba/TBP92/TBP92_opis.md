# [To be] ТБП92. Вернуть из архива

| **Наименование процесса** | ТБП92 — Вернуть из архива |
| --- | --- |
| **Суть процесса** | Процесс описывает возврат электронного дела из архивного состояния для дальнейшей работы. Процесс начинается при возникновении одного из предусмотренных оснований для получения ранее архивированного дела. Система формирует электронную заявку на возвращение дела и по сведениям ПК САД проверяет факт его уничтожения. Если дело уничтожено, Система уведомляет об этом сотрудника суда; сотрудник определяет необходимость получения копии акта об уничтожении, и при необходимости Система предоставляет электронную копию ранее зарегистрированного акта. Если дело не уничтожено, электронная заявка оформляется и подписывается в ТБП49 «Сформировать и подписать документ», после чего Система выполняет поиск электронного архивного дела и формирует отчет по результатам поиска. Результат передается в ТБП139 «Проверить выводы системы», в рамках которого пользователь подтверждает вывод Системы либо при необходимости корректирует его. После завершения ТБП139 в процесс возвращается проверенный результат поиска. На его основании Система возвращает электронное дело из архивного состояния путем изменения статуса с «В архиве» на «Возвращено из архива» и уведомляет инициатора запроса. Физическая выемка и передача бумажного дела в TO BE не выполняются. |
| **Участники процесса** | Судья / Председатель судебного состава / Председатель суда; Сотрудник суда, запрашивающий дело из архива; Сотрудник отдела архивации |
| **НПА** | Постановление Пленума ВАС РФ от 25.12.2013 № 100 «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)» |

**UC001 — Поиск электронного архивного дела и возврат из архивного состояния**

| **№ шага процесса** | 11–15 |
| --- | --- |
| **Выполняемая задача** | Получить результат автоматического поиска электронного архивного дела и выполнить предусмотренную ТБП139 проверку результата перед возвратом дела из архивного состояния. |
| **Цель** | Обеспечить использование проверенного результата автоматического поиска перед возвратом электронного дела из архивного состояния. |
| **Роль / Актор** | Сотрудник отдела архивации |

| **Рекомендуемая функциональность** | Автоматический поиск электронного архивного дела по данным заявки; формирование отчета по результатам поиска; передача отчета в ТБП139 «Проверить выводы системы»; использование проверенного результата для возврата электронного дела из архивного состояния. |

| **Триггер** | Сформирована и подписана электронная заявка на возвращение дела. |
| **Предварительные условия** | Электронная заявка на возвращение дела сформирована и подписана; по результатам проверки дело не признано уничтоженным. |
| **Основной сценарий** | 1. Система уведомляет сотрудника отдела архивации о необходимости возврата электронного дела из архива.  2. Система выполняет автоматический поиск электронного архивного дела по данным заявки.  3. Система формирует отчет по результатам поиска.  4. Выполняется ТБП139 «Проверить выводы системы». После его завершения в ТБП92 возвращается подтвержденный либо скорректированный результат поиска.  5. На основании проверенного результата Система возвращает электронное дело из архивного состояния, изменяя статус с «В архиве» на «Возвращено из архива». |
| **Расширение (альтернативный сценарий)** | 4a. Если в рамках ТБП139 выявлена ошибка автоматического результата поиска, сотрудник отдела архивации корректирует результат в предусмотренном ТБП139 порядке.
