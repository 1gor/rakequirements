UC-002: Процессуальный срок совершенного действия/наступившего события

|  |  |
| --- | --- |
| **Поле** | **Описание** |
| № шага процесса | 8-19 |
| Выполняемая задача | Проверить процессуальный срок совершенного действия или наступившего процессуального события. |
| Цель | Установить, соблюден или нарушен процессуальный срок по уже совершенному процессуальному действию или наступившему событию, зафиксировать соответствующий вывод в Системе и уведомить пользователя о результате проверки. |
| Роль/Актор (в соответствии со схемой) | Судья / сотрудник суда. |
| Ожидаемый результат | В Системе зафиксирован статус соблюдения или нарушения процессуального срока. Вывод Системы проверен и подтвержден судьей/сотрудником суда. |
| Рекомендованная функциональность | Автоматический расчет даты начала, даты окончания и продолжительности процессуального срока. Учет даты события-основания, фактической даты совершения действия / наступления события, применимых норм АПК РФ, нерабочих праздничных дней и особенностей исчисления сроков. Автоматическое сравнение фактической даты с рассчитанной датой окончания срока. Автоматическая фиксация статуса: срок соблюден / срок нарушен. Сохранение результата проверки в карточке дела. Направление уведомления пользователю о результате проверки. Возможность пользовательской проверки, корректировки и подтверждения вывода Системы. Поддержка ручного ввода данных для расчета срока, если автоматический расчет требует дополнительных сведений. |
| Критичность\* | Необходимая. |
| Триггер | В Системе зарегистрировано совершенное процессуальное действие, наступившее процессуальное событие или поступивший процессуальный документ, по которому требуется установить соблюдение или нарушение процессуального срока. |
| Предварительные условия | 1. В Системе зарегистрировано процессуальное действие, событие или поступивший процессуальный документ.  2. Система определила, что проверяется срок совершенного действия / наступившего события.  3. Для соответствующего процессуального срока доступны применимые правила расчета по закону.  5. Пользователь имеет полномочия на проверку и подтверждение выводов Системы. |
| Основной сценарий | 1. Система выполняет автоматический расчет процессуального срока.  2. Система сравнивает фактическую дату совершения процессуального действия / наступления события с рассчитанной датой процессуального срока.  3. Система определяет, что процессуальный срок нарушен 4. Система направляет судье/сотруднику суда уведомление о результате проверки срока.  5. Судья/сотруднику суда подтверждает вывод Системы.  6. Система присваивает сроку статус «Нарушен». |
| Расширение (альтернативный сценарий) | 1а Система не может однозначно определить дату-основание/применимые нормы закона. 1а.1 Система выводит форму для заполнения необходимых полей. 1а.2 Судья/сотрудник судья вводит необходимые данные. 1а.3 Система выполняет расчет на основании введенных данных. 1а.4 Процесс продолжается с шага 4 основного сценария.  3а. Система определяет, что процессуальный срок соблюден 3а3 Система присваивает сроку статус «Соблюден» |
