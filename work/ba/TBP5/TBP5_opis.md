| **Наименование процесса** | ТБП5:Проверить срок |
| **Суть процесса** | Процесс направлен на контроль соблюдения процессуальных и плановых сроков в арбитражном судопроизводстве и начинается с возникновения у сотрудника суда необходимости проверить срок совершения процессуального либо планового действия. Основанием может являться поступление документа, подготовка судебного акта, контроль исполнения поручения или иное процессуальное событие. В рамках процесса определяется вид проверяемого срока (процессуальный или плановый), после чего выбирается способ проверки: автоматически через информационную систему суда либо вручную. Процесс завершается фиксацией результата проверки. |
| **Участники процесса** | Судья, Сотрудник суда |

| Цель | Установить факт соблюдения или нарушения процессуального срока по уже совершенному процессуальному действию или наступившему событию, подтвердить вывод системы пользователем и получить актуальный статусы. |
| Роль / Актор | Судья/сотрудник суда. |
| Ожидаемый результат | В карточке дела зафиксирован подтвержденный пользователем вывод о соблюдении или нарушении процессуального срока совершенного действия или наступившего события, а также установлен соответствующий статус проверки и дата проверки. |
| Рекомендованная функциональность | Отображение фактической даты совершения действия или наступления события из справочника событий,  отображение рассчитанного процессуального срока, автоматический вывод системы о соблюдении/нарушении срока, отображение основания расчета и результата сравнения, интерфейс для обязательного подтверждения вывода пользователем и фиксации результата в карточке дела, калькулятор процессуальных сроков, справочник статусов процессуальных сроков. |
| Критичность | Необходимая. |
| Триггер | Внешняя система направляет уведомление о необходимости проверки на соблюдение процессуального срока. |
| Предварительные условия | Открыта карточка дела. В системе содержатся сведения о фактической дате совершения процессуального действия или наступления события. Процессуальный срок для проверки рассчитан системой для всех событий данного дела и доступен для отображения в карточке дела. |
| Основной сценарий | 1.Пользватель открывает уведомление.  1.Система открывает форму со списком с фактическую датой совершенного процессуального действия или наступления события и рассчитанным процессуальным сроком.  3.Система отображает вывод о соблюдении /нарушении процессуального срока.  4.Судья/Сотрудник суда подтверждает вывод системы в форме. 5. Система устанавливает статус проверки процессуального срока. |

Система записывает статус «Процессуальный срок соблюден».  7б. По результату проверки и подтверждения установлен факт нарушения процессуального срока для действия/события. 7б.1.
