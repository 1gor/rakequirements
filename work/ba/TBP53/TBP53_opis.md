| **Наименование процесса** | ТБП53.Принять входящий документ |
| **Суть процесса** | Процеcс регламентирует автоматизированную обработку входящего документа в суде: от первичной регистрации и проверки формальных требований (валидации) до принятия решения о его статусе (отклонение, пересылка по подсудности или принятие). Успешно прошедшие проверку документы регистрируются в системе и распределяются конкретному судье с фиксацией факта передачи в электронном реестре. |
| **Участники процесса** | Сотрудник канцелярии, ответственный за распределение, судья/помощник судьи/секретарь СЗ/специалист судебного состава/председатель/заместитель председателя |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025)  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)  Приказ Судебного департамента при Верховном Суде РФ от 28.12.2016 N 252 (ред. от 20.02.2018) "Об утверждении Порядка подачи в арбитражные суды Российской Федерации документов в электронном виде, в том числе в форме электронного документа" (вместе с "Порядком подачи в арбитражные суды Российской Федерации документов в электронном виде, в том числе в форме электронного документа")  Постановление Пленума Верховного Суда РФ от 26.12.2017 N 57 "О некоторых вопросах применения законодательства, регулирующего использование документов в электронном виде в деятельности судов общей юрисдикции и арбитражных судов" |

UC-006 Распределить дело и зафиксировать передачу судье

|  |  |
| --- | --- |
| Поле | Содержание |
| Выполняемая задача | Распределить зарегистрированное дело на судью и зафиксировать передачу дела судье в электронном реестре. |
| Цель | Назначить судью для рассмотрения дела и зафиксировать передачу дела судье. |
| Роль / Актор | Сотрудник, ответственный за распределение. |
| Ожидаемый результат | Дело распределено на судью, в карточке дела отображается статус «Распределен», в электронном реестре сохранена запись о передаче судье. |
| Рекомендованная функциональность | Отображение списка дел, поступивших на распределение.  Открытие карточки зарегистрированного дела.  Действие «Распределить дело».  Сохранение результата распределения в системе.  Автоматическое изменение статуса карточки дела на «Распределен».  Автоматическое создание записи о передаче судье в электронном реестре.  Автоматическое добавление ссылки на карточку дела в запись реестра.  Фиксация даты, времени и участника передачи.  Логирование действий пользователя и системных изменений. |
| Критичность | необходимая |
| Триггер | Сотрудник, ответственный за распределение, открывает дело, поступившее на распределение. |
| Предварительные условия | Дело зарегистрировано в системе.  В карточке дела отображается статус «Зарегистрирован».  В системе имеется запись о передаче дела на распределение.  Сотрудник, ответственный за распределение, авторизован в системе.  Сотрудник, ответственный за распределение, имеет права на выполнение распределения.  Электронный реестр передачи доступен в системе. |
| Основной сценарий | 1. Сотрудник, ответственный за распределение, открывает список дел, поступивших на распределение.  2. Система отображает список дел, поступивших на распределение.  3. Сотрудник, ответственный за распределение, открывает карточку зарегистрированного дела.  4. Система отображает карточку дела со статусом «Зарегистрирован».  5. Сотрудник, ответственный за распределение, нажимает кнопку «Распределить дело».  6. Система отображает результат распределения с указанием назначенного судьи.  7. Система отображает в карточке дела статус «Распределен».  8. Система создает запись о передаче судье в электронном реестре.  9. Система отображает в записи электронного реестра ссылку на карточку дела. |
| Альтернативные сценарии | 3а. Карточка дела недоступна для открытия.  3а1. Система отображает сообщение о невозможности открыть карточку дела.  3а2. Сотрудник, ответственный за распределение, возвращается к списку дел.    5а. Система не выполнила распределение дела.  5а1. Система отображает сообщение об ошибке распределения.  5а2. Сотрудник, ответственный за распределение, повторно нажимает кнопку «Распределить дело».    6а. Система не отобразила назначенного судью.  6а1. Система отображает сообщение о невозможности завершить распределение.  6а2. Сотрудник, ответственный за распределение, закрывает карточку дела без сохранения результата.    8а. Система не создала запись о передаче в электронном реестре.  8а1. Система отображает сообщение об ошибке создания записи в реестре.  8а2. Сотрудник, ответственный за распределение, повторно нажимает кнопку «Распределить дело». |
