|  |  |
| --- | --- |
| **Наименование процесса** | ТБП90:Рассмотреть вопрос о разъяснении СА |
| **Суть процесса** | Процесс начинается с возникновения необходимости разъяснить судебный акт. Такая необходимость может возникнуть в связи с поступлением в суд соответствующего ходатайства. Судья осуществляет две проверки: проверяет, приведено ли решение в исполнение, а также проверяет, не истек ли срок принудительного исполнения. Если решение еще не было исполнено и срок не истек, судья принимает определение о разъяснении СА; если же решение уже исполнено/срок принудительного исполнения истек - судья принимает определение об отказе в удовлетворении ходатайства. Принятое определение направляется ЛУВД/Приставу-исполнителю/Иному лицу, после чего процесс завершается. |
| **Участники процесса** | Судья, канцелярия, ЛУВД |
