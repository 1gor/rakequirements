|  |  |
| --- | --- |
| **Наименование процесса** | ОБП11. Формирование почтовой отправки (одновременный вывод пакетной печати конвертов, уведомлений) внутри каждой функциональной директории. Формирование почтовых реестров по форме 103 Ф внутри каждой функциональной директории |
| **Суть процесса** | Процесс обеспечивает подготовку и направление выбранного документа или вынесенного судебного акта по предусмотренным каналам: в личный кабинет пользователя, через специальную интеграцию с государственными органами, по факсу, телеграммой, телефонограммой, гибридной почтой и по электронной почте.
