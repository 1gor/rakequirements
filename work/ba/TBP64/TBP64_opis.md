# [To be] ТБП64. Рассмотреть вопрос о прекращении производства по делу

| **Наименование процесса** | ТБП64. Рассмотреть вопрос о прекращении производства по делу |
| --- | --- |
| **Суть процесса** | Процесс предназначен для рассмотрения вопроса о прекращении производства по делу. Система выполняет автоматические проверки отдельных оснований прекращения производства, формирует протокол проверки, после чего судья проверяет выводы Системы, при необходимости указывает иные обстоятельства, предусмотренные законом, и фиксирует решение о наличии либо отсутствии оснований для прекращения. При наличии оснований последовательно решаются вопросы о возврате государственной пошлины и распределении судебных расходов, проводится контроль полноты рассмотрения ходатайств и заявлений и принимается судебный акт. Отдельная событийная ветвь применяется при поступлении документов, свидетельствующих о намерении сторон примириться: определяется вид документа, судья выполняет предусмотренные проверки и решает вопрос об утверждении соглашения. При отсутствии оснований дело продолжает рассматриваться; при прекращении производства фиксируется соответствующий статус дела. |
| **Участники процесса** | Судья; ЛУВД; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): ст. 48, п. 1 ч. 1 ст. 127.1, ст. 138–141, 150–151; Налоговый кодекс Российской Федерации (часть вторая) от 05.08.2000 N 117-ФЗ (ред. от 04.08.2026, с изм. и доп., вступ. в силу с 01.10.2026): ст. 333.40; Федеральный закон от 27.07.2010 N 193-ФЗ «Об альтернативной процедуре урегулирования споров с участием посредника (процедуре медиации)» (ред. от 26.07.2019). |

# 3.Реестр UC **UC001 — Фиксация решения о наличии или отсутствии оснований для прекращения производства**

| **№ шага процесса** | 33–38 |
| --- | --- |
| **Выполняемая задача** | При необходимости указать иные обстоятельства прекращения производства по делу и зафиксировать итоговое решение о наличии либо отсутствии оснований для прекращения производства. |
| **Цель** | Зафиксировать процессуальный вывод судьи по вопросу прекращения производства по делу на основании проверенных результатов и иных обстоятельств, предусмотренных законом. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксировано решение судьи о наличии либо отсутствии оснований для прекращения производства по делу; указанные судьёй иные обстоятельства, если они были внесены, учтены в зафиксированном результате. |
| **Рекомендуемая функциональность** | Просмотр проверенных результатов по делу; ввод иных обстоятельств, предусмотренных законом; фиксация решения о наличии либо отсутствии оснований для прекращения производства; просмотр зафиксированного результата. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступает к фиксации итогового решения после завершения проверки выводов Системы. |
| **Предварительные условия** | Судье доступны проверенные результаты по делу; проверка выводов Системы завершена. |
| **Основной сценарий** | 1. Судья открывает проверенные результаты по делу.  2. Система отображает результаты проверок, доступные для принятия решения.  3. Судья фиксирует решение о наличии оснований для прекращения производства по делу.  4. Система отображает зафиксированное решение. |
| **Расширение (альтернативный сценарий)** | 2а. Судья указывает иные обстоятельства прекращения производства по делу, предусмотренные законом.  2а1. Система отображает внесённые обстоятельства в составе данных, используемых для принятия решения.  2а2. Выполнение продолжается с шага 3 основного сценария.  3а. Судья фиксирует решение об отсутствии оснований для прекращения производства по делу.  3а1. Система отображает зафиксированное решение об отсутствии оснований; дело продолжает рассматриваться. |

| **№ шага процесса** | 54–61 |
| --- | --- |

Судья фиксирует результат проверки соглашения о примирении на соответствие требованиям закона.  2б2. Судья фиксирует вывод о соблюдении прав и законных интересов третьих лиц.  2б3. **UC003 — Принятие решения об утверждении соглашения**
