## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья | Проводит комплексные проверки документа (подсудность, срок, полномочия, форма/подпись/ЭП, право на подачу, госпошлина, тождественность дел, досудебный порядок, специальные проверки для жалоб и банкротных кейсов), принимает судебные акты |
| Помощник судьи / секретарь судебного заседания | Проверяет статус, готовит проекты документов, обеспечивает оформление и организацию направления |
| Канцелярия | Формирует сопроводительные письма, собирает и направляет комплект документов, фиксирует отправку |
| Заявитель | Получает судебные акты, принимает решение об обжаловании либо о повторной подаче |
| Система | Система проводит проверки, формирует отчет о проведенных проверках, информирует судью, формирует документы по шаблону, фиксирует ошибки анализа для технической поддержки, отправляет документы заявителю, рассчитывает сроки, фиксирует данные о ознакомлении в системе арбитражного суда. |
