# [To be] ТБП136. Провести ВКС

| **Наименование процесса** | ТБП136 — Провести ВКС |
| --- | --- |
| **Суть процесса** | Процесс предназначен для организации и проведения судебного заседания с использованием видеоконференц-связи во взаимодействии суда, рассматривающего дело, и суда, содействующего проведению заседания. После наступления запланированных даты и времени выполняются установление соединения и технические проверки с возможностью передачи неисправностей в техническую поддержку. При технической готовности участники судов переходят к проведению заседания: содействующий суд организует видеозапись и фиксацию хода ВКС, а судьи получают сведения о явке и определяют возможность продолжения заседания. При успешном проведении запись завершается, оформляется протокол и прекращается соединение; при неустраненных технических неисправностях либо необеспеченной явке соответствующая ветвь завершается с фиксацией причины несостоявшейся ВКС. |
| **Участники процесса** | Судья суда, рассматривающего дело; Секретарь судебного заседания суда, рассматривающего дело; Судья суда, содействующего проведению СЗ путем использования ВКС; Секретарь судебного заседания суда, содействующего проведению СЗ путем использования ВКС; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026), в том числе ст. 73, 74, 153.1, 155.  Постановление Пленума ВАС РФ от 17.02.2011 № 12 (ред. от 27.06.2017) «О некоторых вопросах применения Арбитражного процессуального кодекса Российской Федерации в редакции Федерального закона от 27.07.2010 № 228-ФЗ», в том числе п. 23–28. |

# **3. Реестр UC**

**UC001 — установка соединение с содействующим судом**

| **№ шага процесса** | 1-5 |
| --- | --- |
| **Выполняемая задача** | Установить телефонный контакт с содействующим судом, затем проверить готовность к видеоконференц-связи. |
| **Цель** | Обеспечить техническую возможность участия в судебном заседании с использованием видеоконференц-связи. |
| **Роль / Актор** | Судья, Секретарь с/з |
| **Ожидаемый результат** | В материалах судебного заседания отражены объявление о проведении судебного заседания с ВКС, факт телефонного обращения, принятие звонка и результат проверки соединения. |
| **Рекомендованная функциональность** | Отражение сведений о проведении судебного заседания с использованием видеоконференц-связи; регистрация телефонных обращений и результатов проверки соединения. |
| **Критичность** | Необходимая |
| **Триггер** | Судья объявляет о проведении судебного заседания с использованием видеоконференц-связи. |
| **Предварительные условия** | Судья объявляет о проведении судебного заседания с использованием видеоконференц-связи. |
| **Основной сценарий** | 1. Судья делает объявление о проведении судебного заседания с использованием видеоконференц-связи.  2. Система отражает объявление о проведении судебного заседания с использованием видеоконференц-связи в материалах судебного заседания.  3. Секретарь с/з инициирует телефонный звонок в содействующий суд.  4. Система сохраняет факт телефонного обращения в содействующий суд для организации видеоконференц-связи в материалах дела.  5. Секретарь с/з отвечает на телефонный звонок.  6. Система сохраняет отметку о принятии телефонного звонка и инициировании подготовки к проверке соединения и оборудования для ВКС в материалах заседания.  7. Секретарь с/з проверяет, установлено ли соединение, и исправна ли аппаратура для видеоконференц-связи.  8. Система отображает результат проверки соединения и работоспособности оборудования в материалах подготовки ВКС. |

**UC002 — проверка технической возможности проведения ВКС**

| **№ шага процесса** | 7-20 |
| --- | --- |
| **Выполняемая задача** | Проверить техническую возможность проведения ВКС и при выявлении неисправностей организовать их передачу в техническую поддержку. |
| **Цель** | Подтвердить техническую готовность соединения и аппаратуры обоих судов для проведения судебного заседания с использованием ВКС. |
| **Роль / Актор** | Секретарь судебного заседания суда, рассматривающего дело; Секретарь судебного заседания суда, содействующего проведению СЗ путем использования ВКС |
| **Ожидаемый результат** | Определено, может ли ВКС быть продолжена с учетом состояния соединения и аппаратуры; при наличии неисправностей зафиксирован результат их устранения. |
| **Рекомендуемая функциональность** | Отображение результата технической проверки; фиксация передачи выявленных неисправностей в техническую поддержку; отображение результата устранения неисправностей и дальнейшего маршрута. |
| **Критичность** | Необходимая |
| **Триггер** | Получен результат первичной проверки соединения и состояния аппаратуры для ВКС. |
| **Предварительные условия** | Установлен телефонный контакт между судами; выполнена первичная проверка соединения и состояния аппаратуры. |
| **Основной сценарий** | 1. Секретарь судебного заседания суда, рассматривающего дело, оценивает результат технической проверки.  2. При выявлении технической неисправности секретарь передает информацию в техническую поддержку и ожидает завершения работ.  3. После выполнения работ фиксируется результат устранения неисправности и определяется возможность продолжения ВКС.  4. Секретарь судебного заседания содействующего суда проверяет соединение  5. Система проверяет состояние аппаратуры.  6. При подтвержденной технической готовности  продолжается проведение ВКС. |
| **Расширение (альтернативный сценарий)** | Если технические неисправности не устранены  то  Система фиксирует невозможность  проведения ВКС либо исполнения судебного поручения по техническим причинам. |
