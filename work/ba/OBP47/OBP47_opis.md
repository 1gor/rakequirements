|  |  |
| --- | --- |
| **Наименование процесса** | ОБП47 — Регистрация, учет, хранение, списание в электронный архив, отправка и пр. по зарегистрированным внутри суда документов. |
| **Суть процесса** | Организация регистрации, рассмотрения, подготовки, согласования, направления, публикации и хранения служебных документов суда в электронном контуре с фиксацией маршрутов обработки и архивного хранения. |

## ****3. Реестр UC****

**UC001 — Зарегистрировать входящий документ и обработать поручение**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–17 |
| **Выполняемая задача** | Зарегистрировать поступивший служебный запрос или письмо, передать его председателю суда, назначить ответственного сотрудника, определить вид поручения и обработать информационное письмо. |
| **Цель** | Обеспечить регистрацию и маршрутизацию поступившего документа, доведение поручения до ответственного сотрудника и завершение ветви ознакомления с документом. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Лицо ответственное за межведомственный документооборот. Участники: Председатель суда; Сотрудник ответственный на основании поручения; Система. |
| **Ожидаемый результат** | Входящий документ зарегистрирован и передан председателю суда, ответственному сотруднику поставлена задача, вид поручения определен; при ветви ознакомления информация принята к сведению, а документ сохранен в номенклатурном деле. |
| **Рекомендованная функциональность** | Регистрация входящего документа; вызов ТБП106 «Передать документ»; постановка и закрытие задач на ознакомление; назначение ответственного сотрудника; фиксация вида поручения; вызов ОБП48 при необходимости изменения локального акта; сохранение документа в номенклатурном деле. |
| **Критичность** | Необходимая. |
| **Триггер** | В суд поступил служебный запрос или письмо либо возникла необходимость изготовить служебный документ. |
| **Предварительные условия** | Документ поступил в суд и доступен для регистрации; определено лицо, ответственное за межведомственный документооборот. |
| **Основной сценарий** | 1. Лицо ответственное за межведомственный документооборот регистрирует поступивший входящий документ.  2. Выполняется ТБП106 «Передать документ», в результате которого документ передается председателю суда.  3. Председатель суда знакомится с запросом или письмом.  4. Председатель суда определяет ответственного сотрудника для исполнения поручения.  5. Система ставит ответственному сотруднику задачу на ознакомление с запросом или поручением.  6. Сотрудник ответственный на основании поручения знакомится с запросом или письмом.  7. Сотрудник определяет вид поручения.  8. Для поручения «Ознакомиться с поступившим письмом» сотрудник учитывает содержащуюся в документе информацию в работе.  9. Сотрудник определяет необходимость изменения локального акта.  10. Если изменение локального акта не требуется, Система сохраняет документ в номенклатурное дело.  11. Ветка завершается результатом «Информационное письмо принято к сведению. Документ подшит в номенклатурное дело». |
| **Расширение (альтернативный сценарий)** | 7а. Вид поручения — «Подготовить ответ на запрос».  7а.1 Процесс продолжается по UC002.  7б. Вид поручения — «Подготовить служебный документ».  7б.1 Процесс продолжается по UC003.  10а. Для учета информации в работе требуется изменить локальный акт.  10а.1 Сотрудник инициирует ОБП48 «Принять локальный акт».  10а.2 После принятия локального акта процесс продолжается с сохранением документа в номенклатурное дело. |

**UC002 — Подготовить и направить ответ на запрос**

|  |  |
| --- | --- |
| **№ шага процесса** | 18–41 |
| **Выполняемая задача** | Подготовить ответ на поступивший запрос, проверить сформированные Системой материалы, определить необходимость направления, зарегистрировать исходящий документ и направить его выбранным способом. |
| **Цель** | Подготовить и направить адресату ответ на запрос с фиксацией его регистрации, доставки и хранения. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник ответственный на основании поручения. Участники: Председатель суда; Лицо ответственное за межведомственный документооборот; Система. |
| **Ожидаемый результат** | Ответ на запрос подготовлен; при необходимости направлен адресату фельдъегерской связью, по системе ведомственного документооборота или электронной почте; результат доставки зафиксирован, документ сохранен в номенклатурном деле. |
| **Рекомендованная функциональность** | Подготовка информации по запросу; вызов ТБП139 «Проверить выводы системы»; закрытие задачи по поручению; фиксация решения председателя суда о направлении документа; вызов ТБП106; регистрация исходящего письма; выбор способа отправки; получение квитанции или отчета о доставке; сохранение документа в номенклатурном деле. |
| **Критичность** | Необходимая. |
| **Триггер** | Ответственный сотрудник определил вид поручения «Подготовить ответ на запрос». |
| **Предварительные условия** | Входящий запрос зарегистрирован; председателем суда назначен ответственный сотрудник; сотрудник ознакомлен с поручением. |
| **Основной сценарий** | 1. Система обеспечивает подготовку информации по запросу.  2. Выполняется ТБП139 «Проверить выводы системы» для проверки сформированных материалов.  3. После подготовки документа Система закрывает задачу на ознакомление с запросом или поручением.  4. Председатель суда определяет необходимость направления подготовленного документа.  5. Если документ необходимо направить, выполняется ТБП106 «Передать документ».  6. Исходящее письмо регистрируется.  7. Лицо ответственное за межведомственный документооборот определяет способ направления документа.  8. При направлении по системе ведомственного документооборота Система передает документ адресату.  9. Система получает квитанцию о доставке.  10. Система сохраняет документ в номенклатурное дело.  11. Ветка завершается подтверждением направления ответа по системе ведомственного документооборота. |
| **Расширение (альтернативный сценарий)** | 4а. Председатель суда определяет, что документ направлять не требуется.  4а.1 Система определяет место хранения документа.  4а.2 Если документ хранится в секретариате председателя суда, Система сохраняет его в номенклатурное дело.  7а. Документ требуется направить фельдъегерской связью.  7а.1 Лицо ответственное за межведомственный документооборот передает документ для направления фельдъегерской связью.  7а.2 Ветка завершается результатом «Ответ на запрос направлен фельдъегерской связью».  7б. Документ требуется направить по электронной почте.  7б.1 Система направляет документ по электронной почте.  7б.2 Система получает отчет о доставке.  7б.3 Документ сохраняется в номенклатурное дело.  7б.4 Ветка завершается результатом «Ответ на запрос направлен по электронной почте». |

**UC003 — Подготовить и довести внутренний служебный документ**

|  |  |
| --- | --- |
| **№ шага процесса** | 20–77 |
| **Выполняемая задача** | Подготовить внутренний служебный документ единолично, рабочей группой или комиссией, зарегистрировать результат, определить необходимость публикации или передачи по компетенции и организовать хранение. |
| **Цель** | Обеспечить подготовку, принятие, доведение до заинтересованных сотрудников и хранение внутреннего служебного документа или рекомендаций рабочей группы. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник ответственный на основании поручения. Участники: Председатель суда; Рабочая группа; Комиссия; Руководитель структурного подразделения; Система. |
| **Ожидаемый результат** | Внутренний служебный документ или рекомендации подготовлены и зарегистрированы, при необходимости опубликованы либо переданы рабочей группе, комиссии или структурному подразделению, а документ сохранен в номенклатурном деле. |
| **Рекомендованная функциональность** | Фиксация состава участников подготовки документа; автоматизированный анализ документа; вызов ТБП49 для формирования и подписания документа; поддержка работы рабочей группы и комиссии; вызов ОБП48 при создании комиссии; регистрация рекомендаций и документов; публикация во внутренней системе; уведомление сотрудников; маршрутизация документа по компетенции; определение места хранения и сохранение в номенклатурном деле. |
| **Критичность** | Необходимая. |
| **Триггер** | Ответственный сотрудник определил вид поручения «Подготовить служебный документ». |
| **Предварительные условия** | Ответственный сотрудник назначен председателем суда и ознакомлен с поручением; определена задача подготовки служебного документа. |
| **Основной сценарий** | 1. Сотрудник ответственный на основании поручения определяет состав лиц для подготовки документа.  2. Для единоличной подготовки Система проводит анализ документа.  3. Сотрудник выполняет ТБП49 «Сформировать и подписать документ».  4. После подготовки документа Система закрывает задачу на ознакомление с запросом или поручением.  5. Председатель суда определяет необходимость направления документа и место его дальнейшего хранения.  6. После подготовки внутреннего документа сотрудник определяет необходимость его публикации во внутренней системе.  7. При необходимости публикации сотрудник публикует документ.  8. Система уведомляет сотрудников суда о публикации.  9. Система определяет место хранения документа и сохраняет его в номенклатурное дело.  10. Ветка завершается результатом «Рекомендации рабочей группы/служебный документ приняты и опубликованы. Сотрудники ознакомлены. Документ подшит в номенклатурное дело». |
| **Расширение (альтернативный сценарий)** | 2а. Документ подготавливается рабочей группой.  2а.1 Ответственный сотрудник включает вопрос в повестку заседания рабочей группы.  2а.2 Рабочая группа открывает заседание, заслушивает доклад и мнения членов группы.  2а.3 Рабочая группа принимает рекомендации, закрывает заседание и подписывает протокол.  2а.4 Система регистрирует рекомендации рабочей группы.  2б. Документ подготавливается комиссией.  2б.1 Определяется, создана ли необходимая комиссия в суде.  2б.2 Если комиссия не создана, определяется ее состав и инициируется ОБП48 «Принять локальный акт».  2б.3 Комиссия принимает служебный документ.  2б.4 Система регистрирует документ.  6а. Публикация документа не требуется.  6а.1 Ответственный сотрудник передает документ по компетенции.  6а.2 Если документ предназначен рабочей группе, Система сохраняет его в номенклатурное дело, после чего рабочая группа использует документ в работе.  6а.3 Если документ предназначен структурному подразделению, Система знакомит сотрудников подразделения с документом и сохраняет его в номенклатурное дело.  6а.4 Если документ предназначен комиссии, Система сохраняет его в номенклатурное дело, после чего комиссия использует документ в работе. |
