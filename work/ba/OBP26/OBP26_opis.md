|  |  |

## ****3. Реестр UC****

**UC001 — Назначить ответственного и организовать ознакомление сотрудников**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–5 |
| **Выполняемая задача** | Подготовка локального акта, назначение ответственного за проведение инструктажа, уведомление назначенного сотрудника и автоматическое формирование заданий на ознакомление с утвержденными в суде нормами. |
| **Цель** | Определить ответственное лицо за организацию ознакомления сотрудников и обеспечить доведение до сотрудников утвержденных в суде норм. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: председатель суда. Участники: сотрудник, ответственный за проведение инструктажа; Система. |
| **Ожидаемый результат** | Ответственный за проведение инструктажа назначен локальным актом, уведомлен о назначении и ознакомлен с ним; сотрудникам сформированы задания на ознакомление с утвержденными нормами. |
| **Рекомендованная функциональность** | Автоматическое формирование шаблона локального акта; фиксация назначенного ответственного; автоматическое уведомление назначенного сотрудника; автоматическое формирование заданий на ознакомление с утвержденными в суде нормами. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость организовать ознакомление сотрудников с утвержденными в суде санитарными нормами, правилами пожарной безопасности, охраны труда и техники безопасности, а также нормами надлежащей эксплуатации зданий, сооружений и помещений суда. |
| **Предварительные условия** | В суде утверждены нормы, с которыми необходимо ознакомить сотрудников; председатель суда имеет полномочия назначить ответственного за проведение инструктажа. |
| **Основной сценарий** | 1. Возникает необходимость организовать ознакомление сотрудников с утвержденными в суде нормами.  2. Система автоматически подготавливает шаблон локального акта о назначении ответственного за проведение инструктажа.  3. Председатель суда определяет ответственное лицо и оформляет его назначение локальным актом.  4. Система автоматически уведомляет назначенного сотрудника о возложении на него обязанностей по проведению инструктажа.  5. Назначенный сотрудник знакомится с локальным актом и своим назначением.  6. Система автоматически формирует сотрудникам задания на ознакомление с утвержденными в суде нормами. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

**UC002 — Проконтролировать ознакомление и зафиксировать его прохождение**

|  |  |
| --- | --- |
| **№ шага процесса** | 6–8 |
| **Выполняемая задача** | Контроль прохождения ознакомления сотрудниками суда, ознакомление с установленными нормами и фиксация факта ознакомления в электронном журнале. |
| **Цель** | Обеспечить прохождение сотрудниками обязательного ознакомления с установленными нормами и зафиксировать его результат. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: сотрудник, ответственный за проведение инструктажа. Участники: судьи, сотрудники суда; Система. |
| **Ожидаемый результат** | Судьи и сотрудники суда ознакомлены с установленными нормами, факт ознакомления зафиксирован в электронном журнале, инструктаж завершен. |
| **Рекомендованная функциональность** | Отображение статуса выполнения заданий на ознакомление; поддержка контроля прохождения ознакомления ответственным сотрудником; ведение электронного журнала ознакомления; фиксация факта ознакомления сотрудниками суда. |
| **Критичность** | Необходимая. |
| **Триггер** | Сотрудникам сформированы задания на ознакомление с утвержденными в суде нормами. |
| **Предварительные условия** | Назначен сотрудник, ответственный за проведение инструктажа; сотрудникам доступны утвержденные нормы и задания на ознакомление. |
| **Основной сценарий** | 1. Сотрудник, ответственный за проведение инструктажа, контролирует прохождение сотрудниками заданий на ознакомление.  2. Судьи и сотрудники суда знакомятся с доведенными до них нормами.  3. Судьи и сотрудники суда подтверждают факт ознакомления путем заполнения электронного журнала ознакомления.  4. Ответственный сотрудник контролирует завершение ознакомления сотрудниками суда.  5. После завершения ознакомления процесс заканчивается с результатом «Инструктаж проведен». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
