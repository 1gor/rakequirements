## \*\*\*\*4. Пользователи и роли\*\*\*\*

|  |  |
| --- | --- |
|  |  |
| Роль | Описание |
| Председатель суда | Назначает ответственного за проведение инструктажа. |
| Сотрудник, ответственный за проведение инструктажа | Ознакомляется с локальным актом о назначении ответственного лица.<br><br>Проводит инструктаж и обеспечивает ознакомление сотрудников с санитарными нормами, правилами пожарной безопасности, охране труда и техникой безопасности, нормами надлежащей эксплуатации зданий, сооружений и помещений суда. |
| Судьи, сотрудники суда | Проходят инструктаж и ставят подпись в журнал. |
| Система | Система подготавливает шаблон локального акта об утверждении ответственного за ознакомление сотрудников с санитарными нормами, правилами пожарной безопасности, охране труда и техникой безопасности, нормами надлежащей эксплуатации зданий, сооружений и помещений суда, ознакамливает сотрудников с утвержденными в суде нормами, уведомляет сотрудника о назначении ответственным за проведение инструктажа, формирую электронный журнал ознакомления для подтверждения подписью и хранения в электронном виде. |
