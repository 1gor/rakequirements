# [To be] ТБП141:Выполнить формальные проверки

|  |  |
| --- | --- |
| **Наименование процесса** | ТБП141:Выполнить формальные проверки |
| **Суть процесса** | Процесс описывает автоматическую проверку поданного документа системой без участия пользователя. Если в ходе проверки системой установлено, что файл превышает размер, документ нечитаем, файл поврежден, отсутствует подпись на документе, тогда система отклоняет такой документ автоматически. При обнаружении нарушений, система направляет уведомление в личный кабинет заявителя, предоставляет возможность исправить недостатки в течение 24 часов. Если неполадки устранены - документ считается принятым системой. Если нарушения не были устранены в указанный срок, система завершает этот процесс выводом о необходимости отклонения документа. |
| **Участники процесса** | Система |
| **НПА** | - |
