|  |
| --- |
| **Название НПА с реквизитами** |
| Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" |

| Федеральный закон от 14.06.1994 N 5-ФЗ (ред. от 01.05.2019) "О порядке опубликования и вступления в силу федеральных конституционных законов, федеральных законов, актов палат Федерального Собрания" |

## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела, ответственный за обеспечение доступа к СПС | Организует обеспечение функционирования СПС, организует выдачу новых УЗ, организует обучение работе с СПС |
| Сотрудник суда | Формирует и направляет заявку в случае возникновения сбоев в работе СПС, работает с СПС |
| Сотрудник службы технической поддержки суда | Обрабатывает заявку об устранении неполадок в СПС, устраняет неполадки по заявке, закрывает заявку, уведомляет инициатора заявки о завершении работ |
| Система | Создает заявку, назначает группу ответственных |

## 5. Реестр справочников

## 7. Межведомственное взаимодействие

Межведомственное взаимодействие в процессе не используется

## 8. Информация о сроках

Сроки действий в процессе не регламентированы. Установлен общий срок обработки заявок техподдержкой от 2 до 4 часов с момента поступления заявок, но этот срок не регламентирован НПА.
