## ****3.  Реестр UC****

### UC001 — Проанализировать изменения законодательства и проинформировать работников суда

|  |  |
| --- | --- |
| **№ шага процесса** | 0–16 |
| **Выполняемая задача** | Автоматизированный анализ изменений законодательства и связанной судебной практики, проверка выводов Системы и информирование работников суда об изменениях. |
| **Цель** | Выявить значимые изменения законодательства, проверить результаты автоматизированного анализа и своевременно довести необходимую информацию до работников суда. |

| **Рекомендованная функциональность** | Автоматический анализ изменений законодательства и связанной судебной практики; уведомление сотрудника о завершении анализа; проверка выводов Системы; автоматическое формирование уведомления об изменённом акте; установка признака обязательного ознакомления; публикация изменённого акта; автоматическая рассылка уведомлений работникам суда; фиксация обязательного ознакомления. |

| **Триггер** | Внесены изменения в законодательство. |
| **Предварительные условия** | Системе доступны сведения об изменениях законодательства и судебной практике, необходимые для проведения автоматизированного анализа. |
| **Основной сценарий** | 1. Система автоматически анализирует изменения законодательства. 2. Система уведомляет сотрудника о выполнении автоматизированного анализа. 3. Система анализирует судебную практику, связанную с изменёнными положениями законодательства. 4. Сотрудник проверяет сформированные Системой выводы в рамках ТБП139 «Проверить выводы системы». 5. Сотрудник определяет необходимость информирования работников суда. 6. При необходимости информирования Система формирует уведомление об изменённом акте. 7. Сотрудник определяет необходимость обязательного ознакомления с уведомлением. 8. При необходимости Система устанавливает признак обязательного ознакомления. 9. Сотрудник определяет необходимость публикации изменённого акта. 10. При необходимости Система публикует изменённый акт во внутреннем информационном ресурсе суда. 11. Система направляет уведомление работникам суда. 12. Сотрудник определяет необходимость формирования судебной практики в связи с внесёнными изменениями. 13. Если формирование судебной практики не требуется, процесс завершается после доведения изменений до работников суда. |
| **Расширение (альтернативный сценарий)** | **5а. Информирование работников суда не требуется.** 5а.1 Процесс завершается без направления уведомлений. **7а. Обязательное ознакомление не требуется.** 7а.1 Процесс продолжается без установки признака обязательного ознакомления. **9а. Публикация изменённого акта не требуется.**9а.1 Процесс продолжается без публикации акта. **12а. Требуется формирование судебной практики.** 12а.1 Процесс переходит к UC002 «Сформировать и довести подходы судебной практики». |

### UC002 — Сформировать и довести подходы судебной практики

|  |  |
| --- | --- |
| **№ шага процесса** | 17–24 |
| **Выполняемая задача** | Организация работы научно-консультационного совета, обсуждение изменений законодательства, формирование подходов судебной практики, оформление результатов и их доведение до работников суда при необходимости. |
| **Цель** | Сформировать и документально зафиксировать согласованные подходы к применению изменённых норм законодательства и при необходимости довести их до работников суда. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** сотрудник отдела обобщения судебной практики и анализа судебной статистики.**Участники:** научно-консультационный совет суда. |
| **Ожидаемый результат** | Сформированы и зафиксированы подходы к применению изменений законодательства, составлен протокол научно-консультационного совета и при необходимости документ с выработанной практикой направлен работникам суда. |
| **Рекомендованная функциональность** | Создание и ведение сведений о заседании научно-консультационного совета; фиксация результатов обсуждения; оформление протокола; хранение выработанных подходов судебной практики; подготовка и направление документа работникам суда. |
| **Критичность** | Необходимая. |
| **Триггер** | По результатам анализа изменений законодательства принято решение о необходимости формирования судебной практики. |
| **Предварительные условия** | Изменения законодательства проанализированы, выводы Системы проверены сотрудником, работники суда проинформированы об изменениях и определена необходимость формирования подходов судебной практики. |
| **Основной сценарий** | 1. Сотрудник организует собрание научно-консультационного совета. 2. На заседании обсуждаются внесённые изменения законодательства и вопросы их применения. 3. Сотрудник фиксирует результаты обсуждения в Системе. 4. По результатам обсуждения формируются подходы судебной практики в связи с внесёнными изменениями. 5. Сотрудник составляет протокол собрания научно-консультационного совета. 6. Сотрудник определяет необходимость доведения выработанной практики до всех работников суда. 7. При необходимости сотрудник направляет работникам суда документ, содержащий выработанные подходы к применению изменений законодательства. 8. Процесс завершается после формирования судебной практики. |
| **Расширение (альтернативный сценарий)** | **6а. Доведение выработанной практики до всех работников суда не требуется.** 6а.1 Документ с выработанной практикой не направляется всем работникам суда. 6а.2 Процесс завершается после фиксации сформированных подходов и оформления протокола. |
