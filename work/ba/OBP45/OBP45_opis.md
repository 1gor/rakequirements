## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела кадров | - Запускает процесс при наступлении срока формирования графика - Формирует письмо о необходимости формирования графика отпусков - Обрабатывает возврат после корректировок (шаг 6) - Формирует таблицу графика отпусков в Excel - Ознакамливается с предложениями председателя - Вносит данные в СЕШР - Фиксирует данные в журнале отпусков - Рассылает утверждённый график сотрудникам - Вносит изменения в график при корректировках - Фиксирует изменения в журнале - Направляет измененный график сотрудникам |
| Система | - Создает сущность для графиков отпусков - Рассылает письмо о формировании графика - Направляет таблицу на согласование председателю - Рассылает запросы на изменение дат сотрудникам |
| Сотрудник суда | - Ознакамливается с письмом - Указывает желаемую дату отпуска - Указывает скорректированную дату при необходимости - Подает заявление об изменении даты отпуска - Ознакамливается с утвержденным графиком - Подписывает ознакомление с графиком - Ознакамливается с измененным графиком |
| Председатель суда | - Ознакамливается с таблицей графика - Принимает решение о согласовании - Вносит корректировки при необходимости - Направляет утвержденный график - Ознакамливается с заявлением сотрудника об изменении даты - Принимает решение о возможности изменения даты - Отказывает в изменении графика или согласовывает изменения - Передает заявление сотруднику отдела кадров после утверждения изменений |
