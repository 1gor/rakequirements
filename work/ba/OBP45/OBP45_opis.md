# [To be] ОБП45. Контроль за составлением и соблюдением графиков очередных отпусков

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП45 — Контроль за составлением и соблюдением графиков очередных отпусков |
| **Суть процесса** | Процесс обеспечивает формирование и согласование графика очередных отпусков, ознакомление сотрудников с утвержденными датами, учет сведений об отпусках и обработку заявлений об изменении дат отпуска. |
| **Участники процесса** | Сотрудник отдела кадров; Сотрудник суда; Председатель суда; Система |
| **НПА** | Трудовой кодекс Российской Федерации от 30.12.2001 № 197-ФЗ; Постановление Госкомстата России от 05.01.2004 № 1 «Об утверждении унифицированных форм первичной учетной документации по учету труда и его оплаты» |

| **Выполняемая задача** | Формирование проекта графика очередных отпусков, сбор желаемых дат сотрудников и корректировка проекта по предложениям председателя суда. |
| **Цель** | Подготовить полный и согласованный проект графика отпусков на следующий календарный год с учетом пожеланий сотрудников и организационных ограничений суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участники: Сотрудник суда; Председатель суда; Система. |
| **Ожидаемый результат** | Желаемые даты отпусков собраны, проект графика сформирован в формате xlsx, рассмотрен председателем суда и при необходимости скорректирован. |
| **Рекомендованная функциональность** | Создание сущности графика отпусков; массовая рассылка уведомлений; сбор желаемых дат сотрудников; формирование и хранение проекта графика в формате xlsx; передача председателю суда; фиксация предложений по корректировке; повторный сбор измененных дат и ведение версий графика. |
| **Критичность** | Необходимая. |
| **Триггер** | Наступил установленный срок формирования графика отпусков на следующий календарный год. |
| **Предварительные условия** | В Системе имеются актуальные сведения о сотрудниках суда; определен период формирования графика; сотруднику отдела кадров доступна рассылка уведомлений и формирование таблицы. |
| **Основной сценарий** | 1. Система создает сущность для подготовки графика отпусков.  2. Сотрудник отдела кадров формирует письмо о необходимости предоставить желаемые даты отпусков.  3. Система рассылает письмо всем сотрудникам суда.  4. Сотрудники суда знакомятся с уведомлением.  5. Каждый сотрудник сообщает желаемую дату отпуска.  6. Сотрудник отдела кадров формирует проект графика отпусков в формате xlsx на основании полученных сведений.  7. Система направляет проект графика председателю суда на согласование.  8. Председатель суда знакомится с проектом и принимает решение по графику.  9. Председатель суда подтверждает возможность согласования графика.  10. Процесс продолжается с утверждения графика отпусков. |
| **Расширение (альтернативный сценарий)** | 9а. Председатель суда определяет, что проект графика требует корректировки.  9а.1 Председатель суда фиксирует предложения по изменению дат отпусков.  9а.2 Сотрудник отдела кадров знакомится с предложениями и определяет сотрудников, которым необходимо изменить даты.  9а.3 Система направляет соответствующим сотрудникам запросы на предоставление новых желаемых дат.  9а.4 Сотрудники указывают измененные даты отпусков.  9а.5 Сотрудник отдела кадров обновляет проект графика и повторно направляет его на согласование. |

**UC002 — Утвердить график отпусков и ознакомить сотрудников**

|  |  |
| --- | --- |
| **№ шага процесса** | 16–23 |
| **Выполняемая задача** | Утверждение графика отпусков, внесение сведений в СЕШР и журнал отпусков, направление графика сотрудникам и подтверждение ознакомления. |
| **Цель** | Зафиксировать утвержденные даты отпусков во всех учетных источниках и довести их до сотрудников суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участники: Председатель суда; Сотрудник суда. |
| **Ожидаемый результат** | График утвержден, сведения внесены в СЕШР и журнал отпусков, сотрудники ознакомлены с установленными датами и подтвердили ознакомление. |
| **Рекомендованная функциональность** | Фиксация утверждения графика; регистрация утвержденной версии; внесение и синхронизация дат в СЕШР и журнале отпусков; направление графика сотрудникам; постановка задач на ознакомление; хранение подтверждений ознакомления. |
| **Критичность** | Необходимая. |
| **Триггер** | Председатель суда согласовал проект графика отпусков. |
| **Предварительные условия** | Сформирована согласованная версия графика отпусков; сотруднику отдела кадров доступны СЕШР и журнал отпусков. |
| **Основной сценарий** | 1. Председатель суда утверждает график отпусков и направляет его сотруднику отдела кадров.  2. Сотрудник отдела кадров вносит утвержденные даты отпусков в СЕШР.  3. Сотрудник отдела кадров фиксирует сведения утвержденного графика в журнале отпусков.  4. Сотрудник отдела кадров направляет утвержденный график сотрудникам суда.  5. Сотрудник суда знакомится с утвержденным графиком и проверяет установленную для него дату отпуска.  6. Сотрудник определяет, что изменение даты отпуска не требуется.  7. Сотрудник подтверждает ознакомление с утвержденным графиком.  8. Процесс завершается с результатом «Сотрудник пойдет в отпуск по утвержденному графику, информация зафиксирована в СЕШР и журнале». |
| **Расширение (альтернативный сценарий)** | 6а. Сотруднику требуется изменить утвержденную дату отпуска.  6а.1 Процесс продолжается по UC003 «Изменить утвержденную дату отпуска». |

**UC003 — Изменить утвержденную дату отпуска**

|  |  |
| --- | --- |
| **№ шага процесса** | 24–35 |
| **Выполняемая задача** | Рассмотрение заявления сотрудника об изменении даты отпуска, согласование либо отказ, внесение изменений в график и уведомление сотрудников. |
| **Цель** | Обработать запрос на изменение утвержденной даты отпуска и обеспечить актуальность сведений в графике и журнале отпусков. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник суда. Участники: Председатель суда; Сотрудник отдела кадров. |
| **Ожидаемый результат** | Изменение даты согласовано и отражено в актуальной версии графика и журнале отпусков либо сотруднику отказано и сохраняется ранее утвержденная дата. |
| **Рекомендованная функциональность** | Формирование и подача заявления об изменении даты; передача заявления председателю суда; фиксация решения и основания отказа; постановка задачи отделу кадров; изменение графика и журнала отпусков; направление актуальной версии сотрудникам; фиксация ознакомления. |
| **Критичность** | Необходимая. |
| **Триггер** | После ознакомления с утвержденным графиком сотрудник определил необходимость изменить дату отпуска. |
| **Предварительные условия** | График отпусков утвержден; дата отпуска сотрудника внесена в СЕШР и журнал отпусков; сотруднику доступна подача заявления. |
| **Основной сценарий** | 1. Сотрудник суда определяет новую желаемую дату или период отпуска.  2. Сотрудник оформляет и направляет председателю суда заявление об изменении даты отпуска с указанием желаемой даты и основания.  3. Председатель суда рассматривает заявление и оценивает возможность изменения утвержденного графика.  4. Председатель суда согласовывает изменение даты отпуска и передает решение в отдел кадров.  5. Сотрудник отдела кадров вносит согласованные изменения в график отпусков.  6. Сотрудник отдела кадров обновляет сведения в журнале отпусков.  7. Сотрудник отдела кадров направляет сотрудникам актуальную версию измененного графика.  8. Сотрудник суда знакомится с измененным графиком.  9. Процесс завершается с результатом «График отпусков изменен». |
| **Расширение (альтернативный сценарий)** | 4а. Председатель суда определяет, что изменить дату отпуска невозможно.  4а.1 Председатель суда фиксирует отказ в изменении графика отпусков.  4а.2 График отпусков не изменяется.  4а.3 Процесс завершается с результатом «График отпусков не изменен. Сотрудник пойдет в отпуск по утвержденному графику». |
