# [To be] КБП7. Производство по административным встречным требованиям

| **Наименование процесса** | Производство по административным встречным требованиям |
| --- | --- |
| **Суть процесса** | Процесс охватывает действия арбитражного суда, аппарата суда и лиц, участвующих в деле, связанные с рассмотрением административных встречных требований, заявленных ответчиком в рамках уже возбужденного административного дела. Бизнес-процесс начинается с подачи административного встречного заявления и прилагаемых документов, включает проверку судом условий его принятия, рассмотрение требований в судебном заседании, исследование доказательств и оценку законности оспариваемых актов, решений или действий (бездействия). Процесс завершается переходом в административное производства для рассмотрения первоначального заявления и вынесения единого СА по делу. |
| **Участники процесса** | Орган, принявший оспариваемый документ, совершивший действие (бездействие), иные ЛУВД, Заявитель(ЮЛ/ИП), Судья, Помощник судьи, Канцелярия, Система |
| **НПА** | Не выявлено нормативных ограничений для данного процесса в to be. Применяются нормы НПА процесса в as is |
