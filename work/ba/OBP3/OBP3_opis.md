# [To be] ОБП3. Формирование оперативной отчетности о работе суда

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП3. Формирование оперативной отчетности о работе суда |
| **Суть процесса** | Процесс охватывает формирование, проверку, согласование и утверждение оперативной отчетности о работе суда для последующего использования в аналитической и управленческой деятельности. После возникновения необходимости сотрудник определяет состав данных и форму отчета; при необходимости создается и сохраняется новая внутренняя форма. Система формирует отчет, выполняет формально-логический контроль и при выявлении ошибок формирует уведомление на исправление. Ответственные за подготовку отчетов проверяют показатели, при необходимости корректируют сведения в информационной системе, подписывают отчет и передают его для дальнейшего учета. После согласования всех отчетов Система формирует итоговый отчет по суду, который подписывается ответственным сотрудником и председателем суда; при наличии замечаний сведения корректируются повторно. Результат используется для анализа работы суда, нагрузки и специализации судей и обеспечения качественного и своевременного рассмотрения дел. |
| **Участники процесса** | Сотрудник ответственный за ведение стат. отчетности; Лица ответственные за подготовку отчетов (судьи/председатели судебных составов/коллегий); Председатель суда; Система |
| **НПА** | Федеральный закон от 08.01.1998 № 7-ФЗ «О Судебном департаменте при Верховном Суде Российской Федерации» Приказ Судебного департамента при Верховном Суде РФ от 25.06.2021 № 124 «Об утверждении Инструкции по ведению судебной статистики» |

# 3. Реестр UC

**UC001 — Подготовка и направление оперативного отчета**

|  |  |
| --- | --- |
| **№ шага процесса** | 2–14 |
| **Выполняемая задача** | Определить состав данных и форму отчета, получить рассчитанный отчет с результатом ФЛК, при необходимости исправить данные и направить отчет на проверку и согласование. |
| **Цель** | Обеспечить формирование рассчитанного оперативного отчета без ошибок ФЛК и его передачу ответственным лицам для согласования. |
| **Роль / Актор** | Сотрудник ответственный за ведение стат. отчетности |
| **Ожидаемый результат** | Рассчитанный отчет без ошибок ФЛК направлен на проверку и согласование. |
| **Рекомендуемая функциональность** | Определение состава данных; выбор существующей или создание новой внутренней формы; автоматическое формирование отчета и ФЛК; отображение уведомления об ошибках; корректировка данных учетно-статистических карточек; направление рассчитанного отчета на проверку и согласование. |
| **Критичность** | Необходимая |
| **Триггер** | Сотрудник начинает подготовку оперативного отчета после возникновения соответствующей необходимости. |
| **Предварительные условия** | Сотруднику доступны данные учетно-статистических карточек и функции подготовки оперативной отчетности; в Системе доступна существующая форма либо предусмотрено создание новой формы. |
| **Основной сценарий** | 1. Сотрудник открывает функцию подготовки оперативного отчета и определяет необходимые данные. 2. Сотрудник выбирает существующую форму отчета. 3. Система формирует рассчитанный отчет по данным учетно-статистических карточек и выполняет ФЛК. 4. Система проверяет наличие ошибок ФЛК; при отсутствии ошибок выполнение переходит к направлению отчета на проверку и согласование. 5. Сотрудник открывает рассчитанный отчет и инициирует его направление на проверку и согласование. |
| **Расширение (альтернативный сценарий)** | Если необходима новая форма, сотрудник создает ее структуру и состав показателей, Система сохраняет форму, после чего сотрудник выбирает ее для подготовки отчета. Если Система выявляет ошибки ФЛК, она формирует уведомление на исправление; сотрудник открывает уведомление, корректирует связанные данные учетно-статистических карточек и сохраняет изменения. После этого отчет формируется и проверяется повторно. |

**UC002 — Проверка, согласование и контроль завершения согласования отчетов**

|  |  |
| --- | --- |
| **№ шага процесса** | 15–26 |
| **Выполняемая задача** | Получить рассчитанный отчет, проверить показатели, при корректности подписать отчет, при выявлении ошибок исправить исходные данные и сообщить о внесенных изменениях, а также обеспечить прохождение отчета до завершения общего цикла согласования. |
| **Цель** | Обеспечить проверку и согласование оперативных отчетов и переход к формированию итогового отчета после завершения согласования всех необходимых отчетов. |
| **Роль / Актор** | Лица ответственные за подготовку отчетов (судьи/председатели судебных составов/коллегий); Сотрудник ответственный за ведение стат. отчетности |
| **Ожидаемый результат** | Каждый отчет проверен и либо согласован и подписан, либо возвращен на повторную подготовку после исправления данных; после завершения согласования всех необходимых отчетов процесс готов к формированию итогового отчета по суду. |
| **Рекомендуемая функциональность** | Получение и открытие рассчитанного отчета; фиксация результата проверки показателей; формирование уведомления об ошибках; корректировка учетно-статистических карточек; подписание отчета электронной подписью; передача согласованного отчета; направление и получение информации об изменениях в ИС; контроль состояния согласования всех отчетов; уведомление об истечении срока согласования и повторный контроль после наступления установленного момента. |
| **Критичность** | Необходимая |
| **Триггер** | Лицу, ответственному за подготовку отчетов, доступен рассчитанный отчет, направленный на проверку и согласование. |
| **Предварительные условия** | Рассчитанный отчет сформирован и доступен ответственному лицу; пользователь имеет доступ к функциям проверки показателей, исправления исходных данных и подписания отчета. |
| **Основной сценарий** | 1. Ответственное лицо получает и открывает рассчитанный отчет в Системе. 2. Ответственное лицо проверяет показатели отчета и фиксирует результат проверки как «данные корректны». 3. Ответственное лицо открывает проверенный отчет и подписывает его электронной подписью. 4. Система передает согласованный и подписанный отчет в общий поток контроля согласования. 5. После объединения потоков состояние согласования используется для маршрутизации процесса. 6. Если все необходимые отчеты согласованы, выполнение переходит к формированию итогового отчета по суду. |
| **Расширение (альтернативный сценарий)** | 1. Если при проверке выявлены ошибки, ответственное лицо фиксирует несоответствия, открывает связанные учетно-статистические карточки, вносит исправления и сохраняет их. 2. Ответственное лицо формирует и направляет информацию о внесенных изменениях. 3. Сотрудник, ответственный за ведение статистической отчетности, получает информацию об изменениях; выполнение возвращается к повторной подготовке отчета. 4. Если согласование всех отчетов не завершено, Система направляет уведомление об истечении срока согласования. 5. После наступления установленного момента повторной проверки выполнение возвращается к контролю состояния согласования отчетов. |

**UC003 — Формирование и утверждение итогового отчета**

|  |  |
| --- | --- |
| **№ шага процесса** | 27–36 |
| **Выполняемая задача** | Получить автоматически сформированный итоговый отчет, подписать его, передать председателю суда для проверки и по результату либо утвердить отчет, либо зафиксировать замечания и внести исправления. |
| **Цель** | Обеспечить утверждение итогового оперативного отчета суда на основании согласованных отчетов. |
| **Роль / Актор** | Сотрудник ответственный за ведение стат. отчетности; Председатель суда |
| **Ожидаемый результат** | Согласованный итоговый отчет подписан председателем суда и доступен для использования в аналитической и управленческой работе суда. |
| **Рекомендуемая функциональность** | Автоматическое формирование итогового отчета; подписание электронной подписью; автоматическая передача председателю суда; фиксация результата проверки; создание и получение замечаний; внесение исправлений; подписание председателем суда. |
| **Критичность** | Необходимая |
| **Триггер** | Все отчеты согласованы, и процесс перешел к формированию итогового отчета по суду. |
| **Предварительные условия** | В Системе имеются согласованные и подписанные отчеты, необходимые для формирования итогового отчета. |
| **Основной сценарий** | 1. Система формирует согласованный итоговый отчет по суду. 2. Сотрудник, ответственный за ведение статистической отчетности, открывает итоговый отчет и подписывает его электронной подписью. 3. Система передает итоговый отчет председателю суда. 4. Председатель суда открывает отчет и фиксирует результат проверки как «отчет корректен». 5. Председатель суда подписывает итоговый отчет электронной подписью. 6. Процесс завершается; подписанный итоговый отчет доступен для использования в работе суда. |
| **Расширение (альтернативный сценарий)** | 1. Если председатель суда фиксирует, что отчет требует исправлений, он формирует и направляет замечания. 2. Сотрудник, ответственный за ведение статистической отчетности, получает замечания, вносит изменения в Системе и сохраняет их. 3. После внесения изменений процесс возвращается к повторной подготовке и согласованию отчета. 4. После завершения повторного согласования и перехода по ветви, в которой все необходимые отчеты согласованы, Система повторно формирует итоговый отчет по суду. |
