## ****3. Реестр UC****

**UC001 — Подготовить проект новости для публикации**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–10 |
| **Выполняемая задача** | Подбор и подготовка исходных материалов, автоматическое формирование проекта новости, проверка выводов Системы и передача проекта руководителю на согласование. |
| **Цель** | Подготовить достоверный и структурированный проект информационного материала для последующего согласования и публикации на официальном сайте суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник пресс-службы. Участник: Система. |
| **Ожидаемый результат** | Исходные материалы подготовлены, проект новости сформирован Системой, проверен сотрудником пресс-службы и направлен Председателю суда либо заместителю Председателя суда на согласование. |
| **Рекомендованная функциональность** | Создание объекта проекта новости; загрузка и хранение исходных материалов; автоматизированное формирование текста проекта; хранение истории изменений и сведений об ответственном сотруднике; вызов ТБП139 для проверки выводов Системы; передача проекта на согласование руководителю. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость подготовить и опубликовать информационный материал о деятельности суда. |
| **Предварительные условия** | Определено событие или тема, требующая информационного освещения; сотруднику пресс-службы доступны внутренние материалы суда либо открытые материалы других арбитражных судов. |
| **Основной сценарий** | 1. Сотрудник пресс-службы оценивает предполагаемую новость, определяет ее предмет, значимость и предполагаемый состав материала.  2. Сотрудник пресс-службы определяет, относится ли новость к внутреннему процессу суда.  3. Для новости о внутреннем процессе сотрудник пресс-службы подбирает сведения и материалы о деятельности суда.  4. Сотрудник пресс-службы выбирает подготовленные материалы и запускает формирование проекта новости в Системе.  5. Система формирует текст проекта новости на основе предоставленных материалов.  6. Система создает объект для хранения проекта, исходных материалов, истории изменений, сведений об ответственном сотруднике и связанных задач.  7. Сотрудник пресс-службы выполняет ТБП139 «Проверить выводы системы».  8. Сотрудник пресс-службы проверяет достоверность, полноту и качество сформированного проекта.  9. Сотрудник пресс-службы передает проект новости Председателю суда либо заместителю Председателя суда на согласование. |
| **Расширение (альтернативный сценарий)** | 2а. Новость не относится к внутреннему процессу суда.  2а.1 Сотрудник пресс-службы получает материалы по выбранной теме из доступных источников других арбитражных судов.  2а.2 Сотрудник пресс-службы проверяет применимость полученных материалов.  2а.3 Сотрудник пресс-службы перерабатывает материалы, приводит сведения к единой структуре и формирует авторский текст.  2а.4 Процесс продолжается с запуска формирования проекта новости в Системе. |
