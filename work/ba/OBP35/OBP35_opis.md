## ****3.  Реестр UC****

UC-01. Инициация и оценка новости

|  |  |
| --- | --- |
| **Выполняемая задача** | Инициация процесса ведения информационного блока и оценка новости |
| **№ шага процесса** | **0-2** |
| **Цель** | Определить необходимость подготовки новости и классифицировать ее как внутреннюю или внешнюю |
| **Актор** | Сотрудник пресс-службы |
| **Ожидаемый результат** | Принято решение о подготовке новости и выбран дальнейший сценарий обработки |
| **Рекомендованная функциональность** | Фиксация события/запроса на подготовку новости, интерфейс оценки и классификации новости |
| **Критичность** | Дополнительная |
| **Триггер** | Поступил запрос на создание новости (анонса) или произошло событие, требующее освещения |
| **Предварительные условия** | -Сотрудник пресс-службы авторизован в системе  -Система поддерживает ведение информационного блока сайта суда |
| **Основной сценарий** | 1. Сотрудник пресс-службы фиксирует возникновение события или запроса на подготовку новости  2. Сотрудник пресс-службы оценивает содержание новости  3. Сотрудник пресс-службы определяет, относится ли новость к внутренним процессам суда |
| **Расширенный (альтернативный сценарий)** | 3а. Если новость не относится к внутренним процессам суда — переход к получению материалов из других судов   3б. Если новость относится к внутренним процессам суда — переход к подбору внутренних материалов |
