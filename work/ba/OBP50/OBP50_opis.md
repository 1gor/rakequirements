## ****3. Реестр UC****

**UC001 — Сформировать табель учета рабочего времени**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–8 |
| **Выполняемая задача** | Автоматическое заполнение основных сведений табеля учета рабочего времени, проверка данных об отсутствиях сотрудников, формирование итогового табеля и передача его на согласование. |
| **Цель** | Сформировать актуальный табель учета рабочего времени работников аппарата суда на основании данных Системы и сведений, проверенных сотрудником отдела кадров. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участник: Система. |
| **Ожидаемый результат** | Табель учета рабочего времени сформирован на основании актуальных сведений о явках, неявках, отработанных часах, отпусках и больничных и направлен председателю суда на согласование. |
| **Рекомендованная функциональность** | Автоматическое заполнение реквизитов табеля; автоматическое отражение явок, отработанных часов, отпусков и больничных; возможность проверки и корректировки сведений о неявках; автоматическое формирование табеля; передача актуальной версии председателю суда на согласование. |
| **Критичность** | Необходимая. |
| **Триггер** | Наступил установленный срок заполнения табеля учета рабочего времени. |
| **Предварительные условия** | В Системе имеются сведения о работниках аппарата суда, отчетном периоде, явках, отработанном времени, отпусках и больничных. |
| **Основной сценарий** | 1. При наступлении установленного срока Система начинает подготовку табеля учета рабочего времени.  2. Система автоматически заполняет наименование суда, номер и дату документа, отчетный период, должности, табельные номера и ФИО работников.  3. Система отражает сведения о явке сотрудников за отчетный период.  4. Сотрудник отдела кадров проверяет сведения об отсутствующих сотрудниках и при необходимости указывает причины неявки.  5. Система автоматически отражает фактически отработанные сотрудниками часы.  6. Система отражает периоды отпусков сотрудников.  7. Система отражает периоды временной нетрудоспособности сотрудников.  8. Система формирует итоговый табель учета рабочего времени.  9. Сотрудник отдела кадров направляет сформированный табель председателю суда на проверку и согласование. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

| **Цель** | Подтвердить корректность сформированного табеля учета рабочего времени и зафиксировать его согласование председателем суда. |

| **Рекомендованная функциональность** | Предоставление председателю суда актуальной версии табеля; фиксация результата проверки и замечаний; возврат табеля сотруднику отдела кадров на корректировку; хранение актуальной версии; электронное подписание согласованного табеля. |

| **Предварительные условия** | Табель сформирован за соответствующий отчетный период и содержит сведения о рабочем времени работников аппарата суда. |
| **Основной сценарий** | 1. Председатель суда получает сформированный табель учета рабочего времени.  2. Председатель суда проверяет корректность оформления и содержащихся в табеле сведений.  3. Председатель суда определяет, что табель составлен корректно.  4. Председатель суда подписывает согласованный табель учета рабочего времени.  5. Подписанный табель передается для последующей проверки бухгалтерией. |
| **Расширение (альтернативный сценарий)** | 3а.
