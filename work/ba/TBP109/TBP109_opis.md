# [To be] ТБП109. Рассмотреть вопрос о прекращении производства по банкротству

| **Наименование процесса** | Рассмотреть вопрос о прекращении производства по банкротству |
| --- | --- |
| **Суть процесса** | Процесс описывает действия суда при принятии решения о прекращении производства по делу о банкротстве после оценки доказательств. Проверяется тайна совещания (при нарушении доступ к вынесению акта закрывается); затем автоматически проверяются типовые предпосылки прекращения и полнота рассмотрения заявлений — при необходимости судебного заседания принятие решения приостанавливается. Суд определяет применимые нормы и позицию по ссылкам участников, оценивает обстоятельства дела (включая злоупотребления, отказ от требований, примирение, права кредиторов, платежеспособность должника), при необходимости рассматривает частное определение, ходатайство Банка России и судьбу средств на спецсчёте, устанавливает основание прекращения и проверяет соблюдение его условий — иначе дело продолжается. При выводе о прекращении при необходимости распределяются судебные расходы и разрешаются вопросы обеспечительных мер, либо процесс снова останавливается для дополнительного исследования; иначе формулируются последствия прекращения, выносится определение. |
| **Участники процесса** | Судья |
