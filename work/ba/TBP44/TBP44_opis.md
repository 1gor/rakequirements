# [To be] ТБП44. Назначить СЗ

|  |  |
| --- | --- |
| **Наименование процесса** | ТБП44.Назначить СЗ |
| **Суть процесса** | Процесс охватывает действия судьи, помощника судьи, секретаря судебного заседания, канцелярии и информационных систем суда, направленные на определение и официальное закрепление даты, времени, места и формата проведения судебного заседания либо предварительного судебного заседания по делу. Бизнес-процесс начинается с возникновения у судьи необходимости назначения СЗ/ПСЗ и включает проверку процессуальных сроков, выбор даты и времени заседания с учётом графика судьи и занятости залов, определение формы проведения заседания (очное, с использованием ВКС, открытое или закрытое), установление круга лиц, подлежащих участию и извещению, а также согласование организационных параметров при участии помощника судьи и секретаря СЗ. Процесс завершается вынесением и подписанием определения о назначении СЗ/ПСЗ либо отражением соответствующих сведений в ином судебном акте, их фиксацией в информационных системах суда и направлением извещений лицам, участвующим в деле, включая иностранных участников при необходимости. |
| **Участники процесса** | Судья |
| **НПА** | "Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ  Постановление Пленума Верховного Суда РФ от 04.06.2024 N 12 "О подготовке дела к судебному разбирательству в арбитражном суде"  Постановление Пленума ВАС РФ от 17.02.2011 N 12 (ред. от 27.06.2017) "О некоторых вопросах применения Арбитражного процессуального кодекса Российской Федерации в редакции Федерального закона от 27.07.2010 N 228-ФЗ "О внесении изменений в Арбитражный процессуальный кодекс Российской Федерации" |

## ****3. Реестр UC (в части выполняемых пользователем задач и рекомендованной функциональности Системы)****

UC-001: Проверка срока (расчет срока рассмотрения дела и периода, возможный для отложения/назначения СЗ)

|  |  |
| --- | --- |
| **Поле** | **Значение** |
| **№ шага процесса** | 0-1 |
| **Выполняемая задача** | Проверка срока рассмотрения дела и определение периода, допустимого для назначения либо отложения судебного заседания |
| **Цель** | Обеспечить соблюдение процессуальных сроков при назначении судебного заседания и исключить назначение СЗ за пределами допустимых сроков рассмотрения дела |
| **Роль (в соответствии со схемой)** | Судья |
| **Ожидаемый результат** | Судье доступна информация о процессуальном сроке рассмотрения дела и допустимом временном интервале для назначения либо отложения судебного заседания |
| **Рекомендованная функциональность** | Автоматизированный расчёт процессуальных сроков на основании данных дела, учёт приостановлений, продлений и иных влияющих факторов, отображение допустимого периода назначения СЗ, предупреждение судьи о риске нарушения сроков |
| **Критичность** | Необходимая |
| **Триггер** | Судья в карточке дела нажал кнопку «Назначить СЗ/ПСЗ». |
| **Предварительные условия** | Дело зарегистрировано в системе, в системе указана категория/вид производства, даты ключевых процессуальных события, признаки приостановления/продления процессуальных сроков, в системе доступен производственный календарь |
| **Основной сценарий** | 1. Судья в карточке дела нажимает кнопку «Назначить СЗ/ПСЗ».  2. Система отображает блок «Процессуальные сроки» с полями: - Процессуальное состояние - Дата перехода - Период (число) дней до нарушения процессуального срока для назначения либо отложения СЗ/ПСЗ.  3. Судья нажимает кнопку «Перейти к выбору даты и времени».  4. Система обновляет календарь, согласно текущего календарного года, согласно производственного календаря.  5. | **Предварительные условия** | СЗ/ПСЗ назначено и оформлено процессуально; в системе доступны данные об участниках дела; у пользователей есть полномочия на выполнение действий (помощник/судья). |
| **Основной сценарий** | 1.Помощник судьи открывает в карточке СЗ/ПСЗ раздел «Извещение иностранных лиц».  2.Система отображает форму «Извещение иностранных лиц»: список участников с признаком «Иностранное лицо» и кнопку «Начать извещение».  3.Помощник судьи выбирает иностранного участника в списке и нажимает кнопку «Начать извещение».  4.Система отображает форму «Параметры извещения» с вопросом «На территории РФ находится представитель, уполномоченный на получение документов?» и вариантами ответа.  5.Помощник судьи выбирает вариант «Нет» и нажимает «Продолжить».  6.Система выполняет поиск международного договора об извещении и отображает результат на экране (найденный договор/порядок извещения) и кнопку «Проверить/подтвердить выводы».  7.Помощник судьи нажимает кнопку «Проверить/подтвердить выводы».  8.Система отображает экран проверки выводов (результаты поиска и выбранный системой порядок) с кнопками «Подтвердить» / «Скорректировать».  9.Помощник судьи нажимает кнопку «Подтвердить».  10.Система фиксирует подтверждение выводов и отображает кнопку «Передать судье для решения по порядку извещения».  11.Помощник судьи нажимает кнопку «Передать судье».  12.Система отображает судье задачу/экран «Порядок извещения иностранного лица» с результатами поиска договора и кнопкой «Зафиксировать решение».  13.Судья нажимает кнопку «Зафиксировать решение».  14.Система отображает форму решения судьи с параметрами: «Требуется перевод СА/документа?» (Да/Нет).  15.Судья выбирает «Да» и нажимает кнопку «Направить на перевод».  16.Система создаёт задание/статус «Ожидает перевода» и отображает это в карточке извещения.  17.Система отображает уведомление судье о поступлении перевода и прикрепляет «Переведённый судебный акт/документ».  18.Судья открывает переведённый документ  19. Судья нажимает кнопку «Продолжить оформление извещения».  20.Система отображает форму с параметром «Требуется судебное поручение?» (Да/Нет).  21.Судья выбирает «Да» и нажимает кнопку «Сформировать судебное поручение».  22.Система формирует проект документа «Судебное поручение» и отображает его в редакторе с кнопками «Сохранить» / «Подписать».  23.Судья нажимает кнопку «Подписать».  24.Система выполняет подписание УКЭП и сохраняет подписанное «Судебное поручение» в электронном деле,  25. Система отображает статус документа «Принят».  26.Система отображает параметр «Применяются нормы Гаагской конвенции 1965 г.?» (Да/Нет).  27.Судья выбирает «Да» и нажимает кнопку «Заполнить форму по Гаагской конвенции».  28.Система отображает форму по Гаагской конвенции для заполнения.  29.Судья заполняет форму и нажимает кнопку «Сформировать пакет документов».  30.Система формирует «Свидетельство о вручении» и отображает сформированный пакет документов для извещения.  31.Помощник судьи нажимает кнопку «Поставить электронную гербовую печать».  32.Система сохраняет документ с наложением электронной гербовой печати.  33.Помощник судьи нажимает кнопку «Сформировать реестр Ф-103А».  34.Система формирует реестр Ф-103А.  35.Система отображает его в карточке извещения  36.Помощник судьи выбирает маршрут «Извещение напрямую» и нажимает кнопку «Направить документы».  37.Система отображает форму «Направить документ» (канал/адресат/вложения) с кнопкой «Отправить».  38.Помощник судьи нажимает кнопку «Отправить».  39.Система выполняет отправку документов и фиксирует статус/факт направления в карточке извещения.  40.Система отображает отметку «Приняты меры к извещению иностранного лица» в карточке дела/СЗ/ПСЗ. |
| **Расширение (альтернативный сценарий)** | 2а. В составе участников нет иностранных лиц  2а1. Система отображает сообщение «Иностранные участники не указаны» и кнопку «Зафиксировать: извещение не требуется».  2а2. Помощник судьи нажимает кнопку «Зафиксировать: извещение не требуется».  2а3. Система фиксирует отметку «Извещение иностранных лиц не требуется» в карточке СЗ/ПСЗ/дела.  5а. Представитель на территории РФ имеется  5а1. Помощник судьи выбирает вариант «Да» и нажимает «Продолжить».  5а2. Система отображает форму «Направить документ представителю» с кнопкой «Отправить».  5а3. Помощник судьи нажимает кнопку «Отправить».  5а4. Система фиксирует факт направления документов представителю и отображает отметку о направлении.  9а. Помощник судьи корректирует выводы системы  9а1. Помощник судьи нажимает кнопку «Скорректировать».  9а2. Система отображает форму корректировки (выбор договора/маршрута/порядка).  9а3. Помощник судьи вносит изменения и нажимает «Сохранить».  9а4. Система фиксирует скорректированные данные и отображает кнопку «Передать судье».  15а. Перевод не требуется  15а1. Судья выбирает «Нет» в параметре «Требуется перевод?» и нажимает «Продолжить».  15а2. Система отображает форму «Требуется судебное поручение?» без ожидания перевода.  20а. Судебное поручение не требуется  20а1. Судья выбирает «Нет» и нажимает «Продолжить».  20а2. Система отображает экран подготовки документа для извещения с кнопкой «Сформировать и подписать документ».  20а3. Судья нажимает «Сформировать и подписать документ».  20а4. Система формирует документ для извещения и отображает кнопку «Подписать».  20а5. Судья нажимает «Подписать».  20а6. Система выполняет подписание УКЭП и сохраняет документ в электронном деле.  25а. Нормы Гаагской конвенции не применяются  25а1. Судья выбирает «Нет» и нажимает «Продолжить».  25а2. Система формирует пакет документов для извещения без формы по Гаагской конвенции и отображает пакет.  33а. Извещение не напрямую  33а1. Помощник судьи выбирает маршрут «Через иностранный суд» и нажимает «Продолжить».  33а2. Система отображает уточняющий выбор «Напрямую через иностранный суд?» (Да/Нет).  33а3. Помощник судьи выбирает вариант и нажимает «Направить документы».  33а4. Система отображает форму «Направить документ» с кнопкой «Отправить».  33а5. Помощник судьи нажимает «Отправить».  33а6. Система выполняет отправку по выбранному маршруту и фиксирует факт направления.  36а. Ошибка отправки документов  36а1. Система отображает сообщение об ошибке отправки и кнопку «Повторить отправку».  36а2. Помощник судьи нажимает «Повторить отправку».  36а3. Система повторно выполняет отправку и обновляет статус/факт направления. |
