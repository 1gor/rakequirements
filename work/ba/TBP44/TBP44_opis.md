# [To be] ТБП44. Назначить СЗ

| **Наименование процесса** | ТБП44.Назначить СЗ |
| --- | --- |
| **Суть процесса** | Процесс охватывает действия судьи, помощника судьи, секретаря судебного заседания, канцелярии и информационных систем суда, направленные на определение и официальное закрепление даты, времени, места и формата проведения судебного заседания либо предварительного судебного заседания по делу. Бизнес-процесс начинается с возникновения у судьи необходимости назначения СЗ/ПСЗ и включает проверку процессуальных сроков, выбор даты и времени заседания с учётом графика судьи и занятости залов, определение формы проведения заседания (очное, с использованием ВКС, открытое или закрытое), установление круга лиц, подлежащих участию и извещению, а также согласование организационных параметров при участии помощника судьи и секретаря СЗ. Процесс завершается вынесением и подписанием определения о назначении СЗ/ПСЗ либо отражением соответствующих сведений в ином судебном акте, их фиксацией в информационных системах суда и направлением извещений лицам, участвующим в деле, включая иностранных участников при необходимости. |
| **Участники процесса** | Судья |
| **НПА** | "Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ  Постановление Пленума Верховного Суда РФ от 04.06.2024 N 12 "О подготовке дела к судебному разбирательству в арбитражном суде"  Постановление Пленума ВАС РФ от 17.02.2011 N 12 (ред. от 27.06.2017) "О некоторых вопросах применения Арбитражного процессуального кодекса Российской Федерации в редакции Федерального закона от 27.07.2010 N 228-ФЗ "О внесении изменений в Арбитражный процессуальный кодекс Российской Федерации" |

## **3. Реестр UC (в части выполняемых пользователем задач и рекомендованной функциональности Системы)**

UC-001: Выбор и утверждение даты, времени и места проведения СЗ/ПСЗ

| **Поле** | **Значение** |
| --- | --- |
| **№ шага процесса** | 2-8 |
| **Выполняемая задача** | Выбор и утверждение даты, времени и места проведения судебного заседания (бронирование зала) или предварительного судебного заседания |
| **Цель** | Определить релевантные дату, время и зал проведения СЗ/ПСЗ с учётом графика. |
| **Роль (в соответствии со схемой)** | Судья |
| **Ожидаемый результат** | В системе зафиксированы утверждённые дата, время и место проведения СЗ/ПСЗ, выбранный слот забронирован и недоступен для иных назначений для данного зала. |
| **Рекомендованная функциональность** | Подбор свободных слотов (дата, время, зал), временное бронирование слота, визуальное отображение статусов слотов (свободен / забронирован / занят), поддержка сценария получения мнения сторон внутри СЗ, фиксация окончательного утверждения параметров СЗ/ПСЗ |
| **Критичность** | Необходимая |
| **Триггер** | Судья на экране назначения СЗ/ПСЗ нажал кнопку «Выбрать дату и время». |
| **Предварительные условия** | Рассчитаны процессуальные сроки, в системе актуализирован график судебных заседаний и занятость залов, пользователь обладает полномочиями судьи, использование производственного календаря для определения рабочих дней. |
| **Основной сценарий** | 1. Судья нажимает кнопку «Выбрать дату и время».  2. Система отображает календарь и доступные слоты (дата, время, зал) для выбранной категории заседания.  3. Судья выбирает один слот в календаре.  4. Система временно бронирует выбранный слот.  5. Судья подтверждает выбранные дату, время и зал.  6. Система фиксирует параметры СЗ/ПСЗ и блокирует слот от возможности брони иным пользователем. |
| **Расширение (альтернативный сценарий)** | 2а. Система отображает пустой список слотов и сообщение «Нет доступных слотов».  2а1. Судья изменяет период поиска (даты/время) и повторяет выбор.  5б. Судья фиксирует возражения сторон по выбранному слоту (внутри СЗ).  5б1. Судья нажимает кнопку «Подобрать другой слот».  5б2. Система снимает временную бронь.  5б3. Система возвращает судью к календарю. |

UC-002: Проведение СЗ/ПСЗ в формате закрытого заседания

| **Поле** | **Значение** |
| --- | --- |
| **№ шага процесса** | 14, 19-20 |
| **Выполняемая задача** | Установление ограничений доступа и функций при выборе закрытого режима проведения СЗ. |
| **Цель** | Обеспечить проведение СЗ/ПСЗ в закрытом режиме с установлением необходимых ограничений |
| **Роль (в соответствии со схемой)** | Судья |
| **Ожидаемый результат** | В системе зафиксирована форма закрытое СЗ/ПСЗ, судья выбрал ограничения, система применила ограничения доступа к материалам электронного дела и/или ограничения на использование функций (сценариев) согласно выбранным параметрам |
| **Рекомендованная функциональность** | Выбор формы закрытое СЗ/ПСЗ в карточке судебного заседания, справочник/набор типовых ограничений для закрытого заседания (выбор значений судьёй), применение ограничений системой по ролям пользователей (ограничение доступа к материалам дела), ограничение доступности функций (например, запрет определённых действий/сценариев в зависимости от выбранных ограничений), протоколирование факта применения ограничений и состава ограничений в карточке СЗ/ПСЗ |
| **Критичность** | Высокая |
| **Триггер** | Судья на экране назначения СЗ/ПСЗ выбрал вариант «Закрытое заседание». |
| **Предварительные условия** | Предварительные условия: дата/время/место СЗ/ПСЗ утверждены, судье доступно редактирование карточки (объекта) СЗ/ПСЗ, в системе доступен выбор формы проведения заседания. |
| **Основной сценарий** | 1. Судья открывает поле с формой проведения в карточке СЗ/ПСЗ.  2. Судья выбирает вариант с закрытой формой заседания.  3. Система отображает перечень доступных ограничений для закрытого заседания.  4. Судья выбирает значения ограничений из перечня  5. Система применяет ограничения доступа/функций согласно выбранным параметрам. 6. Система фиксирует состав применённых ограничений в карточке СЗ/ПСЗ  7. Система отображает подтверждение применения ограничений. |
| **Расширение (альтернативный сценарий)** | 2а. Судья выбирает форму проведения, отличную от «Закрытое заседание».  2а1. Система не отображает перечень ограничений и сохраняет выбранную форму проведения.  2б. Судья выбирает другую форму после применения ограничений.  2б1. Система запрашивает подтверждение снятия закрытого режима и удаления ограничений.  2б2. Судья подтверждает.  2б3. Система снимает ограничения  2б4. Система фиксирует изменения в карточке СЗ/ПСЗ.  4а. Судья не выбрал обязательные ограничения (если такие предусмотрены настройками).  4а1. Система отображает сообщение о незаполненных обязательных значениях и не применяет ограничения.  4а2. Судья выбирает обязательные значения и повторяет применение.  7а. Судья изменяет набор ограничений после применения. 7а1. Судья открывает форму ограничений. 7а2. Судья изменяет значения чек-листа ограничений. 7а3. Судья нажимает «Применить». 7а4. Система обновляет ограничения  7а5. Система фиксирует новый состав в карточке СЗ/ПСЗ. |
