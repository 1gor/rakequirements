# [To be] ТБП112. Проверить правильность формирования и оформления дела

| **Наименование процесса** | ТБП112 — Проверить правильность формирования и оформления дела |
| --- | --- |
| **Суть процесса** | Процесс предназначен для проверки правильности формирования и оформления дела при его передаче в другой суд, другому судье либо при сдаче дела в архив. Система последовательно проверяет наличие необходимых подписей, электронной описи документов, соответствие файлов дела данным описи и корректность заполнения полей в карточках. По результатам проверок Система формирует протокол, который передается на проверку Помощнику судьи/Лицу, осуществляющему проверку. Процесс завершается фиксацией вывода о корректном либо некорректном формировании (оформлении) дела. |
| **Участники процесса** | Помощник судьи/Лицо, осуществляющее проверку; Система |
| **НПА** | Постановление Пленума ВАС РФ от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)». |

# 3. Реестр UC

UC001 — Осуществление проверок корректности формирования (оформления) дела

| **№ шага процесса** | 0-6 |
| --- | --- |
| **Выполняемая задача** | Выполнить проверки корректности формирования (оформления) дела и подготовить результаты проверок. |
| **Цель** | Убедиться в корректности формирования и оформления дела по требованиям Инструкции № 100. |
| **Роль / Актор** | Помощник судьи/Лицо, осуществляющее проверку |
| **Ожидаемый результат** | В Системе отображены результаты проверок корректности формирования (оформления) дела и сформирован протокол проверки формирования (оформления) дела. |
| **Рекомендуемая функциональность** | Проверка состава и реквизитов дела; сопоставление с описью; контроль подписей; формирование протокола проверки |
| **Критичность** | Необходимая |
| **Триггер** | Помощник судьи/Лицо, осуществляющее проверку, запускает проверку корректности формирования (оформления) дела. |
| **Предварительные условия** | В Системе заведены карточка дела и перечень документов дела, а также доступна электронная опись документов и данные для сопоставления; в деле присутствуют документы и обложка дела. |
| **Основной сценарий** | 1. Система проводит проверку оформления  2. Система формирует протокол проверки с результатами проверок 3. Система отображает сформированный протокол проверки формирования (оформления) дела. 4. Помощник судьи/Лицо, осуществляющее проверку, подтверждает протокол проверки формирования (оформления) дела. 5. Система сохраняет подтверждённый протокол проверки формирования (оформления) дела. |
| **Расширение (альтернативный сценарий)** | 4а1 Помощник судьи/Лицо, осуществляющее проверку, корректирует результаты проверки в протоколе. 4а2 Система сохраняет подтверждённый протокол проверки формирования (оформления) дела. |
