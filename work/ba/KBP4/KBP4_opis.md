# [To be] КБП4. Упрощенное производство

|  |  |
| --- | --- |
| **Наименование процесса** | КБП4. Упрощенное производство |
| **Суть процесса** | Процесс представляет собой комплексную систему автоматизированного рассмотрения арбитражных дел в упрощенном порядке, которая охватывает все этапы судопроизводства — от поступления документов до окончательного решения и архивации дела, включая возможности обжалования, исполнения решения и исправления процессуальных ошибок |
| **Участники процесса** | Судья, Канцелярия, Заявитель/Истец, Иные ЛУВД (в том числе Ответчик), Помощник судьи, Система |
| **НПА** | Не выявлено нормативных ограничений для данного процесса в to be. Применяются нормы НПА процесса в as is |

## UC-012: Рассмотрение вопроса о привлечении третьих лиц для обеспечения всестороннего рассмотрения дела

| **Поле** | **Значение** |
| --- | --- |
| № шага процесса | 31-39 |
| Выполняемая задача | Инициация процесса привлечения третьих лиц, подача ходатайства о привлечении третьего лица через ТБП7, регистрация ходатайства, рассмотрение вопроса об изменении состава ЛУВД через ТБП116, изменение состава участников процесса |
| Цель | Обеспечить рассмотрение вопроса о привлечении третьих лиц для обеспечения всестороннего рассмотрения дела |
| Роль (в соответствии со схемой) | Заявитель/Истец, Иные ЛУВД (в т.ч. Ответчик) или Суд |
| Ожидаемый результат | Ходатайство о привлечении третьего лица зарегистрировано через ТБП7, вопрос рассмотрен судом через ТБП116, состав ЛУВД изменен, третьи лица извещены о привлечении к делу, дело дополнено новыми участниками |
| Рекомендованная функциональность | Форма подачи ходатайства о привлечении третьего лица через ТБП7, отображение информации о деле и участниках процесса, регистрация ходатайства, интеграция с ТБП116 для рассмотрения вопроса об изменении состава ЛУВД, изменение состава участников в системе, формирование извещений, уведомления участников |
| Критичность | необходимая |

| Предварительные условия | Дело находится в упрощенном производстве (КБП4); Имеются основания для привлечения третьих лиц; Дело не завершено |
| Основной сценарий | 1. Истец/Ответчик/Суд определяет необходимость привлечения третьего лица (шаг 31/34/37) |

| 3. Истец/Ответчик заполняет форму ходатайства (указывает третье лицо, основания для привлечения) |
| 4. Истец/Ответчик прикрепляет документы, подтверждающие необходимость привлечения |

| 6. Система проверяет корректность заполнения |

| 8. Система присваивает статус "рассмотрение документов" (шаг 33/36) |
| 9. Система передает ходатайство суду на рассмотрение |
| 10. Суд рассматривает вопрос об изменении состава ЛУВД через ТБП116 (шаг 38) |

| 12. Суд принимает решение о привлечении третьих лиц |
| 13. Система изменяет состав ЛУВД в карточке дела (шаг 39) |
| 14. Система формирует извещения для третьих лиц |
| 15. Система уведомляет участников процесса о привлечении третьих лиц |
| Расширение (альтернативный сценарий) | 6а: Если данные заполнены некорректно, система выводит сообщение об ошибке и возвращает к шагу 3 |
