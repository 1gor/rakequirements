| **Суть процесса** | Оценка обеспеченности суда компьютерно-информационными технологиями, определение потребности и возможности финансирования, планирование внедрения, проведение закупочной процедуры, приемка и оформление результата обеспечения КИТ. |

## ****3. Реестр UC****

### UC001 — Определить потребность и спланировать обеспечение КИТ

| **№ шага процесса** | **0–8** |
| --- | --- |
| **Выполняемая задача** | Анализ обеспеченности суда компьютерно-информационными технологиями, определение дополнительной потребности, оценка возможности финансирования и разработка плана внедрения КИТ. |
| **Цель** | Определить необходимость дополнительного обеспечения суда КИТ и подготовить план их внедрения с учетом доступного финансирования. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** начальник отдела информатизации суда. |
| **Ожидаемый результат** | Подтверждена потребность в дополнительном обеспечении КИТ, решён вопрос финансирования и разработан детальный план внедрения. |
| **Рекомендованная функциональность** | Фиксация результатов анализа обеспеченности КИТ; регистрация выявленной потребности; фиксация сведений о возможности финансирования; ведение плана внедрения КИТ с указанием задач, сроков, ответственных лиц и критериев приёмки. |
| **Критичность** | Необходимая. |
| **Триггер** | Выявлена необходимость проведения оценки соответствия имеющихся КИТ требованиям суда. |
| **Предварительные условия** | Имеются сведения о текущем составе и состоянии используемых в суде компьютерно-информационных технологий. |
| **Основной сценарий** | 1. Начальник отдела информатизации суда проводит анализ состояния имеющихся КИТ и их соответствия потребностям суда. 2. По результатам анализа определяется наличие потребности в дополнительном обеспечении КИТ. 3. При наличии потребности начальник отдела информатизации оценивает возможность комплектования необходимыми КИТ и определяет потребность в финансировании. 4. Определяется возможность выделения необходимого бюджета. 5. После решения вопроса финансирования начальник отдела информатизации разрабатывает детальный план внедрения КИТ, включая задачи, сроки, ответственных лиц и критерии приёмки.6. Процесс переходит к организации закупки и приёмки КИТ. |
| **Расширение (альтернативный сценарий)** | **2а. Дополнительная потребность в КИТ отсутствует.** 2а.1 Процесс завершается со статусом «Суд обеспечен всеми КИТ». **4а. Бюджет на обеспечение КИТ не выделен.** 4а.1 Начальник отдела информатизации выполняет согласование выделения бюджета. 4а.2 После решения вопроса финансирования процесс продолжается с разработки плана внедрения КИТ. |

### UC002 — Организовать закупку и приёмку КИТ

| **№ шага процесса** | **9–12** |
| --- | --- |
| **Выполняемая задача** | Организация закупки необходимых КИТ, приёмка поставленных или внедрённых решений и оформление результата обеспечения суда. |
| **Цель** | Обеспечить закупку и фактическое получение необходимых КИТ с подтверждением их комплектности, работоспособности и соответствия требованиям суда. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** начальник отдела информатизации суда.**Участники:** подрядчик. |
| **Ожидаемый результат** | Закупочная процедура завершена, КИТ поставлены или внедрены, проведена их приёмка и подписан акт приёма-передачи. |
| **Рекомендованная функциональность** | Инициация связанного процесса закупки; фиксация связи с ОБП18; регистрация сведений о поставленных или внедрённых КИТ; фиксация результатов приёмки; хранение сведений о подписанном акте приёма-передачи. |
| **Критичность** | Необходимая. |
| **Триггер** | Разработан детальный план внедрения КИТ и определена необходимость их закупки. |
| **Предварительные условия** | Подтверждена потребность в КИТ, решён вопрос финансирования и сформирован детальный план внедрения. |
| **Основной сценарий** | 1. Начальник отдела информатизации инициирует ОБП18 «Участвовать в госзакупках». 2. В рамках связанного процесса проводится закупочная процедура и обеспечивается взаимодействие с подрядчиком. 3. После исполнения обязательств подрядчиком начальник отдела информатизации осуществляет приёмку поставленных или внедрённых КИТ. 4. В ходе приёмки проверяются комплектность, работоспособность и соответствие КИТ установленным требованиям. 5. По результатам приёмки начальник отдела информатизации подписывает акт приёма-передачи. 6. Процесс завершается со статусом «Организовано обеспечение современными КИТ». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
