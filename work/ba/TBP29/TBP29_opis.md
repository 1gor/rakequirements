# [To be] ТБП29. Опубликовать СА

| **Наименование процесса** | ТБП29: Опубликовать СА |
| --- | --- |
| **Суть процесса** | Процесс охватывает действия по публикации судебного акта. Процесс начинается с момента, когда судебный акт был принят и подписан. Сперва формируется пакет данных, который направляется в БД Кад Арбитр. Кад Арбитр обрабатывает полученные данные: формирует файл в формате .pdf, публикует судебный акт, записывает и направляет данные о дате и времени публикации в ИС суда. Затем процесс идет в зависимости от условия получения данных из Кад Арбитр по истечении 24 часов с даты подписания: если прошло 24 часа и данные не были получены, проводится служебная проверка и принимается решение о повторной отправке. Если данные были получены в течение 24 часа, ИС суда записывает и отображает дату и время публикации СА в карточке документа, после чего процесс завершается. |
| **Участники процесса** | Помощник судьи / Судья |
| **НПА** | Федеральный закон от 22.12.2008 № 262-ФЗ «Об обеспечении доступа к информации о деятельности судов в Российской Федерации», ст. 15; Положение о порядке размещения текстов судебных актов на официальных сайтах судов, утв. Постановлением Президиума Верховного Суда РФ от 27.09.2017, пп. 2.2, 4.2. |

| **Выполняемая задача** | Опубликовать СА для ознакомления ЛУВД |

| **Рекомендуемая функциональность** | Интерфейс выбора варианта повторной публикации с сохранением решения пользователя; отображение даты и времени публикации в карточке судебного акта., интеграция с КАД Арбитр |

По истечении установленного времени система получает данные о публикации из внешней системы.  4. Система сохраняет данные о публикации в карточке судебного акта. |
| **Расширение (альтернативный сценарий)** | 2а. По истечении установленного времени система формирует отчет о публикации  2а1. Система устанавливает факт отсутствия данных о публикации.  2а2. Помощник судьи / Судья выбирает опцию по повторной публикации.  Далее происходит процесс повторной публикации, начиная с шага 2 основного сценария. |
