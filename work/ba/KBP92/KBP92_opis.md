# [to be] КБП92. Кассационное производство, включая производство по делам, рассмотренным в упрощенном порядке

| Наименование процесса | КБП92 Кассационное производство, включая производство по делам, рассмотренным в упрощенном порядке |
| --- | --- |
| Суть процесса | Процесс TO BE для схем AS IS КБП 56,58. Процесс описывает рассмотрение дела в суде кассационной инстанции в общем порядке и по делам рассмотренным в порядке упрощенного производства. Процесс начинается с подачи заявителем кассационной жалобы в суд. поступившее в суд заявление регистрируется и передается на рассмотрение судье. Система определяет будет общее производство по кассационной жалобе или будет запущен процесс рассмотрения дела рассмотренного в упрощенном порядке. Затем судья принимает решение по вопросу принятия жалобы к рассмотрению. Затем рассматривает КЖ (общий порядок-тройка судей, упрощенный-судей единолично). По результатом рассмотрения Система для судьи формирует позицию по делу, судья знакомится со сформированной позицией по делу, валидирует ее и в дальнейшем выносит СА. В зависимости от изначально поданного заявления и результата его рассмотрения будет вынесен соответствующий СА. После принятия СА Система синхронизирует решение кассационной инстанции с делами судов нижестоящих инстанций. Процесс завершается передачей рассмотренного электронного дела в электронный архив. |

| 4 | Судья кассационной инстанции | чтобы система определяла, подлежит ли жалоба рассмотрению по правилам ст. 288.2 АПК РФ | не назначать заседание, когда закон требует рассмотреть жалобу без вызова сторон, и не пропустить заседание, когда ст. 288.2 не применяется |
