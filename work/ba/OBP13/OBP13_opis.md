# [To be] ОБП13. Ведение работы по подбору и приобретению печатных изданий

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП13 — Ведение работы по подбору и приобретению печатных изданий |
| **Суть процесса** | Процесс охватывает организацию подбора, согласования, закупки и получения печатных изданий для нужд суда. Он начинается с возникновения необходимости закупить печатные издания при наличии сформированного бюджета и соблюдении установленных сроков. Внутри процесса председатель суда поручает собрать потребности, судьи формируют перечни необходимых изданий, а председатели судебных коллегий и составов консолидируют их в заявки. Далее ответственный отдел формирует сводный перечень, согласует его с финансовым отделом и председателем суда, при необходимости вносит корректировки по замечаниям. После согласования закупка осуществляется либо через УСД, либо через финансовый отдел и отдел МТО, после чего полученные издания сверяются с актом приема-передачи. Процесс завершается подписанием акта председателем суда и фактическим получением закупленных печатных изданий. |
| **Участники процесса** | Председатель суда  Председатели судебных коллегий и судебных составов  Судьи  Отдел, ответственный за закупку печатных изданий  Финансовый отдел  Отдел материально-технического обеспечения  УСД — в части приобретения печатных изданий через Управление Судебного департамента |
| **НПА** | Федеральный закон от 05.04.2013 N 44-ФЗ "О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд"  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)"  Федеральный закон от 29.12.1994 N 77-ФЗ "Об обязательном экземпляре документов" |

## ****3.  Реестр UC****

**UC001-Выявить потребности в печатных изданиях**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–7 |
| **Выполняемая задача** | Сбор, проверка и консолидация сведений о потребностях судей и подразделений суда в печатных изданиях. |
| **Цель** | Сформировать единый обоснованный перечень печатных изданий, необходимых для обеспечения деятельности суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: отдел, ответственный за закупку печатных изданий.  Участники: председатель суда; председатели судебных коллегий и судебных составов; судьи. |
| **Ожидаемый результат** | Сформирован сводный перечень печатных изданий на основании поступивших и проверенных заявок. |
| **Рекомендованная функциональность** | Создание и маршрутизация задач; определение участников сбора; электронная форма потребности с указанием издания и количества; контроль срока исполнения; агрегирование заявок; проверка полноты и устранение дублирования; формирование сводного перечня. |
| **Критичность\*** | Необходимая. |
| **Триггер** | Председателем суда принято решение о необходимости собрать сведения для закупки печатных изданий. |
| **Предварительные условия** | В Системе определены организационная структура суда, ответственные подразделения и пользователи, участвующие в сборе потребностей. |
| **Основной сценарий** | 1. Председатель суда создаёт задачу на сбор информации и определяет участников.  2. Председатели судебных коллегий и судебных составов создают задачи судьям.  3. Судьи указывают необходимые издания и количество экземпляров.  4. Председатели коллегий и составов проверяют сведения.  5. На основании подтверждённых данных Системой формируются и направляются заявки.  6. Ответственный отдел изучает заявки и формирует сводный перечень печатных изданий. |
| **Расширение (альтернативный сценарий)** | 4а Выявлены неполные, противоречивые или дублирующие сведения.  4а.1 Система  возвращает заявку  на уточнение.  4а.2 Процесс возвращается на шаг 3 основного сценария. |

| **Цель** | Подтвердить соответствие перечня установленным финансовым ограничениям и получить решение председателя суда о его согласовании. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: отдел, ответственный за закупку печатных изданий.  Участники: финансовый отдел; председатель суда. |
| **Ожидаемый результат** | Актуальная версия перечня согласована финансовым отделом и председателем суда; задача согласования закрыта. |
| **Рекомендованная функциональность** | Версионирование перечня; электронное согласование; проверка лимитов и доступного финансирования; фиксация замечаний по отдельным позициям; возврат на доработку; повторное согласование; журнал решений и изменений; уведомления ответственным лицам. |

| **Предварительные условия** | Перечень содержит наименования изданий, количество экземпляров и сведения, достаточные для финансовой оценки. |

| **Расширение (альтернативный сценарий)** | ***3а Финансовый отдел фиксирует замечания, предложения или исключения*.**  3а. 1 Финансовый отдел возвращает перечень на доработку.  3а.2 Ответственный отдел корректирует перечень  3а. 3 Ответственный отдел направляет скорректированный  перечень в финансовый отдел.  3а.4 Процесс возвращается на шаг 2 основного сценария. |

**UC-03. Организовать приобретение и приёмку печатных изданий**

|  |  |
| --- | --- |
| **№ шага процесса** | 26–49 |
| **Выполняемая задача** | Определение способа приобретения, организация закупки либо взаимодействия с УСД, получение, сверка и документальное оформление приёмки печатных изданий. |
| **Цель** | Обеспечить фактическое получение согласованных печатных изданий и завершить их приёмку с оформлением подтверждающих документов. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: отдел, ответственный за закупку печатных изданий.  Участники: председатель суда; УСД; финансовый отдел; отдел МТО. |
| **Ожидаемый результат** | Печатные издания получены, сверены с актом приёма-передачи; акт подписан председателем суда; процесс завершён. |
| **Рекомендованная функциональность** | Выбор способа приобретения; передача перечня и замечаний; контроль статуса рассмотрения УСД; создание закупочной задачи; формирование и маршрутизация пакета документов; контроль поставки; регистрация полученных изданий и актов; сверка факта с перечнем и актом; электронное подписание и закрытие процесса. |
| **Критичность\*** | Необходимая. |
| **Триггер** | Председателем суда согласован перечень печатных изданий и определена необходимость их приобретения. |
| **Предварительные условия** | Имеется утверждённый перечень; определён способ приобретения — через УСД либо посредством закупочной процедуры суда. |
| **Основной сценарий** | 1. Председатель суда определяет способ приобретения изданий.  2. При приобретении через УСД согласованный перечень передаётся в УСД на проверку.  3.
