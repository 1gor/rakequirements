# [To be] ОБП10. Подготовить ответ на обращение/запрос

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП10. Подготовить ответ на обращение/запрос |
| **Суть процесса** | Процесс охватывает действия суда по обработке поступающих внепроцессуальных обращений и (или) запросов. Сперва производится первичный анализ запроса для определения дальнейших действий по его обработке. Если запрос (обращение) необходимо направить в иной суд - формируется уведомление о перенаправлении обращении, которое вместе с обращением направляется в другой суд на обработку. Также обращение может быть передано приемной председателя суда/ заместителю председателя суда / Приемной председателя судебной коллегии. После обработки обращения формируется ответ на обращение, который направляется заявителю, а также при необходимости публикуется на сайте суда, после чего процесс завершается. |
| **Участники процесса** | Сотрудник отдела делопроизводства, ответственный за работу с обращениями/Пресс-служба; Приемная председателя суда/ заместитель председателя суда; Приемная председателя судебной коллегии; Система |
| **НПА** | Федеральный закон от 02.05.2006 № 59-ФЗ «О порядке рассмотрения обращений граждан Российской Федерации»  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)"  Приказ ВАС РФ от 30.06.2011 N 68 "Об утверждении Положения о порядке рассмотрения предложений, заявлений и жалоб на действия судей и работников аппаратов арбитражных судов Российской Федерации, а также запросов о предоставлении информации о деятельности судов" |

| **Роль / Актор** | Сотрудник отдела делопроизводства, ответственный за работу с обращениями/Пресс-служба |
| **Ожидаемый результат** | В Системе сохранен проверенный результат автоматического анализа; этап анализа завершен и готов для дальнейшей маршрутизации. |
| **Рекомендуемая функциональность** | Открытие карточки обращения; действие «Запустить анализ»; отображение результата анализа и рекомендации; проверка и корректировка выводов; действие «Завершить анализ». |
| **Критичность** | Необходимая |
| **Триггер** | Зарегистрированное обращение/запрос доступно сотруднику для рассмотрения. |
| **Предварительные условия** | Обращение/запрос зарегистрировано и доступно в Системе. |
| **Основной сценарий** | 1. Сотрудник открывает карточку зарегистрированного обращения/запроса в Системе.  2. Сотрудник выбирает действие «Запустить анализ».  3. Система выполняет анализ обращения, формирует рекомендацию к дальнейшим действиям и создает задачу на обработку.  4. Сотрудник открывает сформированные выводы, проверяет их и фиксирует подтвержденный либо скорректированный результат.  5. Сотрудник выбирает действие «Завершить анализ».  6. В Системе фиксируется завершение этапа анализа; результат доступен для дальнейшей маршрутизации. |
| **Расширение (альтернативный сценарий)** | Если при проверке сформированных выводов требуется корректировка, сотрудник фиксирует корректный результат и завершает анализ после его сохранения. |

**UC002 — Рассмотрение обращения в приемной председателя суда**

|  |  |
| --- | --- |
| **№ шага процесса** | 23–30, 41–51 |
| **Выполняемая задача** | Рассмотреть обращение в приемной председателя суда, при необходимости передать его на публикацию, подготовить ответ и обеспечить его доведение до заявителя либо публикацию. |
| **Цель** | Обеспечить рассмотрение обращения приемной председателя суда и завершить соответствующую ветвь подготовкой и доведением ответа. |
| **Роль / Актор** | Приемная председателя суда/ заместитель председателя суда; Сотрудник отдела делопроизводства, ответственный за работу с обращениями/Пресс-служба |
| **Ожидаемый результат** | Решение о публикации обращения при необходимости зафиксировано; при ветви подготовки ответа приемной ответ сохранен и передан ответственному сотруднику; итоговый ответ опубликован либо направлен заявителю, процесс завершен результатом «Ответ подготовлен и направлен». |
| **Рекомендуемая функциональность** | Открытие карточки обращения; фиксация решения о публикации; передача обращения на публикацию; подготовка и сохранение ответа; публикация или направление ответа; закрытие задачи на обработку. |
| **Критичность** | Необходимая |
| **Триггер** | Система создала задачу на рассмотрение обращения для приемной председателя суда/заместителя председателя суда. |
| **Предварительные условия** | Обращение доступно в Системе; задача на рассмотрение создана. |
| **Основной сценарий** | 1. Приемная председателя суда/заместитель председателя суда открывает карточку обращения и доступные материалы.  2. Если обращение подлежит публикации, приемная фиксирует решение о публикации и выбирает действие передачи обращения для публикации.  3. Система закрывает задачу на рассмотрение и публикует обращение на сайте суда.  4. При переходе к ветви, в которой ответ готовит приемная председателя суда, приемная вносит текст ответа в Системе и сохраняет подготовленный документ.  5. Система передает подготовленный ответ ответственному сотруднику и закрывает задачу на рассмотрение.  6. Если публикация подготовленного ответа не требуется, ответ направляется заявителю по предусмотренному каналу.  7. Сотрудник отдела делопроизводства, ответственный за работу с обращениями/Пресс-служба, выбирает действие «Закрыть задачу на обработку».  8. Процесс завершается результатом «Ответ подготовлен и направлен». |
| **Расширение (альтернативный сценарий)** | Если публикация обращения не требуется, шаги фиксации решения и передачи обращения для публикации пропускаются. Если подготовленный ответ требуется опубликовать, Система публикует ответ на сайте суда, после чего процесс завершается результатом «Ответ подготовлен и направлен» без выполнения шага направления ответа заявителю в данной ветви. |
