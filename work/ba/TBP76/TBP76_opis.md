Результат шага: В системе сохранены структурированные сведения о требованиях, включая перечень требований и признак связи требования об установлении оснований ответственности ответчика с требованием о применении мер ответственности. |  |

Роль: Судья Входящие данные: Отсутствуют Исходящие данные: Отсутствуют |  |

Результат шага: В системе сохранен результат проверки наличия нескольких самостоятельных требований, включая признак «несколько самостоятельных требований: да/нет». |  |
