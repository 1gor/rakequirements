# 3. Реестр UC

**UC001 — Проведение основных проверок оснований для отвода/самоотвода**

| **№ шага процесса** | 0-13 |
| --- | --- |
| **Выполняемая задача** | Проведение основных проверок оснований для отвода/самоотвода |
| **Цель** | Предоставить пользователю результаты основных проверок оснований для отвода/самоотвода для дальнейшего рассмотрения вопроса. |
| **Роль / Актор** | Председатель суда, заместитель председателя суда, председатель судебного состава, судья |
| **Ожидаемый результат** | Пользователю отображены результаты основных проверок по применимым основаниям отвода/самоотвода с их статусами. |
| **Рекомендуемая функциональность** | Раздел карточки вопроса об отводе/самоотводе с отображением результатов основных проверок по каждому применимому основанию. |
| **Критичность** | Необходимая |
| **Триггер** | В карточке вопроса об отводе/самоотводе доступны результаты основных проверок. |
| **Предварительные условия** | В Системе зарегистрирован вопрос об отводе/самоотводе и определены основания, подлежащие основной проверке. |
| **Основной сценарий** | 1. Система отображает пользователю результаты основных проверок по применимым основаниям отвода/самоотвода. 2. Пользователь просматривает результат по каждому проверенному основанию. 3. Система отображает статус проверки и доступные сведения, подтверждающие полученный результат. |
| **Расширение (альтернативный сценарий)** | 1. Если по отдельному основанию результат не может быть сформирован, Система отображает отсутствие результата либо необходимость дополнительной проверки. 2. Пользователь видит, по какому основанию требуется продолжение проверки. |

**UC002 — Проведение специальных проверок оснований для отвода/самоотвода**

| **№ шага процесса** | 14-28 |
| --- | --- |
| **Выполняемая задача** | Проведение специальных проверок оснований для отвода/самоотвода |
| **Цель** | Зафиксировать выбранные дополнительные основания и результаты специальных проверок в Системе. |
| **Роль / Актор** | Председатель суда, заместитель председателя суда, председатель судебного состава, судья |
| **Ожидаемый результат** | Выбранные дополнительные основания и результаты специальных проверок сохранены; пользователю отображены итоговые сведения по выполненным проверкам. |
| **Рекомендуемая функциональность** | Рекомендация по дополнительным основаниям; выбор оснований; формы фиксации результатов выбранных проверок; раздел итогов дополнительных проверок. |
| **Критичность** | Необходимая |
| **Триггер** | Система отображает пользователю рекомендацию по дополнительным основаниям, которые могут потребовать проверки. |
| **Предварительные условия** | Основные проверки завершены; в Системе сформирована рекомендация по дополнительным основаниям проверки. |
| **Основной сценарий** | 1. Система отображает пользователю рекомендованные дополнительные основания для проверки. 2. Пользователь выбирает одно или несколько дополнительных оснований и подтверждает выбор. 3. Система сохраняет выбранные основания и отображает пользователю соответствующие формы фиксации результатов. 4. Пользователь указывает результаты только по выбранным дополнительным основаниям. 5. Система сохраняет введенные результаты и отображает их пользователю. 6. Пользователь вносит и подтверждает итоговые сведения по выполненным дополнительным проверкам. 7. Система отображает сохраненные итоги дополнительных проверок и статус подготовки протокола проверки. |
| **Расширение (альтернативный сценарий)** | 1. Пользователь может выбрать несколько дополнительных оснований; Система предоставляет формы только для выбранных оснований. 2. Если отдельное дополнительное основание не выбрано, действия по его проверке пользователю не предъявляются. 3. Если обязательные сведения по выбранному основанию не заполнены, Система сообщает о необходимости их заполнения до подтверждения итогов. |
