|  |  |
| --- | --- |
| Наименование процесса | **ТБП73: Рассмотреть вопрос об отложении СЗ** |
| Суть процесса | В рамках процесса судья решает вопрос об отложении судебного заседания. Процесс может начаться либо ввиду поступившего заявления об отложении, либо по инициативе суда. Сперва судья определяет основание(-я) отложения (например, неявка лица, сведения об извещении которого отсутствуют/явка которого признана обязательной, необходимость привлечения иных лиц и т.д.). Если основанием является болезнь судьи - такое основание может установить только председатель, который также при наличии возможности производит замену судьи без необходимости отложения. После судья делает вывод о необходимости отложения. Если такой необходимости нет - процесс либо просто завершается, если инициатором рассмотрения вопроса был суд, либо судья выносит определение об отказе в удовлетворении соответствующего ходатайства лица. Если необходимость в отложении определена, судья заслушивает свидетеля/эксперта/специалиста, и откладывает СЗ на более позднюю дату с вынесением соответствующего определения, которое направляется ЛУВД. После этого процесс завершается. |
