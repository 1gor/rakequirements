## ****3. Реестр UC****

**UC001 — Проверить наличие ТМЦ и сформировать сводную заявку**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–5 |
| **Выполняемая задача** | Проверка наличия запрошенных товарно-материальных ценностей на складе и формирование либо корректировка сводной заявки при отсутствии необходимых запасов. |
| **Цель** | Определить возможность удовлетворить поступившую потребность за счет складских остатков либо зафиксировать потребность в закупке недостающих ТМЦ. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела МТО. |
| **Ожидаемый результат** | Наличие ТМЦ на складе подтверждено и процесс передан в ОБП55 либо сформирована/скорректирована сводная заявка на недостающие ТМЦ. |
| **Рекомендованная функциональность** | Регистрация заявки на МТО; получение сведений о складских остатках; сопоставление запрошенных позиций с наличием на складе; создание и корректировка сводной заявки; сохранение связи между исходной заявкой и сводной заявкой; переход к ОБП55 при наличии ТМЦ. |
| **Критичность** | Необходимая. |
| **Триггер** | Поступила заявка на материально-техническое обеспечение. |
| **Предварительные условия** | Заявка на МТО содержит перечень требуемых товарно-материальных ценностей; сотруднику отдела МТО доступны сведения о складских остатках. |
| **Основной сценарий** | 1. Сотрудник отдела МТО получает заявку на материально-техническое обеспечение.  2. Сотрудник отдела МТО запрашивает сведения о наличии требуемых ТМЦ на складе.  3. Сотрудник отдела МТО проверяет складские остатки по позициям, указанным в заявке.  4. Сотрудник отдела МТО устанавливает, что требуемые ТМЦ отсутствуют на складе полностью или частично.  5. Сотрудник отдела МТО создает новую сводную заявку либо корректирует существующую, включая в нее недостающие позиции.  6. Сводная заявка передается для расчета потребности в закупке. |
| **Расширение (альтернативный сценарий)** | 4а. Требуемые ТМЦ имеются на складе в необходимом количестве.  4а.1 Текущий процесс завершается.  4а.2 Дальнейшие действия выполняются в ОБП55 «Организация отпуска товарно-материальных ценностей». |

**UC002 — Рассчитать и согласовать потребность в закупке**

|  |  |
| --- | --- |
| **№ шага процесса** | 6–13 |
| **Выполняемая задача** | Расчет потребности и суммы закупки, согласование финансовых параметров и подготовка итогового перечня ТМЦ для запуска закупочной процедуры. |
| **Цель** | Сформировать обоснованный и финансово согласованный перечень ТМЦ, подлежащих закупке. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Руководитель отдела МТО. Участники: Сотрудник отдела бухгалтерского учета и отчетности; Система. |
| **Ожидаемый результат** | Потребность в закупке рассчитана, сумма закупки согласована, подготовлен итоговый список ТМЦ и скорректирована сводная заявка для перехода к ОБП18. |
| **Рекомендованная функциональность** | Расчет потребности по видам ТМЦ; фиксация достаточности объема для проведения закупочной процедуры; автоматический расчет общей суммы закупки по сводной заявке; маршрутизация на согласование бухгалтерии; фиксация решения о согласовании суммы; возврат расчета на пересмотр; формирование итогового перечня ТМЦ для закупки; переход к ОБП18. |
| **Критичность** | Необходимая. |
| **Триггер** | Сформирована или скорректирована сводная заявка на недостающие ТМЦ. |
| **Предварительные условия** | В сводной заявке определены позиции ТМЦ и объем потребности; руководителю отдела МТО доступны сведения, необходимые для расчета закупки. |
| **Основной сценарий** | 1. Руководитель отдела МТО рассчитывает потребность в закупке по видам ТМЦ на основании сводной заявки.  2. Руководитель отдела МТО оценивает достаточность объема потребности для проведения закупочной процедуры.  3. Система автоматически рассчитывает общую сумму закупки по данным сводной заявки.  4. Сотрудник отдела бухгалтерского учета и отчетности рассматривает рассчитанную сумму закупки с учетом финансовых возможностей.  5. Сотрудник отдела бухгалтерского учета и отчетности согласовывает сумму закупки.  6. Руководитель отдела МТО формирует итоговый список ТМЦ для размещения закупки.  7. При необходимости руководитель отдела МТО корректирует сводную заявку с учетом согласованных финансовых параметров.  8. Процесс завершается подготовкой списка ТМЦ для размещения закупки и переходит в ОБП18 «Участие в организации размещения заказов на поставки товаров». |
| **Расширение (альтернативный сценарий)** | 5а. Сумма закупки не согласована.  5а.1 Расчет возвращается на пересмотр.  5а.2 Руководитель отдела МТО повторно оценивает потребность и параметры закупки.  5а.3 Система повторно рассчитывает сумму закупки.  5а.4 Скорректированная сумма повторно передается сотруднику отдела бухгалтерского учета и отчетности на согласование. |
