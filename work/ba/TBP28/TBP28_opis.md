## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Председатель суда/уполномоченное лицо арбитражного суда | Принятие решения о необходимости замены судьи, вынесение определения о замене, распределение дела новому судье, координация процесса замены |
| Судебное отделение арбитражного суда | Направление документов лицам, участвующим в деле, подготовка дела к передаче, передача дела судье, ведение документооборота |
| Судья арбитражного суда | Получение дела для рассмотрения по существу, переход к рассмотрению дела на стадии подготовки |
| Лица, участвующие в деле | Получение определения о замене судьи, ознакомление с содержанием определения |
| Другой суд | Получение дела для рассмотрения по существу при передаче из вышестоящего суда |
| Система | Формирует рекомендации пользователю с учетом производственного календаря, с учетом отпусков и больничных, с учетом специфики дела и состава суда, позволяет выбрать пользователя для замены, формирует шаблоны документов с учетом новых данных, информирует лиц участвующих в деле и вышестоящий суд в случае необходимости, фиксирует данные об ознакомлении по лицам участвующим в деле, связывает сущности при вынесении судебных документов. |

Примечание: В российском арбитражном процессе нет установленных процессуальных сроков для самой замены судьи, поскольку она происходит при наличии оснований, предусмотренных законом, таких как длительное отсутствие судьи или его прекращение полномочий. Однако при такой замене судебное разбирательство должно начаться с начала, а решение по делу должно быть принято в установленные законом сроки, которые могут быть продлены в исключительных случаях.
