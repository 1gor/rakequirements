|  |  |

| Суть процесса | Замена судьи по делу при возникновении оснований, препятствующих дальнейшему рассмотрению дела текущим составом суда. 3. Реестр UC (в части выполняемых пользователем задач и рекомендованной функциональности Системы)

UC-001. Выбор нового судьи для замены

|  |  |
| --- | --- |
| **Поле** | **Значение** |
| **№ шага процесса** | 0-1 |
| **Выполняемая задача** | Инициировать процесс замены судьи и выбрать нового судью для замены. |
| **Цель** | Обеспечить своевременное управленческое решение о необходимости замены судьи и определить кандидата для замены по делу. |
| **Роль (в соответствии со схемой)** | Председатель суда/уполномоченное лицо; Система |
| **Ожидаемый результат** | Зафиксирована необходимость замены судьи; выбран кандидат судьи для замены; данные переданы для дальнейших процедур (оформление определения/проверка условий). |
| **Рекомендованная функциональность** | 1. Подбор кандидатов с учетом доступности и ограничений (нагрузка, отпуск/больничный и т.п.). 2. Проверка прав пользователя и фиксация основания замены в журнале действий. 3. Журналирование выбора (кто/когда/какого судью выбрал) и возможность отмены до завершения оформления. |
| **Критичность** | Высокая |
| **Триггер** | Возникла необходимость заменить судью по делу. |
| **Предварительные условия** | Дело заведено в системе; у председателя/уполномоченного лица есть права на выполнение замены судьи. |
| **Основной сценарий** | 1. Возникает необходимость заменить судью. 2. Председатель/уполномоченное лицо выбирает нового судью для замены. 3. Система фиксирует выбор и инициирует последующие действия по оформлению/проверке (переход к шагу 2). |
| **Расширение (альтернативный сценарий)** | 2а. Подходящий кандидат отсутствует система отображает причины (статусы/ограничения) и предлагает повторить выбор/изменить параметры. |

|  |  |
| --- | --- |
| **Поле** | **Значение** |
| **№ шага процесса** | 2-5 |
| **Выполняемая задача** | Определить необходимость вынесения определения о замене судьи и, при необходимости, оформить его. |
| **Цель** | Юридически оформить замену судьи судебным актом (определением) в случаях, когда это требуется, с фиксацией результата в системе. |
| **Роль (в соответствии со схемой)** | Председатель суда/уполномоченное лицо; Система |

Версионирование и журналирование действий по определению (создание/подписание/регистрация) с неизменяемым хранением. |

| **Предварительные условия** | Выбран кандидат; доступны реквизиты дела и данные для формирования определения (при необходимости). |

На шлюзе «Необходимо вынести определение о замене судьи?» (шаг 3) определяется маршрут:  - Да: председатель/уполномоченное лицо оформляет определение в рамках ТБП80.Принять СА (шаг 4).  - Нет: переход к шагу 6. 3. После завершения ветви процесс сходится на шаге 5 и продолжает выполнение (переход к шагу 6). |
| **Расширение (альтернативный сценарий)** | 2а. Недостаточно данных для формирования определения система уведомляет о недостающих реквизитах и блокирует продолжение до устранения. |

UC-003. Анализ возможности замены судьи в том же арбитражном суде

| **Цель** | Обосновать и подтвердить выполнимость замены судьи в текущем составе суда либо определить необходимость передачи дела в другой арбитражный суд. |

| **Предварительные условия** | Доступны сведения о судьях и ограничениях; пользователь имеет права на проверку/подтверждение. |
| **Основной сценарий** | 1. Система анализирует возможность замены судьи в данном составе суда (шаг 6). 2. Система формирует протокол проверки (шаг 7). 3. Председатель/уполномоченное лицо проверяет выводы системы (шаг 8, ТБП139.Проверить выводы системы). 4. На шлюзе «Имеется возможность замены в данном составе суда?» (шаг 9) фиксируется исход:  - Да: переход к шагу 14.  - Нет: переход к шагу 10. |

UC-004. Передача дела в другой арбитражный суд при невозможности замены судьи

|  |  |
| --- | --- |
| **Поле** | **Значение** |
| **№ шага процесса** | 9-13 |
| **Выполняемая задача** | Организовать передачу дела в другой арбитражный суд при невозможности замены судьи в рамках данного суда. |
| **Цель** | Обеспечить соблюдение процессуального порядка передачи дела и фиксацию результата в системе при невозможности сформировать состав суда для замены. |
| **Роль (в соответствии со схемой)** | Председатель суда/уполномоченное лицо; Сотрудник судебного отделения; Система |
| **Ожидаемый результат** | Выбран арбитражный суд для передачи; дело подготовлено и направлено; процесс завершен событием «Замена судьи не произведена» |
| **Рекомендованная функциональность** | 1. Справочник арбитражных судов и контроль корректности выбора адресата. 2. Контроль комплектности материалов при подготовке к передаче ТБП88.Подготовить дело к передаче и статусы прохождения. 3. Уведомления ответственным участникам и журналирование этапов передачи/реквизитов отправки. |
| **Критичность** | Высокая |
| **Триггер** | На шлюзе шага 9 зафиксирован исход «Нет» (замена в данном составе суда невозможна). |
| **Предварительные условия** | Доступны данные о деле и маршруте передачи; у участников есть права на подготовку/направление дела. |
| **Основной сценарий** | 1. По результату шлюза (шаг 9) процесс переходит к сценарию передачи дела. 2. Председатель/уполномоченное лицо выбирает другой арбитражный суд для передачи дела (шаг 10). 3. Сотрудник судебного отделения подготавливает дело к передаче шаг 11, ТБП88.Подготовить дело к передаче. 4. Сотрудник судебного отделения направляет дело (шаг 12, ТБП47.Направить дело). 5. Процесс завершается (шаг 13). |
| **Расширение (альтернативный сценарий)** | 3а. Подготовка невозможна (некомплект/ошибка) фиксируется причина, выполняется доукомплектование и повтор шага 3. |

UC-005. Замена судьи в рамках данного арбитражного суда (распределение/вручную) и передача дела судье

|  |  |
