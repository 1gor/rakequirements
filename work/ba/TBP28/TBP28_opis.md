# [To be] ТБП28. Заменить судью

| **Наименование процесса** | ТБП28 — Заменить судью |
| --- | --- |
| **Суть процесса** | Замена судьи по делу при удовлетворении заявления об отводе или самоотводе, длительном отсутствии судьи, приостановлении либо прекращении его полномочий. Система проверяет возможность замены среди фактически работающих судей, поддерживает выбор дальнейшего маршрута, анализ оснований замены, распределение дела и фиксацию передачи. При невозможности сформировать состав суда обеспечивается оформление и направление дела в другой арбитражный суд того же уровня. |
| **Участники процесса** | Председатель суда/уполномоченное лицо; Сотрудник судебного отделения |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): ст. 18, 39, 185;  Постановление Пленума ВАС РФ от 17.02.2011 № 12 (ред. от 27.06.2017) «О некоторых вопросах применения Арбитражного процессуального кодекса Российской Федерации в редакции Федерального закона от 27.07.2010 № 228-ФЗ»: п. 3.1, 3.7;  Постановление Пленума ВАС РФ от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)». |

# **3. Реестр UC**

**UC001 — Передать дело в другой арбитражный суд при невозможности замены**

| **№ шага процесса** | 0–8 |
| --- | --- |
| **Выполняемая задача** | Проверить возможность замены судьи и, если сформировать состав суда невозможно, оформить и выполнить передачу дела в другой арбитражный суд. |
| **Цель** | Обеспечить законный и прослеживаемый маршрут дела при невозможности заменить судью в пределах данного суда. |
| **Роль / Актор** | Председатель суда/уполномоченное лицо; Сотрудник судебного отделения |
| **Ожидаемый результат** | Сформирован результат проверки возможности замены; принято определение о передаче дела; материалы подготовлены и направлены; делу присвоен статус «Передано в другой АС». |
| **Рекомендуемая функциональность** | Автоматизированная проверка возможности замены среди фактически работающих судей; формирование предложения по другому суду; отображение статуса подготовки и направления дела; журналирование ключевых действий и изменения статуса. |
| **Критичность** | Высокая |
| **Триггер** | Наступило основание для замены судьи. |
| **Предварительные условия** | Дело находится в производстве суда; зафиксировано основание для замены; у участников есть необходимые права на действия по передаче. |
| **Основной сценарий** | 1. Система проверяет возможность замены судьи среди фактически работающих судей.  2. Если возможность замены отсутствует, система формирует предложение по другому арбитражному суду.  3. Оформляется определение о передаче дела в рамках ТБП80 «Принять СА».  4. Материалы дела подготавливаются к передаче в рамках ТБП88 «Подготовить дело к передаче».  5. Дело направляется в рамках ТБП47 «Направить дело».  6. Система присваивает делу статус «Передано в другой АС».  7. Процесс завершается передачей дела в другой арбитражный суд того же уровня. |
| **Расширение (альтернативный сценарий)** | 1. Если возможность замены судьи внутри суда имеется, выполнение продолжается с шага 9 по сценарию UC002.  2. Если подготовка или направление дела не завершены, процесс остается в соответствующем типовом процессе до устранения причины согласно его правилам. |

**UC002 — Определить нового судью и оформить замену**

| **№ шага процесса** | 9, 11–16 |
| --- | --- |
| **Выполняемая задача** | Проанализировать основание замены, распределить дело новому судье, проверить результат системы и оформить документ, соответствующий основанию замены. |
| **Цель** | Определить судью, назначаемого взамен, и оформить замену с учетом установленного основания. |
| **Роль / Актор** | Председатель суда/уполномоченное лицо |
| **Ожидаемый результат** | Дело распределено новому судье; результат системы проверен; оформлен документ по соответствующей ветви; альтернативные ветви объединены для последующей передачи дела. |
| **Рекомендуемая функциональность** | Автоматический анализ категории основания замены; интеграция с ТБП54 для распределения дела; интерфейс проверки выводов системы; маршрутизация к соответствующему виду оформления; журналирование принятого решения. |
| **Критичность** | Высокая |
| **Триггер** | На шаге 2 установлено, что замена судьи в пределах данного суда возможна. |
| **Предварительные условия** | Доступны сведения о составе суда и основании замены; пользователь обладает полномочиями на проверку результатов и оформление замены. |
| **Основной сценарий** | 1. Система анализирует основание замены судьи.  2. Дело распределяется новому судье в рамках ТБП54 «Распределить дело судье», формируется АРПД.  3. Уполномоченное лицо проверяет выводы системы в рамках ТБП139 «Проверить выводы системы».  4. На основании результата шага 9 выбирается ветвь документального оформления.  5. При длительном отсутствии либо прекращении/приостановлении полномочий выполняется ТБП49 «Сформировать и подписать документ».  6. При удовлетворении отвода или самоотвода выполняется ТБП80 «Принять СА».  7. Ветви объединяются и процесс переходит к подготовке дела к передаче. |
| **Расширение (альтернативный сценарий)** | 1. Если проверка выводов системы выявляет необходимость корректировки, дальнейшие действия выполняются по правилам ТБП139 до получения подтвержденного результата.  2. Если основание замены не позволяет однозначно определить ветвь, переход к документальному оформлению не должен выполняться до уточнения основания. |

**UC003 — Передать дело судье, назначенному взамен**

| **№ шага процесса** | 17–20 |
| --- | --- |
| **Выполняемая задача** | Подготовить дело, создать запись о передаче в реестре и выполнить передачу дела новому судье. |
| **Цель** | Завершить замену судьи фактической и учетной передачей дела судье, назначенному взамен. |
| **Роль / Актор** | Сотрудник судебного отделения |
| **Ожидаемый результат** | Дело подготовлено; в реестре создана запись о передаче; дело передано судье; процесс завершен. |
| **Рекомендуемая функциональность** | Контроль готовности дела к передаче; автоматическое создание записи в реестре; фиксация даты и результата передачи; отображение итогового статуса процесса. |
| **Критичность** | Высокая |
| **Триггер** | Завершено документальное оформление замены и объединены альтернативные ветви на шаге 16. |
| **Предварительные условия** | Определен новый судья; завершено предусмотренное схемой документальное оформление; дело доступно для подготовки к передаче. |
| **Основной сценарий** | 1. Дело подготавливается к передаче в рамках ТБП88 «Подготовить дело к передаче».  2. Система автоматически создает запись о передаче судье в реестре.  3. Система выполняет предусмотренную процессом передачу дела судье.  4. Процесс завершается фиксацией произведенной замены судьи и передачи дела. |
| **Расширение (альтернативный сценарий)** | 1. Если подготовка, создание записи либо техническая передача не завершены, дальнейшая операция не выполняется до устранения причины; после устранения выполняется повтор с фиксацией результата в журнале действий. |
