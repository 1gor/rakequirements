# [To be] ТБП101. Проверить соответствие стратегической организации

| **Наименование процесса** | ТБП101 — Проверить соответствие стратегической организации |
| --- | --- |
| **Суть процесса** | Процесс предназначен для установления соответствия юридического лица признакам стратегической организации. Система выполняет поиск юридического лица в перечне стратегических организаций и выявляет в материалах дела довод ЛУВД о наличии соответствующего признака. При необходимости получения дополнительных сведений выполняется переход к типовому процессу направления запроса в ведомство. По результатам проверок Система формирует протокол, выводы Системы проверяются Судьей, после чего Судья принимает итоговое решение о соответствии либо несоответствии юридического лица признакам стратегической организации. |
| **Участники процесса** | Судья; Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)»: ст. 190. |

# 3. Реестр UC

**UC001 — Проверки на соответствие стратегической организации**

| **№ шага процесса** | 0-5 |
| --- | --- |
| **Выполняемая задача** | Проверить соответствие юридического лица признакам стратегической организации и оформить решение о соответствии либо несоответствии. |
| **Цель** | Установить факт соответствия юридического лица признакам стратегической организации для определения дальнейшего процессуального пути. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе сформировано решение «ЮЛ является стратегической организацией» либо «ЮЛ не соответствует признакам стратегической организации». |
| **Рекомендуемая функциональность** | Поиск юридического лица в перечне стратегических организаций; отображение актуального перечня стратегических предприятий и организаций; оформление решения о соответствии с указанием основания. |
| **Критичность** | Необходимая |
| **Триггер** | Судья запускает поиск по перечню стратегических организаций |
| **Предварительные условия** | В Системе доступен актуальный перечень стратегических предприятий и организаций, опубликованный Правительством Российской Федерации. |
| **Основной сценарий** | 1. Судья вводит реквизиты проверяемого юридического лица и запускает поиск по перечню стратегических организаций. 2. Система регистрирует результат сопоставления юридического лица с перечнем стратегических организаций (найдено/не найдено). 3. Судья открывает актуальный перечень стратегических предприятий и организаций. 4. Судья фиксирует признаки (категория организации), указанные ЛУВД, и привязывает их к соответствующим сведениям перечня в Системе. 5. Система формирует запись о доводе ЛУВД о признаке стратегической организации с указанием сопоставленного положения перечня. 6. Судья выбирает вариант решения о соответствии либо несоответствии признакам стратегической организации. 7. Система формирует решение «ЮЛ является стратегической организацией» либо «ЮЛ не соответствует признакам стратегической организации». |
