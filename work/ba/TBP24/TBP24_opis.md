# [To be] ТБП24. Принять частное определение о нарушении законности

| **Наименование процесса** | ТБП24: Принять частное определение о нарушении законности |
| --- | --- |
| **Суть процесса** | Вынесение и направление частного определения при выявлении нарушения законодательства Российской Федерации, получение сведений о принятых мерах и контроль реагирования на частное определение. | **Участники процесса** | Судья, Помощник судьи, Канцелярия, Система, орган/организация/должностное лицо, в отношении которого вынесено частное определение, вышестоящие организации, Органы дознания/предварительного следствия, Лицо, в отношении которого вынесено частное определение |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ, ст. 188.1. |

| **Цель** | Получить в Системе сведения о поступлении либо отсутствии ответа по частному определению и ознакомиться с доступной информацией о принятых мерах. |

| **Ожидаемый результат** | Судья ознакомлен с отображаемым Системой результатом контроля: поступившим ответом и его реквизитами либо статусом отсутствия ответа. |
| **Рекомендуемая функциональность** | Отображение уведомления о поступлении либо отсутствии ответа; переход из уведомления к карточке частного определения и доступным сведениям о принятых мерах; фиксация факта ознакомления. |
| **Критичность** | Необходимая |
| **Триггер** | В интерфейсе судьи отображено уведомление о поступлении ответа либо об отсутствии ответа по частному определению. |
| **Предварительные условия** | Частное определение находится на контроле исполнения; Система сформировала для судьи результат контроля поступления ответа. |
| **Основной сценарий** | 1. Судья открывает уведомление.  2. Система отображает карточку частного определения и доступные сведения о поступившем информационном письме и принятых мерах.  3. Судья знакомится с отображенными сведениями.  4. Система фиксирует факт ознакомления судьи. |
| **Расширение (альтернативный сценарий)** | 1. Система отображает судье уведомление об отсутствии ответа по частному определению.  2. Судья открывает уведомление.  3. Система отображает карточку частного определения со статусом отсутствия ответа и доступной информацией о контроле исполнения.  4. Судья знакомится с отображенной информацией.  5. Система фиксирует факт ознакомления судьи. |
