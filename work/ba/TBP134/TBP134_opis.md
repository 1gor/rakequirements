# [To be] ТБП134. Рассмотреть вопрос о завершении реализации

| **Наименование процесса** | ТБП134 — Рассмотреть вопрос о завершении реализации |
| --- | --- |
| **Суть процесса** | Процесс описывает действия суда по разрешению вопроса о завершении процедуры реализации имущества должника с использованием Системы для автоматизации отдельных проверок и формирования данных. Процесс начинается после оценки доказательств, когда суд переходит к принятию решения по вопросу о завершении реализации. Суд оценивает необходимость продления процедуры, погашение требований кредиторов, влияние завершения процедуры на права лиц, участвующих в деле, полноту рассмотрения заявлений и ходатайств, применимые нормы права, отчет арбитражного управляющего и исполнение им обязанностей. Если требуется продление реализации, рассмотрение неразрешенных обращений либо дополнительное исследование доказательств, текущая стадия принятия решения прекращается для совершения необходимых процессуальных действий. При отсутствии препятствий Суд подтверждает решение о завершении реализации и переходит к рассмотрению вопроса об освобождении должника от обязательств. |
| **Участники процесса** | Судья |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026): в том числе ст. 57, 213.9, 213.28.  Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): в том числе ст. 41, 167–170. |

| **№ шага процесса** | 1-7 |

| **Критичность** | Необходимая |
| **Триггер** | Суд инициирует оформление формы о соблюдении тайны совещательной комнаты |
| **Предварительные условия** | у Системы есть материалы дела и актуальный этап принятия решения по вопросу завершения реализации. |
| **Основной сценарий** | 1. Судья инициирует оформление формы о соблюдении тайны совещательной комнаты в Системе.  2. Система открывает форму о соблюдении тайны совещательной комнаты для заполнения.  4. Судья  заполняет форму о тайне совещательной комнаты в Системе, указывая обстоятельства обеспечения либо невозможности обеспечения тайны.  5. Система сохраняет в форме признак « не обеспечена».  6. Система  закрывает доступ к вынесению судебного акта е при выявлении нарушения тайны совещательной комнаты. |
| **Расширение (альтернативный сценарий)** | 5а1 Система сохраняет признак «обеспечена».  5а2 Система возвращается к рассмотрению вопроса |
