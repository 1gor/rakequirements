| **Наименование процесса** | ТБП66. Подготовиться к судебному заседанию |
| **Суть процесса** | Процесс охватывает совокупность процессуальных действий судьи и аппарата арбитражного суда, направленных на обеспечение правильного, всестороннего и своевременного рассмотрения дела в судебном заседании. Бизнес-процесс начинается с возникновения у судьи необходимости подготовки дела к судебному заседанию и включает изучение материалов дела и поступивших от сторон документов, направление и анализ ответов на межведомственные запросы, проверку и рассмотрение ходатайств о содействии в получении доказательств, при необходимости истребование дополнительных доказательств, проведение собеседования со сторонами, разъяснение их процессуальных прав и возможностей примирения, определение подлежащих совершению процессуальных действий и установление соответствующих сроков. Процесс завершается определением формата предстоящего судебного заседания (явочного либо неявочного), актуализацией графика судебных заседаний при необходимости и завершением подготовки дела к его рассмотрению по существу. |
| **Участники процесса** | Судья |

| **Ожидаемый результат** | Судья определил необходимость онлайн‑собеседования и назначил его; в назначенное время собеседование проведено; в системе зафиксированы отметки разъяснений, поручения/действия и сроки для ЛУВД; при отсутствии необходимости в собеседовании блок пропущен; блок онлайн‑собеседования завершён и подготовка к судебному заседанию продолжается. |
| **Рекомендованная функциональность** | Планирование онлайн‑собеседования из карточки дела; формирование ссылки/приглашений для участников и отправка уведомлений; создание и запуск онлайн‑сессии; контроль подключения/явки участников и фиксация статусов участия; фиксация протокольных отметок и ключевых результатов; онлайн‑транскрибация с привязкой к делу (при наличии сервиса); чек‑лист разъяснений (арбитражные заседатели/посредник/примирительные процедуры) с возможностью отметить «разъяснено»; интерфейс формирования поручений/действий для ЛУВД и их детализации; установка сроков и контрольных дат по каждому действию; уведомления участникам о поручениях и сроках; хранение истории изменений поручений/сроков; журналирование действий и событий; разграничение прав доступа и защита служебной информации по делу. |
| **Критичность** | необходимая |
| **Триггер** | Судья в карточке дела открывает раздел «Онлайн-собеседование». |
| **Предварительные условия** | Подготовка к судебному заседанию инициирована; судья авторизован и имеет доступ к карточке дела; в системе доступен функционал онлайн‑собеседования (создание/запуск сессии, подключение участников); известны контактные данные/учётные записи участников для подключения; у судьи есть права на фиксацию результатов (поручения/сроки) в системе; сервис транскрибации (при использовании) доступен. |
| **Основной сценарий** | 1. Судья в карточке дела открывает раздел «Онлайн‑собеседование». 2. Система отображает текущий статус онлайн‑собеседования по делу и доступные действия в разделе. 3. Судья выбирает действие «Назначить онлайн‑собеседование». 4. Система отображает форму назначения онлайн‑собеседования (дата/время, участники, способ подключения). 5. Судья указывает дату и время онлайн‑собеседования. 6. Судья выбирает участников онлайн‑собеседования. 7. Судья подтверждает назначение онлайн‑собеседования. 8. Система сохраняет назначение и устанавливает статус «Назначено». 9. Система формирует приглашения/ссылки подключения для участников. 10. Система отправляет участникам уведомления о назначенном онлайн‑собеседовании. 11. Система отображает статус «Ожидание наступления даты и времени собеседования». 12. Система фиксирует наступление назначенной даты и времени собеседования. 13. Судья нажимает «Начать собеседование». 14. Система создаёт онлайн‑сессию и отображает статусы подключения участников. 15. Судья подтверждает начало собеседования. 16. Система запускает запись/транскрибацию (при наличии) и фиксирует протокольную отметку «Собеседование начато». 17. Судья фиксирует отметку «Разъяснены процессуальные возможности: арбитражные заседатели». 18. Судья фиксирует отметку «Разъяснены процессуальные возможности: посредник». 19. Судья фиксирует отметку «Разъяснены процессуальные возможности: примирительные процедуры». 20. Судья добавляет поручение/действие для ЛУВД. 21. Система отображает форму детализации поручения (описание, адресат, срок). 22. Судья заполняет параметры поручения и срок исполнения. 23. Судья сохраняет поручение. 24. Система сохраняет поручение и срок в карточке дела. 25. Система отправляет участникам уведомления о поручениях и сроках. 26. Судья завершает онлайн‑собеседование. 27. Система фиксирует протокольную отметку «Собеседование завершено» и сохраняет результаты (при наличии записи/транскрипции). 28. Система закрывает блок онлайн‑собеседования и отображает продолжение подготовки к судебному заседанию. |
| **Расширение (альтернативный сценарий)** | 3а. Онлайн‑собеседование не назначено и не требуется. 3а1. Судья выбирает решение «Собеседование не требуется». 3а2. Система фиксирует решение о пропуске онлайн‑собеседования. 3а3. Система закрывает блок онлайн‑собеседования и отображает продолжение подготовки к судебному заседанию.  14а. Участники не подключились к онлайн‑собеседованию. 14а1. Система отображает статус «Участник не подключился» по каждому отсутствующему участнику. 14а2. Судья фиксирует результат «Собеседование не состоялось по неявке участников». 14а3. Система сохраняет протокольную отметку о неявке. 14а4. Судья выбирает действие «Переназначить собеседование». 14а5. Система отображает форму переназначения (дата/время). 14а6. Судья указывает новую дату и время. 14а7. Судья подтверждает переназначение. 14а8. Система сохраняет переназначение и отправляет участникам обновлённые приглашения.  14б. Техническая ошибка при создании/проведении онлайн‑сессии. 14б1. Система отображает сообщение о технической ошибке проведения онлайн‑собеседования. 14б2. Судья фиксирует результат «Собеседование не состоялось по технической причине». 14б3. Система сохраняет протокольную отметку о технической причине. 14б4. Судья выбирает решение «Продолжить подготовку по имеющимся материалам». 14б5. Система фиксирует решение судьи о продолжении подготовки без собеседования. |
