# [To be] ТБП133. Рассмотреть вопрос о завершении конкурсного производства

| **Наименование процесса** | ТБП133 — Рассмотреть вопрос о завершении конкурсного производства |
| --- | --- |
| **Суть процесса** | Процесс в TO BE описывает действия суда по разрешению вопроса о завершении конкурсного производства с использованием Системы для автоматизации отдельных проверок и формирования данных. Процесс начинается после оценки доказательств, когда суд переходит к вынесению решения по вопросу о завершении конкурсного производства. В ходе процесса судья проверяет необходимость продления процедуры, определяет возможность ее завершения, учитывает состояние расчетов с кредиторами, соблюдение прав лиц, участвующих в деле, и полноту рассмотрения поступивших заявлений и ходатайств. Система автоматически формирует отдельные сведения для подготовки судебного акта, а судья проверяет выводы конкурсного управляющего и надлежащее исполнение им обязанностей, оценивает необходимость дополнительного исследования доказательств и разрешения вопросов обеспечительных мер. При полном погашении требований кредиторов производство по делу о банкротстве прекращается; при наличии обстоятельств, требующих продолжения процессуальных действий, текущая стадия принятия решения прекращается. При отсутствии препятствий процесс завершается подтверждением судьей решения о завершении конкурсного производства и переходом к изготовлению судебного акта. |
| **Участники процесса** | Судья; Система |
| **НПА** | Федеральный закон от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026): в том числе ст. 124, 125, 127, 144, 147, 149. |

| **Цель** | Обеспечить процессуальную корректность рассмотрения вопроса завершения конкурсного производства с учетом соблюдения тайны совещательной комнаты. |

Судья подтверждает сведения формы.  5. Система отображает в карточке дела ограничение доступа к вынесению судебного акта (статус ограничения активен). |
| **Расширение (альтернативный сценарий)** | 3а. Судья указывает в форме отсутствие нарушения тайны совещательной комнаты.  3а1. Система сохраняет результат проверки без ограничения доступа к вынесению судебного акта. |

**UC002 — Рассмотрение вопроса завершения конкурсного производства**

| **№ шага процесса** | 8-38 |
| --- | --- |
| **Выполняемая задача** | Подготовить и отразить в проекте судебного акта выводы по вопросу завершения конкурсного производства. |
| **Цель** | Принять решение о возможности завершения конкурсного производства и обосновать его в судебном акте. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | Проект судебного акта содержит обоснование выводов по вопросу завершения конкурсного производства, включая применение нормативных положений и содержание норм права в официальном толковании и судебной практике, а также сведения о правах и обязанностях лиц, участвующих в деле. |
| **Рекомендованная функциональность** | Электронный рабочий интерфейс судьи для формирования разделов проекта судебного акта (нормативная база, мотивы, реквизиты, выводы по правам и обязанностям, результаты проверки материалов). |
| **Критичность** | Необходимая |
| **Триггер** | Судья инициирует фиксацию решения о завершении конкурсного производства. |
| **Предварительные условия** | В Системе доступен проект судебного акта по вопросу завершения конкурсного производства и выполнены ранее установленные исходные данные, используемые для подготовки выводов. |
| **Основной сценарий** | 1. Судья фиксирует в Системе вывод об отсутствии необходимости продления конкурсного производства.  2. Судья фиксирует в Системе вывод о наличии оснований для завершения конкурсного производства.  3. Судья фиксирует в Системе вывод о том, что завершение процедуры не нарушает права ЛУВД.  4. Судья указывает в Системе законы и НПА, подлежащие применению.  5. Система отображает перечень законов и НПА, на которые ссылаются ЛУВД.  6. Судья фиксирует в Системе содержание норм права в официальном толковании.  7. Судья фиксирует в Системе содержание норм права в судебной практике.  8. Судья фиксирует в Системе права и обязанности ЛУВД.  9. Система отображает в проекте судебного акта заполненные идентифицирующие реквизиты дела и участников.  10. Судья фиксирует в Системе вывод о соответствии выводов арбитражного управляющего в отчёте материалам дела.  11. Судья фиксирует в Системе вывод о надлежащем исполнении обязанностей арбитражным управляющим.  12. Система отображает в проекте судебного акта сведения об исключении должника из ЕГРЮЛ.  13. Судья фиксирует в Системе результат по вопросу освобождения арбитражного управляющего от исполнения обязанностей.  14. Система отображает в проекте судебного акта реквизиты для оплаты арбитражного управляющего.  15. Судья фиксирует в Системе вывод о достаточности доказательств для принятия решения.  16. Судья подтверждает решение о завершении конкурсного производства. |
| **Расширение (альтернативный сценарий)** | 1а. Судья подтверждает прекращение текущей стадии принятия решения в связи с необходимостью продления конкурсного производства.  5а. Судья указывает в проекте судебного акта мотивы неприменения НПА, на которые ссылаются ЛУВД. |
