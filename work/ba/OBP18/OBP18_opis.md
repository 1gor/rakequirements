# [To be] ОБП18. Участие в организации размещения заказов на поставки товаров

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП18 — Участие в организации размещения заказов на поставки товаров |
| **Суть процесса** | Определение способа закупки, подготовка и согласование закупочных документов, проведение закупочной процедуры и заключение контракта с использованием автоматизированных функций Системы. |
| **Участники процесса** | Сотрудник отдела МТО; Руководитель отдела МТО; Председатель суда; Комиссия по осуществлению закупок; Система; Единая информационная система (ЕИС). |
| **НПА** | Федеральный закон от 05.04.2013 № 44-ФЗ (ред. от 28.12.2025, с изм. и доп., вступ. в силу с 01.07.2026) «О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд». Распоряжение Правительства РФ от 21.03.2016 № 471-р (ред. от 31.10.2022) «О перечне товаров, работ, услуг, в случае осуществления закупок которых заказчик обязан проводить аукцион в электронной форме (электронный аукцион)». |

### UC001 — Осуществить закупку у единственного поставщика

|  |  |
| --- | --- |
| **№ шага процесса** | 0–33 |
| **Выполняемая задача** | Проверка соответствия закупки плану-графику, определение способа закупки, выбор единственного поставщика, автоматическое формирование закупочных документов, их согласование, подписание контракта и размещение необходимых сведений в ЕИС. |
| **Цель** | Обеспечить подготовку, согласование и заключение контракта с единственным поставщиком в соответствии с выбранным способом закупки. |

| **Ожидаемый результат** | Контракт с единственным поставщиком согласован, подписан председателем суда, сохранён в Системе и необходимые сведения размещены в ЕИС либо принято решение об отмене или повторном проведении закупки. |
| **Рекомендованная функциональность** | Проверка и фиксация соответствия закупки плану-графику; фиксация выбранного способа закупки и поставщика; автоматическое формирование проекта контракта и сопутствующих документов; автоматическое назначение ответственных; электронное согласование и возврат документов на доработку; хранение версий документов; сохранение подписанного контракта; подготовка комплекта сведений для размещения в ЕИС. |
| **Критичность** | Необходимая. |
| **Триггер** | Подготовлено техническое задание либо сформирован список ТМЦ для закупки. |
| **Предварительные условия** | Подготовлены сведения о закупаемых товарах, работах или услугах; имеется актуальный план-график закупок. |
| **Основной сценарий** | 1. Сотрудник отдела МТО сверяет закупку с планом-графиком. 2. При соответствии плану-графику сотрудник определяет способ закупки. 3. В качестве способа закупки выбирается закупка у единственного поставщика. 4. Сотрудник отдела МТО выбирает поставщика. 5. Система автоматически формирует проект контракта с единственным поставщиком и необходимые сопутствующие документы. 6. Система назначает руководителя отдела МТО ответственным за рассмотрение документов. 7. Руководитель отдела МТО рассматривает контракт и при отсутствии необходимости доработки принимает решение по проекту. 8. Руководитель отдела МТО согласовывает контракт и направляет его председателю суда. 9. Система назначает председателя суда ответственным за следующий этап согласования. 10. Председатель суда рассматривает и подписывает контракт. 11. Система сохраняет подписанный контракт в карточке закупки. 12. Сотрудник отдела МТО размещает необходимые сведения и документы в ЕИС. 13. Процесс завершается заключением контракта с поставщиком. |
| **Расширение (альтернативный сценарий)** | **1а. Закупка не соответствует плану-графику.** 1а.1 Процесс завершается без проведения закупки. **7а. Руководитель отдела МТО выявил необходимость доработки контракта.** 7а.1 Руководитель формирует замечания и возвращает контракт сотруднику отдела МТО. 7а.2 Сотрудник корректирует контракт и возвращает его на повторное рассмотрение. 7а.3 Процесс возвращается к рассмотрению контракта руководителем отдела МТО. **8а. Руководитель отдела МТО отказывает в согласовании либо председатель суда отклоняет контракт.** 8а.1 Документы возвращаются сотруднику отдела МТО. 8а.2 Сотрудник знакомится с причинами отклонения и определяет необходимость продолжения поиска поставщика. 8а.3 При продолжении закупки процесс возвращается к повторному выбору способа закупки. 8а.4 При отказе от дальнейшего поиска процесс завершается отменой закупки. |
