## 3. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Суд | завершает оценку доказательств, отвечает на вопрос о тайне совещательной, знакомится с анализом системы, указывает мотивы неприменения НПА, устанавливает содержание норм права, определяет права и обязанности ЛУВД, принимает решение по основному иску, знакомится с анализом встречного иска, принимает решение по встречному иску, производит зачет требований, проверяет расчеты системы, определяет судьбу вещественных доказательств, определяет срок исполнения решения, определяет порядок исполнения решения, прекращает процесс при необходимости дополнительных исследований |
| Система | инициирует проверку тайны совещательной, задает вопрос судье, проверяет ответ о тайне совещательной, закрывает доступ к вынесению СА при нарушении тайны, сохраняет информацию о соблюдении тайны, проверяет выводы, проверяет ссылки на НПА, объединяет потоки процесса, разделяет процесс на параллельные потоки, синхронизирует параллельные потоки, проверяет наличие встречного иска, формирует анализ по встречному иску, проверяет выводы по встречному иску, определяет необходимость зачета, рассчитывает сумму после зачета, определяет необходимость распределения расходов, распределяет судебные расходы, проверяет необходимость определения судьбы доказательств, определяет необходимость обеспечительных мер, останавливает процесс при необходимости обеспечительных мер, проверяет необходимость установления срока исполнения, проверяет необходимость дополнительных исследований, сохраняет данные о решении, сохраняет данные о прекращении процесса |
