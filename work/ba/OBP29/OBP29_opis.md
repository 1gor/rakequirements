# [To be] ОБП29. Организация исполнения обязательств и контроль за исполнением государственных договоров

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП29 — Организация исполнения обязательств и контроль за исполнением государственных договоров |
| **Суть процесса** | Организация приемки товаров, работ и услуг по государственным договорам, фиксация и устранение нарушений, ведение претензионной работы и оформление расторжения контракта при неисполнении обязательств. |

| **НПА** | Федеральный закон от 05.04.2013 № 44-ФЗ «О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд»  Федеральный закон от 06.12.2011 № 402-ФЗ «О бухгалтерском учете»  Постановление Госкомстата РФ от 18.08.1998 № 88 «Об утверждении унифицированных форм первичной учетной документации по учету кассовых операций, по учету результатов инвентаризации»  Постановление Росстата от 09.08.1999 № 66 «Об утверждении унифицированных форм первичной учетной документации по учету продукции, товарно-материальных ценностей в местах хранения»  Федеральный закон от 22.12.2008 № 262-ФЗ «Об обеспечении доступа к информации о деятельности судов в Российской Федерации» |

# ****1. Реестр US****

| 1 | Руководитель/сотрудник отдела, ответственного за контроль гос. договоров | провести приемку и зафиксировать результат исполнения обязательств | подтвердить надлежащее исполнение либо документально оформить выявленные нарушения |

## ****3. Реестр UC****

**UC001 — Провести приемку и оформить надлежащее исполнение обязательств**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–9 |
| **Выполняемая задача** | Проведение приемки товаров, работ или услуг, оформление приемочных документов через ЕИС либо вне ЕИС и проверка данных бухгалтерией. |
| **Цель** | Подтвердить надлежащее исполнение обязательств по государственному договору и корректно оформить результат приемки. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель/сотрудник отдела, ответственного за контроль гос. договоров. Участники: инициатор закупки; сотрудник отдела бухгалтерского учета и отчетности; Система; ЕИС. |
| **Ожидаемый результат** | Товары, работы или услуги приняты без нарушений, приемочные документы подписаны, их данные проверены в информационной системе, обязательства по контракту признаны исполненными. |
| **Рекомендованная функциональность** | Регистрация результата приемки; фиксация способа оформления документов через ЕИС либо вне ЕИС; хранение подписанных первичных учетных документов; передача сведений для бухгалтерской проверки; фиксация завершения исполнения обязательств. |
| **Критичность** | Необходимая. |
| **Триггер** | Суду переданы товары, результаты выполненных работ или оказанных услуг для приемки в рамках исполнения обязательств по договору. |
| **Предварительные условия** | Заключен государственный договор; предмет поставки или результат исполнения передан суду; имеется первичный учетный документ. |
| **Основной сценарий** | 1. Руководитель или сотрудник отдела, ответственного за контроль государственных договоров, выполняет приемку товаров, работ или услуг.  2. Ответственный сотрудник проверяет количество, качество и объем исполнения и сопоставляет результат с условиями договора и первичным учетным документом.  3. По результатам приемки определяется отсутствие нарушений.  4. Ответственный сотрудник определяет, ведется ли работа с подрядчиком через ЕИС.  5. Если работа ведется вне ЕИС, ответственный сотрудник проверяет реквизиты и подписывает первичный учетный документ.  6. Если работа ведется через ЕИС, инициатор закупки подписывает первичный учетный документ усиленной квалифицированной электронной подписью.  7. Инициатор закупки подписывает в ЕИС документ о приемке.  8. Сотрудник отдела бухгалтерского учета и отчетности проверяет реквизиты и показатели приемочных документов в информационной системе.  9. Процесс завершается с результатом «Обязательства по контракту исполнены». |
| **Расширение (альтернативный сценарий)** | 3а. По результатам приемки выявлены нарушения.  3а.1 Процесс переходит к UC002 «Зафиксировать нарушения и проконтролировать устранение недостатков». |

**UC002 — Зафиксировать нарушения и проконтролировать устранение недостатков**

|  |  |
| --- | --- |
| **№ шага процесса** | 10–24 |
| **Выполняемая задача** | Подготовка и направление акта несоответствия, ожидание его подписания и исправления недостатков, контроль результата устранения. |
| **Цель** | Документально зафиксировать выявленные нарушения и предоставить подрядчику возможность устранить недостатки в установленный срок. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель/сотрудник отдела, ответственного за контроль гос. договоров. Участники: Подрядная организация; Система; ЕИС. |
| **Ожидаемый результат** | Акт несоответствия направлен подрядчику; недостатки устранены либо зафиксированы основания для перехода к претензионной работе. |
| **Рекомендованная функциональность** | Автоматическое формирование акта несоответствия; поддержка его подписания и направления через ЕИС либо вне ЕИС; фиксация срока подписания и срока исправления недостатков; получение уведомлений от подрядчика; регистрация результата устранения недостатков. |
| **Критичность** | Необходимая. |
| **Триггер** | По результатам приемки выявлены нарушения условий договора. |
| **Предварительные условия** | Проведена приемка; выявленные нарушения зафиксированы; имеются сведения договора и первичного учетного документа. |
| **Основной сценарий** | 1. Система формирует акт несоответствия на основании данных договора, первичного учетного документа и результатов приемки.  2. Ответственный сотрудник проверяет содержание акта и организует его подписание уполномоченными участниками проверки.  3. Ответственный сотрудник определяет, ведется ли работа с подрядчиком через ЕИС.  4. Система направляет подписанный акт подрядчику вне ЕИС либо размещает его в ЕИС и фиксирует результат отправки.  5. После направления акта процесс ожидает его подписания подрядчиком либо истечения установленного срока.  6. При получении уведомления о подписании акта процесс ожидает устранения недостатков либо истечения срока, установленного для их исправления.  7. При поступлении сведений об устранении недостатков ответственный сотрудник определяет результат их устранения.  8. Если недостатки устранены, процесс завершается с результатом «Недостатки устранены». |
| **Расширение (альтернативный сценарий)** | 5а. Истек срок, установленный для подписания акта несоответствия.  5а.1 Процесс переходит к UC003 «Провести претензионную работу и расторгнуть контракт».  6а. Истек срок, установленный для исправления недостатков.  6а.1 Процесс переходит к UC003 «Провести претензионную работу и расторгнуть контракт».  7а. По результатам проверки установлено, что недостатки не устранены.  7а.1 Процесс переходит к UC003 «Провести претензионную работу и расторгнуть контракт». |

**UC003 — Провести претензионную работу и расторгнуть контракт**

|  |  |

| **Цель** | Предъявить подрядчику юридически значимые требования и оформить расторжение контракта при неисполнении обязательств. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: инициатор закупки. Участники: руководитель/сотрудник отдела, ответственного за контроль гос. договоров; сотрудник отдела бухгалтерского учета и отчетности; Подрядная организация; Система; ЕИС. |
