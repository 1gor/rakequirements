| **Предварительные условия** | Определен предмет инвентаризации; доступны сведения об объектах учета; уполномоченные участники имеют доступ к Системе и средства электронной подписи. |
| **Основной сценарий** | 1. Процесс начинается при наступлении срока плановой годовой инвентаризации либо при поступлении запроса на внеплановую инвентаризацию.  2. Начальник отдела информатизации/отдела МТО/отдела анализа и обобщения определяет состав инвентаризационной комиссии.  3. Система автоматически формирует шаблон решения о проведении инвентаризации.  4. Начальник отдела заполняет решение, указывая предмет, сроки, состав комиссии и ответственное лицо.  5. Начальник отдела направляет решение председателю суда на подписание посредством электронного документооборота в Системе.  6. Председатель суда проверяет и подписывает решение усиленной квалифицированной электронной подписью.  7. Начальник отдела формирует в Системе инвентаризационную опись материальных ценностей и технических средств.  8. Начальник отдела определяет дату и время начала инвентаризации и доводит сведения до членов комиссии.  9. В установленную дату начальник отдела организует начало инвентаризации.  10. Инвентаризационная комиссия проверяет фактическое наличие и состояние объектов, включенных в опись.  11. Комиссия сверяет учетные инвентаризационные номера и наименования с фактическими данными и вносит результаты в Систему.  12. Система автоматически формирует проект акта о результатах инвентаризации.  13. Инвентаризационная комиссия проверяет, при необходимости дополняет и подписывает акт усиленной квалифицированной электронной подписью.  14. Комиссия определяет наличие расхождений по итогам инвентаризации. |
| **Расширение (альтернативный сценарий)** | 1а. Основанием является запрос на проведение внеплановой инвентаризации.  1а.1 Процесс продолжается по общему маршруту с определения состава комиссии.  14а. Расхождения по итогам инвентаризации отсутствуют.  14а.1 Процесс переходит к сохранению результатов инвентаризации в рамках UC002. |

**UC002 — Оформить расхождения и сохранить результаты инвентаризации**

|  |  |
| --- | --- |
| **№ шага процесса** | 17–23 |
| **Выполняемая задача** | Оформление выявленных расхождений, утверждение дефектного акта и итоговых документов, а также сохранение результатов инвентаризации в Системе. |
| **Цель** | Документально зафиксировать выявленные расхождения и сохранить полный комплект результатов проведенной инвентаризации. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: начальник отдела информатизации/отдела МТО/отдела анализа и обобщения. Участники: инвентаризационная комиссия; Система. |
| **Ожидаемый результат** | Результаты инвентаризации и утвержденные документы сохранены в Системе; при наличии расхождений оформлены дефектный акт и документы по итогам инвентаризации. |
| **Рекомендованная функциональность** | Автоматическое формирование шаблона дефектного акта и комплекта документов по итогам; подписание документов усиленной квалифицированной электронной подписью; автоматическое сохранение результатов и связывание всех утвержденных документов с записью инвентаризации. |
| **Критичность** | Необходимая. |
| **Триггер** | Инвентаризационная комиссия утвердила акт о результатах инвентаризации и определила наличие либо отсутствие расхождений. |
| **Предварительные условия** | Акт о результатах инвентаризации утвержден; результаты проверки и сведения о расхождениях внесены в Систему. |
| **Основной сценарий** | 1. По итогам инвентаризации выявлены расхождения.  2. Система автоматически формирует шаблон дефектного акта с использованием сведений о расхождениях и объектах инвентаризации.  3. Инвентаризационная комиссия проверяет сформированный дефектный акт, дополняет необходимые сведения и подписывает его усиленной квалифицированной электронной подписью.  4. Система формирует комплект документов по итогам инвентаризации с учетом утвержденного дефектного акта.  5. Начальник отдела информатизации/отдела МТО/отдела анализа и обобщения проверяет и дополняет подготовленные документы.  6. Начальник отдела подписывает документы по расхождениям усиленной квалифицированной электронной подписью.  7. Система сохраняет результаты инвентаризации и связывает с ними акт о результатах, дефектный акт и документы по выявленным расхождениям.  8. Процесс завершается с результатом «Инвентаризация проведена. Результаты инвентаризации зафиксированы». |
| **Расширение (альтернативный сценарий)** | 1а. Расхождения по итогам инвентаризации отсутствуют.  1а.1 Подготовка и утверждение дефектного акта и документов по расхождениям не выполняются.  1а.2 Система сохраняет результаты инвентаризации и утвержденный акт о ее результатах.  1а.3 Процесс завершается с результатом «Инвентаризация проведена. Результаты инвентаризации зафиксированы». |
