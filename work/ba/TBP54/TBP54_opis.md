Описание ТБП54 "Распределить дело судье" To Be

|  |  |
| --- | --- |
| Наименование процесса | ТБП54:Распределить дело судье |
| Суть процесса | Началом процесса является необходимость распределения дела на конкретного судью после его регистрации. В ходе процесса определяется, будет ли дело распределено автоматически, либо по правилам, установленным ЛНА, либо председателем судебного состава либо председателем судебной коллегии либо председателем суда. В ходе автоматического распределения проверяется корректность внесенных данных и происходит распределение дела. После распределения проверяются результаты. Если распределение успешно, то формируется акт АРПД; если произошла ошибка распределения, то вносятся коррективы и распределение запускается заново. Председатель состава распределяет дело автоматической системой случайного распределения между судьями состава. Председатель коллегии выбирает судью, если между судебными составами есть спор о распределении. Председатель суда назначает судью, если есть спор между судебными коллегиями. Процесс завершается распределением дела судье. |
| Участники процесса | Лицо, ответственное за распределение арбитражного суда  Председатель судебного состава арбитражного суда  Председатель коллегии арбитражного суда  Председатель арбитражного суда |
| НПА | Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" (далее-Инструкция по делопроизводству)  Приказ АСГМ № ПР-16/12 (С приложениями) от 29.03.2024 (ЛНА) |
