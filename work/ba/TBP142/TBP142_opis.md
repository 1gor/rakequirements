3. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия / функции** |
| --- | --- |
| Суд / Судья | инициирует процесс формирования правовой позиции, оценивает доказательства по делу, определяет вид спора, рассматривает различные категории дел по существу (административная ответственность, выдача исполнительного листа, отмена третейского решения, исковые заявления, недействительность сделки, корпоративные споры, признание юридических фактов и др.), проверяет подсудность, принимает решение о наличии оснований препятствующих рассмотрению, завершает процесс |
| Система | анализирует материалы дела и определяет направления правовой позиции, запускает параллельные ветви анализа, инициирует параллельные проверки процессуальных оснований, проверяет основания для оставления без рассмотрения, проверяет основания для прекращения производства, объединяет результаты проверок, фиксирует выявленные основания в отчете, синхронизирует все ветви, формирует отчет по правовой позиции, создает событие и ставит задачу судье |
