# [To be] ОБП12. Организация кодификационно-справочной работы в суде

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП12 — Организация кодификационно-справочной работы в суде |
| **Суть процесса** | Выявление изменений законодательства, их автоматизированный анализ с использованием Системы, проверка выводов сотрудником, информирование работников суда и подготовка проектов изменений локальных НПА при необходимости. |

| **НПА** | Федеральный конституционный закон от 07.02.2011 № 1-ФКЗ «О судах общей юрисдикции в Российской Федерации». Приказ Судебного департамента при Верховном Суде РФ от 29.05.2023 № 91 «Об утверждении Положения об аппарате федерального суда общей юрисдикции». |

### ****UC. Организовать кодификационно-справочную работу при изменении законодательства****

|  |  |
| --- | --- |
| **№ шага процесса** | 1–11 |
| **Выполняемая задача** | Организовать кодификационно-справочную работу при изменении законодательства |
| **Цель** | Проанализировать новый или изменённый нормативный правовой акт, определить его влияние на деятельность суда, при необходимости организовать информирование работников суда и подготовить проект создания или изменения локального НПА. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор — сотрудник отдела обобщения судебной практики и анализа судебной статистики. Вспомогательный актор — Система. |
| **Ожидаемый результат** | Изменения законодательства проанализированы, выводы Системы проверены сотрудником, работники суда при необходимости проинформированы, а также сформирован проект нового или изменённого локального НПА либо зафиксировано решение оставить локальные НПА без изменений. |
| **Рекомендованная функциональность** | Загрузка и хранение нормативных правовых актов; автоматизированный анализ изменений с использованием LLM; выявление существенных изменений и оценка их влияния на деятельность суда; формирование обоснованных рекомендаций; проверка, корректировка и подтверждение выводов Системы; фиксация решения о необходимости информирования работников; запуск связанного процесса информирования; определение необходимости создания или изменения локального НПА; автоматическое формирование проекта локального НПА; ведение версий и сохранение результатов процесса. |
| **Критичность** | Необходимая |
| **Триггер** | Изменение действующего законодательства либо принятие нового нормативного правового акта, требующего анализа его влияния на деятельность суда. |
| **Предварительные условия** | Сотруднику доступен текст нового или изменённого НПА; сотрудник авторизован в Системе и обладает необходимыми правами; при изменении локального НПА его актуальная версия доступна в Системе. |
| **Основной сценарий** | 1. Сотрудник знакомится с новым или изменённым НПА.  2. Сотрудник загружает НПА в Систему.  3. Система анализирует документ, выявляет существенные изменения и оценивает их возможное влияние на деятельность суда.  4. Система формирует предложения о необходимости информирования работников суда и создания либо изменения ЛНА  5. Сотрудник проверяет выводы Системы.  6. Сотрудник подтверждает выводы Системы  7. Сотрудник подтверждает необходимость информирования работников суда.  8. Система информирует  работников об изменениях законодательства.  9. Сотрудник подтверждает необходимость создания нового или изменения действующего ЛНА  10. Система формирует проект нового ЛНА  или вносит  изменения в  действующий ЛНА  11. Проект ЛНА  готов для последующего утверждения. |
| **Расширение (альтернативный сценарий)** | 5 а. Выводы Системы содержат ошибки или являются неполными.  5а1 Сотрудник корректирует  их  5а2 Сотрудник фиксирует проверенный результат.  7а Если информирование работников суда не требуется  7а1 Сотрудник подтверждает, что информирование не нужно  7а2 Система не запускает процесс информирование сотрудников  7а3 Переход к шагу 9 основного процесса  9а. Если необходимость создания или изменения ЛНА отсутствует  9а 1 Сотрудник подтверждает решение оставить локальные НПА без изменений  9а2Система завершает процесс без внесения изменений или создания нового ЛНА. |
