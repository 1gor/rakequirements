# [To be] ОБП40. Подготовка обоснования потребности в бюджетных ассигнованиях для финансирования деятельности суда

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП40 — Подготовка обоснования потребности в бюджетных ассигнованиях для финансирования деятельности суда |
| **Суть процесса** | Подготовка, проверка, согласование и направление в УСД обоснования потребности суда в бюджетных ассигнованиях и формы по ОКУД. |
| **Участники процесса** | Отдел бухгалтерии; Председатель; Система; Управление Судебного департамента (УСД). |
| **НПА** | Приказ Судебного департамента при Верховном Суде Российской Федерации от 28.06.2013 № 129 «Об утверждении Порядка подготовки обоснований бюджетных ассигнований на очередной финансовый год и плановый период» (с изменениями, внесенными приказом Судебного департамента при Верховном Суде Российской Федерации от 26.02.2026 № 58). |

## ****3. Реестр UC****

**UC001 — Проанализировать расходы и сформировать смету**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–16 |
| **Выполняемая задача** | Проведение анализа исполнения бюджета, учет нормативных требований и факторов изменения расходов, формирование и детализация сметы, определение объема бюджетных ассигнований и связывание расходов с результатами деятельности суда. |
| **Цель** | Подготовить расчетную и аналитическую основу для обоснования потребности суда в бюджетных ассигнованиях на соответствующий финансовый год и плановый период. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Отдел бухгалтерии. Участник: Система. |
| **Ожидаемый результат** | Сформирована детализированная смета расходов, определены объемы ассигнований и расчетные показатели, а расходы сопоставлены с конкретными результатами деятельности суда. |
| **Рекомендованная функциональность** | Создание сущности обоснования потребности в бюджетных ассигнованиях; автоматический анализ исполнения бюджета предыдущего года; формирование рекомендаций; ведение сметы расходов; автоматическая детализация расходов по статьям; хранение расчетов и нормативных оснований; вызов ТБП2 при недостаточности данных; связывание расходов с результатами деятельности. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость подготовить обоснование потребности в бюджетных ассигнованиях для финансирования деятельности суда. |
| **Предварительные условия** | Доступны показатели исполнения бюджета предыдущего года, применимые нормативные правовые акты и исходные сведения для планирования расходов. |
| **Основной сценарий** | 1. Сотрудник отдела бухгалтерии запускает в Системе функцию подготовки обоснования потребности в бюджетных ассигнованиях для соответствующего финансового года и планового периода.  2. Система создает сущность для накопления данных об обосновании потребности в бюджетных ассигнованиях.  3. Система анализирует показатели исполнения бюджета за предыдущий год и сохраняет результаты анализа в созданной сущности.  4. Система формирует рекомендацию для оценки будущих расходов.  5. Сотрудник отдела бухгалтерии изучает нормативные правовые акты, которые могут повлиять на состав или объем будущих расходов.  6. Сотрудник отдела бухгалтерии сопоставляет рекомендации Системы с нормативными требованиями и определяет факторы увеличения или уменьшения расходов.  7. Сотрудник отдела бухгалтерии формирует структуру сметы расходов и связывает ее с обоснованием потребности.  8. Система детализирует показатели по предусмотренным статьям расходов.  9. Сотрудник отдела бухгалтерии указывает расчеты, нормативные основания и иные сведения по каждой статье расходов.  10. Сотрудник отдела бухгалтерии определяет необходимый объем бюджетных ассигнований по каждой статье.  11. Сотрудник отдела бухгалтерии определяет расчетные показатели, используемые для будущего расчета бюджета.  12. Сотрудник отдела бухгалтерии оценивает достаточность данных для сопоставления расходов с результатами деятельности.  13. При достаточности данных сотрудник отдела бухгалтерии связывает планируемые расходы с конкретными результатами деятельности суда. |
| **Расширение (альтернативный сценарий)** | 12а. Подготовленных данных недостаточно для сопоставления расходов с конкретными результатами деятельности.  12а.1 Сотрудник отдела бухгалтерии инициирует ТБП2 «Сформировать отчет».  12а.2 В рамках ТБП2 формируется отчет, дополняющий данные обоснования.  12а.3 После формирования отчета сотрудник отдела бухгалтерии связывает расходы с конкретными результатами деятельности суда. |

**UC002 — Подготовить обоснование и форму по ОКУД**

|  |  |
| --- | --- |
| **№ шага процесса** | 17–23 |
| **Выполняемая задача** | Определение итоговой запрашиваемой суммы, обоснование ее необходимости и достаточности, определение кодов бюджетных ассигнований, формирование и подписание формы по ОКУД и передача документов председателю. |
| **Цель** | Подготовить корректный и комплектный пакет документов, содержащий обоснование потребности в бюджетных ассигнованиях и форму по ОКУД. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Отдел бухгалтерии. Участник: Система. |
| **Ожидаемый результат** | Итоговая сумма ассигнований обоснована, коды бюджетных ассигнований проверены, форма по ОКУД сформирована и подписана, а пакет документов передан председателю на согласование. |
| **Рекомендованная функциональность** | Фиксация итоговой суммы бюджетных ассигнований; хранение обоснования необходимости и достаточности суммы; автоматическое определение кодов бюджетных ассигнований; вызов ТБП139 для проверки выводов Системы; вызов ТБП49 для формирования и подписания формы по ОКУД; передача документов председателю и создание связанной задачи на ознакомление. |
| **Критичность** | Необходимая. |
| **Триггер** | Смета расходов сформирована, объемы ассигнований определены, а расходы связаны с результатами деятельности суда. |
| **Предварительные условия** | В обосновании имеются расчеты по статьям расходов, расчетные показатели и результаты сопоставления расходов с деятельностью суда. |
| **Основной сценарий** | 1. Сотрудник отдела бухгалтерии указывает итоговую сумму бюджетных ассигнований, необходимую для финансирования деятельности суда.  2. Сотрудник отдела бухгалтерии формирует обоснование необходимости и достаточности указанной суммы.  3. Система определяет применимые коды бюджетных ассигнований на основании подготовленных данных о расходах.  4. Сотрудник отдела бухгалтерии выполняет ТБП139 «Проверить выводы системы» и проверяет корректность определенных кодов.  5. Сотрудник отдела бухгалтерии инициирует ТБП49 «Сформировать и подписать документ».  6. В рамках ТБП49 формируется и подписывается форма по ОКУД, а обоснование потребности актуализируется.  7. Сотрудник отдела бухгалтерии передает председателю обоснование потребности, форму по ОКУД и связанные материалы.  8. Система создает председателю задачу на ознакомление и предоставляет доступ к подготовленному обоснованию. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

**UC003 — Согласовать и направить документы в УСД**

|  |  |
| --- | --- |
| **№ шага процесса** | 24–33 |
| **Выполняемая задача** | Рассмотрение обоснования председателем, формирование и устранение замечаний, согласование документов и направление согласованного пакета в Управление Судебного департамента. |
| **Цель** | Обеспечить проверку и окончательное согласование потребности суда в бюджетных ассигнованиях перед направлением документов в УСД. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Председатель. Участники: Отдел бухгалтерии; Система; Управление Судебного департамента (УСД). |
| **Ожидаемый результат** | Обоснование потребности и форма по ОКУД согласованы председателем и направлены в УСД либо возвращены в отдел бухгалтерии на исправление с последующим повторным согласованием. |
| **Рекомендованная функциональность** | Создание и закрытие задачи председателя на ознакомление; фиксация результата рассмотрения; формирование замечаний; автоматическое создание задачи на исправление и передача замечаний; ведение версий исправленного обоснования; повторный запуск ТБП49 и цикла согласования; фиксация согласования; автоматическое направление пакета документов в УСД и регистрация результата отправки. |
| **Критичность** | Необходимая. |
| **Триггер** | Председателю создана задача на ознакомление с подготовленным обоснованием потребности в бюджетных ассигнованиях. |
| **Предварительные условия** | Обоснование потребности и форма по ОКУД сформированы и переданы председателю вместе со связанными материалами. |
| **Основной сценарий** | 1. Председатель открывает задачу и знакомится с обоснованием потребности в бюджетных ассигнованиях.  2. Председатель изучает расчеты, формулировки и состав подготовленных документов.  3. Председатель определяет, что документы подготовлены корректно.  4. Председатель согласовывает обоснование потребности в бюджетных ассигнованиях.  5. Система направляет согласованный пакет документов в Управление Судебного департамента.  6. Система фиксирует выполнение отправки.  7. Процесс завершается с результатом «Бюджетное ассигнование для финансирования деятельности суда обосновано. Документы переданы в УСД». |
| **Расширение (альтернативный сценарий)** | 3а. Председатель выявляет замечания к расчетам, формулировкам или составу документов.  3а.1 Председатель формирует и фиксирует замечания к обоснованию.  3а.2 Система создает задачу на исправление и передает замечания в отдел бухгалтерии.  3а.3 Сотрудник отдела бухгалтерии вносит необходимые изменения в расчеты и текст обоснования.  3а.4 Сотрудник отдела бухгалтерии передает исправленные документы на повторное формирование, подписание и согласование.  3а.5 Процесс возвращается к ТБП49 и повторному рассмотрению председателем. |
