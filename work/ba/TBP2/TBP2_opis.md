**ТБП2:Сформировать отчет**

|  |  |
| --- | --- |
| Наименование процесса | ТБП2:Сформировать отчет |
| Суть процесса | Процесс описывает создание процессуального или статистического отчета по делу или группе дел. Процесс запускается если требуется сформировать отчет по запросу пользователя. В процессе происходит выбор вида отчета, формирование отчетов, по статистическим отчетам происходит анализ ФЛК, если ошибки логического контроля обнаружены, то вносятся коррективы в данные системы и отчет запускается заново. Если ошибок в отчете нет, то пользователь переходит к выбору конечного действия с отчетом: распечатать, экспортировать, просто закрыть после ознакомления. Процесс завершается когда отчет сформирован. |
| Участники процесса | Пользователь ИС арбитражного суда |
| НПА | Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)"  Приказ Судебного департамента при Верховном Суде РФ от 25.06.2021 N 124 "Об утверждении Инструкции по ведению судебной статистики" |
