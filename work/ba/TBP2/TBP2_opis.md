# [To be] ТБП2. Сформировать отчет

| **Наименование процесса** | ТБП2:Сформировать отчет |
| --- | --- |
| **Суть процесса** | Формирование процессуального или статистического отчета. Для статистического отчета выполняется формально-логический контроль; при выявлении ошибок данные корректируются и отчет формируется повторно. После формирования пользователь может распечатать, экспортировать или закрыть отчет. |
| **Участники процесса** | Сотрудник суда, Система |
| **НПА** | Постановление Пленума ВАС РФ от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)»; Приказ Судебного департамента при Верховном Суде РФ от 25.06.2021 № 124 «Об утверждении Инструкции по ведению судебной статистики». |

Система подтверждает сохранение изменений и после обновления отчета отображает актуальный результат.  4. При передаче на исправление сотрудник суда выбирает действие «Направить на исправление».  5. Система подтверждает направление на исправление и отображает соответствующий статус.  6. После устранения ошибок Система отображает обновленный отчет, после чего сотрудник суда продолжает работу по основному сценарию. |

При необходимости сотрудник суда открывает связанную карточку документа.  6. Система отображает выбранную карточку документа; после просмотра сотрудник возвращается к отчету.  7. Сотрудник суда продолжает работу по основному сценарию и выбирает необходимое действие с отчетом. |
