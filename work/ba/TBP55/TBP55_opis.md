# ТБП55: Зарегистрировать дело/документ TO BE

|  |  |
| --- | --- |
| **Наименование процесса** | ТБП55: Зарегистрировать дело/документ |
| **Суть процесса** | Описывает процесс регистрации входящего документа/дела в арбитражном суде. Процесс начинается с момента, когда входящие документ/дело прошли проверки на соответствие требованиям к подаче документов в суд и ожидают регистрации. Процесс регистрации выбирается в зависимости от вида поступившего документа (ПД/дело - одна ветка регистрации. Вторичный документ по уже существующему делу/иной документ по уже существующему делу/Обособленный спор-другая ветка регистрации). Процесс завершается или зарегистрированным делом или зарегистрированным документом в уже существующем деле или зарегистрированным обособленным спором. |
| **Участники процесса** | Сотрудник канцелярии |
| **НПА** | Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" (далее- Инструкция по делопроизводству) |

## **1. Реестр US**

|  |  |  |  |

| **№** | **Я КАК** | **ХОЧУ** | **ЧТОБЫ** |
| 1 | Сотрудник канцелярии | Понимать, что поступило: новое дело или документ по уже существующему делу | Правильно выбрать порядок регистрации |
| 2 | Сотрудник канцелярии | Проверять, есть ли в системе уже такое же дело | Не создавать дубликат и при необходимости присоединить документы к существующему делу |
| 3 | Сотрудник канцелярии | Выбирать тип дела или документа из справочника | Правильно классифицировать поступившие материалы |
| 4 | Сотрудник канцелярии | Искать участника дела в базе арбитражного суда | Использовать уже имеющиеся данные и не создавать дубликаты |
| 5 | Сотрудник канцелярии | Добавлять нового участника дела, если его нет в базе | Внести все нужные данные для дальнейшего ведения дела |
| 6 | Сотрудник канцелярии | Проверять результаты автоматической проверки данных дела | Убедиться, что карточка дела заполнена правильно |
| 7 | Сотрудник канцелярии | Регистрировать дело после проверки данных | Присвоить делу номер и официально зафиксировать его в системе |
| 8 | Сотрудник канцелярии | Получать автоматически сформированный электронный штамп с номером дела, датой, временем и моими ФИО | Подтвердить регистрацию материалов дела |
| 9 | Сотрудник канцелярии | Проверять данные по апелляционной или кассационной жалобе, поступившей из нижестоящего суда | Убедиться, что данные из карточки нижестоящего суда перенесены правильно |
| 10 | Сотрудник канцелярии | Регистрировать документ по уже существующему делу и указывать, относится ли он к обособленному спору | Привязать документ к нужному делу, производству или спору |
