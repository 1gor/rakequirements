# [To be] ТБП105. Проверить соответствие признакам субъекта естественной монополии

| **Наименование процесса** | ТБП105 — Проверить соответствие признакам субъекта естественной монополии |
| --- | --- |
| **Суть процесса** | Процесс отражает рассмотрение вопроса о соответствии юридического лица признакам субъекта естественной монополии. В рамках процесса Система выполняет поиск юридического лица в реестре субъектов естественных монополий, анализирует материалы дела и результаты поиска, после чего формирует протокол проверки. Судья проверяет выводы Системы и определяет достаточность данных. При недостаточности сведений выполняется повторное получение необходимых данных через типовой процесс направления запроса в ведомство. При достаточности данных Судья принимает окончательное решение о соответствии либо несоответствии юридического лица признакам субъекта естественной монополии. |
| **Участники процесса** | Судья; Система |
| **НПА** | Федеральный закон от 17.08.1995 № 147-ФЗ «О естественных монополиях». Письмо ФАС России от 06.07.2018 № АЦ/51469/18 «О разъяснении по вопросу отнесения организации к субъектам естественной монополии в случае отсутствия указанной организации в реестре субъектов естественных монополий». |

# 3. Реестр UC

UC001 — Осуществление проверок в отношении ЮЛ для решения вопроса о соответствии признакам естественной монополии

| **№ шага процесса** | 0-6 |
| --- | --- |
| **Выполняемая задача** | Выполнить поиск юридического лица в реестре субъектов естественных монополий и определить наличие записи в реестре. |
| **Цель** | Установить наличие юридического лица в реестре субъектов естественных монополий для дальнейшего решения по вопросу соответствия признакам естественной монополии. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе сохранён подтверждённый Судьёй протокол проверки юридического лица на соответствие признакам субъекта естественной монополии. |
| **Рекомендованная функциональность** | Поиск юридического лица в реестре субъектов естественных монополий и регистрация результата анализа. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступает к проверке юридического лица на соответствие признакам субъекта естественной монополии. |
| **Предварительные условия** | У Судьи имеются реквизиты юридического лица (наименование, ИНН, ОГРН). |
| **Основной сценарий** | 1. Судья запускает в Системе проверку юридического лица на соответствие признакам субъекта естественной монополии. 2. Судья направляет в ведомство запрос сведений, необходимых для проверки юридического лица. 3. Система отображает результат поиска юридического лица в реестре субъектов естественных монополий. 4. Система отображает выводы по материалам дела и полученным ответам на запросы. 5. Система отображает сформированный протокол проверки. 6. Судья подтверждает протокол проверки.  7. Система отображает факт сохранения подтверждённого протокола проверки. |
| **Расширение (альтернативный сценарий)** | 6а. Судья фиксирует недостаточность данных для решения вопроса. 6а1. Судья направляет в ведомство дополнительный запрос сведений. 7а. Система отображает ошибку сохранения  7а1. Система отображает кнопку сохранить повторно. 7а2. Судья нажимает кнопку сохранить повторно. |
