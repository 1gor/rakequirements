# [To be] ТБП32. Рассмотреть вопрос об отказе в принятии

| ТБП32: Рассмотреть вопрос об отказе в принятии |
| --- |
| Процесс охватывает проверку поступившего документа на наличие оснований для отказа в принятии, специальные проверки заявления о выдаче судебного приказа, формирование протокола и проверку выводов Системы, решение вопроса о государственной пошлине, принятие определения об отказе и, для неэлектронных документов, формирование и направление комплекта документов заявителю. |
| Судья; Помощник судьи; Канцелярия; Заявитель; Система |
| Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): статьи 127, 127.1, 229.2, 229.4;  Налоговый кодекс Российской Федерации (часть вторая) от 05.08.2000 N 117-ФЗ (ред. от 04.08.2026, с изм. и доп., вступ. в силу с 01.09.2026): подп. 7 п. 1 ст. 333.22, ст. 333.40;  Постановление Пленума Верховного Суда РФ от 23.12.2021 N 46; Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014), разделы 9, 10, 13, 21. |

**UC001 — Проверка оснований для отказа в принятии документа**

| **№ шага процесса** | 0-22 |
| --- | --- |
| **Выполняемая задача** | Проверить основания для отказа в принятии документа и зафиксировать результаты проверок в Системе. |
| **Цель** | Определить наличие оснований для отказа в принятии документа и подготовить результаты для дальнейшего принятия решения. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе сформированы и сохранены результаты проверок, включая протокол проверки оснований для отказа в принятии. |
| **Рекомендованная функциональность** | Проверка оснований для отказа в принятии документа и сохранение результатов проверок в карточке заявления. |
| **Критичность** | Необходимая |
| **Триггер** | Судья инициирует проверку оснований для отказа в принятии документа |
| **Предварительные условия** | В карточке заявления о выдаче судебного приказа доступны сведения, необходимые для выполнения проверок. |
| **Основной сценарий** | 1. Судья выполняет проверку отказа в признании и исполнении решения суда.  2. Система сохраняет признак «Отказ в признании и исполнении решения иностранного суда установлен»   3. Судья фиксирует проверку тождественности как пройденную.  4. Система устанавливает статус «Проверка тождественности пройдена» и результат «Тождественность не установлена».  5. Судья выполняет проверку факта отмены решения.  6. Система отражает результат проверки «Решение третейского суда отменено» и подготавливает условие для дальнейшего выбора.  7. Судья фиксирует проверку тождественности как пройденную.  8. Система устанавливает статус «Проверка тождественности пройдена» и результат, соответствующий ветке при отмене решения.  9. Судья выполняет проверку, что заявлено требование предусмотренное ст. 229.2 АПК.  10. Система формирует результат проверки соответствия заявления требованиям ст. 229.2 АПК РФ со статусом «соответствует/не соответствует».  11. Судья выполняет проверку отсутствия спора о праве.  12. Система регистрирует результат проверки отсутствия спора о праве со статусом «отсутствует/имеется».  13. Система формирует протокол проверки.  14.
