ТБП139:Проверить выводы системы

|  |  |
| --- | --- |
| **Наименование процесса** | ТБП139:Проверить выводы системы |
| **Суть процесса** | Процесс инициирует выполненная системой проверка в рамках того или иного процесса, результаты которой необходимо провалидировать со стороны пользователя. Пользователь знакомится с результатами отработанного системой процесса; в случае, если была найдена ошибка - пользователь запускает формирование отчета об ошибке, который затем направляется на обработку в техническую поддержку. При необходимости пользователем также вносятся корректные данные вручную. После подтверждения данных пользователем и сохранением данных системой процесс завершается.  Данный процесс является результатом проектирования целевой модели to-be и не существовал в предыдущей конфигурации as-is. |
| **Участники процесса** | Судья |
| **НПА** | - |
