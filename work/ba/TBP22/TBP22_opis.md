**ТБП22:"Проверить статус исполнения ИЛ"**

|  |  |
| --- | --- |
| Наименование процесса | ТБП22:"Проверить статус исполнения ИЛ" |
| Суть процесса | Процесс описывает проверку статуса исполнительного листа в ходе исполнения судебного акта. В рамках процесса судья проверяет данные, полученные от ФССП, о статусе ИЛ. Затем определяется, достаточно ли полученных данных. Если да - процесс завершается. Если данных недостаточно - также направляется запрос в ФССП для получения дополнительной информации о статусе. После получения и ознакомления с ответом процесс завершается. |
| Участники процесса | Судья, Помощник судьи |
| НПА | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025)  Постановление Пленума Высшего Арбитражного Суда Российской Федерации от 25.12.2013 N 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)»  «Федеральный закон «Об исполнительном производстве»» от 02.10.2007 N 229-ФЗ |

| 1 | Заполнить данные ИЛ | Тип: Пользовательская задача Назначение: Ввод реквизитов исполнительного листа для получения сведений о статусе его исполнения. Роль: Помощник судьи Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Помощник судьи вносит данные исполнительного листа для поиска и получения сведений о ходе исполнительного производства. Результат шага: Заполнены данные исполнительного листа для получения сведений о статусе исполнения. |  |
| 2 | Актуализировать данные, получаемые от ФССП | Тип: Сервисная задача Назначение: Получение актуальных данных о ходе исполнительного производства от ФССП. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Система по введенным реквизитам исполнительного листа получает и актуализирует сведения о ходе исполнительного производства. Результат шага: Получены актуализированные данные от ФССП. |  |
| 3 | Определить степень полноты актуализированных данных | Тип: Сервисная задача Назначение: Определение полноты актуализированных данных о ходе исполнительного производства. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Система анализирует полученные сведения и определяет, достаточно ли информации для дальнейшего информирования судьи либо требуется направление запроса в ведомство. Результат шага: Определена степень полноты актуализированных данных. |  |
| 4 | Информации об исполнении достаточно? | Тип: Развилка «ИЛИ/ИЛИ» Назначение: решения о достаточности сведений о ходе исполнительного производства определенное на шаге 3. Роль: Помощник судьи Входящие данные: Отсутствуют Исходящие данные: Отсутствуют |  |
| 5 | [ТБП23.Направить запрос в ведомство](https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=533163710) | Тип: Вызов активности Назначение: Получение уточненной информации о статусе исполнительного производства из ведомства. Роль: Помощник судьи Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Переход к типовому процессу «Направить запрос в ведомство». В рамках типового процесса осуществляется подготовка и направление запроса в ФССП о предоставлении актуальных сведений об исполнительном производстве. Результат шага: Получен ответ ведомства с актуальными сведениями о статусе исполнения. |  |
| 6 | Сходящаяся развилка | Тип: Сходящаяся развилка Назначение: Объединение потоков обработки после получения достаточной информации о статусе исполнения. Роль: Помощник судьи Входящие данные: Отсутствуют Исходящие данные: Отсутствуют |  |
| 7 | Сформировать справку о статусе исполнения | Тип: Сервисная задача Назначение: Формирование справки о статусе исполнения исполнительного листа. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Справка о статусе исполнения  Описание: Система формирует справку на основании полученной информации о ходе исполнительного производства для последующего ознакомления и доклада судье. Результат шага: Сформирована справка о статусе исполнения. |  |
| 8 | Уведомить инициатора и судью о завершении формирования справки | Тип: Сервисная задача Назначение: Информирование инициатора и судьи о завершении формирования справки. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Система направляет уведомление о готовности справки для ознакомления. Результат шага: Инициатор и судья уведомлены о завершении формирования справки. |  |
| 9 | Ознакомиться со справкой | Тип: Пользовательская задача Назначение: Ознакомление со справкой о статусе исполнения исполнительного листа. Роль: Помощник судьи Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Помощник судьи открывает и просматривает сформированную справку о статусе исполнения для последующего доклада судье. Результат шага: Помощник судьи ознакомлен со справкой о статусе исполнения. |  |
