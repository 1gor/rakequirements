## ****3. Реестр UC****

**UC001 — Проверить нормы и согласовать выдачу ТМЦ**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–7 |
| **Выполняемая задача** | Проверка заявки на МТО на соответствие установленным нормам выдачи ТМЦ и согласование сверхнормативной выдачи при наличии превышения. |
| **Цель** | Определить допустимый объем выдачи ТМЦ и получить зафиксированное решение руководителя МТО в случаях превышения установленных норм. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела МТО. Участник: Руководитель МТО. |
| **Ожидаемый результат** | Потребность сопоставлена с нормативами; сформировано основание для выдачи ТМЦ в пределах нормы либо заявка содержит визу руководителя МТО на сверхнормативную выдачу; при отказе процесс завершен без выдачи. |
| **Рекомендованная функциональность** | Предоставление сотруднику МТО заявки и локального акта о нормах выдачи; фиксация результата сопоставления потребности с нормативами; маршрутизация сверхнормативной заявки руководителю МТО; фиксация решения об отказе или согласовании; проставление и хранение визы о сверхнормативной выдаче. |
| **Критичность** | Необходимая. |
| **Триггер** | Из ОБП53 поступила заявка на МТО при наличии запрашиваемых ТМЦ на складе. |
| **Предварительные условия** | Запрашиваемые ТМЦ имеются на складе; сотруднику отдела МТО доступны заявка на МТО и локальный акт о нормах выдачи ТМЦ. |
| **Основной сценарий** | 1. Сотрудник отдела МТО получает заявку на МТО и сведения о наличии запрашиваемых ТМЦ на складе.  2. Сотрудник отдела МТО изучает локальный акт о нормах выдачи ТМЦ.  3. Сотрудник отдела МТО сопоставляет наименования и количество запрошенных ТМЦ с установленными нормами.  4. Сотрудник отдела МТО устанавливает, что потребность не превышает установленную норму.  5. Заявка используется как основание для выдачи ТМЦ со склада.  6. Процесс продолжается с выдачи ТМЦ сотруднику суда. |
| **Расширение (альтернативный сценарий)** | 4а. Потребность в ТМЦ превышает установленную норму.  4а.1 Руководитель МТО рассматривает заявку и сведения о превышении нормы.  4а.2 Руководитель МТО принимает решение о возможности сверхнормативной выдачи.  4а.3 При согласовании руководитель МТО проставляет в заявке визу о выдаче ТМЦ сверх установленной нормы.  4а.4 Заявка с визой используется как основание для выдачи ТМЦ со склада.  4б. Руководитель МТО отказывает в сверхнормативной выдаче.  4б.1 Решение об отказе фиксируется.  4б.2 Процесс завершается с результатом «Отказано в выдаче ТМЦ». |

**UC002 — Выдать ТМЦ и отразить операцию в учете**

|  |  |
| --- | --- |
| **№ шага процесса** | 8–11 |
| **Выполняемая задача** | Выдача ТМЦ со склада, подтверждение получения сотрудником суда и отражение перемещения либо списания ТМЦ в бухгалтерском учете. |
| **Цель** | Обеспечить фактическую выдачу согласованных ТМЦ и синхронное отражение операции в журнале выдачи и бухгалтерском учете. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела МТО. Участники: Сотрудник суда (автор заявки); Сотрудник бухгалтерии. |
| **Ожидаемый результат** | ТМЦ выданы получателю, факт получения подтвержден электронной подписью в журнале выдачи, а операция отражена в бухгалтерском учете как перемещение основного средства либо списание расходного материала. |
| **Рекомендованная функциональность** | Фиксация состава и количества выданных ТМЦ; ведение электронного журнала выдачи; электронное подтверждение получения; передача бухгалтерии сведений о выдаче; отражение перемещения основного средства с указанием получателя и кабинета либо списания расходного материала. |
| **Критичность** | Необходимая. |
| **Триггер** | Сформировано основание для выдачи ТМЦ: заявка в пределах норм либо заявка с визой руководителя МТО на сверхнормативную выдачу. |
| **Предварительные условия** | ТМЦ имеются на складе; определены получатель, состав и количество выдаваемых ценностей; при превышении нормы получено согласование руководителя МТО. |
| **Основной сценарий** | 1. Сотрудник отдела МТО подбирает ТМЦ на складе в соответствии с заявкой и основанием для выдачи.  2. Сотрудник отдела МТО передает ТМЦ сотруднику суда.  3. Сотрудник суда проверяет сведения о полученных ТМЦ.  4. Сотрудник суда подтверждает получение электронной подписью в журнале выдачи ТМЦ.  5. Сотрудник бухгалтерии получает сведения о выданных ТМЦ и подтвержденную запись журнала выдачи.  6. Сотрудник бухгалтерии определяет характер учетной операции по виду ТМЦ.  7. Для основного средства сотрудник бухгалтерии отражает перемещение с указанием получателя и кабинета либо для расходного материала выполняет списание.  8. Процесс завершается с результатом «ТМЦ выдан». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
