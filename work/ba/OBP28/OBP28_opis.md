## ****3. Реестр UC****

**UC001 — Провести проверку соблюдения требований охраны труда и техники безопасности**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–9 |
| **Выполняемая задача** | Создание и проведение проверки по охране труда и технике безопасности, определение необходимости комиссионной проверки, утверждение состава комиссии и фиксация результата проверки. |
| **Цель** | Проверить соблюдение требований охраны труда и техники безопасности и определить наличие нарушений. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель МТО. Участники: председатель суда; Система. |
| **Ожидаемый результат** | Проверка проведена; подтверждено соблюдение требований охраны труда и техники безопасности либо выявлены нарушения, требующие устранения. |
| **Рекомендованная функциональность** | Создание сущности проверки; фиксация решения о необходимости комиссионного проведения проверки; автоматическое уведомление о подготовке проекта локального акта; фиксация состава комиссии и локального акта об ее утверждении; регистрация результатов проверки. |
| **Критичность** | Необходимая. |
| **Триггер** | Инициирована проверка по охране труда и технике безопасности. |
| **Предварительные условия** | Определена необходимость проведения проверки; руководитель МТО имеет доступ к Системе и полномочия на организацию проверки. |
| **Основной сценарий** | 1. Руководитель МТО создает в Системе сущность проверки по охране труда и технике безопасности.  2. Руководитель МТО определяет необходимость проведения проверки комиссионно и фиксирует принятое решение в Системе.  3. Если требуется комиссионная проверка, Система направляет уведомление о необходимости подготовки проекта локального акта.  4. Председатель суда утверждает состав комиссии, по результату формируется локальный акт об утверждении комиссии.  5. Руководитель МТО проводит проверку соблюдения требований охраны труда и техники безопасности.  6. По результатам проверки определяется, соблюдаются ли требования охраны труда и техники безопасности.  7. Если требования соблюдаются, процесс завершается с результатом «Требования охраны труда и техники безопасности соблюдены». |
| **Расширение (альтернативный сценарий)** | 2а. Проверка не требует комиссионного проведения.  2а.1 Подготовка локального акта и утверждение состава комиссии не выполняются.  2а.2 Процесс продолжается с проведения проверки.  6а. По результатам проверки выявлены нарушения требований охраны труда и техники безопасности.  6а.1 Процесс переходит к UC002 «Организовать устранение выявленных нарушений». |

**UC002 — Организовать устранение выявленных нарушений**

|  |  |
| --- | --- |
| **№ шага процесса** | 10–16 |
| **Выполняемая задача** | Фиксация выявленных нарушений, информирование председателя суда, определение и исполнение мер по устранению нарушений, а также подтверждение результата. |
| **Цель** | Обеспечить устранение выявленных нарушений и восстановить соблюдение требований охраны труда и техники безопасности. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель МТО. Участники: председатель суда; Система. |
| **Ожидаемый результат** | Нарушения устранены, факт их устранения зафиксирован в Системе, требования охраны труда и техники безопасности соблюдены. |
| **Рекомендованная функциональность** | Регистрация выявленных нарушений; фиксация сообщения председателю суда; автоматическое уведомление о необходимости подготовки проекта локального акта; хранение локального акта по устранению нарушений; фиксация исполнения поручения и подтверждения устранения нарушений. |
| **Критичность** | Необходимая. |
| **Триггер** | По результатам проверки выявлены нарушения требований охраны труда и техники безопасности. |
| **Предварительные условия** | Проверка завершена; нарушения зафиксированы в материалах проверки. |
| **Основной сценарий** | 1. Руководитель МТО фиксирует факты нарушения требований охраны труда и техники безопасности.  2. Руководитель МТО сообщает председателю суда о выявленных нарушениях и передает сведения, необходимые для определения мер по их устранению.  3. Система направляет уведомление о необходимости подготовки проекта локального акта по устранению нарушений.  4. Председатель суда определяет меры по устранению нарушений и оформляет их локальным актом.  5. Руководитель МТО исполняет поручение и организует выполнение предусмотренных мер.  6. Руководитель МТО проверяет результат исполнения поручения и фиксирует факт устранения нарушений в Системе.  7. Процесс завершается с результатом «Нарушения устранены. Требования охраны труда и техники безопасности соблюдены». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
