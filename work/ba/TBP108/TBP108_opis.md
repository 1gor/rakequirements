# [To be] ТБП108. Рассмотреть КЖ

| **Наименование процесса** | ТБП108 — Рассмотреть кассационную жалобу по существу |
| --- | --- |
| **Суть процесса** | Процесс предназначен для рассмотрения кассационной жалобы по существу на стадии вынесения постановления. Система проверяет наличие мирового соглашения; при его поступлении Судья проверяет соответствие соглашения закону и отсутствие нарушения прав третьих лиц, после чего решается вопрос об утверждении мирового соглашения и связанных с ним последствиях для ранее принятых судебных актов. При продолжении рассмотрения Судья оценивает соответствие выводов судов фактическим обстоятельствам, соблюдение норм процессуального права, законность состава суда, корректность применения и толкования норм материального права, полноту установления фактических обстоятельств, а затем определяет наличие оснований для отмены или изменения судебного акта, возможность разрешения спора по существу и необходимость направления дела на новое рассмотрение. Отдельным событийным подпроцессом предусмотрена проверка заинтересованности судьи с переходом к типовому процессу направления запроса в ведомство. Процесс завершается фиксацией результата рассмотрения кассационной жалобы и переходом к иным процессуальным вопросам в рамках принятия решения. |
| **Участники процесса** | Судья; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): гл. 3, гл. 15, гл. 35, в том числе ст. 21–26, 139–141, 284, 286–289.  Постановление Пленума Верховного Суда РФ от 30.06.2020 № 13 «О применении Арбитражного процессуального кодекса Российской Федерации при рассмотрении дел в арбитражном суде кассационной инстанции».  Постановление Пленума Верховного Суда РФ от 22.06.2021 № 18 «О некоторых вопросах досудебного урегулирования споров, рассматриваемых в порядке гражданского и арбитражного судопроизводства». |

# 3. Реестр UC

**UC001 — Выявление оснований для отмены СА в связи с утвержденным мировым соглашением**

| **№ шага процесса** | 1-7 |
| --- | --- |
| **Выполняемая задача** | Определить наличие мирового соглашения и зафиксировать основания для отмены судебных актов в связи с его утверждением. |
| **Цель** | Выбрать правовую логики дальнейшего рассмотрения жалобы и подготовить основание отмены судебных актов нижестоящих инстанций. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксированы результаты проверок мирового соглашения и указание основания отмены судебных актов в проекте судебного акта. |
| **Рекомендуемая функциональность** | Просмотр и проверка данных в карточке кассационного производства; ввод результата проверки и сохранение судебного акта. |
| **Критичность** | Необходимая |
| **Триггер** | Судья приступает к рассмотрению кассационной жалобы по существу. |
| **Предварительные условия** | В карточке кассационного производства доступна информация о поступлении мирового соглашения. |
| **Основной сценарий** | 1. Судья открывает в Системе карточку кассационного производства.  2. Система отображает сведения о поступлении мирового соглашения от сторон.  3. Судья фиксирует в Системе вывод о соответствии мирового соглашения требованиям закона.  4. Судья фиксирует в Системе вывод об отсутствии нарушения прав третьих лиц.  5. Судья утверждает мировое соглашение.  6. Система отображает в проекте судебного акта основание для отмены ранее принятых судебных актов. |
| **Расширение (альтернативный сценарий)** | 2а. Система отображает отсутствие поступившего мирового соглашения.  5а. Судья отказывает в утверждении мирового соглашения. |
