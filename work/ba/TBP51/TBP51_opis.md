## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья Арбитражного суда | Принимает решение о необходимости проведения ВКС, определяет предполагаемую дату, ставит задачи, принимает судебные акты об отказе в проведении ВКС, выбирает новую дату при необходимости |
| Помощник судьи/секретарь судебного заседания Арбитражного суда | Получает задания от судьи, передает задачи сотрудникам, получает информацию о результатах организации ВКС, докладывает судье, направляет документы |
| Сотрудник Арбитражного суда, ответственный за организацию ВКС | Определяет суд для содействия, знакомится с расписанием, выбирает временные слоты, связывается с судами, направляет запросы, получает информацию, передает результаты |
| Суд, содействующий проведению СЗ путем использования систем ВКС | Получает запросы на организацию ВКС, проверяет возможность проведения в выбранную дату, подтверждает или отклоняет запросы, предоставляет дополнительную информацию |
| Лица, участвующие в деле | Получает определения об отказе в проведении ВКС, знакомится с их содержанием |
| Система арбитражного суда | Календарь судьи, обмен данными между судами содействующими ВКС, постановка задачи, автоматические ответы между системами, формирование карточки документа, формирование документов, отправка документа ЛУВД, система предлагает судье даты проведения ВКС 1-2 дня вперед с учетом производственного календаря. |
