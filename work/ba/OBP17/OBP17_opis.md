## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник отдела информатизации | * Мониторинг состояния систем (измерение параметров: загрузка процессора, доступность сервисов). * Устранение неисправностей в системах (диагностика и исправление сбоев). * Проведение профилактического обслуживания систем. * Координация с подрядными организациями (передача задач подрядчику). * Обеспечение резервного копирования (создание и проверка копий). * Обеспечение взаимодействия систем (настройка API, устранение сбоев интеграции). * Проведение тестирования систем после обновлений (функциональное и нагрузочное). * Подписание акта приемки. Инициирование подписания документа. |
| Уполномоченное лицо, подписант (подрядчика). | * Подписание акта приемки выполненных работ. |
| Подрядная организация (подрядчик) | * Проведение работ по устранению проблем. * Направление акта приема-передачи выполненных работ. |
| Система | Регистрирует поступление заявки на техническое обеспечение, объединяет потоки входящих заявок при дублировании, запрашивает информацию о загруженности сотрудников из базы данных, определяет исполнителя в соответствии с нагрузкой и отпусками или проставляет группу ответственного отдела, инициирует процесс участия в госзакупках, объединяет потоки из различных шагов, формирует отчет о проведенном обслуживании и сохраняет его, передает отчет на согласование руководителю информируя в сущности обращения. |
