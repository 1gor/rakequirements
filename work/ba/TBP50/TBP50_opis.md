# [To be] ТБП50. Изготовить копии

| **Наименование процесса** | ТБП50: Изготовить копии |
| --- | --- |
| **Суть процесса** | Процесс охватывает изготовление копий судебных актов, материалов дела и протокола судебного заседания для направления участнику процесса, в иной суд либо органам следствия/дознания. После указания оригинала определяется вид требуемых копий. В зависимости от выбранной ветви Система изготавливает копии, определяет необходимость дальнейшего заверения, наносит электронные реквизиты, формирует копии протокола либо записывает цифровую копию материалов. При необходимости заверения копии направляются судье для подписания УКЭП и решения вопроса о гербовой печати. Для направления материалов органам следствия/дознания выбирается адресат и осуществляется переход к типовому процессу направления документа. |
| **Участники процесса** | Помощник судьи/секретарь/сотрудник отдела делопроизводства; Судья/председатель судебного состава; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): статья 41, часть 9 статьи 155; Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)»: разделы 7, 10, 18. |

# 3. Реестр UC

**UC001 — Изготовление копий материалов дела**

| **№ шага процесса** | 0-20 |
| --- | --- |
| **Выполняемая задача** | Изготовить копии материалов дела для суда, подготовить копии судебного акта и протокола судебного заседания, включая оформление признаков заверения и подготовку к подписанию. |
| **Цель** | Обеспечить подготовку копий материалов дела для направления адресатам с корректным оформлением реквизитов и заверений. |
| **Роль / Актор** | Помощник судьи/секретарь/сотрудник отдела делопроизводства |
| **Ожидаемый результат** | В Системе отражен факт изготовления копий материалов дела для суда в рамках текущего задания. |
| **Рекомендуемая функциональность** | Выбор типа оригинала документов для изготовления копий; выполнение изготовления копий материалов дела. |
| **Критичность** | Необходимая |
| **Триггер** | Помощник судьи/секретарь/сотрудник отдела делопроизводства необходимость изготовления копий |
| **Предварительные условия** | В Системе зарегистрирована необходимость изготовления копий. |
| **Основной сценарий** | 1. Помощник судьи/секретарь/сотрудник отдела делопроизводства указывает, копии каких документов подлежат изготовлению.  2. Система фиксирует состав подлежащих копированию документов  3. Система формирует задание на изготовление копий материалов дела.  4. Помощник судьи/секретарь/сотрудник отдела делопроизводства выполняет ксерокопирование необходимых листов бумажного дела.  5. Система отражает факт изготовления копий материалов дела для суда в рамках текущего задания. |
| **Расширение (альтернативный сценарий)** | — |

Система отображает зафиксированный выбранный орган следствия/дознания как адресат для направления электронных копий материалов дела. |
