# [To be] ОБП36. Ведение трудовых книжек

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП36 — Ведение трудовых книжек |
| **Суть процесса** | Ведение сведений о трудовой деятельности работников суда: оформление кадрового основания, актуализация личного дела, определение необходимости передачи сведений в СФР, формирование и отправка отчета ЕФС-1, внесение записи в бумажную трудовую книжку, ознакомление работника, выдача либо организация хранения трудовой книжки. |

Сотрудник отдела кадров инициирует ОБП38 «Формирование личных дел судей и работников аппарата суда».  5. В рамках ОБП38 личное дело работника формируется или актуализируется на основании кадрового события и локального акта.  6. Процесс продолжается с определения необходимости передачи сведений в СФР. |

**UC002 — Сформировать и передать сведения в СФР**

|  |  |
| --- | --- |
| **№ шага процесса** | 3–7 |
| **Выполняемая задача** | Определение необходимости передачи сведений в СФР, автоматическое формирование отчета ЕФС-1 и его направление через электронный документооборот. |
| **Цель** | Своевременно исполнить обязанность по представлению в СФР сведений о кадровом событии и трудовой деятельности работника. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участник: Система. |
| **Ожидаемый результат** | Необходимость передачи сведений определена; при наличии обязанности отчет ЕФС-1 сформирован, подписан и направлен через ЭДО, а статус доставки проконтролирован. |
| **Рекомендованная функциональность** | Фиксация решения о необходимости передачи сведений в СФР; автоматическое формирование отчета ЕФС-1 на основании кадровых данных и локального акта; предоставление отчета сотруднику отдела кадров; фиксация подписания, отправки и статуса доставки через ЭДО. |
| **Критичность** | Необходимая. |
| **Триггер** | Локальный акт принят, а личное дело работника сформировано или актуализировано. |
| **Предварительные условия** | В Системе имеются кадровые сведения и данные локального акта; сотрудник отдела кадров имеет доступ к каналу ЭДО. |
| **Основной сценарий** | 1. Сотрудник отдела кадров анализирует кадровое событие и сведения о работнике.  2. Сотрудник отдела кадров определяет необходимость передачи данных в СФР.  3. Сотрудник отдела кадров фиксирует решение о необходимости представления отчетности.  4. Система автоматически формирует отчет по форме ЕФС-1 на основании кадровых сведений и данных локального акта.  5. Сформированный отчет становится доступен сотруднику отдела кадров.  6. Сотрудник отдела кадров выбирает отчет, подписывает его и направляет через ЭДО.  7. Сотрудник отдела кадров контролирует факт отправки и полученный статус доставки.  8. Процесс продолжается с уточнения вида трудовой книжки работника. |
| **Расширение (альтернативный сценарий)** | 2а. Передача сведений о кадровом событии в СФР не требуется.  2а.1 Формирование и направление отчета ЕФС-1 не выполняются.  2а.2 Процесс продолжается с уточнения вида трудовой книжки работника. |

| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. |
| **Ожидаемый результат** | Сведения отражены в электронной форме либо внесены в бумажную трудовую книжку; работник ознакомлен с записью; трудовая книжка выдана работнику либо помещена на хранение в отделе кадров. |
| **Рекомендованная функциональность** | Фиксация вида трудовой книжки; регистрация записи и реквизитов документа-основания; фиксация ознакомления работника; регистрация решения о выдаче либо хранении; учет выдачи под расписку; фиксация места хранения и ограничения доступа. |
| **Критичность** | Необходимая. |
| **Триггер** | Завершено определение необходимости передачи сведений в СФР и выполнена соответствующая ветвь отчетности. |
| **Предварительные условия** | Принят локальный акт по кадровому вопросу; личное дело работника актуализировано; при необходимости сведения направлены в СФР. |
| **Основной сценарий** | 1. Сотрудник отдела кадров уточняет вид трудовой книжки работника.  2. Сотрудник отдела кадров устанавливает, что у работника имеется бумажная трудовая книжка.  3. Сотрудник отдела кадров вносит запись в бумажную трудовую книжку на основании локального акта.  4. Сотрудник отдела кадров указывает необходимые даты, реквизиты и формулировку кадрового события и проверяет соответствие записи документу-основанию.  5. Сотрудник отдела кадров предоставляет работнику актуализированную трудовую книжку для ознакомления.  6. Сотрудник отдела кадров получает предусмотренное подтверждение ознакомления работника.  7. Сотрудник отдела кадров определяет дальнейший порядок нахождения трудовой книжки.  8. Если трудовая книжка остается в личном деле, сотрудник отдела кадров размещает ее в установленном месте хранения.  9. Сотрудник отдела кадров обеспечивает доступ к трудовой книжке только уполномоченным лицам.  10. Процесс завершается с результатом «Внесена новая запись в трудовую книжку. Сотрудник ознакомлен. Обеспечено хранение». |
| **Расширение (альтернативный сценарий)** | 2а. У работника отсутствует бумажная трудовая книжка.  2а.1 Запись в бумажную трудовую книжку не вносится.  2а.2 Процесс завершается с результатом «Информация передана в СФР. Запись в электронную трудовую книжку внесена».  7а. Принято решение выдать бумажную трудовую книжку работнику.  7а.1 Сотрудник отдела кадров подготавливает трудовую книжку к выдаче и проверяет личность получателя.  7а.2 Трудовая книжка передается работнику под расписку.  7а.3 Сотрудник отдела кадров оформляет необходимые учетные отметки.  7а.4 Процесс завершается с результатом «Внесена новая запись в трудовую книжку. Сотрудник ознакомлен. Трудовая книжка выдана на руки». |
