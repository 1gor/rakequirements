ТБП20 "Проверить компетенцию"

|  |  |
| --- | --- |
| Наименование процесса | ТБП20:"Проверить компетенцию" |
| Суть процесса | Процесс описывает проверку компетенции арбитражного суда по рассмотрению спора. Процесс начинается тогда, когда решается вопрос о принятии первичного/вторичного/иного документа к производству или когда происходит проверка подсудности в ходе судебного разбирательства. В ходе процесса определяется состав участников, вид спора, а также компетенция спора; в случае, если компетенция не относится к АС, но дело поступило из СОЮ - дело/документ признается относящимся к компетенции АС в связи с недопустимостью споров о подсудности. Если дело поступило не из СОЮ, то определяется полностью или частично относятся требования к компетенции АС. Если требования полностью относятся, то процесс завершается установлением компетентности АС. Если часть требований подсудны СОЮ, то проверяется, возможно ли разделение требований. Если разделение возможно, то процесс завершается установленной необходимостью разделить требования. Если все требования не подсудны АС, либо их невозможно разделить, то процесс завершается установленным основанием для возвращения в случае, если дело еще не принято к производству. Или завершается установлением основания передачи по подсудности если дело принято к производству. |
| Участники процесса | Судья, помощник судьи |
| НПА | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025) |

| 1 | Определить состав участников спора | Тип: Сервисная задача Назначение: Определить состав участников спора для проверки участия в деле физического лица. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Вид спора определяется для установления подсудности в случае участия в деле физического лица. При участии физического лица арбитражному суду будет подсудно только дело о банкротстве. Результат шага: Определён вид спора для проверки подсудности. |  |

Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: Выполняется оценка соответствия спора положениям законодательства о компетенции арбитражных судов. Результат шага: Определено, относится ли спор к компетенции арбитражных судов. |  |
| 4 | Определить степень относимости требований к компетенции АС | Тип: Сервисная задача Назначение: Определить степень относимости требований к компетенции арбитражного суда. Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют Описание: По результатам проверки определяется, относятся ли требования полностью к компетенции арбитражного суда либо заявление содержит несколько требований, часть из которых подсудна судам общей юрисдикции. Результат шага: Определена степень относимости требований к компетенции арбитражного суда. |  |

Роль: Система Входящие данные: Отсутствуют Исходящие данные: Отсутствуют  Описание: На основе результатов выполненных проверок определяется, поступило ли дело из суда общей юрисдикции.
