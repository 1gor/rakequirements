# [To be] ТБП20. Проверить компетенцию

| **Наименование процесса** | ТБП20: Проверить компетенцию |
| --- | --- |
| **Суть процесса** | Процесс описывает проверку компетенции арбитражного суда по рассмотрению спора. Процесс начинается тогда, когда решается вопрос о принятии первичного/вторичного/иного документа к производству или когда происходит проверка подсудности в ходе судебного разбирательства. В ходе процесса определяется состав участников, вид спора, а также компетенция спора; в случае, если компетенция не относится к АС, но дело поступило из СОЮ - дело/документ признается относящимся к компетенции АС в связи с недопустимостью споров о подсудности. Если дело поступило не из СОЮ, то определяется полностью или частично относятся требования к компетенции АС. Если требования полностью относятся, то процесс завершается установлением компетентности АС. Если часть требований подсудны СОЮ, то проверяется, возможно ли разделение требований. Если разделение возможно, то процесс завершается установленной необходимостью разделить требования. Если все требования не подсудны АС, либо их невозможно разделить, то процесс завершается установленным основанием для возвращения в случае, если дело еще не принято к производству. Или завершается установлением основания передачи по подсудности если дело принято к производству. |
| **Участники процесса** | Судья, Помощник судьи |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): гл. 4 (ст. 27–33), ст. 39, ст. 129. |

**UC002 — Ознакомление с результатом проверки при неполной компетенции**

| **№ шага процесса** | 12–27 |
| --- | --- |
| **Выполняемая задача** | Ознакомиться с результатами проверки неполной компетенции и уведомлением о требуемом дальнейшем действии. |
| **Цель** | Получить в Системе явно раскрытый результат проверки и основание для разделения требований, возврата документа либо передачи дела по подсудности. |
| **Роль / Актор** | Судья/Помощник судьи |
| **Ожидаемый результат** | Пользователю отображено одно из применимых дальнейших действий и его основание. |
| **Рекомендуемая функциональность** | Отображение результата анализа требований; уведомления о возможности разделения требований, необходимости возврата документа или передачи дела по подсудности; переход к карточке дела. |
| **Критичность** | Необходимая |
| **Триггер** | По результатам проверки установлено, что не все требования относятся к компетенции арбитражного суда. |
| **Предварительные условия** | В Системе доступны результаты первичной проверки компетенции и сведения о заявленных требованиях. |
| **Основной сценарий** | 1. Система отображает пользователю результат проверки заявленных требований.  2. Если требования могут быть разделены, Система отображает уведомление о возможности разделения требований.  3. Если дело не принято к производству и требуется возврат документа, Система отображает уведомление о необходимости возврата документа.  4. Если дело принято к производству и требуется передача по подсудности, Система отображает уведомление о необходимости передачи дела по подсудности.  5. Судья/Помощник судьи открывает соответствующее уведомление и знакомится с отображенным основанием дальнейшего процессуального действия. |
| **Расширение (альтернативный сценарий)** | В зависимости от результата проверки Система отображает только применимый вариант дальнейшего действия. |
