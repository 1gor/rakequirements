# [To be] ОБП41. Составление и представление бюджетной отчетности

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП41 — Составление и представление бюджетной отчетности |
| **Суть процесса** | Процесс обеспечивает автоматизированное формирование комплекта бюджетной отчетности, его согласование и подписание, направление в Управление Судебного департамента, а также корректировку отчетности по замечаниям руководителя и УСД. |
| **Участники процесса** | Сотрудник отдела бухгалтерского учета и отчетности; Система; Председатель суда / заместитель председателя; Управление Судебного департамента (УСД). |
| **НПА** | Бюджетный кодекс Российской Федерации от 31.07.1998 № 145-ФЗ.  Налоговый кодекс Российской Федерации (часть вторая) от 05.08.2000 № 117-ФЗ.  Трудовой кодекс Российской Федерации от 30.12.2001 № 197-ФЗ.  Федеральный закон от 06.12.2011 № 402-ФЗ «О бухгалтерском учете».  Приказ Минфина России от 30.08.2024 № 121н «Об утверждении федерального стандарта бухгалтерского учета государственных финансов „Единый план счетов бухгалтерского учета государственных финансов“».  Приказ Минфина России от 20.09.2024 № 132н «Об утверждении федерального стандарта бухгалтерского учета государственных финансов „План счетов бюджетного учета“».  Приказ Минфина России от 28.12.2010 № 191н «Об утверждении Инструкции о порядке составления и представления годовой, квартальной и месячной отчетности об исполнении бюджетов бюджетной системы Российской Федерации».  Приказ Минфина России от 30.03.2015 № 52н «Об утверждении форм первичных учетных документов и регистров бухгалтерского учета, применяемых органами государственной власти (государственными органами), органами местного самоуправления, органами управления государственными внебюджетными фондами, государственными (муниципальными) учреждениями, и Методических указаний по их применению».  Приказ Минфина России от 15.04.2021 № 61н «Об утверждении унифицированных форм электронных документов бухгалтерского учета, применяемых при ведении бюджетного учета, бухгалтерского учета государственных (муниципальных) учреждений, и Методических указаний по их формированию и применению».  Приказ Федерального казначейства от 19.09.2025 № 10н «О сроках представления главными распорядителями средств федерального бюджета, главными администраторами доходов федерального бюджета, главными администраторами источников финансирования дефицита федерального бюджета консолидированной месячной, квартальной и годовой бюджетной отчетности в 2026 году». |

| **Цель** | Подготовить полный комплект бюджетной отчетности, содержащий установленные отчетные формы и пояснительную записку, для последующего согласования. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела бухгалтерского учета и отчетности. Участник: Система. |
| **Ожидаемый результат** | В сущности бюджета сформированы отчет об исполнении бюджета, баланс исполнения бюджета, отчет о финансовых результатах деятельности, отчет о движении денежных средств и пояснительная записка; комплект бюджетной отчетности готов к согласованию. |
| **Рекомендованная функциональность** | Создание сущности бюджета для отчетного периода; автоматическое формирование основных отчетных форм; хранение сформированных документов; редактирование пояснительной записки; проверка состава комплекта; объединение документов в единый комплект бюджетной отчетности. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость составить и представить бюджетную отчетность за установленный отчетный период. |
| **Предварительные условия** | В Системе имеются данные бюджетного учета за выбранный период; сотрудник отдела бухгалтерского учета и отчетности имеет доступ к функции подготовки отчетности. |
| **Основной сценарий** | 1. Система создает сущность бюджета для выбранного отчетного периода.  2. Система автоматически формирует отчет об исполнении бюджета по данным бюджетного учета.  3. Система автоматически формирует баланс исполнения бюджета.  4. Система автоматически формирует отчет о финансовых результатах деятельности.  5. Система автоматически формирует отчет о движении денежных средств.  6. Сотрудник отдела бухгалтерского учета и отчетности составляет пояснительную записку к отчетности.  7. Сотрудник проверяет состав автоматически сформированных отчетных форм.  8. Сотрудник добавляет пояснительную записку и формирует единый комплект бюджетной отчетности.  9. Комплект бюджетной отчетности становится готов к передаче на согласование. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

**UC002 — Согласовать и подписать бюджетную отчетность**

|  |  |
| --- | --- |
| **№ шага процесса** | 8–16 |
| **Выполняемая задача** | Передача бюджетной отчетности руководителю, рассмотрение, корректировка по замечаниям, подписание УКЭП и сохранение подписанного комплекта в Системе. |
| **Цель** | Получить согласование руководителя и зафиксировать юридически значимую подписанную версию бюджетной отчетности. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Председатель суда / заместитель председателя. Участники: Сотрудник отдела бухгалтерского учета и отчетности; Система. |
| **Ожидаемый результат** | Бюджетная отчетность рассмотрена руководителем, при необходимости скорректирована, подписана усиленной квалифицированной электронной подписью и сохранена в сущности бюджета. |
| **Рекомендованная функциональность** | Автоматическая передача комплекта на согласование; фиксация маршрута согласования; предоставление руководителю доступа к отчетности; регистрация замечаний; автоматическая передача замечаний исполнителю; ведение версий отчетности; повторная передача исправленной версии; подписание УКЭП; сохранение подписанного документа в сущности бюджета. |
| **Критичность** | Необходимая. |
| **Триггер** | Сформирован полный комплект бюджетной отчетности. |
| **Предварительные условия** | Комплект содержит обязательные отчетные формы и пояснительную записку; определен председатель суда либо заместитель председателя, уполномоченный на согласование и подписание. |
| **Основной сценарий** | 1. Система автоматически направляет комплект бюджетной отчетности председателю суда либо заместителю председателя.  2. Система фиксирует передачу отчетности на согласование.  3. Руководитель знакомится с составом и показателями бюджетной отчетности.  4. Руководитель определяет, что корректировка отчетности не требуется.  5. Руководитель подписывает бюджетную отчетность усиленной квалифицированной электронной подписью.  6. Система сохраняет подписанную отчетность в соответствующей сущности бюджета.  7. Система связывает подписанный документ с комплектом бюджетной отчетности.  8. Процесс продолжается с направлением отчетности в УСД. |
| **Расширение (альтернативный сценарий)** | 4а. Руководитель определяет, что бюджетная отчетность требует корректировки.  4а.1 Руководитель фиксирует замечания к отчетности.  4а.2 Система передает замечания сотруднику отдела бухгалтерского учета и отчетности.  4а.3 Сотрудник вносит необходимые изменения в показатели и содержание отчетных форм.  4а.4 Система направляет исправленную версию отчетности руководителю.  4а.5 Процесс продолжается с подписания исправленной бюджетной отчетности. |

**UC003 — Представить отчетность в УСД и обработать замечания**

|  |  |
| --- | --- |
| **№ шага процесса** | 17–26 |
| **Выполняемая задача** | Направление подписанной бюджетной отчетности в УСД, контроль результата рассмотрения и повторное представление скорректированной отчетности при наличии замечаний. |
| **Цель** | Представить в УСД актуальную подписанную бюджетную отчетность и завершить процесс после ее принятия либо повторного направления исправленной версии. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела бухгалтерского учета и отчетности. Участники: Председатель суда / заместитель председателя; Система; Управление Судебного департамента (УСД). |
| **Ожидаемый результат** | Подписанная бюджетная отчетность направлена в УСД и принята либо скорректирована по замечаниям, повторно подписана и представлена в УСД. |
| **Рекомендованная функциональность** | Формирование пакета передачи в УСД; автоматическое направление подписанной отчетности; фиксация отправки; регистрация ответа УСД; хранение замечаний; создание новой версии отчетности; повторное подписание; повторное направление скорректированного комплекта. |
| **Критичность** | Необходимая. |
| **Триггер** | Бюджетная отчетность согласована руководителем, подписана УКЭП и сохранена в сущности бюджета. |
| **Предварительные условия** | Сформирован подписанный комплект бюджетной отчетности; Системе доступен канал передачи документов в УСД. |
| **Основной сценарий** | 1. Система формирует пакет передачи подписанной бюджетной отчетности.  2. Система направляет бюджетную отчетность в Управление Судебного департамента.  3. Сотрудник отдела бухгалтерского учета и отчетности контролирует поступление ответа УСД.  4. Система фиксирует получение ответа УСД по отчетности.  5. По результатам рассмотрения определяется, что бюджетная отчетность принята.  6. Процесс завершается с результатом «Бюджетная отчетность составлена и представлена в УСД». |
| **Расширение (альтернативный сценарий)** | 5а. УСД не приняло бюджетную отчетность и направило замечания.  5а.1 Сотрудник отдела бухгалтерского учета и отчетности анализирует замечания УСД.  5а.2 Сотрудник вносит коррективы в показатели и содержание отчетности.  5а.3 Сотрудник формирует новую версию комплекта бюджетной отчетности.  5а.4 Председатель суда либо заместитель председателя рассматривает и подписывает скорректированную отчетность.  5а.5 Система формирует пакет передачи и повторно направляет скорректированную отчетность в УСД.  5а.6 Процесс завершается с результатом «Бюджетная отчетность скорректирована по замечаниям и представлена в УСД». |
