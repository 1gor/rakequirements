## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник суда | Формирует заявление на отпуск, ознакамливается и подписывает приказ о предоставлении отпуска |
| Председатель суда | Согласовывает заявление на отпуск сотрудника, подписывает заявление сотрудника, согласовывает и подписывает проект приказа о предоставлении отпуска |
| Бухгалтерия | Переводит необходимые перечисления в иные фонды, уплачивает НДФЛ, фиксирует информацию в ИС |
| Система | Направляет документы сотрудникам для согласования, производит расчет отпускных, |
