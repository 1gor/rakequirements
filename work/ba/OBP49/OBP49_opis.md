## ****3. Реестр UC****

**UC001 — Оформить и согласовать заявление на отпуск**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–12 |
| **Выполняемая задача** | Оформление заявления на отпуск, его передача председателю суда, рассмотрение и фиксация решения о согласовании либо отказе. |
| **Цель** | Получить официальное решение председателя суда по заявлению на отпуск и обеспечить автоматическую фиксацию и доведение результата до сотрудника и отдела кадров. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник суда. Участники: Председатель суда; Система. |
| **Ожидаемый результат** | Заявление на отпуск согласовано и передано в отдел кадров либо сотруднику возвращено заявление с зафиксированным отказом председателя суда. |
| **Рекомендованная функциональность** | Формирование заявления на отпуск в Системе; автоматическая передача на согласование; фиксация визы согласования или отказа; уведомление сотрудника о статусе; автоматическая передача согласованного заявления в отдел кадров. |
| **Критичность** | Необходимая. |
| **Триггер** | У сотрудника суда возникла необходимость оформить отпуск. |
| **Предварительные условия** | Сотрудник суда имеет доступ к Системе и сведения, необходимые для указания дат и иных параметров отпуска. |
| **Основной сценарий** | 1. Сотрудник суда оформляет в Системе заявление на отпуск с указанием необходимых сведений и дат отпуска.  2. Система автоматически передает заявление председателю суда для согласования.  3. Председатель суда знакомится с заявлением и заявленными датами отпуска.  4. Председатель суда принимает решение о согласовании отпуска.  5. Председатель суда проставляет визу согласования на заявлении.  6. Система возвращает сотруднику согласованное заявление.  7. Система уведомляет сотрудника о положительном статусе согласования.  8. Система передает согласованное заявление в отдел кадров для подготовки проекта приказа. |
| **Расширение (альтернативный сценарий)** | 4а. Председатель суда отказывает в согласовании отпуска.  4а.1 Председатель суда проставляет визу об отказе.  4а.2 Система возвращает сотруднику заявление с зафиксированным отказом.  4а.3 Сотрудник суда знакомится с решением председателя суда.  4а.4 Процесс завершается с результатом «В предоставлении отпуска отказано председателем». |

**UC002 — Подготовить приказ об отпуске и ознакомить сотрудника**

|  |  |
| --- | --- |
| **№ шага процесса** | 13–28 |
| **Выполняемая задача** | Подготовка проекта приказа о предоставлении отпуска, его проверка и подписание председателем суда, ознакомление сотрудника и включение подписанного приказа в личное дело. |
| **Цель** | Оформить юридически значимый приказ о предоставлении отпуска и документально подтвердить ознакомление сотрудника с его содержанием. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участники: Председатель суда; Сотрудник суда; Система. |
| **Ожидаемый результат** | Приказ о предоставлении отпуска сформирован, проверен и подписан председателем суда, сотрудник ознакомлен с приказом электронной подписью, документ включен в личное дело и направлен в бухгалтерию. |
| **Рекомендованная функциональность** | Формирование проекта приказа на основании согласованного заявления; автоматическая маршрутизация председателю суда; фиксация замечаний и доработки; подписание приказа УКЭП; автоматическая передача приказа сотруднику и в отдел кадров; фиксация электронной подписи сотрудника; включение приказа в личное дело; направление экземпляра в бухгалтерию. |
| **Критичность** | Необходимая. |
| **Триггер** | В отдел кадров поступило согласованное председателем суда заявление на отпуск. |
| **Предварительные условия** | Согласованное заявление доступно сотруднику отдела кадров; в Системе имеются данные сотрудника и параметры отпуска. |
| **Основной сценарий** | 1. Сотрудник отдела кадров знакомится с согласованным заявлением и необходимыми сведениями.  2. Сотрудник отдела кадров формирует в Системе проект приказа о предоставлении отпуска.  3. Система автоматически передает проект приказа председателю суда для подписания.  4. Председатель суда знакомится с проектом приказа и проверяет корректность содержащихся в нем сведений.  5. Председатель суда подтверждает корректность проекта приказа.  6. Председатель суда подписывает проект приказа УКЭП.  7. Система возвращает подписанный приказ в отдел кадров.  8. Система направляет приказ сотруднику суда для ознакомления.  9. Сотрудник суда знакомится с содержанием приказа.  10. Сотрудник суда подтверждает ознакомление электронной подписью в графе «С приказом ознакомлен».  11. Система возвращает приказ с подтвержденным ознакомлением в отдел кадров.  12. Система включает подписанный приказ в личное дело сотрудника.  13. Система направляет экземпляр приказа в бухгалтерию для расчета отпускных. |
| **Расширение (альтернативный сценарий)** | 5а. Председатель суда выявляет ошибки или иные замечания к проекту приказа.  5а.1 Председатель суда передает проект приказа на доработку с замечаниями.  5а.2 Сотрудник отдела кадров корректирует проект приказа в соответствии с полученными замечаниями.  5а.3 Исправленный проект возвращается председателю суда для подписания. |

**UC003 — Рассчитать и начислить отпускные**

|  |  |
| --- | --- |
| **№ шага процесса** | 29–40 |
| **Выполняемая задача** | Расчет среднего заработка и суммы отпускных, проверка автоматизированных расчетов, начисление отпускных, выполнение обязательных удержаний и перечислений и фиксация сведений о выплатах. |
| **Цель** | Обеспечить корректный расчет и начисление отпускных, выполнение обязательных удержаний и перечислений и отражение сведений о выплатах и сроках в информационной системе. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Бухгалтерия. Участник: Система. |
| **Ожидаемый результат** | Отпускные рассчитаны, проверены и начислены; НДФЛ и иные необходимые перечисления выполнены; сведения о начислениях, удержаниях, перечислениях и сроках выплат зафиксированы в ИС. |
| **Рекомендованная функциональность** | Автоматический расчет среднего заработка и суммы отпускных; вызов ТБП139 для проверки выводов Системы; фиксация начисления отпускных; учет НДФЛ и дополнительных перечислений; хранение сведений о начислениях, удержаниях и перечислениях; фиксация срока выплаты отпускных. |
| **Критичность** | Необходимая. |
| **Триггер** | В бухгалтерию поступил подписанный приказ о предоставлении отпуска. |
| **Предварительные условия** | Приказ о предоставлении отпуска подписан председателем суда; в Системе доступны расчетные данные сотрудника и продолжительность отпуска. |
| **Основной сценарий** | 1. Сотрудник бухгалтерии изучает поступивший приказ о предоставлении отпуска.  2. Система автоматически рассчитывает средний заработок сотрудника.  3. Система автоматически рассчитывает сумму отпускных с учетом среднего заработка и продолжительности отпуска.  4. Бухгалтерия выполняет ТБП139 «Проверить выводы системы» и подтверждает корректность результатов расчета.  5. Бухгалтерия начисляет сотруднику отпускные.  6. Бухгалтерия выполняет удержание и уплату НДФЛ с суммы отпускных.  7. Бухгалтерия определяет необходимость иных перечислений и удержаний.  8. Бухгалтерия вносит в ИС сведения о произведенных начислениях, удержаниях и перечислениях.  9. Бухгалтерия фиксирует сроки выплаты отпускных.  10. Процесс завершается с результатом «Отпуск согласован. Сотруднику начислены отпускные». |
| **Расширение (альтернативный сценарий)** | 7а. Требуются дополнительные перечисления или удержания в иные фонды.  7а.1 Бухгалтерия выполняет необходимые перечисления и удержания.  7а.2 Процесс продолжается с фиксации сведений о начислениях, удержаниях и перечислениях в ИС. |
