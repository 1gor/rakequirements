## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Сотрудник, ответственный за пожарную безопасность | Организует и проводит проверки работоспособности систем пожарной сигнализации, оповещения и дымоудаления. Составляет, завершает подготовку и подписывает акт проверки. Принимает решение о необходимости и проводит противопожарные учения и инструктажи. Вносит в систему дату следующей плановой проверки. |
| Эксплуатирующая организация | Участвует в проверке работоспособности противопожарных систем на основании договора. Подписывает акт проверки автоматической установки пожарной сигнализации. |
| Система | Автоматически уведомляет ответственного сотрудника о наступлении даты проведения проверки. Подготавливает и предоставляет шаблон акта проверки. |
