## ****3. Реестр UC****

**UC001 — Провести плановую проверку противопожарных систем и оформить результаты**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–6 |
| **Выполняемая задача** | Организация плановой проверки работоспособности противопожарных систем, оформление результатов проверки и подписание акта. |
| **Цель** | Обеспечить своевременную проверку работоспособности противопожарных систем и зафиксировать результаты проверки в установленном документе. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: сотрудник, ответственный за пожарную безопасность. Участники: эксплуатирующая организация; Система. |
| **Ожидаемый результат** | Работоспособность датчиков дыма и связанных противопожарных систем проверена, акт проверки автоматической установки пожарной сигнализации подготовлен и подписан участниками проверки. |
| **Рекомендованная функциональность** | Автоматическое уведомление ответственного сотрудника о наступлении даты проверки; автоматическая подготовка шаблона акта проверки; возможность заполнения акта по результатам проверки и фиксации подписанного документа в Системе. |
| **Критичность** | Необходимая. |
| **Триггер** | Наступила дата проведения противопожарной проверки, установленная локальным актом. |
| **Предварительные условия** | Дата противопожарной проверки определена локальным актом; обеспечено участие сотрудника, ответственного за пожарную безопасность, и представителя эксплуатирующей организации. |
| **Основной сценарий** | 1. При наступлении установленной даты Система уведомляет сотрудника, ответственного за пожарную безопасность, о необходимости проведения противопожарной проверки.  2. Сотрудник совместно с представителем эксплуатирующей организации выполняет задымление датчиков и контролирует их реакцию, а также работу системы дымоудаления и системы оповещения о пожаре.  3. Сотрудник с участием представителя эксплуатирующей организации проверяет работоспособность датчиков дыма и связанных противопожарных систем.  4. Система автоматически подготавливает шаблон акта проверки автоматической установки пожарной сигнализации.  5. Сотрудник проверяет подготовленный шаблон, вносит сведения по результатам проверки и завершает подготовку акта.  6. Сотрудник организует подписание акта участниками проверки, включая представителя эксплуатирующей организации.  7. Результаты противопожарной проверки зафиксированы в подписанном акте. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

**UC002 — Определить необходимость проведения учений и запланировать следующую проверку**

|  |  |
| --- | --- |
| **№ шага процесса** | 7–13 |
| **Выполняемая задача** | Определение необходимости проведения противопожарных учений, их проведение при необходимости и планирование следующей противопожарной проверки. |
| **Цель** | Обеспечить выполнение предусмотренных локальным актом противопожарных мероприятий и зафиксировать дату следующей плановой проверки. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: сотрудник, ответственный за пожарную безопасность. Участник: Система. |
| **Ожидаемый результат** | Определена необходимость проведения противопожарных учений; при необходимости учения проведены; в Системе зафиксирована следующая дата противопожарной проверки. |
| **Рекомендованная функциональность** | Возможность фиксации решения о необходимости проведения противопожарных учений; ввод и хранение следующей даты противопожарной проверки в Системе. |
| **Критичность** | Необходимая. |
| **Триггер** | Завершена плановая проверка противопожарных систем и подписан акт проверки. |
| **Предварительные условия** | Имеется действующий локальный акт, регламентирующий проведение противопожарных мероприятий; результаты плановой проверки оформлены. |
| **Основной сценарий** | 1. Сотрудник, ответственный за пожарную безопасность, изучает положения локального акта, регламентирующие проведение противопожарных мероприятий.  2. Сотрудник определяет необходимость проведения противопожарных учений.  3. Если проведение учений требуется, сотрудник организует и проводит противопожарные учения в соответствии с установленным порядком.  4. После проведения учений сотрудник вносит в Систему следующую дату противопожарной проверки в соответствии с установленной периодичностью.  5. Процесс завершается с результатом «Обеспечена противопожарная безопасность. Проведены учения». |
| **Расширение (альтернативный сценарий)** | 2а. Согласно локальному акту проведение противопожарных учений не требуется.  2а.1 Сотрудник вносит в Систему следующую дату противопожарной проверки в соответствии с установленной периодичностью.  2а.2 Процесс завершается с результатом «Проведение учений не требуется. Обеспечена противопожарная безопасность». |
