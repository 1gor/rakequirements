| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участники: Руководители структурных подразделений. |
| **Ожидаемый результат** | Проект локального акта сформирован или доработан, при необходимости согласован руководителями структурных подразделений и передан председателю суда на утверждение. |
| **Рекомендованная функциональность** | Создание и хранение проекта акта; ведение версий документа; фиксация замечаний; формирование листа согласования; назначение согласующих руководителей; передача проекта на согласование; фиксация виз согласования; возврат проекта сотруднику отдела кадров на доработку. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость принять локальный акт по кадровому вопросу. |
| **Предварительные условия** | Сотруднику отдела кадров доступны сведения, необходимые для подготовки проекта акта; определены кадровый вопрос и предполагаемый вид локального акта. |
| **Основной сценарий** | 1. Сотрудник отдела кадров определяет, требуется ли доработка ранее подготовленного проекта акта.  2. Если доработка не требуется, сотрудник отдела кадров формирует проект локального акта и проверяет наличие необходимых реквизитов.  3. Сотрудник отдела кадров определяет необходимость согласования проекта руководителями структурных подразделений.  4. Если согласование требуется, сотрудник отдела кадров определяет состав согласующих руководителей.  5. Сотрудник отдела кадров формирует лист согласования.  6. Руководители структурных подразделений рассматривают проект акта в части своей компетенции.  7. Руководители структурных подразделений подтверждают согласование проекта.  8. Руководители структурных подразделений проставляют визу согласования.  9. Согласованный проект акта передается председателю суда на утверждение. |
| **Расширение (альтернативный сценарий)** | 1а. Проект акта требуется доработать по ранее полученным замечаниям.  1а.1 Сотрудник отдела кадров вносит изменения в проект акта.  1а.2 Сотрудник отдела кадров сохраняет актуальную редакцию документа.  1а.3 Процесс продолжается с определения необходимости согласования.  3а. Согласование руководителями структурных подразделений не требуется.  3а.1 Проект акта передается председателю суда без формирования листа согласования.  7а. Руководители структурных подразделений не согласовали проект.  7а.1 Руководители формируют замечания к проекту акта.  7а.2 Замечания передаются сотруднику отдела кадров.  7а.3 Процесс возвращается к доработке проекта акта. |

**UC002 — Утвердить и зарегистрировать локальный акт**

|  |  |
| --- | --- |
| **№ шага процесса** | 15–20 |
| **Выполняемая задача** | Рассмотрение проекта локального акта председателем суда, его утверждение усиленной квалифицированной электронной подписью и регистрация. |
| **Цель** | Получить окончательное решение по проекту акта, придать документу юридическую силу и обеспечить его официальный учет. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Председатель суда. Участники: Сотрудник отдела кадров; Лицо ответственное за ведение бланков строгой отчетности. |
| **Ожидаемый результат** | Проект акта утвержден председателем суда, подписан УКЭП и зарегистрирован с присвоением номера и даты либо возвращен сотруднику отдела кадров на доработку. |
| **Рекомендованная функциональность** | Передача проекта председателю суда; предоставление проекта и результатов согласования; фиксация замечаний председателя; возврат проекта на доработку; подписание документа УКЭП; регистрация утвержденного акта; присвоение регистрационного номера; фиксация даты и наименования документа. |
| **Критичность** | Необходимая. |
| **Триггер** | Проект локального акта подготовлен и передан председателю суда на утверждение. |
| **Предварительные условия** | Проект акта содержит необходимые реквизиты; при необходимости завершено согласование руководителями структурных подразделений. |
| **Основной сценарий** | 1. Председатель суда получает проект локального акта.  2. Председатель суда изучает проект и результаты предшествующего согласования.  3. Председатель суда принимает решение об утверждении проекта.  4. Председатель суда подписывает проект акта усиленной квалифицированной электронной подписью.  5. После подписания документ приобретает статус утвержденного акта.  6. Лицо ответственное за ведение бланков строгой отчетности регистрирует утвержденный акт.  7. Ответственное лицо присваивает акту регистрационный номер.  8. Ответственное лицо фиксирует дату и наименование документа.  9. Процесс продолжается с определения способа доведения утвержденного акта до работников. |
| **Расширение (альтернативный сценарий)** | 3а. Председатель суда не согласовал проект акта.  3а.1 Председатель суда формирует замечания к проекту.  3а.2 Замечания направляются сотруднику отдела кадров.  3а.3 Процесс возвращается к определению необходимости доработки проекта акта. |

**UC003 — Опубликовать акт или организовать индивидуальное ознакомление**

|  |  |
| --- | --- |
| **№ шага процесса** | 21–32 |
| **Выполняемая задача** | Определение способа доведения локального акта до работников, публикация во внутренней системе либо индивидуальное ознакомление с подписанием УКЭП и сохранением документа. |
| **Цель** | Обеспечить доведение утвержденного локального акта до работников и сохранить документ в соответствующем номенклатурном или личном деле. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Лицо ответственное за ведение бланков строгой отчетности. Участники: Сотрудник отдела кадров; Сотрудник; Система. |
| **Ожидаемый результат** | Утвержденный акт опубликован и сохранен в номенклатурном деле либо работник индивидуально ознакомлен с актом, подписал его УКЭП, а документ сохранен в личном деле. |
| **Рекомендованная функциональность** | Фиксация решения о необходимости публикации; публикация акта во внутренней системе; автоматическое уведомление работников; автоматическое связывание акта с номенклатурным делом; направление акта в отдел кадров; постановка задачи на ознакомление; предоставление доступа работнику; подписание акта УКЭП; автоматическое сохранение подписанного акта в личном деле. |
| **Критичность** | Необходимая. |
| **Триггер** | Локальный акт утвержден, подписан УКЭП и зарегистрирован. |
| **Предварительные условия** | Утвержденный акт зарегистрирован; определены работники или категории работников, до которых необходимо довести его содержание. |
| **Основной сценарий** | 1. Лицо ответственное за ведение бланков строгой отчетности определяет необходимость публикации локального акта во внутренней системе.  2. Ответственное лицо принимает решение о публикации акта.  3. Ответственное лицо размещает утвержденный акт во внутренней системе.  4. Система автоматически уведомляет предусмотренных работников суда о публикации акта.  5. Система связывает утвержденный акт с соответствующим номенклатурным делом.  6. Процесс завершается с результатом «Локальный акт по кадровому вопросу принят и опубликован. Сотрудники ознакомлены. Акт сохранен в номенклатурное дело». |
| **Расширение (альтернативный сценарий)** | 2а. Публикация локального акта во внутренней системе не требуется.  2а.1 Система направляет утвержденный акт в отдел кадров.  2а.2 Сотрудник отдела кадров предоставляет работнику доступ к акту и организует ознакомление.  2а.3 Работник знакомится с содержанием утвержденного акта.  2а.4 Работник подписывает акт УКЭП, подтверждая факт ознакомления.  2а.5 Система связывает подписанный работником акт с его личным делом.  2а.6 Процесс завершается с результатом «Локальный акт по кадровому вопросу принят. Сотрудник ознакомлен. Акт сохранен в личное дело». |
