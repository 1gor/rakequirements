UC-01. Инициация и подготовка проекта локального акта

|  |  |  |  |
| --- | --- | --- | --- |
| № шага процесса | № связанной US | Выполняемая задача | Инициировать подготовку локального акта, определить необходимость доработки и сформировать/доработать проект акт |
| 0-6 | US-OBP37-01- US-OBP37-05 | Цель | Запустить процесс принятия акта и подготовить качественный проект документа |
| Актор | Сотрудник отдела кадров |
| Ожидаемый результат | Проект акта создан либо доработан по замечаниям и готов к маршрутизации на согласование/утверждение |
| Рекомендованная функциональность | Создание проекта по шаблонам; версионирование; хранение замечаний и истории доработок; статусная модель (“черновик/на доработке/готов к согласованию”); контроль полноты обязательных реквизитов |
| Критичность | Необходимая |
| Триггер | Возникла необходимость принять локальный акт по кадровым вопросам |
| Предварительные условия | - Сотрудник отдела кадров авторизован  - В системе доступны шаблоны/карточка документа (если предусмотрено) |
| Основной сценарий | 1. Сотрудник отдела кадров инициирует процесс принятия локального акта  2. Система переводит процесс к подготовке проекта  3. Сотрудник определяет необходимость доработки проекта  4. Если доработка требуется — сотрудник дорабатывает проект по замечаниям  5. Если доработка не требуется — сотрудник формирует проект акта  6. Система фиксирует актуальную версию проекта и статус “готов к маршрутизации”  7. Процесс переходит к определению необходимости согласования |
| Расширенный (альтернативный сценарий) | 4а: Если замечания отсутствуют/не приложены, система просит указать источник замечаний либо перевести проект в статус “сформирован без замечаний”.  4б: Если при сохранении доработок произошла ошибка, система фиксирует сбой, сохраняет черновик/предыдущую версию и предлагает повторить операцию. |
