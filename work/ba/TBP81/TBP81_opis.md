## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья | Принимает решение о назначении экспертизы, утверждает кандидатуру эксперта, формирует определение о назначении экспертизы, проводит Судебные заседания, оценивает заключение эксперта, принимает решение о дополнительной или повторной экспертизе |
| Канцелярия арбитражного суда | Направляет документы участникам процесса |
| Лицо, участвующее в деле | Представляет вопросы для экспертизы, высказывает мнение по вопросам экспертизы, предлагает кандидатуру эксперта |
| Экспертное учреждение/эксперт | Проводит экспертизу, предоставляет заключение эксперта |
| Помощник Судьи | Подготавливает дело к передаче в экспертное учреждение, направляет дело |
| Система | Формирует рекомендацию по назначению экспертизы и создаёт событие с уведомлением пользователя, отправляет в систему суда дату и время ознакомления с определением, мониторит поступление средств на депозит суда и заносит сведения в номенклатурное/Судебное дело, анализирует документы ЛУВД на наличие льгот и проверяет их по источникам, формирует рекомендацию по применению льгот и уведомляет пользователя, вносит категорию освобождения (льготу) в карточку ЛУВД и номенклатурное дело и информирует Судью, указывает в проекте определения основания назначения экспертизы, фиксирует ФИО выбранного эксперта в деле, фиксирует наименование экспертного учреждения в деле, направляет эксперту данные для ознакомления с предупреждением об уголовной ответственности и получает подтверждение ознакомления |
