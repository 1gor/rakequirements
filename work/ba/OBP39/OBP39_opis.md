## ****3. Реестр UC****

**UC001 — Обеспечить наличие и учет бланков удостоверений**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–8 |
| **Выполняемая задача** | Проверка наличия бланков служебных удостоверений, формирование и направление запроса на их получение при необходимости, а также регистрация полученных бланков в электронном журнале. |
| **Цель** | Обеспечить наличие и контролируемый учет бланков служебных удостоверений для своевременного оформления документа сотруднику. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участник: Управление судебного департамента (УСД) / Судебный департамент при Верховном Суде Российской Федерации. |
| **Ожидаемый результат** | Наличие бланков подтверждено либо необходимые бланки получены по запросу; сведения о бланках зарегистрированы в электронном журнале учета удостоверений. |
| **Рекомендованная функциональность** | Формирование запроса на получение бланков; фиксация реквизитов суда и потребности в бланках; регистрация направления запроса; учет ожидания и поступления бланков; ведение электронного журнала бланков с указанием идентифицирующих реквизитов, количества, даты и основания получения. |
| **Критичность** | Необходимая. |
| **Триггер** | Сотрудник арбитражного суда согласован и принят в штат, в связи с чем требуется оформить служебное удостоверение. |
| **Предварительные условия** | В отделе кадров ведется учет бланков служебных удостоверений; сотруднику отдела кадров доступны сведения о принятом работнике и установленное место хранения бланков. |
| **Основной сценарий** | 1. Сотрудник отдела кадров проверяет фактическое наличие неиспользованных бланков удостоверений.  2. Сотрудник отдела кадров определяет, что бланки имеются в достаточном количестве.  3. Процесс переходит к регистрации бланков в электронном журнале.  4. Сотрудник отдела кадров вносит в электронный журнал идентифицирующие реквизиты бланков, их количество, дату поступления и основание получения.  5. После регистрации бланка процесс продолжается с оформлением служебного удостоверения. |
| **Расширение (альтернативный сценарий)** | 2а. Бланки удостоверений отсутствуют или их недостаточно.  2а.1 Сотрудник отдела кадров формирует в информационной системе запрос на получение необходимого количества бланков.  2а.2 В запросе указываются реквизиты суда и сведения о потребности в бланках.  2а.3 Сотрудник отдела кадров направляет запрос в УСД / Судебный департамент при Верховном Суде Российской Федерации.  2а.4 Сотрудник отдела кадров контролирует поступление бланков.  2а.5 После фактического получения бланков процесс возвращается к их регистрации в электронном журнале. |

**UC002 — Оформить и подписать служебное удостоверение**

|  |  |
| --- | --- |
| **№ шага процесса** | 9–17 |
| **Выполняемая задача** | Оформление бланка служебного удостоверения, внесение обязательных реквизитов, размещение защитных элементов и передача документа председателю суда на проверку и подписание. |
| **Цель** | Подготовить служебное удостоверение установленного образца и подтвердить его действительность подписью председателя суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник отдела кадров. Участник: Председатель суда. |
| **Ожидаемый результат** | Бланк удостоверения полностью оформлен, проверен и подписан председателем суда, после чего передан сотруднику отдела кадров для выдачи получателю. |
| **Рекомендованная функциональность** | Фиксация используемого бланка за конкретным сотрудником; ведение сведений о реквизитах работника, суда и сроке действия удостоверения; фиксация статуса оформления; регистрация передачи председателю суда и возврата подписанного удостоверения. |
| **Критичность** | Необходимая. |
| **Триггер** | Бланк служебного удостоверения зарегистрирован в электронном журнале и доступен для оформления. |
| **Предварительные условия** | Имеются фотография сотрудника, кадровые сведения, данные суда, применимый срок действия удостоверения, голограмма и возможность использования гербовой печати. |
| **Основной сценарий** | 1. Сотрудник отдела кадров сверяет фотографию с данными сотрудника и наклеивает ее на бланк удостоверения.  2.
