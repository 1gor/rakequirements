2.3. Реестр UC (в части выполняемых пользователем задач и рекомендованной функциональности Системы)

UC-01. Обеспечение наличия и учета бланков служебных удостоверений

|  |  |
| --- | --- |
| № шага процесса | 0-6 |
| Выполняемая задача | Проверка наличия бланков удостоверений, формирование и отправка запроса в УСД, учет поступивших бланков |
| Цель | Обеспечить наличие и учет бланков служебных удостоверений для непрерывного оформления документов |
| Актор | Сотрудник отдела кадров |
| Ожидаемый результат | Бланки удостоверений доступны и зарегистрированы в электронном журнале учета |
| Рекомендованная функциональность | Проверка остатков бланков; формирование и отправка запросов в УСД; фиксация поступления бланков; электронный журнал учета бланков; уведомления о поступлении |
| Критичность | Необходимая |
| Триггер | Сотрудник арбитражного суда согласован и принят в штат |
| Предварительные условия | - Сотрудник отдела кадров авторизован в системе  - В системе ведется учет бланков удостоверений |
| Основной сценарий | 1. Сотрудник отдела кадров инициирует проверку наличия бланков удостоверений  2. Система отображает информацию о наличии или отсутствии бланков  3. При отсутствии бланков сотрудник формирует запрос в УСД  4. Система отправляет запрос и переводит процесс в режим ожидания  5. При поступлении бланков система фиксирует факт получения  6. Сотрудник регистрирует полученные бланки в электронном журнале учета |
| Расширенный (альтернативный сценарий) | 2а: Если данные об остатках недоступны, система отображает сообщение о технической ошибке  5а: Если бланки не поступили в ожидаемый срок, система формирует напоминание ответственному |

UC-02. Оформление бланка служебного удостоверения сотрудника

|  |  |
| --- | --- |
| № шага процесса | 7-14 |
| Выполняемая задача | Физическое и реквизитное оформление служебного удостоверения сотрудника |
| Цель | Создать корректно оформленное удостоверение установленного образца |
| Актор | Сотрудник отдела кадров |
| Ожидаемый результат | Бланк удостоверения заполнен, оформлен и готов к передаче на подпись |
| Рекомендованная функциональность | Ведение карточки удостоверения; контроль заполнения обязательных реквизитов; фиксация этапов оформления; связь с электронным журналом учета |
| Критичность | Необходимая |
| Триггер | Бланки удостоверений зарегистрированы и доступны для оформления |
| Предварительные условия | - В наличии зарегистрированный бланк удостоверения  - В системе доступны данные сотрудника и суда |
| Основной сценарий | 1. Сотрудник отдела кадров выбирает зарегистрированный бланк удостоверения  2. Сотрудник наклеивает фотографию сотрудника  3. Сотрудник наклеивает голограмму установленного образца  4. Сотрудник проставляет гербовую печать  5. Сотрудник заполняет срок действия удостоверения  6. Сотрудник вносит данные суда  7. Сотрудник заносит реквизиты сотрудника  8. Сотрудник передает удостоверение на подпись председателю суда |
| Расширенный (альтернативный сценарий) | 5а: Если срок действия не соответствует установленным требованиям, система блокирует дальнейшие действия  7а: Если данные сотрудника отсутствуют или неполны, система требует их актуализации |
