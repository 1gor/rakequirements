## ****3. Реестр UC****

**UC001 — Сформировать и проверить пакет документов сотрудника**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–11 |
| **Выполняемая задача** | Формирование электронного пакета документов сотрудником, автоматическая проверка его полноты и обязательных реквизитов, а также получение и передача недостающих документов. |
| **Цель** | Обеспечить получение отделом кадров полного и корректного электронного пакета документов, необходимого для формирования личного дела. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник. Участники: Отдел кадров; Система. |
| **Ожидаемый результат** | Электронный пакет документов передан в отдел кадров, проверен на полноту, наличие обязательных подписей и согласия на обработку персональных данных; недостающие документы при необходимости представлены. |
| **Рекомендованная функциональность** | Формирование и отправка электронного пакета документов; автоматическая проверка полноты комплекта; проверка обязательных подписей и согласия на обработку персональных данных; вызов ТБП139 для проверки выводов Системы; автоматическое формирование запроса на недостающие документы; повторная загрузка и проверка документов. |
| **Критичность** | Необходимая. |
| **Триггер** | Сотрудник принят в штат суда. |
| **Предварительные условия** | Определен перечень документов, необходимых для формирования личного дела; сотруднику доступна возможность подготовки и направления электронных документов. |
| **Основной сценарий** | 1. Сотрудник формирует электронный пакет документов для трудоустройства.  2. Сотрудник направляет сформированный пакет документов в отдел кадров.  3. Система автоматически проверяет полноту представленного комплекта документов.  4. Система проверяет наличие подписи сотрудника в документах, для которых она обязательна.  5. Система проверяет наличие согласия сотрудника на обработку персональных данных.  6. Сотрудник отдела кадров выполняет ТБП139 «Проверить выводы системы».  7. Отдел кадров подтверждает, что состав документов полный.  8. Процесс продолжается с созданием электронного личного дела. |
| **Расширение (альтернативный сценарий)** | 7а. По результатам проверки установлено, что состав документов неполный.  7а.1 Система автоматически формирует и направляет сотруднику запрос на предоставление недостающих документов.  7а.2 Сотрудник подготавливает пакет недостающих документов.  7а.3 Сотрудник передает недостающие документы в отдел кадров.  7а.4 Процесс возвращается к автоматической проверке полного комплекта документов. |

| **Ожидаемый результат** | Документы, фотография и персональные данные сотрудника загружены в электронное личное дело, результаты автоматизированного заполнения проверены, формирование дела завершено. |
| **Рекомендованная функциональность** | Создание электронного личного дела; автоматическая загрузка документов и фотографии; автоматическое заполнение персональных данных; вызов ТБП139 для проверки выводов Системы; фиксация завершения формирования дела в подсистеме «Кадры». |
| **Критичность** | Необходимая. |
| **Триггер** | Отдел кадров подтвердил полноту и корректность электронного пакета документов сотрудника. |
| **Предварительные условия** | Полный пакет документов прошел проверку; сотрудник отдела кадров имеет доступ к подсистеме «Кадры». |
| **Основной сценарий** | 1. Сотрудник отдела кадров выбирает действие «Добавить сотрудника» в интерфейсе Системы.  2. Система создает электронное личное дело нового сотрудника.  3. Система автоматически загружает документы в создаваемое личное дело.  4. Система автоматически загружает фотографию сотрудника.  5. Система автоматически заполняет персональные данные сотрудника.  6. Сотрудник отдела кадров выполняет ТБП139 «Проверить выводы системы».  7. Сотрудник отдела кадров проверяет корректность загруженных документов, фотографии и персональных данных.  8. Сотрудник отдела кадров подтверждает завершение формирования электронного личного дела.  9. Процесс завершается с результатом «Личное дело сформировано в подсистеме „Кадры“». |

**UC003 — Актуализировать и архивировать электронное личное дело**

|  |  |
| --- | --- |
| **№ шага процесса** | 19–27 |
| **Выполняемая задача** | Актуализация электронного личного дела при изменении сведений о сотруднике и архивирование дела после увольнения. |
| **Цель** | Поддерживать электронное личное дело в актуальном состоянии и обеспечить его надлежащее завершение и хранение после увольнения сотрудника. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Отдел кадров. |
| **Ожидаемый результат** | Измененные или новые документы внесены в электронное личное дело; при увольнении сведения актуализированы, а личное дело перемещено в электронный архив. |
| **Рекомендованная функциональность** | Фиксация события изменения сведений или увольнения; загрузка сканов новых и измененных документов; внесение изменений в персональные данные и состав личного дела; хранение истории изменений; перемещение личного дела в электронный архив; фиксация статуса архивирования. |
| **Критичность** | Необходимая. |
| **Триггер** | Изменилась информация по сотруднику, имеющему электронное личное дело, либо сотрудник уволен. |
| **Предварительные условия** | Электронное личное дело сотрудника сформировано и доступно сотруднику отдела кадров. |
| **Основной сценарий** | 1. Отдел кадров получает сведения об изменении информации по сотруднику.  2. Сотрудник отдела кадров сканирует измененные или новые документы.  3. Сотрудник отдела кадров вносит изменения в сведения и состав документов электронного личного дела.  4. Система сохраняет актуальную редакцию электронного личного дела.  5. Процесс завершается с результатом «Внесены изменения в электронное личное дело сотрудника». |
| **Расширение (альтернативный сценарий)** | 1а. Сотрудник, имеющий электронное личное дело, уволен.  1а.1 Сотрудник отдела кадров сканирует документы об увольнении.  1а.2 Сотрудник отдела кадров вносит в электронное личное дело сведения и документы, связанные с увольнением.  1а.3 Сотрудник отдела кадров перемещает электронное личное дело в электронный архив.  1а.4 Процесс завершается после актуализации и архивирования электронного личного дела. |
