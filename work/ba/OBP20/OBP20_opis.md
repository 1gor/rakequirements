# [To be] ОБП20. Организация выдачи работникам суда необходимых нормативных правовых актов, юридической и справочной литературы

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП20 — Организация выдачи работникам суда необходимых нормативных правовых актов, юридической и справочной литературы |
| **Суть процесса** | Организация оформления и выдачи поступивших печатных изданий работникам суда: формирование актов приема-передачи, автоматическое уведомление инициатора закупки, передача литературы в судебные составы и коллегии и последующая выдача конкретным сотрудникам суда. |
| **Участники процесса** | Сотрудник отдела, ответственного за выдачу литературы; Система; Председатель судебных составов и судебных коллегий; Сотрудники суда. |
| **НПА** | Процесс выдачи работникам суда необходимых нормативных правовых актов, юридической и справочной литературы не регламентирован конкретными НПА. |

## ****3. Реестр UC****

### UC001 — Оформить поступление и передачу печатных изданий

| **№ шага процесса** | **0–5** |
| --- | --- |
| **Выполняемая задача** | Оформление поступивших печатных изданий, формирование акта приема-передачи, уведомление инициатора закупки и передача литературы в судебный состав или коллегию. |
| **Цель** | Зафиксировать поступление приобретённой литературы и обеспечить её передачу председателю соответствующего судебного состава или судебной коллегии. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** сотрудник отдела, ответственного за выдачу литературы.**Участники:** Система; председатель судебных составов и судебных коллегий. |
| **Ожидаемый результат** | Акт приема-передачи сформирован и подписан; председатель судебного состава или коллегии уведомлён о поступлении литературы и получил печатные издания. |
| **Рекомендованная функциональность** | Формирование акта приема-передачи в Системе; автоматическое формирование и направление уведомления инициатору закупки; электронное подписание акта приема-передачи; фиксация факта передачи печатных изданий судебному составу или коллегии. |
| **Критичность** | Необходимая. |
| **Триггер** | В суд поступили приобретённые печатные издания. |
| **Предварительные условия** | Печатные издания приобретены и фактически поступили в суд; определён инициатор закупки и получатель литературы. |
| **Основной сценарий** | 1. Сотрудник отдела, ответственного за выдачу литературы, формирует в Системе акт приема-передачи поступивших печатных изданий. 2. Система автоматически формирует и направляет инициатору закупки уведомление о поступлении литературы. 3. Председатель судебного состава или судебной коллегии получает уведомление и знакомится с ним. 4. Председатель проверяет и подписывает акт приема-передачи в Системе. 5. Председатель получает физические экземпляры печатных изданий для последующей выдачи сотрудникам суда. |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |

### UC002 — Выдать печатные издания сотрудникам суда

| **№ шага процесса** | **6–10** |
| --- | --- |
| **Выполняемая задача** | Оформление передачи печатных изданий конкретным сотрудникам суда, фактическая выдача литературы и подтверждение её получения. |
| **Цель** | Обеспечить выдачу заказанной литературы конкретным сотрудникам суда с фиксацией факта её получения. |
| **Роль/Актор (в соответствии со схемой)** | **Основной актор:** председатель судебных составов и судебных коллегий.**Участники:** сотрудники суда. |
| **Ожидаемый результат** | Печатные издания выданы конкретным сотрудникам суда, акт приема-передачи подписан получателем, факт получения литературы подтверждён. |
| **Рекомендованная функциональность** | Формирование и заполнение акта приема-передачи для сотрудников суда; фиксация получателей литературы; электронное подписание акта сотрудником суда; фиксация завершения выдачи печатного издания. |
| **Критичность** | Необходимая. |
| **Триггер** | Председателем судебного состава или судебной коллегии получены поступившие печатные издания. |
| **Предварительные условия** | Печатные издания переданы в соответствующий судебный состав или коллегию; определены сотрудники суда, которым должна быть выдана литература. |
| **Основной сценарий** | 1. Председатель судебного состава или судебной коллегии формирует в Системе акт приема-передачи для сотрудников суда. 2. Председатель передаёт печатные издания конкретным сотрудникам суда. 3. Сотрудник суда подписывает акт приема-передачи в Системе, подтверждая получение издания. 4. Сотрудник получает заказанную литературу на руки. 5. Процесс завершается со статусом «Издание получено». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
