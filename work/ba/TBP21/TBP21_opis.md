# [To be] ТБП21. Направить автоматический запрос в другую ИС

| **Наименование процесса** | ТБП21: Направить автоматический запрос в другую ИС |
| --- | --- |
| **Суть процесса** | Автоматизированное формирование и направление запроса из ИС суда через Систему-обработчик в ИС ведомства, получение и обработка ответа. При получении отчета об ошибке Система формирует обращение в техническую поддержку, после обработки которого пользователь определяет необходимость повторного направления запроса. |
| **Участники процесса** | Судья/Помощник судьи, Тех. поддержка суда, Система, Система-обработчик, ИС ведомства |
| **НПА** | Постановление Правительства РФ от 08.09.2010 № 697 «О единой системе межведомственного электронного взаимодействия». |

# 1. Реестр US

| **№** | **Я КАК** | **ХОЧУ** | **ЧТОБЫ** |

| 2 | Судья/Помощник судьи | получать в Системе сведения возникших ошибках | принять решение о повторном направлении запроса. |

| 5 | Тех. поддержка суда | получать рекомендации Системы по ошибке | оперативно предоставить пользователю дальнейшее решения. |

# 3. Реестр UC

**UC001 — Формирование и обработка отчета об ошибке**

| **№ шага процесса** | 21–22, 25–32 |
| --- | --- |
| **Выполняемая задача** | Проверить причину ошибки запроса и направить пользователю результат обработки обращения. |
| **Цель** | Обеспечить обработку обращения по ошибке автоматического запроса и предоставить пользователю понятную причину ошибки и рекомендации по дальнейшим действиям. |
| **Роль / Актор** | Тех. поддержка суда |
| **Ожидаемый результат** | В карточке обращения зафиксированы причина ошибки и ответ технической поддержки; ответ доступен пользователю в Системе. |

Сотрудник технической поддержки проверяет причину ошибки и фиксирует установленный результат.  4. Система сохраняет зафиксированную причину ошибки в карточке обращения.  5. Сотрудник технической поддержки формирует ответ с причиной ошибки и рекомендациями по дальнейшим действиям и отправляет его.  6. Система фиксирует отправку ответа и делает ответ доступным пользователю в карточке обращения. |
