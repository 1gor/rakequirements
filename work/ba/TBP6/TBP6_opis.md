# [To be] ТБП6. Рассчитать срок

| **Наименование процесса** | ТБП6 — Рассчитать срок |
| --- | --- |
| **Суть процесса** | Определение даты окончания процессуального срока в полуавтоматическом режиме на основании введенных пользователем исходных данных с учетом правил исчисления процессуальных сроков. |
| **Участники процесса** | Судья; Сотрудник суда; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026), глава 10 «Процессуальные сроки», в том числе ст. 113–118. |

## **2.2 Описание схемы процесса**

| **№** | **Наименование элемента** | **Описание** | **Выявленные нормативные ограничения** |
| --- | --- | --- | --- |
| 0 | Пользователь выбрал опцию полуавтоматического расчета срока | **Тип:** Стартовое событие  **Назначение:** Инициировать процесс полуавтоматического расчета процессуального срока.  **Описание:** Пользователь выбирает опцию полуавтоматического расчета срока, после чего начинается процесс расчета. | — |
| 1 | Ввести данные для расчета срока | **Тип:** Пользовательская задача  **Назначение:** Внести данные о деле и параметры требуемого срока, необходимые для выполнения расчета.  **Роль:** Судья/Сотрудник суда  **Входящие данные:** Данные расчета  **Исходящие данные:** —  **Описание:** Пользователь заполняет исходные данные дела и параметры требуемого процессуального срока, включая сведения, необходимые для определения начала течения срока и единицы его исчисления.  **Результат шага:** Исходные данные для расчета срока введены. | — |
| 2 | Запустить расчет срока | **Тип:** Пользовательская задача  **Назначение:** Инициировать автоматизированный расчет срока на основании ранее введенных данных.  **Роль:** Судья/Сотрудник суда  **Входящие данные:** —  **Исходящие данные:** —  **Описание:** Пользователь подтверждает запуск расчета срока в Системе.  **Результат шага:** Запущен автоматизированный расчет срока. | — |
| 3 | Рассчитать срок | **Тип:** Сервисная задача  **Назначение:** Автоматически определить дату окончания процессуального срока по введенным данным и применимым правилам исчисления.  **Роль:** Система  **Входящие данные:** —  **Исходящие данные:** —  **Описание:** Система рассчитывает процессуальный срок с учетом правил главы 10 АПК РФ: течение срока, исчисляемого годами, месяцами или днями, начинается на следующий день после даты или события, определяющих его начало; в сроки, исчисляемые днями, не включаются нерабочие дни; если последний день срока приходится на нерабочий день, днем окончания считается первый следующий за ним рабочий день.  **Результат шага:** Системой сформирован результат расчета процессуального срока для последующей проверки. | — |
| 4 | [<u>ТБП139.Проверить выводы системы</u>](https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=533163178) | **Тип:** Вызов активности  **Назначение:** Перейти к типовому процессу проверки результата, сформированного Системой.  **Роль:** Судья/Сотрудник суда  **Входящие данные:** —  **Исходящие данные:** —  **Описание:** Переход к типовому процессу «ТБП139.Проверить выводы системы», в рамках которого пользователь проверяет корректность рассчитанного процессуального срока.  **Результат шага:** Результат расчета срока проверен пользователем. | — |
| 5 | Срок рассчитан | **Тип:** Конечное событие  **Назначение:** Зафиксировать завершение процесса расчета процессуального срока.  Процессуальный срок рассчитан и результат проверен пользователем. | — |

# **3. Реестр UC**

**UC-001 — Полуавтоматический расчет срока**

| **№ шага процесса** | 0–5 |
| --- | --- |
| **Выполняемая задача** | Ввести исходные данные для расчета срока, запустить расчет и зафиксировать результат в Системе. |
| **Цель** | Определить дату окончания процессуального срока по данным дела и параметрам требуемого срока. |
| **Роль / Актор** | Судья/Сотрудник суда |
| **Ожидаемый результат** | В Системе сформирован результат расчета срока, проверенный пользователем в рамках типового процесса проверки выводов Системы. |
| **Рекомендуемая функциональность** | Карточка расчета срока с вводом исходных данных, запуском расчета и отображением результата. |
| **Критичность** | Необходимая |
| **Триггер** | Пользователь выбирает опцию полуавтоматического расчета срока. |
| **Предварительные условия** | Пользователю доступна функция полуавтоматического расчета срока. |
| **Основной сценарий** | 1. Судья/Сотрудник суда вводит данные для расчета срока.  2. Судья/Сотрудник суда запускает расчет.  3. Система рассчитывает процессуальный срок по введенным данным и применимым правилам.  4. Судья/Сотрудник суда подтверждает результат расчета  5. Система фиксирует завершение расчета срока  6. Завершение основного сценария |
| **Расширение (альтернативный сценарий)** | 4а Корректировка расчета  4а1 Судья/Сотрудник суда выбирает элемент интерфейса «Ошибка расчета»  4а2 Судья корректирует данные  4а3 Судья подтверждает скорректированные данные  4а4 Процесс возвращается на шаг 5 основного сценария. |
