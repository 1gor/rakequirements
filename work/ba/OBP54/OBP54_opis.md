# [To be] ОБП54. Организация приема товарно-материальных ценностей

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП54 — Организация приема товарно-материальных ценностей |
| **Суть процесса** | Прием поставленных товарно-материальных ценностей, проверка их соответствия требованиям и сопроводительным документам, оформление возврата при выявлении несоответствий либо подписание документов, отражение ТМЦ в складском и бухгалтерском учете. |
| **Участники процесса** | Поставщик; Сотрудник МТО; Сотрудник бухгалтерии; Система |
| **НПА** | Федеральный закон от 05.04.2013 № 44-ФЗ "О контрактной системе в сфере закупок товаров, работ, услуг для обеспечения государственных и муниципальных нужд" (ред. от 26.12.2024)  Федеральный закон от 06.12.2011 № 402-ФЗ "О бухгалтерском учете" (ред. от 26.12.2024)  Приказ Судебного департамента при Верховном Суде РФ от 29.06.2010 № 135 "Об утверждении Положения о Главном финансово-экономическом управлении Судебного департамента при Верховном Суде Российской Федерации" (ред. от 25.12.2024)  Приказ Минфина России от 31.12.2016 № 256н (ред. от 13.09.2023) "Об утверждении федерального стандарта бухгалтерского учета для организаций государственного сектора «Концептуальные основы бухгалтерского учета и отчетности организаций государственного сектора»"  Приказ Минфина России от 30.03.2015 № 52н (ред. от 15.06.2020) "Об утверждении форм первичных учетных документов и регистров бухгалтерского учета, применяемых органами государственной власти (государственными органами), органами местного самоуправления, органами управления государственными внебюджетными фондами, государственными (муниципальными) учреждениями, и Методических указаний по их применению"  Приказ Минфина России от 15.04.2021 № 61н (ред. от 30.10.2023) "Об утверждении унифицированных форм электронных документов бухгалтерского учета, применяемых при ведении бюджетного учета, бухгалтерского учета государственных (муниципальных) учреждений, и Методических указаний по их формированию и применению"  Приказ Минфина России от 30.12.2017 № 274н (ред. от 14.02.2025) "Об утверждении федерального стандарта бухгалтерского учета для организаций государственного сектора «Учетная политика, оценочные значения и ошибки»" |

## ****3. Реестр UC****

**UC001 — Принять и проверить поставленные ТМЦ**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–9 |
| **Выполняемая задача** | Поставка товарно-материальных ценностей, создание сущности приемки, проверка соответствия ТМЦ требованиям и сопроводительным документам, оформление возврата при выявлении несоответствий. |
| **Цель** | Проверить поступившую поставку и принять решение о возможности ее приемки либо оформить возврат несоответствующих ТМЦ. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник МТО. Участники: Поставщик; Система. |
| **Ожидаемый результат** | Поставка проверена; при соответствии ТМЦ переданы на дальнейший учет, а при выявлении несоответствий оформлен акт возврата и причины возврата зафиксированы в Системе. |
| **Рекомендованная функциональность** | Регистрация поступления ТМЦ и сопроводительных документов; создание сущности приемки; фиксация результатов проверки качества, комплектности и соответствия документам; оформление акта возврата и причин возврата; автоматическое сохранение сведений о возврате в сущности приемки. |
| **Критичность** | Необходимая. |
| **Триггер** | По заключенному договору поставщик осуществил поставку ТМЦ и передал сопроводительные документы. |
| **Предварительные условия** | Заключен договор на поставку ТМЦ; вместе с поставкой представлены УПД либо ТОРГ-12 и счет-фактура. |
| **Основной сценарий** | 1. Поставщик поставляет ТМЦ и передает предусмотренные договором сопроводительные документы.  2. Сотрудник МТО получает поставленные ТМЦ и сопроводительные документы.  3. Сотрудник МТО создает в Системе сущность приемки ТМЦ.  4. Сотрудник МТО сопоставляет фактически поступившие ТМЦ с сопроводительными документами.  5. Сотрудник МТО проверяет качество, комплектность и соответствие ТМЦ установленным требованиям.  6. Сотрудник МТО подтверждает, что ТМЦ соответствуют требованиям и сопроводительным документам.  7. Процесс продолжается с подписания документов по принятой поставке. |
| **Расширение (альтернативный сценарий)** | 6а. ТМЦ не соответствуют требованиям или сопроводительным документам.  6а.1 Сотрудник МТО оформляет возврат несоответствующих ТМЦ.  6а.2 Сотрудник МТО формирует акт возврата и фиксирует причины возврата.  6а.3 Система автоматически сохраняет сведения о возврате в сущности приемки.  6а.4 Процесс завершается с результатом «Возврат оформлен». |

**UC002 — Учесть принятую поставку ТМЦ**

|  |  |
| --- | --- |
| **№ шага процесса** | 10–14 |
| **Выполняемая задача** | Подписание сопроводительных документов по принятой поставке, отражение ТМЦ в складском учете, передача документов в бухгалтерию и отражение поступления в 1С:БУ. |
| **Цель** | Обеспечить последовательное отражение принятой поставки в складском и бухгалтерском учете. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник МТО. Участник: Сотрудник бухгалтерии. |
| **Ожидаемый результат** | Сопроводительные документы подписаны, ТМЦ учтены на складе, пакет документов передан в бухгалтерию, а поступление отражено в 1С:БУ. |
| **Рекомендованная функциональность** | Фиксация подписания УПД либо ТОРГ-12 и счета-фактуры; регистрация поступления ТМЦ в складском учете; формирование пакета документов для бухгалтерии; фиксация передачи документов; отражение поступления ТМЦ и связанных документов в 1С:БУ. |
| **Критичность** | Необходимая. |
| **Триггер** | По результатам проверки подтверждено соответствие ТМЦ требованиям и сопроводительным документам. |
| **Предварительные условия** | Сущность приемки создана; результат проверки ТМЦ зафиксирован как положительный; сопроводительные документы доступны сотруднику МТО. |
| **Основной сценарий** | 1. Сотрудник МТО подписывает УПД либо комплект ТОРГ-12 и счета-фактуры по принятой поставке.  2. Сотрудник МТО отражает поступившие ТМЦ в складском учете.  3. Сотрудник МТО формирует пакет подписанных сопроводительных документов.  4. Сотрудник МТО передает пакет документов в бухгалтерию для отражения в учете.  5. Сотрудник бухгалтерии получает документы по принятой поставке и сведения о поступлении ТМЦ в складском учете.  6. Сотрудник бухгалтерии вносит документы и сведения о поступлении ТМЦ в 1С:БУ.  7. Процесс завершается с результатом «ТМЦ приняты и учтены». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
