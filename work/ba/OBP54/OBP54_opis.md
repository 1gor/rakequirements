## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Поставщик | Поставка товаров, подготовка документов |
| Сотрудник МТО | Проверка ТМЦ, оформление ТМЦ |
| Сотрудник бухгалтерии | Учет ТМЦ |
