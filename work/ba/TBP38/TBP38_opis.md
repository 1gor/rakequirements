# **3. Реестр UC**

UC001 — Формирование и проверка рекомендации по освобождению

| № шага процесса | 0–4 |
| --- | --- |
| Выполняемая задача | Проверить льготы, сформировать автоматическую рекомендацию и валидировать ее перед маршрутизацией. |
| Цель | Сократить ручную предварительную проверку при сохранении окончательной оценки за Судьей. |
| Роль / Актор | Судья |
| Ожидаемый результат | Рекомендация Системы проверена Судьей; определен маршрут к положительному либо отрицательному судебному акту. |
| Рекомендуемая функциональность | Вызов ТБП25; формирование Системой структурированной предварительной рекомендации; отображение основания; проверка вывода в ТБП139; сохранение результата проверки. |
| Критичность | Необходима |
| Триггер | Возникла необходимость рассмотреть вопрос об освобождении от уплаты государственной пошлины. |
| Предварительные условия | Доступен ТБП25 и сведения, используемые для проверки предусмотренных законом льгот. |
| Основной сценарий | 1. Стартует процесс рассмотрения вопроса. 2. Судья вызывает ТБП25. 3. Система формирует предварительную рекомендацию по основаниям освобождения. 4. Судья проверяет выводы Системы в ТБП139. 5. По результату проверки развилка шага 4 выбирает дальнейшую ветвь. |
| Расширение (альтернативный сценарий) | Если в ТБП139 выявлена необходимость корректировки автоматической рекомендации, Судья уточняет вывод до определения дальнейшего маршрута. |

| Рекомендуемая функциональность | Формирование судебного акта через ТБП80; передача выбранного определения в ТБП46; фиксация отправки и доставки. |
