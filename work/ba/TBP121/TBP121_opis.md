# [To be] ТБП121. Рассмотреть вопрос об истребовании в банкротстве

| **Наименование процесса** | ТБП121 — Рассмотреть вопрос об истребовании в банкротстве |
| --- | --- |
| **Суть процесса** | Процесс описывает рассмотрение Судьёй вопроса об истребовании доказательств в деле о банкротстве. Судья изучает ходатайство и проверяет относимость истребуемого доказательства; Система формирует рекомендации и уведомления, которые проверяются Судьёй. В зависимости от статуса заявителя и характера вопроса выполняются дополнительные автоматизированные проверки, после чего Судья устанавливает наличие оснований для удовлетворения либо отказа. При признании заявления обоснованным Судья определяет срок и порядок представления доказательства и фиксирует основания удовлетворения; при отказе фиксируются основания отказа. После этого процесс переходит к оформлению судебного акта. |
| **Участники процесса** | Судья, Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026)  Федеральный закон от 26.10.2002 N 127-ФЗ «О несостоятельности (банкротстве)» (ред. от 04.08.2026)  Обзор судебной практики разрешения споров о несостоятельности (банкротстве) за 2022 г. (утв. Президиумом Верховного Суда РФ 26.04.2023)  Постановление Пленума Верховного Суда РФ от 13.10.2015 N 45 (ред. от 17.12.2024) «О некоторых вопросах, связанных с введением в действие процедур, применяемых в делах о несостоятельности (банкротстве) граждан» |

# **3. Реестр UC**

**UC001 — Проверка оснований рассмотрения**

| **№ шага процесса** | 0-5 |
| --- | --- |
| **Выполняемая задача** | Изучить заявленное ходатайство об истребовании доказательств и проверить относимость запрашиваемого доказательства к делу о банкротстве. |
| **Цель** | Подготовить основания для решения о дальнейшем рассмотрении ходатайства об истребовании доказательств. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксирован вывод Судьи по содержанию ходатайства и относимости истребуемого доказательства к делу о банкротстве. |
| **Рекомендованная функциональность** | Просмотр материалов ходатайства и карточки документа события, фиксация вывода об относимости доказательства, отображение сформированной Системой рекомендации и уведомления. |
| **Критичность** | Необходимая |
| **Триггер** | Судья открывает в Системе поступившее ходатайство об истребовании доказательств. |
| **Предварительные условия** | В Системе доступна карточка документа события и материалы ходатайства об истребовании доказательств. |
| **Основной сценарий** | 1. Судья открывает в Системе карточку ходатайства об истребовании доказательств.  2. Судья изучает содержание ходатайства и состав запрашиваемых доказательств.  3. Судья проверяет относимость истребуемого доказательства к делу о банкротстве и фиксирует вывод в Системе.  4. Судья открывает отображённую в карточке рекомендацию Системы для последующей проверки сформированных выводов. |
| **Расширение (альтернативный сценарий)** | 1. Судья фиксирует в Системе выявленные недостатки ходатайства или сведения, требующие уточнения. |

**UC002 — Проверка отказа на внесудебное обращение**

| **№ шага процесса** | 10-18 |
| --- | --- |
| **Выполняемая задача** | Проверить результат анализа сведений о внесудебном обращении и установить наличие оснований для удовлетворения либо отказа в удовлетворении ходатайства. |
| **Цель** | Сформировать вывод Судьи по результатам проверки обстоятельств, связанных с невозможностью самостоятельного получения доказательства. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксирован вывод Судьи о наличии оснований для удовлетворения либо отказа в удовлетворении ходатайства. |
| **Рекомендованная функциональность** | Отображение результата автоматической проверки наличия отказа или иных сведений о внесудебном обращении, отображение рекомендаций по удовлетворению/отказу, фиксация решения Судьи. |
| **Критичность** | Необходимая |
| **Триггер** | В Системе сформирован результат проверки сведений о внесудебном обращении. |
| **Предварительные условия** | В карточке дела доступны ходатайство и результаты автоматической проверки соответствующих сведений. |
| **Основной сценарий** | 1. Судья открывает в Системе результат проверки сведений о внесудебном обращении.  2. Судья знакомится с представленной рекомендацией по удовлетворению ходатайства.  3. Судья устанавливает наличие оснований для удовлетворения ходатайства и фиксирует вывод в Системе. |
| **Расширение (альтернативный сценарий)** | 1. Судья при отсутствии подтверждённых оснований по основной ветви знакомится с рекомендацией по подготовке отказа.  2. Судья устанавливает наличие оснований для отказа в удовлетворении ходатайства и фиксирует вывод в Системе. |

**UC003 — Формирование итогового вывода**

| **№ шага процесса** | 19-33 |
| --- | --- |
| **Выполняемая задача** | Определить обоснованность заявления, при необходимости зафиксировать основания отказа либо установить срок, порядок представления доказательства и основания удовлетворения. |
| **Цель** | Сформировать итоговый вывод Судьи и параметры судебного акта по вопросу об истребовании доказательств. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксированы итоговый вывод Судьи и необходимые параметры решения: основания отказа либо срок, порядок представления доказательства и основания удовлетворения. |
| **Рекомендованная функциональность** | Фиксация вывода об обоснованности заявления, ввод оснований решения, установка срока, выбор лица для выдачи доказательства либо способа направления доказательства непосредственно в суд. |
| **Критичность** | Необходимая |
| **Триггер** | Судья переходит к итоговой оценке достаточности данных по ходатайству. |
| **Предварительные условия** | В Системе доступны результаты предыдущих проверок и материалы ходатайства. |
| **Основной сценарий** | 1. Судья оценивает достаточность данных для вывода об обоснованности заявления и фиксирует результат в Системе.  2. Судья при признании заявления обоснованным устанавливает в Системе срок предоставления истребуемого доказательства.  3. Судья указывает в Системе лицо, которому должно быть выдано доказательство, либо фиксирует необходимость направления доказательства непосредственно в суд.  4. Судья устанавливает и сохраняет в Системе основания для удовлетворения ходатайства. |
| **Расширение (альтернативный сценарий)** | 1. Судья при выводе о необоснованности заявления устанавливает основания для отказа в удовлетворении ходатайства.  2. Судья сохраняет сформулированные основания отказа в Системе. |
