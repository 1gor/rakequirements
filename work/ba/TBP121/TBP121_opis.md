## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья | Изучение ходатайств об истребовании доказательств, проверка их обоснованности, принятие процессуальных решений, определение сроков и порядка предоставления доказательств, установление оснований для удовлетворения или отказа в ходатайствах |
| Система | Автоматическая проверка формальных требований к ходатайству, определение принадлежности документа к конкретному делу, формирование системной рекомендации пользователю в событии, создание события с рекомендацией и отметкой судьи, проверка наличия отказа во внесудебном порядке, формирование рекомендаций по существу (наличие обоснования, связь с предметом доказывания, проверка реквизитов), передача судье результатов анализа для проверки выводов системы, запуск отсчёта срока предоставления доказательства с учётом производственного календаря, создание уведомлений и событий для пользователей о результатах проверок и сроках, поддержка шаблонов судебных актов на основе собранных данных. |
