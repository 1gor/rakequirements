**ТБП56:"Проверить график рассмотрения дела в зале СЗ"**

|  |  |
| --- | --- |
| Наименование процесса | ТБП56:"Проверить график рассмотрения дела в зале СЗ" |
| Суть процесса | Процесс описывает проверку графика рассмотрения дела в зале СЗ. В рамках процесса судья знакомится с графиком СЗ, выявляет необходимость внести изменения. Если такой необходимости нет - изменений в график не вносится и процесс завершается. Если необходимость есть - судья определяет параметры, которые необходимо скорректировать: дату, время, место, данные о судье, иные параметры. Затем система актуализирует актуальные данные и уведомляет участников процесса, после чего процесс завершается. |
| Участники процесса | Помощник судьи/Секретарь СЗ суда первой инстанции |
| НПА | "Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" |
