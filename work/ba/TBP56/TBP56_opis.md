# [To be] ТБП56. Проверить график рассмотрения дела в зале сз

**ТБП56:"Проверить график рассмотрения дела в зале СЗ"**

| **Наименование процесса** | ТБП56:"Проверить график рассмотрения дела в зале СЗ" |
| --- | --- |
| **Суть процесса** | Процесс описывает проверку графика рассмотрения дела в зале СЗ. В рамках процесса судья знакомится с графиком СЗ, выявляет необходимость внести изменения. Если такой необходимости нет - изменений в график не вносится и процесс завершается. Если необходимость есть - судья определяет параметры, которые необходимо скорректировать: дату, время, место, данные о судье, иные параметры. Затем система актуализирует актуальные данные и уведомляет участников процесса, после чего процесс завершается. |
| **Участники процесса** | Помощник судьи/Секретарь СЗ суда первой инстанции |
| **НПА** | "Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" |

## **1.Реестр US**

| № | **Я КАК** | **ХОЧУ** | **ЧТОБЫ** |
| --- | --- | --- | --- |
| 1 | Помощник судьи/Секретарь судебного заседания | просматривать сформированный автоматически системой график рассмотрения дел для проверки актуальности сведений о судебных заседаниях | подтвердить корректность запланированных данных и выявить необходимость внесения изменений |
| 2 | Помощник судьи/Секретарь судебного заседания | иметь возможность вносить изменения в параметры графика (дата, время, место, судья) и контролировать его корректность | обеспечить актуальность расписания |
| 3 | Помощник судьи/Секретарь судебного заседания | чтобы данные о судебном заседании автоматически актуализировались в информационной системе после внесения изменений | обеспечить синхронизацию расписания без необходимости ручного ввода |
| 4 | Помощник судьи/Секретарь судебного заседания | чтобы участники процесса были автоматически уведомлены об изменении данных о судебном заседании | обеспечить надлежащее извещение лиц, участвующих в деле |

UC-001: Внесение изменений в график СЗ/ПСЗ

| **Поле** | **Значение** |
| --- | --- |
| **Выполняемая задача** | Актуализация данных в графике проведения СЗ/ПСЗ и оповещение участников процесса |
| № **шага процесса** | 6-14 |
| **Цель** | Поддержание актуальности графика проведения СЗ/ПСЗ в системе и своевременное оповещение участников процесса об изменениях |
| **Роль / Актор** | Помощник судьи/Секретарь СЗ |
| **Ожидаемый результат** | Внесены и сохранены все необходимые изменения в графике СЗ/ПСЗ, участники процесса оповещены. |
| **Рекомендованная функциональность** | Формирование отчета-графика СЗ/ПСЗ, направление уведомлений с данными об изменениях участникам процесса |
| **Критичность** | Необходимая |
| **Триггер** | Помощник судьи/Секретарь СЗ нажал опцию по внесению изменений в график СЗ/ПСЗ |
| **Предварительные условия** | Помощник судьи/Секретарь СЗ авторизирован в системе, предварительно сформирован и отображен график СЗ/ПСЗ для ознакомления/сверки данных |
| **Основной сценарий** | 1. Помощник судьи/Секретарь СЗ нажимает опцию по внесению изменений в график СЗ/ПСЗ  2. Система открывает окно с данными, которые можно изменить  3. Помощник судьи/Секретарь СЗ выбирает графы, отображающие данные о СЗ/ПСЗ, которые необходимо скорректировать  4. Система открывает доступ к редактированию выбранных данных  5. Помощник судьи/Секретарь СЗ вносит необходимые корректировки  6. Помощник судьи/Секретарь СЗ подтверждает сохранение изменений и актуализацию данных  7. Система обновляет данные в графике согласно внесенным изменениям  8. Система формирует уведомление с данными об изменениях  9. Система направляет уведомление участникам СЗ/ПСЗ |
