Система автоматически собирает публикации и упоминания о суде из настроенных источников.  3. Система фильтрует собранные материалы по заданным ключевым словам и критериям мониторинга.  4. Система включает релевантные публикации и сведения о них в ежедневный обзор.  5. Система актуализирует и сохраняет действующий перечень источников и ключевых слов.  6. Система создает сущность для структурированного хранения результатов мониторинга и связывает с ней материалы текущего цикла.  7. Сотрудник пресс-службы выполняет ТБП139 «Проверить выводы системы».  8. Сотрудник пресс-службы оценивает полноту и корректность сформированных материалов и принимает решение о необходимости их редактирования.  9. Сотрудник пресс-службы определяет, что выявленные публикации не требуют отдельного реагирования.  10. Сотрудник пресс-службы направляет сформированный ежедневный обзор Председателю/Зам. председателя.  11. Председатель/Зам. председателя знакомится с ежедневным обзором в Системе.  12. Процесс завершается после ознакомления руководства с результатами мониторинга. |
| **Расширение (альтернативный сценарий)** | 8а. Сотрудник пресс-службы выявляет неточности или неполноту результатов автоматизированной обработки.  8а.1 Сотрудник пресс-службы корректирует материалы ежедневного обзора до определения необходимости реагирования.  9а. Выявлена публикация, требующая реагирования.  9а.1 Процесс переходит к UC002 «Организовать реагирование на значимую публикацию». |

**UC002 — Организовать реагирование на значимую публикацию**

|  |  |
| --- | --- |
| **№ шага процесса** | 8–29 |
| **Выполняемая задача** | Формирование отчета по значимой публикации, оценка репутационных рисков руководством, выбор и исполнение одной или нескольких мер реагирования с последующим включением результатов в ежедневный обзор. |
| **Цель** | Обеспечить своевременную и обоснованную реакцию суда на публикации, содержащие репутационные риски, искажение фактов либо сведения, требующие внутренней проверки. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: Сотрудник пресс-службы. Участники: Председатель/Зам. председателя; Система. |
| **Ожидаемый результат** | Руководитель оценил публикацию и определил форму реакции; порученные меры выполнены либо инцидент принят к сведению; результаты отражены в ежедневном обзоре и представлены руководству. |
| **Рекомендованная функциональность** | Вызов ТБП2 для формирования отчета; сохранение отчета и даты его формирования; автоматическое уведомление руководителя; предоставление доступа к публикации и материалам мониторинга; фиксация репутационной оценки и формы реакции; формирование и передача поручения; регистрация связи с редакцией СМИ; фиксация достоверности публикации; учет официального опровержения, ответа и результатов внутренней проверки; синхронизация нескольких мер реагирования. |
| **Критичность** | Необходимая. |
| **Триггер** | Сотрудник пресс-службы установил, что выявленная публикация требует рассмотрения и возможного реагирования. |
| **Предварительные условия** | Публикация выявлена в ходе мониторинга и включена в сущность хранения данных; результаты автоматизированной обработки проверены сотрудником пресс-службы. |
| **Основной сценарий** | 1. Сотрудник пресс-службы инициирует ТБП2 «Сформировать отчет» по публикации, требующей рассмотрения.  2. Система сохраняет сформированный отчет и дату его формирования в сущности хранения данных.  3. Система уведомляет Председателя/Зам. председателя и предоставляет доступ к публикации и материалам мониторинга.  4. Председатель/Зам. председателя знакомится с содержанием публикации.  5. Руководитель определяет наличие репутационного риска или искажения фактов.  6. Если публикация представляет риск, руководитель выбирает одну или несколько форм реагирования и фиксирует решение в Системе.  7. Председатель/Зам. председателя формирует и направляет поручение сотруднику пресс-службы.  8. Сотрудник пресс-службы определяет предусмотренные поручением маршруты реагирования.  9. При выборе взаимодействия со СМИ сотрудник пресс-службы связывается с редакцией, передает сведения для корректировки и получает подтверждение внесения изменений.  10. При выборе публичной реакции сотрудник пресс-службы оценивает достоверность новости.  11. Если новость недостоверна, сотрудник пресс-службы подготавливает и публикует официальное опровержение.  12. Если новость достоверна, сотрудник пресс-службы подготавливает и публикует официальный ответ с позицией суда.  13. При выборе внутренней проверки сотрудник пресс-службы инициирует проверку, определяет проверяемые сведения и фиксирует ее выводы.  14. После выполнения всех выбранных мер реагирования результаты объединяются для продолжения процесса.  15. Сотрудник пресс-службы направляет ежедневный обзор с результатами реагирования Председателю/Зам. председателя.  16. Председатель/Зам. председателя знакомится с обзором и результатами выполненных мер. |
| **Расширение (альтернативный сценарий)** | 5а. Председатель/Зам. председателя устанавливает, что публикация не представляет репутационной опасности и не содержит существенного искажения фактов.  5а.1 Руководитель отмечает инцидент в Системе как принятый к сведению.  5а.2 Процесс продолжается с направлением ежедневного обзора руководству.  8а. Руководитель выбрал несколько форм реагирования.  8а.1 Соответствующие действия выполняются параллельно.  8а.2 После завершения всех выбранных действий их результаты синхронизируются и включаются в ежедневный обзор. |
