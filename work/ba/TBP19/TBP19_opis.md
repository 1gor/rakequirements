# [To be] ТБП19. Проверить подсудность

| **Наименование процесса** | ТБП19: Проверить подсудность |
| --- | --- |
| **Суть процесса** | Проверка соблюдения правил подсудности по поступившему процессуальному или иному документу, ходатайству либо по инициативе суда. Для споров, связанных с банкротством, определяется допустимость изменения подсудности; для иных дел последовательно проверяются родовая, исключительная, договорная и территориальная подсудность, после чего фиксируется результат о передаче, возвращении документа, отказе в ходатайстве либо отсутствии оснований для изменения подсудности. |
| **Участники процесса** | Судья, помощник судьи |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025)  Постановление Пленума Верховного Суда РФ от 23.12.2021 N 46 "О применении Арбитражного процессуального кодекса Российской Федерации при рассмотрении дел в суде первой инстанции"  Обзор судебной практики Верховного Суда Российской Федерации N 3 (2021) (утв. Президиумом Верховного Суда РФ 10.11.2021)  Постановление Пленума Верховного Суда РФ от 27.06.2017 N 23 "О рассмотрении арбитражными судами дел по экономическим спорам, возникающим из отношений, осложненных иностранным элементом"  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций) (далее-Инструкция по делопроизводству) |

# 1. Реестр US

| **№** | **Я КАК** | **ХОЧУ** | **ЧТОБЫ** |
| --- | --- | --- | --- |
| 1 | Судья | получить результат проверки оснований передачи дела по подсудности | определить дальнейший процессуальный маршрут по делу |
| 2 | Судья | получить результаты проверки подсудности по спору, связанному с банкротством | принять решение о допустимости изменения подсудности |
| 3 | Судья | проверить результаты родовой, исключительной и договорной подсудности | определить наличие оснований для передачи или продолжения рассмотрения дела |
| 4 | Судья | получить результат проверки арбитражного соглашения | учесть его при определении дальнейшего процессуального действия |
| 5 | Судья | получить результат проверки территориальной подсудности | установить, соблюдены ли правила подсудности по адресу ответчика и по выбору истца |
| 6 | Судья / помощник судьи | выбрать итоговый вариант | зафиксировать результат проверки подсудности в Системе |

Судья/помощник судьи  выбирает решение по всем связанным ОС. 3. Система сохраняет выбор и отображает актуализированный итог проверки. 4. Судья/помощник судьи фиксирует итоговое решение по вопросу возможности изменения подсудности. 5. Система сохраняет решение и отображает итоговый статус дальнейшего процессуального маршрута. |
