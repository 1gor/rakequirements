**ТБП9: "Рассмотреть вопрос о продлении срока рассмотрения дела"**

|  |  |
| --- | --- |
| Наименование процесса | ТБП9: "Рассмотреть вопрос о продлении срока рассмотрения дела" |
| Суть процесса | Процесс описывает рассмотрения вопроса по продлению процессуального срока рассмотрения дела. Процесс запускается когда процессуальный срок рассмотрения дела подходит к концу и судье надо его продлить. В рамках процесса судья формирует заявление о продлении процессуального срока и направляет его на рассмотрения председателю суда, а так же по запросу председателя направляет ему и дело, по которому требуется продлить срок. Председатель суда выносит определение по вопросу продления срока рассмотрения дела, которое передает судье вместе с делом. Судья знакомится с определением, затем определение приобщается к материалам дела. Процесс завершается направлением копии определения сторонам в AS IS. В TO BE процесс завершается ознакомлением судьи с определением, так как направление сторонам происходит автоматически при принятии Определения. |
| Участники процесса | Судья,  Председатель/Заместитель председателя арбитражного суда  Помощник судьи/секретарь арбитражного суда  Канцелярия арбитражного суда  Лицо, участвующее в деле |
