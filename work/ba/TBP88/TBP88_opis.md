**ТБП88:"Подготовить дело к передаче"**

|  |  |
| --- | --- |
| Наименование процесса | ТБП88:"Подготовить дело к передаче" |
| Суть процесса | Процесс охватывает действия по подготовке дела к передаче в связи с его направлением в иной суд/передачей по подсудности/направлением на экспертизу/запросом на ознакомление с делом. В рамках процесса помощник судьи осуществляет следующие действия по подготовке дела (В соответствии с положениями Инструкции № 100) : изготавливает копии, изымает файлы-вкладыши, скрепки, скобы, стикеры, раскладывает материалы дела в хронологическом порядке, записывает на материальный носитель аудио и видео-запись протокола СЗ, подшивает дело, формирует новый том дела, проставляет штамп-заверитель, формирует обложку, вносит данные в ИС. После совершения всех указанных действий дело считается готовым к передаче. |
| Участники процесса | Помощник судьи |
| НПА | Арбитражный процессуальный кодекс Российской Федерации" от 24.07.2002 N 95-ФЗ (ред. от 01.04.2025)  Постановление Пленума ВАС РФ от 25.12.2013 N 100 (ред. от 11.07.2014) "Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)" |

  2. Описание схемы процесса

|  |  |  |  |

| 0 | Суд переходит к подготовке дела к передаче в связи с его направлением в иной суд/передачей по подсудности/направлением на экспертизу/запросом на ознакомление с делом | Тип: Стартовое событие  Назначение: Инициировать подготовку дела к передаче в соответствии с основанием.  Роль: Помощник судьи  Входящие данные: Отсутствуют  Исходящие данные: Отсутствуют |  |
| 1 | [ТБП49.Сформировать и подписать документ](https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=533164355) | Тип: Вызов активности  Назначение: Определить необходимость изготовления копий материалов дела.  Роль: Помощник судьи  Входящие данные: Отсутствуют  Исходящие данные: Электронная опись дела  Дополнительное описание: Помощник судьи анализирует основания передачи дела и устанавливает, требуется ли направление копий материалов в суд вышестоящей инстанции. Решение принимается на основании норм процессуального законодательства и внутренних регламентов.  Результат шага: В карточке дела установлен признак «Необходимость изготовления копий» со значением «Да» или «Нет». |  |
| 2 | [ТБП112.Проверить правильность формирования и оформления дела](https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=533165605) | Тип: Вызов активности  Назначение: Изготовить копии материалов дела для вышестоящей инстанции.  Роль: Помощник судьи  Входящие данные: Отсутствуют  Исходящие данные: Отсутствуют  Дополнительное описание: Система инициирует типовой процесс «Изготовить копии» на основании решения, принятого на предыдущем шаге. В рамках процесса создаются электронные образы документов дела, формируются наборы копий и подготавливаются к передаче.  Результат шага: Создан электронный набор копий материалов дела, прикрепленный к карточке дела. |  |
| 3 | Сформировать протокол проверки | Тип: Сервисная задача  Назначение: Подготовить физический том дела к передаче в вышестоящую инстанцию.  Роль: Помощник судьи  Входящие данные: Отсутствуют  Исходящие данные: Протокол проверки корректности данных  Дополнительное описание: Помощник судьи удаляет из дела все временные элементы крепления (скобы, скрепки, стикеры) и файлы-вкладыши. В соответствии с пунктом 22.11 Инструкции по делопроизводству осуществляется прошивка последнего тома дела установленным порядком.  Результат шага: Физический том дела приведен в соответствие с требованиями к оформлению для передачи в вышестоящую инстанцию. |  |
| 4 | [ТБП139.Проверить выводы системы](https://itpm-wiki.mos.ru/pages/viewpage.action?pageId=533163178) | Тип: Вызов активности  Назначение: Утвердить результаты автоматической проверки для завершения подготовки дела.  Роль: Помощник судьи  Входящие данные: Протокол проверки корректности данных  Исходящие данные: Отсутствуют  Дополнительное описание: Исполнитель проверяет протокол автоматической проверки корректности данных дела, сформированный на предыдущем шаге. В случае выявления несоответствий исполнитель инициирует их устранение, при отсутствии замечаний подтверждает корректность данных для передачи дела.  Результат шага: Результаты проверки протокола подтверждены, дело переведено в статус «Готово к передаче». |  |
| 5 | Дело готово к передаче | Тип: Конечное событие  Назначение: Физически упорядочить материалы дела в соответствии с установленными требованиями.  Роль: Помощник судьи  Входящие данные: Отсутствуют  Исходящие данные: Отсутствуют |  |
