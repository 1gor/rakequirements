## ****3. Реестр UC****

**UC001 — Провести проверку надлежащей эксплуатации здания**

|  |  |
| --- | --- |
| **№ шага процесса** | 0–7 |
| **Выполняемая задача** | Организация и проведение проверки надлежащей эксплуатации зданий, сооружений и помещений суда, определение участников проверки и фиксация ее результата. |
| **Цель** | Подтвердить надлежащее состояние здания либо выявить нарушения требований к его эксплуатации. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель отдела эксплуатации здания. Участник: председатель суда. |
| **Ожидаемый результат** | Проверка проведена; надлежащая эксплуатация здания подтверждена либо выявлены нарушения, требующие дальнейшего устранения. |
| **Рекомендованная функциональность** | Фиксация состава участников проверки; фиксация решения о комиссионном проведении проверки; хранение локального акта об утверждении комиссии; регистрация результатов проверки и выявленных нарушений. |
| **Критичность** | Необходимая. |
| **Триггер** | Возникла необходимость проверки надлежащей эксплуатации здания, сооружений и помещений суда. |
| **Предварительные условия** | Определен объект проверки; руководитель отдела эксплуатации здания имеет возможность организовать обследование здания, сооружений и помещений суда. |
| **Основной сценарий** | 1. Руководитель отдела эксплуатации здания определяет участников проверки с учетом характера и объема предстоящего обследования.  2. Руководитель отдела эксплуатации здания определяет, требуется ли комиссионное проведение проверки.  3. При необходимости комиссионной проверки председатель суда утверждает состав комиссии локальным актом.  4. Руководитель отдела эксплуатации здания проводит проверку надлежащей эксплуатации здания, сооружений и помещений суда.  5. Если проверка проводится комиссионно, в ней участвует утвержденный состав комиссии.  6. По результатам проверки определяется, обеспечена ли надлежащая эксплуатация здания.  7. Если нарушений не выявлено, процесс завершается с результатом «Обеспечена надлежащая эксплуатация здания». |
| **Расширение (альтернативный сценарий)** | 2а. Проверка не требует комиссионного проведения.  2а.1 Утверждение состава комиссии председателем суда не выполняется.  2а.2 Руководитель отдела эксплуатации здания самостоятельно организует проведение проверки.  6а. Проверка выявила нарушение требований к эксплуатации здания.  6а.1 Процесс переходит к UC002 «Организовать устранение выявленных нарушений». |

**UC002 — Организовать устранение выявленных нарушений**

|  |  |
| --- | --- |
| **№ шага процесса** | 8–13 |
| **Выполняемая задача** | Фиксация выявленных нарушений, информирование председателя суда, определение мер по их устранению, исполнение поручения и проверка результата. |
| **Цель** | Организовать устранение выявленных нарушений и восстановить надлежащую эксплуатацию здания, сооружений и помещений суда. |
| **Роль/Актор (в соответствии со схемой)** | Основной актор: руководитель отдела эксплуатации здания. Участник: председатель суда. |
| **Ожидаемый результат** | Выявленные нарушения устранены, факт устранения подтвержден, надлежащая эксплуатация здания восстановлена. |
| **Рекомендованная функциональность** | Регистрация выявленных нарушений; фиксация сообщения председателю суда; хранение локального акта по устранению нарушений; фиксация поручений и результата их исполнения; регистрация подтверждения устранения нарушений. |
| **Критичность** | Необходимая. |
| **Триггер** | По результатам проверки выявлены нарушения требований к эксплуатации здания, сооружений или помещений суда. |
| **Предварительные условия** | Проверка завершена; выявлены конкретные нарушения, требующие устранения. |
| **Основной сценарий** | 1. Руководитель отдела эксплуатации здания фиксирует конкретные факты нарушений, выявленные по результатам проверки.  2. Руководитель отдела эксплуатации здания сообщает председателю суда о выявленных нарушениях и обстоятельствах их обнаружения.  3. Председатель суда определяет меры по устранению нарушений.  4. По результатам решения председателя суда оформляется локальный акт по устранению нарушений.  5. Руководитель отдела эксплуатации здания исполняет поручение и организует выполнение необходимых мероприятий.  6. После выполнения мероприятий руководитель отдела эксплуатации здания проверяет фактическое устранение нарушений.  7. При подтверждении устранения нарушений процесс завершается с результатом «Нарушения устранены. Обеспечена надлежащая эксплуатация здания». |
| **Расширение (альтернативный сценарий)** | Не предусмотрен. |
