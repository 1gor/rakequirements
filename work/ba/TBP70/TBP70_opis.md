# [To be] ТБП70. Ознакомить с протоколом СЗ

| **Наименование процесса** | ТБП70: Ознакомить с протоколом СЗ |
| --- | --- |
| **Суть процесса** | Предоставление ЛУВД электронного доступа к протоколу судебного заседания и при наличии к аудиозаписи, фиксация выбора по подаче замечаний, проверка соблюдения срока и рассмотрение поступивших замечаний с оформлением итогового судебного акта. |
| **Участники процесса** | Судья, Помощник/секретарь СЗ, Канцелярия, ЛУВД, Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ: ст. 117, ст. 155; Постановление Пленума ВАС РФ от 25.12.2013 № 100 «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации», раздел 12. |

**UC001 — Открытие доступа к протоколу СЗ**

| **№ шага процесса** | 0–5 |
| --- | --- |
| **Выполняемая задача** | Контролировать предоставление ЛУВД доступа к протоколу СЗ и при наличии к аудиозаписи. |
| **Цель** | Обеспечить предоставление корректных материалов по конкретному судебному делу и видеть результат направления доступа. |
| **Роль / Актор** | Помощник/секретарь СЗ |
| **Ожидаемый результат** | В Системе отображены подготовленные материалы, ссылка доступа и подтверждение ее направления ЛУВД. |
| **Рекомендуемая функциональность** | Карточка найденного протокола и аудиозаписи; отображение сформированной ссылки доступа; статус проверки и направления ссылки ЛУВД. |
| **Критичность** | Необходимая |
| **Триггер** | Система отображает помощнику/секретарю СЗ запрос ЛУВД на ознакомление и подготовленные материалы по делу. |
| **Предварительные условия** | В Системе имеется запрос ЛУВД на ознакомление; протокол СЗ подписан и доступен в электронном виде, аудиозапись доступна при ее наличии. |
| **Основной сценарий** | 1. Система отображает помощнику/секретарю СЗ найденный протокол и при наличии связанную аудиозапись.  2. Помощник/секретарь СЗ просматривает отображенные материалы и сведения о подготовленной ссылке доступа.  3. Система отображает результат проверки подготовленных материалов и готовность ссылки к направлению.  4. После направления доступа Система отображает помощнику/секретарю СЗ статус отправки ссылки ЛУВД. |

**UC002 — Рассмотрение замечаний на протокол СЗ**

| **№ шага процесса** | 24–31 |
| --- | --- |
| **Выполняемая задача** | Ознакомиться с результатами анализа замечаний и зафиксировать итоговое решение по замечаниям на протокол СЗ. |
| **Цель** | Принять итоговое решение по замечаниям с учетом результатов проверки полноты и правильности протокола. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В Системе зафиксировано итоговое решение судьи по замечаниям и отображен результат оформления соответствующего судебного акта. |
| **Рекомендуемая функциональность** | Карточка замечаний и протокола СЗ; отображение результатов анализа полноты и правильности; просмотр протокола проверки; выбор и подтверждение итогового решения; отображение статуса судебного акта. |
| **Критичность** | Необходимая |
| **Триггер** | Система отображает судье результаты анализа замечаний и сформированный протокол проверки. |
| **Предварительные условия** | Замечания допущены к рассмотрению; в Системе доступны протокол СЗ, поступившие замечания и результаты автоматических проверок. |
| **Основной сценарий** | 1. Система отображает судье замечания на протокол и результаты проверки полноты и правильности его составления.  2. Судья просматривает замечания, результаты проверок и сформированный протокол проверки.  3. Система отображает проверенные выводы, доступные для принятия итогового решения.  4. Судья выбирает итоговый вариант решения по замечаниям: принять замечания либо отклонить их, и подтверждает выбор.  5. Система сохраняет итоговое решение и отображает статус оформления соответствующего судебного акта. |
| **Расширение (альтернативный сценарий)** | — |
