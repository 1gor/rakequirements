# [To be] КБП10. Производство по делам об установлении фактов, имеющих юридическое значение

| **Наименование процесса** | Производство по делам об установлении фактов, имеющих юридическое значение |
| --- | --- |
| **Суть процесса** | Процесс охватывает действия арбитражного суда, аппарата суда и участников процесса, связанные с рассмотрением заявлений о признании определённых фактов, имеющих юридическое значение. Бизнес-процесс начинается с подачи заинтересованным лицом заявления и подтверждающих документов, включает принятие дела судом, подготовку и рассмотрение дела в судебном заседании, исследование доказательств, проверку наличия юридически значимого факта, вынесение судебного акта. Процесс завершается передачей рассмотренного дела в архив после вступления СА в законную силу и его исполнения. |
| **Участники процесса** | Заявитель, Заинтересованные лица, Канцелярия, Помощник судьи, Судья, Система |
| **НПА** | Информационное письмо Президиума ВАС РФ от 17.02.2004 N 76. Приложение. Обзор практики рассмотрения арбитражными судами дел об установлении фактов, имеющих юридическое значение  Арбитражный процессуальный кодекс Российской Федерации, глава 27 "Производство по делам об установлении фактов, имеющих юридическое значение" |
