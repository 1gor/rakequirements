# [To be] ТБП115. Определить состав ЛУВД

| **Наименование процесса** | ТБП115 — Определить состав ЛУВД |
| --- | --- |
| **Суть процесса** | Процесс предназначен для определения состава лиц, участвующих в деле. После перехода суда к этому этапу Система определяет основных ЛУВД по первичному документу и наличие необходимости добавления дополнительных участников. При необходимости Судья указывает категории дополнительных ЛУВД, выбирает имеющихся в Системе лиц либо вводит их реквизиты; для новых лиц Система выполняет добавление в дело. После объединения выбранных ветвей Система проверяет корректность заполнения реквизитов и формирует протокол проверки, который передается в ТБП139 «Проверить выводы системы». При выявлении некорректных сведений Судья вносит изменения с повторной проверкой; при положительном результате процесс завершается определением состава ЛУВД. |
| **Участники процесса** | Судья; Система |
| **НПА** | Арбитражный процессуальный кодекс Российской Федерации от 24.07.2002 № 95-ФЗ (ред. от 15.12.2025, с изм. и доп., вступ. в силу с 01.01.2026): гл. 5, в том числе ст. 40, 44, 46, 50, 51, 52, 53.1.  Постановление Пленума Высшего Арбитражного Суда Российской Федерации от 25.12.2013 № 100 (ред. от 11.07.2014) «Об утверждении Инструкции по делопроизводству в арбитражных судах Российской Федерации (первой, апелляционной и кассационной инстанций)», в том числе разд. II, п. 4. |

# 3. Реестр UC

**UC001 — Добавление дополнительных ЛУВД в состав**

| **№ шага процесса** | 2-34 |
| --- | --- |
| **Выполняемая задача** | Установить наличие процессуального соучастия и внести дополнительные лица в состав участников дела в карточке дела. |
| **Цель** | Обеспечить корректный состав лиц, участвующих в деле, с учетом процессуального соучастия. |
| **Роль / Актор** | Судья |
| **Ожидаемый результат** | В карточке дела Система отображает и сохраняет состав дополнительных ЛУВД. |
| **Рекомендуемая функциональность** | Управление составом лиц в карточке дела (добавление и привязка ЛУВД, выбор карточек соистцов/соответчиков/третьих лиц, ввод реквизитов). |
| **Критичность** | Необходимая |
| **Триггер** | Судья открывает карточку дела для определения состава дополнительных ЛУВД. |
| **Предварительные условия** | Судья приступил к определению наличия процессуального соучастия по предмету спора и сведениям первичных документов по участникам. |
| **Основной сценарий** | 1. Судья открывает в Системе карточку дела.  2. Система отображает результат определения необходимости добавления дополнительных ЛУВД.  3. Судья указывает в Системе на участие в деле дополнительного лица: соистца, соответчика, третьего лица, заявляющего самостоятельные требования, или третьего лица, не заявляющего самостоятельные требования.  4. Судья указывает в Системе реквизиты дополнительного лица.  5. Система отображает нового ЛУВД в составе лиц, участвующих в деле, в карточке дела. |
| **Расширение (альтернативный сценарий)** | 4а. Судья выбирает лицо из сведений, имеющихся в Системе.  3б. Судья указывает сторону, на которой участвует третье лицо, не заявляющее самостоятельные требования.  3в. Судья добавляет в карточку дела роль прокурора или уполномоченного по защите прав предпринимателей. |
