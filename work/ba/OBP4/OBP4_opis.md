# [To be] ОБП4. Формирование оперативных сводок и отчетов о деятельности федерального арбитражного суда

|  |  |
| --- | --- |
| **Наименование процесса** | ОБП4. Формирование оперативных сводок и отчетов о деятельности федерального арбитражного суда |
| **Суть процесса** | Процесс охватывает автоматизированную подготовку и направление оперативных сводок, отчетов и аналитико-статистических данных о деятельности арбитражного суда по поступившему запросу. Он начинается с поступления и регистрации запроса, после чего председатель суда определяет ответственных за его исполнение, а сотрудник, ответственный за статистическую отчетность, выбирает форму подготовки ответа. Если существующих отчетов недостаточно, Система проверяет возможность получения данных, автоматически извлекает их из ИС либо направляет запросы во внешние источники, заполняет форму, контролирует поступление ответов и уведомляет об истечении сроков. При необходимости данные запрашиваются у судей, которые проводят анализ судебной практики и заполняют соответствующие формы; сформированные отчеты проверяются, при необходимости корректируются и подписываются ЭП. После согласования всех материалов Система формирует итоговый отчет и сопроводительное письмо, а после их подписания председателем автоматически направляет документы по системе ведомственного документооборота или электронной почте, получает подтверждение доставки и сохраняет его в номенклатурное дело. Процесс завершается после обработки запроса и передачи подготовленных аналитических или статистических данных адресату. |
| **Участники процесса** | Лицо ответственное за межведомственный документооборот; Председатель суда; Сотрудник ответственный за ведение статистической отчетности; Лица ответственные за подготовку отчетов (судьи/председатели судебных составов/коллегий); Система |
| **НПА** | Федеральный закон от 08.01.1998 № 7-ФЗ «О Судебном департаменте при Верховном Суде Российской Федерации» (ред. от 23.07.2025).  Приказ Судебного департамента при Верховном Суде РФ от 25.06.2021 № 124 «Об утверждении Инструкции по ведению судебной статистики», в том числе раздел IV «Статистическая отчетность о деятельности федеральных арбитражных судов». |

**UC002 — Проверка корректности и согласование отчета**

|  |  |
| --- | --- |
| **№ шага процесса** | 5–31 |
| **Выполняемая задача** | Определить способ подготовки ответа, организовать формирование, проверку и согласование отчетов, обработать выявленные ошибки и проконтролировать завершение согласования всех отчетов. |
| **Цель** | Обеспечить использование проверенных и согласованных отчетных данных при формировании итогового ответа по запросу. |
| **Роль / Актор** | Сотрудник ответственный за ведение статистической отчетности; Лица ответственные за подготовку отчетов (судьи/председатели судебных составов/коллегий) |
| **Ожидаемый результат** | Сформированные отчеты проверены и согласованы; при выявлении ошибок выполнено предусмотренное исправление; после завершения согласования всех отчетов процесс готов к формированию итогового ответа. |
| **Рекомендуемая функциональность** | Фиксация формы подготовки ответа; формирование отчета, просмотр и проверка отчета; подписание электронной подписью; передача и подтверждение получения отчета; внесение исправлений в данные или отчет; уведомление об изменениях; внесение изменений в сводный отчет; автоматический контроль завершения согласования всех отчетов и уведомление об истечении срока согласования. |
| **Критичность** | Необходимая |
| **Триггер** | Председатель суда определил ответственных исполнителей по зарегистрированному запросу. |
| **Предварительные условия** | Запрос зарегистрирован и рассмотрен председателем суда; ответственные исполнители определены; сотруднику, ответственному за ведение статистической отчетности, доступен запрос для выбора способа подготовки ответа. |
| **Основной сценарий** | 1. Сотрудник ответственный за ведение статистической отчетности определяет форму подготовки ответа и фиксирует возможность использования существующих отчетов.  2. Пользователь формирует отчет для последующей проверки и согласования.  3. Система уведомляет о сформированном отчете лицам, ответственным за его проверку и согласование.  4. Лицо, ответственное за подготовку отчетов, получает отчет и проверяет его показатели.  5. При корректных данных лицо подписывает отчет электронной подписью и передает его сотруднику, ответственному за ведение статистической отчетности.  6. Сотрудник ответственный за ведение статистической отчетности получает согласованный отчет.  7. После объединения ветвей Система проверяет, завершено ли согласование всех необходимых отчетов.  8. Если все отчеты согласованы, выполнение переходит к формированию итогового отчета по запросу. |
| **Расширение (альтернативный сценарий)** | 1. Если существующих отчетов недостаточно для подготовки ответа, выполнение переходит к получению необходимых данных.  2. Если при проверке отчета выявлены некорректные данные, лицо, ответственное за подготовку отчетов, определяет возможность исправления данных в Системе.  3. Если исправление в Системе возможно, лицо вносит изменения в учетные данные. Система сообщает об изменениях сотруднику, ответственному за ведение статистической отчетности; сотрудник получает информацию, после чего отчет формируется повторно.  4. Если исправление данных в Системе невозможно, лицо вносит изменения непосредственно в сформированный отчет, подписывает исправленную версию электронной подписью и передает ее сотруднику, ответственному за ведение статистической отчетности.  5. Сотрудник получает исправленный отчет и вносит соответствующие изменения в сводный отчет.  6. Если согласование всех отчетов не завершено, Система направляет уведомление об истечении срока согласования. Затем выполнение приостанавливается по таймеру шага 30; после его срабатывания выполняется повторная проверка состояния согласования отчетов. |

**UC003 — Формирование и направление отчета**

|  |  |
| --- | --- |
| **№ шага процесса** | 32–51 |
| **Выполняемая задача** | Подписать итоговый отчет, передать пакет документов председателю суда на подписание, зарегистрировать и направить исходящий ответ, после чего завершить обработку запроса. |
| **Цель** | Обеспечить утверждение, регистрацию, отправку и учет итогового ответа по запросу. |
| **Роль / Актор** | Сотрудник ответственный за ведение статистической отчетности; Председатель суда; Лицо ответственное за межведомственный документооборот |
| **Ожидаемый результат** | Итоговый отчет и сопроводительное письмо подписаны, исходящее письмо зарегистрировано и направлено предусмотренным каналом; подтверждающие материалы сохранены; обработка запроса завершена. |
| **Рекомендуемая функциональность** | Автоматическое формирование итогового отчета и сопроводительного письма; подписание электронной подписью; передача пакета председателю суда; переход к ТБП106 «Передать документ»; регистрация исходящего письма; автоматическая отправка по предусмотренному каналу; получение и сохранение подтверждения доставки; завершение обработки запроса. |
| **Критичность** | Необходимая |
| **Триггер** | Завершено согласование необходимых материалов по запросу либо завершена проверка данных, полученных по альтернативному маршруту. |
| **Предварительные условия** | Согласованные или проверенные материалы по запросу доступны в Системе; пользователям доступны функции подписания, передачи и исходящей регистрации документов. |
| **Основной сценарий** | 1. Система формирует итоговый отчет по запросу.  2. Сотрудник ответственный за ведение статистической отчетности открывает итоговый отчет и подписывает его электронной подписью.  3. Система подготавливает сопроводительное письмо к итоговому отчету.  4. Сотрудник передает письмо и отчет председателю суда на подписание.  5. Председатель суда получает пакет документов и подписывает его электронной подписью.  6. Система отображает данные подписи сотрудника и документ с подписью  7. Лицо ответственное за межведомственный документооборот регистрирует исходящее письмо.  8. В зависимости от выбранного канала Система направляет пакет по системе ведомственного документооборота и/или электронной почте.  9. После срабатывания соответствующего таймера Система получает квитанцию или отчет о доставке и сохраняет комплект документов и подтверждение доставки в номенклатурном деле.  10. Лицо ответственное за межведомственный документооборот завершает обработку запроса.  11. Процесс завершается результатом: запрос обработан, аналитические или статистические данные подготовлены и переданы адресату. |
| **Расширение (альтернативный сценарий)** | 1. Если выбран канал электронной почты, Система направляет пакет по электронной почте; после срабатывания таймера шага 46 получает отчет о доставке и сохраняет его вместе с комплектом документов.  2. Если выбран канал системы ведомственного документооборота, Система направляет пакет по соответствующему каналу; после срабатывания таймера получает квитанцию о доставке и сохраняет ее вместе с комплектом документов.  3. Если предусмотрены оба канала, выполняются обе ветви отправки, после чего ветви объединяются перед завершением обработки запроса. |
