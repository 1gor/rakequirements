## 4. Пользователи и роли

| **Роль** | **Функции** |
| --- | --- |
| Судья | Определение состава ЛУВД, проверка корректности данных, внесение изменений в ИС суда, формирование судебного акта |
| Система | Анализирует первичный документ для определения основных лиц, участвующих в деле, вносит данных о соистце в ИС суда, вводит данные о соистце в ИС суда, вводит данные третьих лиц в ИС суда, проверяет корректность заполнения ИС по получению информации от пользователя и выводит предупреждения, сохраняет в деле выбранный состав ЛУВД. |
