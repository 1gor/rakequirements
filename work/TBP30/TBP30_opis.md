## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Судья | Назначение судебного заседания, проведение судебного заседания, параллельные проверки оснований для дополнительного решения, принятие дополнительного решения либо вынесение определения об отказе |
| Помощник судьи арбитражного суда | Подготовка к судебному заседанию, подготовка материалов и оповещений |
| Канцелярия арбитражного суда | Организация направления судебных актов участникам, учет и регистрация исходящей корреспонденции |
| Заявитель | Получение судебных актов, ознакомление, принятие решения об обжаловании |
| Система | проверяет статус вступления в законную силу первичного судебного акта, проверяет отсутствие решения по требованиям, проводит поиск решений по чек-листу требований и документам, проверяет, решен ли вопрос о судебных расходах, формирует контрольный список расходных требований, проверяет наличие размера присужденной денежной суммы, валидирует наличие сумм в проекте судебного акта, проверяет наличие указания действий, которые обязан совершить ответчик, анализирует судебный акт на наличие реквизитов имущества, подлежащего передаче, координирует процессы через параллельный шлюз, собирает данные о результатах всех проверок, формирует событие для пользователя с отчетом и ссылками на документы, создает текстовую рекомендацию по вынесению дополнительного решения. |
