## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Лицо, ответственное за распределение арбитражного суда | Проверка специализации дел, контроль заполнения полей карточек дел, запуск электронного распределения, устранение ошибок распределения, печать актов распределения, внесение изменений в параметры системы |
| Председатель судебного состава арбитражного суда | Рассмотрение документов для назначения судьи, выбор судьи для рассмотрения дела, принятие решений о случайном выборе судьи, назначение судьи |
| Председатель коллегии арбитражного суда | Рассмотрение документов для назначения судьи, выбор судьи для рассмотрения дела, принятие решений о случайном выборе судьи, назначение судьи, разрешение разногласий между судебными составами |
| Председатель арбитражного суда | Рассмотрение документов для назначения судьи, выбор судьи для рассмотрения дела, принятие решений о случайном выборе судьи, назначение судьи, разрешение разногласий между судебными коллегиями |
| Система | Проверяет доступность судей, валидирует специализацию дел, проверяет полноту заполнения полей, валидирует периоды недоступности, выполняет выбор судьи на основе правил и коэффициента , применяет правила распределения, назначает судью по специализации, формирует акт АРПД, создает отчеты об ошибках, уведомляет о поступлении документов, уведомляет о результатах рассмотрения, уведомляет о завершении распределения, диагностирует ошибки распределения, анализирует ошибки с предложениями, формирует рекомендации по назначению судьи, предлагает корректную специализацию, исправляет типовые ошибки заполнения, предлагает кандидатуры судей для руководства. |
