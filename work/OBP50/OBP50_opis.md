## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Председатель суда | Проверяет табель на корректность, направляет замечания при их наличии, согласовывает и подписывает табель учета |
| Сотрудник бухгалтерии | Проверяет табель на корректность, направляет замечания при их наличии, согласовывает и подписывает табель учета |
| Сотрудник отдела кадров | Формирует табель учета рабочего времени сотрудников с внесением всех метаданных, согласовывает его у председателя и бухгалтерии, вносит коррективы при необходимости |
| Система | Создает сущность табеля и предзаполняет информацию из системы, указывает основные реквизиты (наименование суда, номер и дату документа, отчетный период, должности, табельные номера и ФИО работников), отражает данные о явке сотрудников в табеле собирая информацию об отсутствующих по болезни/отпуску/другим причинам, отражает отработанные часы в табеле, отражает отпуска сотрудников в табеле, отражает больничные в табеле, формирует итоговый табель учета в виде документа или таблицы, передает табель на подпись председателю с информированием о повторном подписании из-за корректировок, информирует и хранит замечания, передает сущность между отделами с назначениями групп ответственных. |
