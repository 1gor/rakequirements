## 4. Пользователи и роли

| **Бизнес-роль (с указанием суда/инстанции/иного административного органа)** | **Выполняемые действия/функция** |
| --- | --- |
| Помощник судьи суда первой инстанции | Изготовление копий материалов дела, обработка электронных материалов, оформление обложки дела, проверка корректности данных, формирование описи дела, постановка штампов-заверителей, подшивка и нумерация листов дела, проверка правильности формирования дела, внесение изменений в дело |
| Система | проверяет корректность заполнения данных по судебному и номенклатурному делу в информационной системе, анализирует материалы дела, формирует рекомендации пользователю по выявленным несоответствиям и передаёт результаты проверки помощнику судьи для дальнейших действий. |
