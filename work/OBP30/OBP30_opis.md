## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Начальник отдела информатизации / отдела МТО / отдела анализа и обобщения | - Инициирует процесс при наступлении срока или поступлении запроса на инвентаризацию  - Определяет состав комиссии  - Готовит решение о проведении инвентаризации  - Передает решение на подписание  - Формирует инвентаризационную опись  - Определяет дату начала инвентаризации  - Уведомляет комиссию о дате/времени начала  - Ожидает начала инвентаризации  - Организует и начинает проведение инвентаризации совместно с комиссией  - Завершает документы по итогам инвентаризации при наличии расхождений  - Завершает процесс после фиксации результатов |
| Система | - Готовит шаблон решения  - Создаёт задачу на подпись  - Закрывает задачу на подпись  - Готовит шаблон акта о результатах инвентаризации  - Готовит шаблон дефектного акта  - Готовит шаблон документов по итогам  - Сохраняет данные о результатах инвентаризации |
| Инвентаризационная комиссия | - Проводит инвентаризацию - Сверяет инвентаризационные номера с фактическими - Завершает акт о результатах инвентаризации - Определяет наличие расхождений - При необходимости оформляет и подписывает дефектный акт |
| Председатель суда | -Подписывает решение о проведении инвентаризации |
