## ****4. Пользователи и роли****

|  |  |
| --- | --- |
| **Роль** | **Описание** |
| Управление информатизации суда | * Провести в суде анализ потребности в КИТ * Оценить возможность комплектования и определение бюджета * Разработать детальный план внедрения конкретных КИТ * Осуществить приемку КИТ |
| Подрядная организация (подрядчик) | * Установить и настроить КИТ на компьютерах в судах * Обучить сотрудников судов пользованию КИТ |
