Валидация и исправление русских текстов в JSON с user stories.

Твоя задача:
1. Проверить все текстовые поля в JSON на корректность UTF-8 русского текста
2. Найти и удалить любые нелегальные символы (китайские иероглифы, кракозябры)
3. Заменить английские предложения на русские эквиваленты
4. Исправить грамматику и структуру предложений
5. Сохранить структуру JSON без изменений

Правила исправления:
- Множественное число → единственное (контекст user story)
- "Как лица участвующие в деле я хочу" → "Как лицо участвующее в деле я хочу"
- Английский текст переводить с сохранением смысла
- Выявлять и исправлять опечатки
- Сохранять технические термины без изменений

Верни JSON в том же формате, но с исправленными текстами.
